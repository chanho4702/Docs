**디무브 메인 테마 색 = 틸(teal) 스케일.** 사용자 확정(2026-07-07): "앞으로 디무브 메인 테마 색이니까 참고" — 새 UI/차트/막대/강조색이 필요하면 임의 색(Atlaskit 보라/블루 등) 대신 이 스케일에서 선택한다.

| 단계 | HEX |
|------|-----|
| 50 | #E9F7F4 |
| 100 | #C9ECE6 |
| 300 | #6FD3C6 |
| **500 (PRIMARY)** | **#21ADAD** |
| 600 | #1A9A90 |
| 700 | #14756E |
| 900 | #103F3A |

**적용 관례(간트에서 확립, [[project-svar-gantt]]):**
- 컨테이너성 요소(폴더 등) = 연한 대역(50~300) + 글자 900 다크 틸. 강조/채움은 두 단계 진하게.
- 다크모드: 다크 배경 위 텍스트/아이콘은 300, 배경 틴트는 rgba(111,211,198,α).
- 단, 의미색(성공 초록/오류 빨강/오늘 파랑 마커, 미일정 회색)은 브랜드색으로 덮지 않는다.
- ⚠️ 전면 도배가 아니라 선택적 적용: 간트에서 이슈 막대까지 틸로 바꿨더니 사용자가 **폴더 레이어만 틸, 이슈 막대는 기존 기능색(블루/그린/퍼플) 유지**로 원복시킴(2026-07-07). 기존 화면의 확립된 기능색을 갈아엎기 전에 확인할 것.
