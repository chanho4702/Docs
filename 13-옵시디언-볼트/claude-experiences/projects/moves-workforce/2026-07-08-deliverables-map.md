## 0. 산출물 맵 한눈에

```
A. 제품 소개·영업        →  도입 검토자 / 경영진 / 영업
B. 사용자 문서           →  PM / 실무자 / 관리자 (실사용자)
C. 기술·운영 문서        →  내부 개발/운영팀 (유지보수)
D. 규정·계약 문서        →  Marketplace 등록 / 고객 납품 (조건부)
+  공통 용어집           →  모든 문서가 참조하는 단일 소스
```

우선순위 표기: ★★★ 필수 · ★★☆ 권장 · ★☆☆ 여유 시 · 조건부(상황 시에만)

## 규격화 포맷 (공통 템플릿)

모든 문서 머리말을 통일해 세트 일관성 확보:

```
문서명 / 버전 / 작성일 / 대상 독자 / 관련 문서
1. 목적·범위
2. 본문 (문서별 상이)
3. 용어 정의 (공통 용어집 참조)
4. 변경 이력
```

- **공통 용어집** 1개를 별도 문서로: 워크로그·MD·MM·가동률·진척도 3층 등. 모든 문서가 이걸 참조 → 정의 중복·불일치 제거. ✅ 작성완료 → `repo:Moves_Workforce_용어집.md`
- 버전 표기는 앱 버전(manifest)과 동기화 권장. 현재 배포 버전: 백엔드 `1.1.17` / 프론트 `0.1.62`.

> **📍 현황(2026-07-09):** 산출물은 실제 저장소 루트 `C:\CloudJira\moves-workforce\Moves_Workforce_*.md`에 위치. 기존 3종(사용자·관리자 매뉴얼, 개발자 온보딩) + 신규 7종(용어집·FAQ·빠른시작·핵심로직·릴리스노트·**아키텍처 설계서·데이터모델 ERD**) = 총 10종. 미작성: A2 1-pager, C3 API명세, D군(법무).

## FAQ 구성 뼈대 (A3 착수용)

- **도입/설치**: 설치 방법, 권한 요구사항, 지원 Jira 플랜(Cloud only)
- **데이터/보안**: 데이터 저장 위치(Forge/Atlassian 인프라), 외부 유출 여부, 권한 격리
- **기능**: 워크로그 원천, MM/가동률 계산 기준, 진척도 3층 의미, 전사 대시보드 범위
- **운영**: 대용량 업로드, 성능(256MB 제약), 공휴일/근무일 설정
- **요금/지원**: 라이선스 정책, 문의 채널
