#ZM-122 [FIX] APM 수신 원자성·SSE 송신 큐·조회 상한·RUM 재시도 보완 -2026-10-06

메트릭 영수증 선점과 1분 적재를 같은 트랜잭션으로 처리하고,
누적형 기준값·bounds 캐시·live·drop 통계가 실패 배치를 공개하지 않게 한다.
bounds 등록 순서를 통일하고 route 워밍 SQL 실패를 전파한다.

SSE 작업 큐를 연결 상한에 맞추고 연결별 작업 중복과 종료 잔여 작업을 방지한다.
writer 스레드 설정을 추가하고 실제 송신 timeout과 실행 대기를 구분한다.
일반 시계열 20,000칸·가용성 120,000칸 상한과 기존 오류 envelope를 적용한다.
RUM Web Vitals는 동일 본문을 시간·건수·바이트 예산 내에서 제한 재시도한다.

검증: 선별 Java 회귀 클래스별 최종 521개, Node 25개,
실제 브라우저 HTTP 4개 및 JDK 17 bootJar 성공.
전체 프로젝트 테스트와 운영 복합 부하시험은 아님.
다중 BE 상태 공유와 누적형 영속 checkpoint는 후속 과제.
