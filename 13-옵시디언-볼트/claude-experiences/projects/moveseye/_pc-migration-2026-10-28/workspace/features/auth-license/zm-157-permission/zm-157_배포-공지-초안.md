## 1. 사용자 공지 (사내 공지·팝업용)

> **[MovesEye] {날짜} 업데이트 안내 — 로그인·권한 관련 변경**
>
> 보안 강화를 위해 권한과 로그인 처리를 정비했습니다. 업데이트 후 아래 사항을 확인해 주세요.
>
> 1. **다시 로그인해야 합니다.** 업데이트 직후 자동으로 로그아웃될 수 있습니다. 기존 비밀번호로 다시 로그인하시면 됩니다.
> 2. **외부 AI 앱(MCP) 연결은 다시 연결해야 합니다.** 설정 › 연결된 앱에서 안내대로 다시 연결해 주세요.
> 3. **업데이트 전에 받은 비밀번호 재설정 메일 링크는 쓸 수 없습니다.** 필요하면 비밀번호 찾기를 다시 요청해 주세요.
> 4. **호스트 상세 화면의 사용자 정의 차트는 편집 권한이 있는 계정만 추가·수정·삭제할 수 있습니다.** 이 차트는 그 호스트를 보는 모든 사용자에게 같이 보이는 설정이라, 편집을 권한으로 묶었습니다. 필요하시면 관리자에게 역할 권한(서버/네트워크 모니터링 편집)을 요청해 주세요.
> 5. **지도의 좌표 편집은 관리자만 할 수 있습니다.**
> 6. 비밀번호를 바꾸면 **다른 기기에서는 로그아웃**되고 연결된 앱도 다시 연결해야 합니다.

## 2. 관리자 공지

> 1. **역할 편집 화면의 권한이 실제로 적용됩니다.** 지금까지 일부 항목은 메뉴만 숨기고 API는 열려 있었습니다. 이제 서버에서 차단하므로, 역할에서 꺼 둔 기능은 화면·AI 어시스턴트·외부 AI 앱(MCP) 어디서도 쓸 수 없습니다. 배포 전에 **역할별 권한 설정을 한 번 점검**해 주세요.
> 2. **효과가 없던 체크박스는 잠금 표시됩니다.** 사용하는 화면이 없거나 관리자 전용인 항목입니다.
> 3. **사용자 목록에서 계정을 활성/비활성할 수 있습니다.** 비활성화하면 모든 기기에서 로그아웃되고 MCP 연결이 끊깁니다. 관리자 계정과 본인 계정은 비활성화할 수 없습니다.
> 4. **관리자가 개별로 비활성화한 계정은 그룹을 활성화하거나 Zabbix 동기화가 돌아도 다시 활성화되지 않습니다.** 목록에 "관리자가 비활성화함"으로 표시됩니다. 다시 쓰려면 목록에서 활성화해 주세요.
> 5. **그룹 활성화 동작이 달라졌습니다.** 그룹을 활성화해도 **다른 비활성 그룹에 속한 사용자**는 활성화되지 않습니다.
> 6. **admin 계정 이메일을 등록해 주세요.** 기본 설치본의 admin 이메일(공개 메일함 주소)은 이번 업데이트에서 지워집니다. 이메일이 없으면 비밀번호 찾기를 쓸 수 없습니다. 마이 페이지에서 등록할 수 있습니다.
> 7. **외부 AI 앱(MCP)에서 삭제 작업은 기본 차단됩니다.** 필요하면 설정으로 켤 수 있고, 켜도 한 번에 한 건만 처리됩니다.

### 환경 설정 주의
- 리버스 프록시 뒤에 BE를 둘 경우 `FORWARD_HEADERS_STRATEGY=native` 필요. 없으면 모든 요청이 프록시 IP로 보여 IP 제한이 전체 사용자에게 걸린다. (현재 실서버는 브라우저가 BE에 직접 접속해 해당 없음)
- 🔴 **Redis는 2.6 이상**이면 된다(연결 소비에 Lua를 쓴다 — 개발 PC의 3.0.504에서 실측). 처음엔 `GETDEL`(6.2+)을 써서 구버전 Redis에서 MCP 연결이 전부 실패했고, 2026-09-21에 고쳤다.
- MCP를 쓰는 설치본은 `AI_MCP_ENABLED=true`·https 필요. 삭제 작업 허용은 `AI_MCP_ALLOW_DESTRUCTIVE`(기본 false)·`AI_MCP_MAX_DESTRUCTIVE_TARGETS`(기본 1).
