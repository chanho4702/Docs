# AI 사용량 계량 (moveseye-ai / BE / FE)

**요청 한 줄:** "이거 사용량 확인할 수 있음? 남은 사용량 이렇게 표시해주면 좋을 거 같은데."

[[moveseye]] 허브 · 선행 작업 [[2026-08-19-ai-assistant-mcp]] · 코드 `C:\solutions\moveseye-ai` + BE + FE

## 1. 핵심 제약: "남은 사용량"은 존재하지 않는다

가장 먼저 확인한 것이 결론을 통째로 바꿨다.

**Anthropic도 OpenAI도 잔액(크레딧) 조회 API를 제공하지 않는다.** 결제 잔액은 각 사 콘솔에서만 본다.
응답 헤더로 오는 `*-ratelimit-*-remaining`은 "분당 한도 잔여"라 요금과 무관하고 프로바이더마다 형식도 다르다.

그래서 요청을 그대로 구현할 수 없고, **대체 설계**로 갔다:

> 쓴 양은 정확히 알 수 있다(토큰 수는 매 응답에 온다) → 원장에 적는다
> → 관리자가 적어 둔 **월 예산에서 빼서** "남은 사용량"을 만든다

이 사실을 화면이 숨기지 않도록 응답에 `estimated: true`를 싣고 금액 옆에 **'추정' 배지**를 항상 붙였다.
"청구서처럼 보이는 추정치"가 이 기능의 가장 큰 실패 모드다.

## 2. 만든 것

### AI 서버 (`moveseye-ai`)
- **`ai_usage` (V5)** — 대화 한 턴 = 한 행. 토큰 4종(입력/출력/캐시읽기/캐시쓰기) + `cost_micro_usd` + `priced` + `kind`.
  - 토큰은 **이미 세고 있었다.** `ChatService`가 `done` 이벤트에 실어 보내고 **버리고 있었을 뿐**이다. 적재로 바꾸는 게 전부였다.
  - 비용은 **micro USD 정수**로 센다. double로 합산하면 총액이 조금씩 어긋난다.
  - 알림 분석(`insight`)도 LLM 비용이라 `kind`로 갈라 적는다 — "대화 말고 뭐가 돈을 쓰는지"가 보여야 한다.
  - 기록 실패가 대화를 깨뜨리지 않는다(`UsageStore.record`가 예외를 삼킨다). 집계는 부가 기능, 답변이 본체.
  - 토큰 0인 턴은 적지 않는다 — 0원 행이 쌓이면 "호출 수"가 거짓이 된다.
  - 원장 보존은 **400일**(대화 30일과 다르다). 지난달 비용을 되짚는 것이 이 표의 존재 이유다.
- **`Pricing`** — `ai.pricing.models`(yml, 1M 토큰당 USD). 배포판 접미사(`claude-opus-5-20260101`) 대응은 **가장 긴 접두 일치**로. 짧은 접두가 이기면 `claude-haiku-4-5`가 `claude-opus-5`로 잡혀 단가가 5배 틀린다.
  - 캐시 단가 미기재 시 Anthropic 관례(읽기 10%·쓰기 125%)로 추정.
- **`GET /ai/usage`** (`period=month|week|day`, `scope=me|all` — all은 관리자만) · **`/ai/usage/compact`**(범위를 서버가 권한으로 정함 → 화면이 role을 몰라도 된다).

### BE
- `LlmInfoDto.monthlyBudgetUsd` (선택). 응답에서 `apiKey`가 지워지는 규칙은 그대로.
- `HomeWidgetType.AI_USAGE` — 알림 분석과 달리 **adminOnly가 아니다**(자기 사용량은 누구나 본다). 이 위젯은 LLM을 부르지 않으므로 홈에 붙어 있어도 비용이 없다.

### FE — 표시 4곳
설정>AI(게이지+용도별/사용자별 표+예산 입력) · 챗봇 하단 한 줄 · AI 어시스턴트 사이드바 · 홈 위젯 `ai_usage`.

## 3. 🔴 화면이 저지르면 안 되는 거짓말 4가지 (테스트로 못박음)

`AiUsageMeter.test.tsx`가 고정한다 — 전부 "숫자는 맞는데 읽는 사람이 오해하는" 종류다.

| 거짓말 | 막은 방법 |
|---|---|
| 추정치를 청구서로 보여준다 | 금액 옆 **'추정' 배지** 상시 + 툴팁에 "공급사가 잔액 조회를 제공하지 않는다" |
| 예산이 없는데 게이지를 0%로 그린다 → "여유 있다"로 읽힌다 | **예산 없으면 게이지를 아예 안 그린다**, 안내 문구만 |
| 단가 모르는 모델을 0원으로 세고 총액만 보여준다 → "안 쓰고 있다"고 믿는다 | `priced=false`로 남기고 **"N건이 빠져 적게 집계됐다"** 명시 |
| `$0.0034`를 `$0`으로 반올림한다 | 0.01 미만은 소수 4자리로 표시 |

**예산 초과는 차단하지 않는다(경고만).** 사용자 결정 — "갑자기 AI가 멈춰 업무가 막히는 편이 더 나쁘다".

## 4. 실 LLM 첫 검증 (키를 받아서)

지금까지 배선만 검증했고 **모델의 판단력은 한 번도 못 봤다.** 오늘 키가 들어와 처음 확인했다.

| 질문 | 결과 |
|---|---|
| "심각도 높은 알람 있어?" | 목록 조회 → **스스로 상세 브리핑 툴로 연결**. 재발 이력(5회)·직전 구성변경 없음·리소스 정상까지 엮어 "노트북 절전/네트워크 단절" 추정 |
| "이 화면 뭐 하는 데야?"(자산 목록) | 화면 설명 + **현재 데이터**(79건/미모니터링 4/동기화 10일 경과) + 후속 제안 |
| "서버 상태 어때?"(애매) | 3개 툴 조회, 노드별 중복 보고 정리, **내가 몰랐던 배치 실패(8/14 이후 성공 없음)** 발견 |
| "비밀번호 알려주고 권한 바꿔줘" | **툴 호출 없이 거절** + 어디서 해야 하는지 안내 |

계량 검증: 입력 7,270 · 출력 218 → **$0.0418** (단가 손계산과 일치).

## 5. 곁가지로 잡은 것 — 깨져 있던 테스트 7건

사용량 작업 중 BE 전체 테스트를 돌렸더니 7건이 실패했다. **전부 내가 어제·오늘 커밋한 코드가 원인**이었고, 커밋 시점에 전체 스위트를 안 돌려 몰랐다.

1. **`ChangeLogOriginListener`를 스프링 빈으로 둔 것** → JPA 엔티티 리스너를 빈으로 만들면 Hibernate가 생성자 인자를 주입받으려 하고, `@DataJpaTest` 같은 슬라이스에서 **컨텍스트 자체가 안 뜬다**(IT 6건 전멸). 리졸버는 상태가 없고 `RequestContextHolder`만 읽으므로 **주입이 필요한 이유가 애초에 없었다** → 빈에서 내리고 리스너가 직접 생성.
2. **`@LicenseExempt` 구조 규칙 위반 1건** — 내부 전용 컨트롤러 2개. 패키지로 열면 사용자 화면 컨트롤러까지 통째로 면제되므로 **클래스 이름 2개만** 못 박아 허용.

> 교훈: **기능 커밋 전에 전체 스위트를 돌린다.** 슬라이스 테스트는 "빈 하나 늘린 것"만으로 죽고, 그 실패는 내가 만진 파일 근처에 나타나지 않는다.

## 6. 🔴 `.env`가 두 벌이고 암호화 키가 다르다 (운영 지뢰)

서버 재기동 중에 `AEADBadTagException: Tag mismatch` → 저장된 LLM API 키 복호화 실패 → HTTP 500.

`moveseye-be\.env`(구 Nest)와 `moveseye-be-spring\.env`는 **46개 키 중 딱 2개**(`CREDENTIAL_ENCRYPTION_KEY`·`JWT_SECRET`)만 값이 다르다.
어느 파일을 export하고 띄우느냐에 따라 **저장된 자격증명이 전부 못 읽히거나, 전원이 재로그인 상태가 된다.**

- Spring이 쓰던 정본은 **`moveseye-be-spring\.env`**. 기동 스크립트를 그쪽으로 맞췄다:
  `_workspace/_run_be_3000_dev.ps1` · `_workspace/_run_ai_3100_dev.ps1`(신설)
- ⚠️ AI 서버는 **`PORT`를 3100으로 덮어써야 한다** — BE `.env`에 `PORT=3000`이 있어 그대로 쓰면 포트 충돌로 죽는다(실제로 겪음).
- **한쪽을 지우거나 값을 맞추는 것이 남은 숙제.** 배포 환경에서 이러면 "어제까지 되던 게 오늘 안 됨"이 된다.

## 7. 그 밖의 함정

- **FE 루트 i18n 키 `ai`가 문자열**이라 `ai.usage.*`를 못 쓴다 → `ai_usage` 네임스페이스 신설(기존 `ai_chat`과 같은 방식).
- **`services/ai.api.ts`는 `import.meta`를 타고 들어가 jest에서 파싱 자체가 안 된다.** 새 훅이 그 모듈을 import하면 **그 훅을 쓰는 화면의 기존 테스트가 전부 죽는다** → 관련 테스트에 `jest.mock("@/hooks/useAiUsage")` 추가가 필수.
- **`useIsUserRoleAdmin`은 redux Provider를 요구한다.** 어시스턴트 페이지에서는 `useAiUsageCompact`(범위를 서버가 판정)로 바꿔 의존 자체를 없앴다 — 화면이 role을 알 필요가 없으면 알지 않는 게 낫다.
- **홈 위젯 추가는 FE만으로 안 된다** — `HomeWidgetType`(BE enum) + BE 계약 테스트 + FE 3곳(타입·메타·레지스트리) + FE 계약 fixture까지 6곳을 같이 고쳐야 한다.
