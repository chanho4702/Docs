# 디자인 시스템 정비 + 화면 도움말 (2026-08-20)

ZM-109를 중심으로 하루치 작업. "모니터링 시스템에 맞게 디자인을 손보자"에서 시작해
팔레트 정본 → 차트 색 규칙 → 심각도 → 한글 폰트 → 다크 모드 → 화면 도움말까지.

## 무엇을 했나

### 디자인 시스템 (P0~P6, 커밋 6개)
- **팔레트 정본** `constants/palette.ts` — 색은 여기서만 정의. 하드코딩 hex 파일 66 → 40개
- **브랜드 램프 교정** — 기존 `COLOR` 50~900이 **파란 램프인데 500만 teal**이라, primary/hover/active를
  거기서 뽑던 버튼·링크가 "기본 teal → 호버 파랑 → 누르면 진파랑"으로 색상축을 갈아탔다
- **차트 색 배정 규칙** `utils/chartColor.ts` — 의미 고정 지표는 화면이 달라도 같은 색,
  나머지는 남은 슬롯 순서 배정(한 차트 안 중복 없음). 방향은 in=파랑/out=주황
- **심각도 이중 인코딩** — 공용 `SeverityTag`(색+라벨), 표시 자리별 색 3종(면/선·핀/넓은 면)
- **한글 폰트 Pretendard 번들** — CDN 제거(설치형 고객은 폐쇄망)
- **다크 모드 정식 지원** — 팔레트 LIGHT/DARK 두 벌, 구독형 스토어, ECharts 테마 2벌
- 설계서: `_workspace/devdesign_design-system.md`

### 화면 도움말 (커밋 3개)
제목 옆 `?` → 도움말 패널(요약 · 할 수 있는 일 · 그 화면의 용어). **31개 화면, 용어 46개**(한/영).
경로 매핑 한 줄이면 붙는다(`constants/page-guide.ts`). 순차 투어는 **하지 않기로** 결정.

### 그 외
설정 정리(메뉴 아이콘·설명, 연결된 앱 분리, 사용자 관리 이동, 카드 초록 테두리 제거),
AI 드로어 3기능(너비 조절·목록 접기·대화 내려받기), 잔업 3건.

## 결정

**도움말은 AI 카탈로그와 합치지 않는다.** 같은 화면 설명이 두 벌(FE 31개 한/영 + AI `screens.json`
30개 영어)이지만 합치지 않기로 했다 — 도움말의 대상이 **AI를 쓰지 않는 고객**이고, 그 환경에는
AI 서버가 아예 없다. 한 벌로 묶으면 의존이 생기고 손해 보는 쪽이 정확히 그 고객이다.
→ 정본은 FE. "AI에게 물어보기" 출구도 두지 않는다.

**순차 투어(antd Tour)를 쓰지 않는다.** 가능은 하다(antd 5.29에 내장). 하지만 투어는 DOM 요소를
지목해 짚어서 버튼이 옮겨가면 **조용히 깨진다**(타입 검사도 테스트도 못 잡는다). 라우트 90개에
화면이 계속 바뀌는 제품이라 유지비가 기능 개발보다 커진다.

## 🔴 교훈

- **절대경로 자식 라우트는 부모 경로로 시작해야 한다.** 사용자 관리를 `/setting`으로 옮기며
  경로 상수를 일괄 치환했더니 `/setting/...`이 `/zabbix-management` 블록에 남아,
  **화면 하나가 아니라 앱 전체가 뜨지 않았다**. 값이 다 유효한 문자열이라 tsc도 테스트도 못 잡는다
- **`title: ""`는 falsy다.** 공용 컬럼 훅이 `title || key`로 폴백해 번역 없는 키가 헤더에 찍혔다
  (Problem 목록의 "expandIcon"). 빈 문자열은 "헤더 없음"이라는 **의도**다
- **CSS 변수가 통하지 않는 자리** — MapLibre paint 속성(지도 렌더러는 CSS를 모른다),
  SVG **attribute**(인라인 style이 아니면 `var()`가 해석되지 않는다). 인라인 style에는 통한다
- **팔레트 훅을 리덕스에 묶으면 안 된다.** `useSelector`로 짰더니 Provider 없이 렌더하는
  **단위 테스트 66개가 한꺼번에 깨졌다**. 색은 스토어 없이도 읽혀야 한다 →
  `useSyncExternalStore`로 팔레트 모듈을 직접 구독
- **심각도 6단계는 색만으로 구분할 수 없다**(측정으로 확인). 경고~재해가 노랑→주황→빨강 한 축에
  4단계로 몰려 있어 어떤 값을 골라도 인접 등급 색차가 기준(ΔE 15) 아래(최선 10.1).
  Zabbix 원색은 재해↔높음이 **정상 시야에서도** ΔE 6.3 → 색은 보조, 라벨이 본체
- **브랜드 teal(#379e9f)은 차트 선으로 쓰면 회색으로 읽힌다**(채도 OKLCH C 0.093).
  UI 강조와 차트 시리즈는 같은 색상축이라도 다른 값이 필요하다
- **antd `<Tag color="#hex">`는 글자를 무조건 흰색으로 칠한다.** 밝은 배경(경고 앰버) 위 흰 글자가
  2.15:1 → 배경 밝기를 재서 고르는 헬퍼(`readableTextOn`)로 해결
- **집계 화면과 목록이 다른 질의를 쓰면 숫자를 눌러도 목록이 빈다.** 그룹 요약은 이력 축
  (기간 내 발생 전부), 목록 기본은 열린 문제만(Zabbix는 해결분을 ok_period=5분만 남긴다)

## ⚠️ 운영 함정

- **`.env`의 `JWT_SECRET`이 20바이트라 BE가 뜨지 않았다.** 코드가 32바이트 최소를 강제한다
  (HS256). BE를 내렸다가 재기동이 막혀 잠시 서비스가 죽었다 → 64바이트로 **영구 교체**(백업 남김).
  교체하면 기존 토큰이 무효라 **전원 재로그인** 필요
- **없는 경로가 500이었다.** catch-all(`Exception.class`)이 `NoResourceFoundException`까지 먹어
  오타 URL이 "서버 장애"처럼 보이고 ERROR 로그가 진짜 오류를 가렸다(실제로 오진했다) → 404로 수정
- **`/api/**`는 Swagger UI 경로(NestJS 호환 `/api`)라 permitAll**이다. 그 아래에 실제 컨트롤러를
  만들면 인증 없이 열린다
- `gradlew bootRun`은 `.env`를 읽지 않는다 — `set -a; . ./.env; set +a` 후 실행.
  **`.env` source가 먼저**여야 한다(나중에 하면 내 export를 덮어쓴다)

## 병행 세션

FE·BE 양쪽에서 다른 세션이 동시에 작업 중이었다(AI 어시스턴트·Problem 표시 모드).
`locales`·`ProblemList.tsx`처럼 파일이 겹칠 때는 **파일 단위로만 스테이징**할 수 있으므로,
남의 미완 로직이 딸려오지 않게 내 단독 파일만 골라 커밋했다. 커밋 직후 `git ls-tree origin/...`으로
내 파일이 살아 있는지 확인하는 습관이 유효했다(과거 되돌림 사고 있었음).
