# 무브스아이 기능 지도 — 기능 영역별 문서 링크 노드 (MOC)

> 허브 [[moveseye]] · 문서 체계 [[moveseye-documentation-system]] · 영역 구분은 `moveseye-docs/guides/features/README.md`(13종) + 프리미엄·문서 2종. 각 노드는 **정본 문서(moveseye-docs) → 설계·계약(_workspace) → 보고·검수 증거 → Vault 경험 노트** 순으로 링크를 모은다.
>
> 외부 문서 링크는 `file:///C:/solutions/...`라 이 PC의 옵시디언에서만 열린다. 출퇴근용 사본은 GitHub `chanho4702/Docs`([[2026-10-07-docs-reading-repo]]). 노드 갱신 날짜는 각 파일 frontmatter `updated`.

## 유지 규칙
- 새 기능·설계·계약이 생기면 **해당 영역 노드에 링크 한 줄** + 필요하면 열린 항목 갱신. 새 영역은 이 표에 행 추가.
- 노드는 링크 모음이지 내용 사본이 아니다 — 설명은 정본 문서에, 경험·교훈은 날짜 노트에.
- `moveseye-docs`가 한글 파일명으로 재편되면 file 링크 경로를 같이 고친다(10-19 기준 미커밋 rename 다수).
