# 문서 전문 통합 기록

사용자가 두 에이전트의 문서를 빠짐없이 Obsidian에 모으도록 요청해 문서 5,240개와 첨부 1,140개를 수집했다.

공용 Vault는 C:/Users/DMOVE/claude-experiences이며 Codex-experiences의 기록도 포함했다. 기존 링크 중심 안내에 더해 전문 사본을 제공한다. 프로젝트 원본과 실행 규칙은 보존한다.

동시 작업 중인 문서는 저장 직전 다시 읽어 반영한다. 원본 삭제나 저장소 이동은 수행하지 않았다. 경로 길이와 이름 충돌을 처리하고, 원본→사본 명세와 SHA-256을 보존했다.
