# 가이드 스크린샷 촬영 목록

실제 출시 후보 사이트에서 한국어·영어 계정을 각각 사용한다. 현재 이미지 파일은 없으며 이 목록은 촬영 준비용이다. 사용자 이름·이슈 내용·메일·사이트 주소의 공개 범위를 확인하고 필요하면 마스킹한다. PIN·서명 키·토큰은 촬영하지 않는다.

파일명은 `ko-<장면>.png`, `en-<장면>.png`로 저장한다. Jira 모듈 제목은 영어로 남을 수 있다. 공개 페이지에는 화면 설명을 alt text로 넣고 첨부 후 익명 접근으로 확인한다.

| 장면 | 연결 문서 | 촬영할 내용·설명 |
| --- | --- | --- |
| inbox | 01·04 | 내 차례·내 요청·필터·대상 유형 |
| first-settings | 02·09 | 적용 프로젝트와 초기 설정 진입 |
| general-request | 03 | 일반 승인 선택·결재선·마감·참조 |
| general-edited | 03 | 요청 이후 수정 표시·재상신 |
| decision | 04 | 단계·승인/반려·결정 이력 |
| my-timesheet | 05 | 기간·합계·제한선·제출 |
| timesheet-snapshot | 05 | 제출본과 현재 기록 구분 |
| team-timesheet | 05 | 팀원별 상태·선택 승인·결과 |
| worklog-lock | 06 | Log work 진입과 기간 잠금 안내 |
| period-close | 06 | 마감·다시 열기·자동 마감 설정 |
| transition-rule | 07 | 목적 상태·결재선·validator 안내 |
| transition-ready | 07 | 승인 후 전환 가능 및 사용됨 표시 |
| field-change | 08 | 이전/새 값·승인·적용 상태 |
| field-conflict | 08 | 충돌·미적용·다시 적용 안내 |
| workforce-status | 10 | 키 원문 없이 서명·게시 상태 |
| worklog-history | 11 | 변경 전후·출처·제한 설명 표시 |
| data-retention | 11 | 보관·내보내기·저장 사용량 |
| certificate | 04·11 | 다운로드한 시험 PDF의 결정 정보 |

필수 장면을 촬영하고 문서의 해당 절에 삽입한다. 심사 R01~R14의 증빙에는 앱 버전·촬영 시각·계정 역할·재현 ID를 별도 기록한다. 스크린샷만으로 권한 거부·변경 감지의 검증 통과를 판단하지 않는다. 사전 승인에는 결재선 선택·미등록 입력안·승인 후 요청자 등록·결과 불명 안내를 포함한다.
