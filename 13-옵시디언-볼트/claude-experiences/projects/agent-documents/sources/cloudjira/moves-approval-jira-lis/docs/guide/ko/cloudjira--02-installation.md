# 설치와 첫 설정

대상은 Jira Cloud입니다. 사이트의 앱 설치 권한이 있는 관리자와 시험용 프로젝트, 요청자·승인자 계정을 준비하세요. Marketplace 공개 전에는 담당자가 제공한 Forge 설치 경로로만 시험합니다.

## 설치

1. 출시 후 Marketplace에서 **Moves Approval for Jira**를 찾아 제품명과 공급자를 확인하고 사이트에 설치합니다.
2. 설치 화면의 접근 권한을 확인합니다. 용도는 [데이터 안내](cloudjira--11-data-security-privacy.md)에 있습니다.
3. Jira의 앱 메뉴에서 **Moves Approval**을 엽니다. Jira 메뉴 구성에 따라 앱 진입 위치는 달라질 수 있습니다.
4. Jira 앱 관리의 **Moves Approval** 설정 또는 업무함의 설정에서 초기 설정을 진행합니다. 앱 설정 관리자는 업무함 경로를 사용합니다.

## 처음 설정할 순서

1. **적용 프로젝트**를 정합니다. 명시적 범위를 설정하기 전에는 전체 프로젝트 허용이 기본이므로, 시험 프로젝트만 선택하고 일반 계정으로 확인하세요.
2. 승인 그룹과 결재선을 만들고 요청자·승인자가 대상 이슈를 볼 수 있는지 확인합니다.
3. 타임시트의 승인 단위·시간대와 팀·팀장을 등록합니다. 필요하면 2단계 결재 그룹도 지정합니다.
4. 일반 승인 요청 → 승인·반려 → 업무함 이력 확인을 시험합니다.
5. 전환 강제는 [validator 설정](cloudjira--07-transition-approval.md)을, 기간 잠금은 [시간 추적 제공자 설정](cloudjira--06-worklog-period-lock.md)을 따로 완료합니다.
6. 접근 제한이 필요하면 승인자 명부·설정 관리자·타임시트 팀을 먼저 등록하고 일반 계정으로 시험한 뒤 켭니다.

최소 시험 결재선은 **1단계 → 승인자 B 한 명 → 필요 승인 수 1**로 저장합니다. 해당 결재선을 시험 프로젝트에서 사용하도록 지정한 뒤 A가 요청하고 B가 내 차례에서 처리합니다.

시간 추적 제공자 선택은 사이트 전체에 영향을 줍니다. 기존 제공자 사용 여부를 확인한 뒤 전환하세요. 팀을 Jira 그룹에서 가져오는 작업은 일회성 복사이며 그룹 변경에 자동 동기화되지 않습니다.

## 업데이트·제거

업데이트에 새 권한이 포함되면 사이트 관리자가 권한 변경을 승인해야 합니다. 실제 지원 범위는 설치 버전과 [심사 검증 기록](cloudjira--13-marketplace-review-guide.md)을 확인하세요.

제거 전에는 필요한 기록을 내보내고, 시간 추적 제공자·워크플로 validator 의존성을 정리하세요. 앱 제거는 Jira 워크로그나 앱이 이미 작성한 댓글을 삭제하는 작업이 아닙니다. 앱 데이터의 제거 후 보관은 Forge 정책을 확인해야 합니다.
