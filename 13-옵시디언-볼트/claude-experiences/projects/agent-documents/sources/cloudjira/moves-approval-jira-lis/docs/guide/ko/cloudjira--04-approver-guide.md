# 승인자·참조자 가이드

## 승인·반려

1. 앱 메뉴 → **Moves Approval** → **내 차례**에서 요청을 엽니다.
2. 대상 이슈·제출본·변경 표시·결재선을 확인합니다. 타임시트는 현재 합계와 제출 시점 내용을 구분해서 읽으세요.
3. **승인** 또는 **반려**를 선택합니다. 기본 정책에서는 반려 사유가 필수입니다.
4. PIN 정책이 켜져 있으면 본인의 서명 PIN으로 확정합니다.
5. 결과와 다음 단계를 확인합니다. 다른 결재자가 먼저 처리했거나 마감이 지난 경우 새로고침해 현재 상태를 확인하세요.

**처리한 건**은 본인이 처리한 요청, **진행 중**은 앞 단계가 진행 중인 요청, **참조**은 참조로 지정된 요청을 확인하는 곳입니다. 참조자는 결정 버튼을 사용할 수 없습니다. 목록·상세는 현재 Jira 이슈 열람 권한에 따라 제한됩니다.

## 일괄 승인

내 차례인 요청을 선택해 일괄 승인할 수 있습니다. 결과의 성공·실패 건수를 확인하세요. 일부 실패가 전체 실패를 뜻하지 않습니다. 타임시트 팀 화면에서도 [선택 승인](cloudjira--05-timesheet-guide.md)을 할 수 있습니다. 필드 변경은 일괄 승인 후에도 **적용 상태**를 별도로 확인합니다.

## 서명·PIN·위임

**내 서명**에서 서명 이미지를 등록하고 PIN을 설정합니다. PIN은 4~12자리 숫자이며 5회 실패하면 15분 동안 잠깁니다. PIN을 다른 사람에게 공유하지 마세요.

관리자가 위임 정책을 켠 경우 **내 위임**에서 대리인과 기간을 지정합니다. 유효 기간 중 허용된 요청을 대리인이 처리하면 실제 처리자가 기록됩니다. 위임은 이슈 열람 권한을 부여하지 않습니다.

## 알림·증명서

앱 내 알림에서 요청·결정·독촉을 확인합니다. 전환 승인에는 정책과 댓글 권한에 따라 Jira @멘션 댓글도 작성될 수 있습니다. Jira 이메일·푸시 수신은 Jira의 알림 설정에 따릅니다.

종료된 요청의 상세에서 제공되는 결재 증명서 PDF와 업무함 엑셀은 필요한 범위만 공유하세요. 이 파일들은 고객이 관리하는 사본입니다.
