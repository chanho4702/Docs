# Moves Approval for Jira documentation

Moves Approval manages reviews, timesheet approvals, transition approvals and field change approvals in Jira Cloud. It works without Moves Workforce.

This publication draft reflects the implementation as of October 5, 2026. Until release-site verification and publication are complete, confirm availability and supported configurations with the product team.
