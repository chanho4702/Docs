# 워크로그 승인 잠금 및 변경 이력 대응 보고

기준일: 2026-10-14 · 팀장 보고 및 고객 설명 초안

**Workforce의 작업시간 입력·조회와 Approval의 승인·잠금·감사 원장을 연동하는 방식으로 핵심 기능을 구현했습니다. 고객 적용 완료 판단에는 팀장 전용 일괄 승인 조건 보완, 고객 사이트의 직접 입력 경로 차단 검증, 보존 기간 확정이 남아 있습니다.**

## 요구사항별 대응

| 고객 요구 | 구현한 해결 방식 | 적용 전 확인 사항 |
|---|---|---|
| 작성자 → 팀장 1단계 승인 | Workforce 팀·팀장 정보를 받아 기록별 승인 요청과 결정을 처리합니다. 자동 요청도 지원합니다. | 자동 요청은 자동 승인이 아닙니다. 고객 조직으로 승인자 연결과 팀장 자기 승인 예외를 확인해야 합니다. |
| 승인 완료 또는 마감 기간 잠금 | Approval 서버가 승인·인증·기간 상태를 검사해 변경을 거부합니다. Workforce도 서명된 규칙과 승인 결과로 저장 가능 여부를 판단합니다. | **건별 승인은 해당 기록의 수정·삭제를 잠그고, 기간 승인·마감은 해당 기간의 추가·수정·삭제를 잠급니다.** 건별 승인만으로 기간 전체가 닫히지는 않습니다. |
| Jira 기본 경로 처리 | 시간 추적 제공자로 기본 UI를 대체하고, 승인·마감 기록에는 앱 전용 공개 범위 제한을 적용하는 통제 경로를 구현했습니다. | 기본 UI 대체만으로 REST·자동화를 막지는 못합니다. 고객 사이트에서 일반 작성자의 직접 수정·삭제 및 마감 기간 신규 입력을 따로 검증해야 합니다. 외부 생성의 사후 감지·조치는 생성 전 차단과 다릅니다. |
| 팀장 일괄 승인 | 여러 요청을 선택해 건별 권한을 검사하고 승인하며, 일부 실패도 구분합니다. | **일반 업무함 일괄 승인은 현재 지정 결재자 기준입니다.** 팀장 전용 타임시트 경로는 있으나 건별 워크로그 일괄 승인에도 팀장 제한을 강제하려면 보완이 필요합니다. |
| 승인 감사 기록 | 승인자, 결정 시각, 대상 기록·작업일·시간, 요청 및 결정 이력을 Approval SQL에 보관합니다. | 화면·내보내기·연동 결과를 같은 요청 ID와 worklogId로 대조합니다. |
| 생성·수정·삭제 이력 | 앱 처리와 Jira 이벤트·누락 보정으로 변경 전후 시간·작업일, 변경자, 변경/관찰 시각, 수정 횟수를 기록합니다. | 관측 이전 변경, 이벤트 누락 중 중간 변경, 확인 불가능한 행위자와 설명 원문 전체의 복원은 보장하지 않습니다. |

## 데이터와 저장소 문제는 이렇게 처리했습니다

**승인·감사 원본은 Approval의 Forge SQL에 저장하고, Jira 프로퍼티는 두 앱이 정보를 주고받는 용도로 사용합니다.** 서명 검증을 거친 데이터만 반영하며, 원본 작업시간이 외부에서 바뀌어도 승인 당시 확정 시간과 변경 사실을 구분합니다.

SQL 변경 이력은 기존 행을 덮어쓰지 않고 추가합니다. 용량 안내와 내보내기·허용 자료 정리를 제공하지만, 승인 핵심 근거는 보호하므로 내보내기만으로 모든 공간이 회수되지는 않습니다. 장기간 대량 보존을 위한 외부 보관·압축 아카이브는 별도 설계가 필요합니다.

산정 기준은 `사용자 수 × 1인 월 생성·수정·삭제 이벤트 수 × 보존 개월 × 실측 이벤트 평균 bytes + 승인 원장·인덱스 용량`입니다. 예를 들어 200명 × 월 60건 × 36개월이면 변경 이벤트만 432,000건이며, 실제 저장량은 대표 데이터를 적재해 측정해야 합니다.

## 고객에게 제안할 최소 적용 범위와 일정 기준

최소 적용 범위는 **1단계 팀장 승인, 팀장 일괄 승인, 승인 기록 수정·삭제 제한, 기간 마감 후 추가·수정·삭제 제한, 승인 및 변경 이력 조회·내보내기**로 잡습니다. 추가 확인이 필요한 Workforce 입력은 저장하지 않고 Approval로 연결합니다.

완료 일정은 ① 고객 조직·보존 기간·잠금 적용 경로 확정 → ② 팀장 전용 조건 보완 → ③ 시험 프로젝트 검증 → ④ 고객 수용 시험 순서로 확정합니다. 현재 자료만으로 확정 납기나 모든 경로 차단 완료를 약속하지 않습니다.

**고객 회신 문안:** “작업시간의 팀장 승인과 승인·마감 후 변경 제한, 승인 및 변경 이력 관리를 Workforce–Approval 연동으로 구현했습니다. 고객 환경의 팀장 권한 조건과 Jira 직접 입력 경로를 검증하고, 보존 규모를 확정한 뒤 적용 범위와 완료 일정을 안내드리겠습니다.”
