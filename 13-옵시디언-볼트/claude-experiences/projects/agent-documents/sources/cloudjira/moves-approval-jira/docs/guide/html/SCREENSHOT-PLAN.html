﻿# 캡처 현황과 남은 촬영

2026-10-20 development 사이트에서 브라우저로 직접 촬영했다. 목업이나 생성 이미지가 아니다. 현재 화면 언어는 한국어이며 영문 캡션을 별도로 제공한다. 원본을 수정하지 않았다.

파일 실제 확인 내용 분류
내 이력 승인 완료·회수된 요청, 작업 일시·시간, 이력 필터 문서용 원본
기본 승인 규칙 연동 모드, 자동 요청, 자동 마감 0 경고 문서용 원본
Workforce 연결 연결 상태, 상대 버전, 통신 진단 문서용 원본
상세 오류 승인 완료·타임라인과 오류 배너 동시 표시 내부 오류 증빙, 홍보 사용 금지

촬영 환경은 Jira 개발 설치이며 Marketplace production 버전이 아니다. 화면의 이름·프로젝트·오류 이력을 공개하기 전 검수하고, 공개용 시험 데이터를 갖춘 출시 후보에서 재촬영한다. 브라우저 계정 언어 변경은 확인을 요청했으며 승인 없이 변경하지 않았다.

남은 촬영: 영문 UI, 이슈 Work log 목록, 신규 작성 폼, 정상 승인 상세/반려, 기간 마감, 통제 해제·잔여 0, 단독 모드. 설정을 변경하거나 승인·반려하는 기능 검증은 이 문서 촬영에서 실행하지 않았다. 화면 로딩 실패를 정상 완료 이미지로 저장하지 않았다.

정상 캡처의 하이라이트 문구와 alt text는 한국어 갤러리·영문 갤러리에 있다. Marketplace 제출용 해상도·crop·공개 검수가 끝나기 전에는 이미지 제출 완료로 표시하지 않는다.
