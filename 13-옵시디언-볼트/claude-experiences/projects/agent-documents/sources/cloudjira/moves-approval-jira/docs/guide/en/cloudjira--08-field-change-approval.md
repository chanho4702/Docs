# General issue and field change availability

The current product flow **does not provide new general issue approval or field change approval requests**. Do not use earlier field-change request and application instructions to configure the current installation.

Check [status change availability](cloudjira--07-transition-approval.md), or use the [author guide](cloudjira--03-requester-guide.md) for worklog approval.

Installations containing historical requests may still display those records. Their presence does not mean the corresponding feature is available for new requests.
