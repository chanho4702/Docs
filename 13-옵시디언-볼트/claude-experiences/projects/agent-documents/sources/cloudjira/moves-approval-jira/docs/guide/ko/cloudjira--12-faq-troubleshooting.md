# FAQ·문제 해결

| 증상 | 확인할 사항 |
| --- | --- |
| 저장은 됐는데 승인 대기 건이 없음 | 자동/수동 정책, 후보 선택, 요청 접수 결과. 같은 시간 재입력 금지 |
| 승인자 후보가 없음 | 팀·상위 팀장·명부·활성 계정·이슈 열람 권한 |
| 승인됐는데 수정 불가 | 정상 잠금. 제공되는 소명 절차 확인 |
| 지난달인데 잠기지 않음 | 자동 마감 0은 꺼짐. 실제 마감 상태 확인 |
| Work log가 없거나 중복됨 | 사이트 시간 추적 제공자와 설치 업그레이드 확인 |
| Jira·다른 앱 합계가 다름 | 숨김 통제·조회 권한·현재 시간/확정 시간/제출본 구분 |
| Workforce 연결 필요 | 스위치뿐 아니라 연결 완료 상태 확인 |
| Workforce 접근 거부 | 상대 앱 권한·행위자·대상 이슈 권한 확인 |
| 변경 이력 누락 | 수집 범위·설명 보관·권한·이벤트와 일일 보정 지연 확인 |

## 지원 요청

앱 버전·환경, 발생 시각과 시간대, 요청 ID·이슈 키·worklogId, 재현 순서, 오류 코드, 기대 결과와 실제 결과를 정리하세요. 민감한 설명·반려 사유·개인정보는 가리고, PIN·개인키·연결 코드·인증 토큰은 보내지 마세요.

공개 출시 후에는 Marketplace에 연결된 공급자 지원 채널을 사용합니다. 공개 전에는 문서를 전달한 담당자에게 문의하세요. 확정되지 않은 응답 시간이나 24시간 지원을 약속하지 않습니다.
