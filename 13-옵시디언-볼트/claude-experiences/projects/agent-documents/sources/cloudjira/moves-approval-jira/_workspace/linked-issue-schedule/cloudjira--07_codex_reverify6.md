설계 기준으로 검토했다. 코드 수정·테스트는 하지 않았다.

- **남은 P1: 미해소.** §5.3.3·§21.4는 저장 실패한 **현재 호출**만 거부한다. 다음 호출까지 유지되는 제한이나 미해결 표식은 명시하지 않았다.
- 반례: 저장본 `rev=300, NOT_REQUIRED` → `rev=200, REQUIRED` 수신·누적 저장 실패 → 현재 호출 거부 → 다음 호출에 `rev=100, NOT_REQUIRED` 재생 → `conflictLimit`이 없으므로 허용 판정 가능.
- §11.2·A5′·A48″·A51의 실패 응답은 일치하지만, 실패 **후 다음 호출**의 제한 보존은 보장하지 않는다.
- 보완 범위에서 별개의 새 P0/P1은 발견하지 않았다.

착수 불가: 충돌 제한 저장 실패 후 다음 호출에서 제한이 풀리는 기존 P1이 남아 있다.
