# audit-retention-sync — 감사 증적 보강·보관/내보내기·인증 즉시 게시·계약 보강

작성일: 2026-10-11. 근거: 사용자 결정 Q131~Q135(`_workspace/QUESTIONS.md`). 선행 커밋: 승인 앱 `01e7441`(worklog-control), 워크포스 `RFC-220` `4788a77`.
검증 권고(worklog-control 03_verify_report 2회차 관찰 1): `ctx.linked` 를 기간 창 판정용과 통제 연동 판정용으로 칸 분리 — 이번에 같이 처리.

## 1. 승인 앱 요구

### R1 통제 판단·조치 이력 (Q131)
- 추가 전용(append-only) 테이블 신설. 결정적 id(불변식 6). 수정·삭제 resolver 없음(보관 정리 배치만 예외).
- 기록 대상: 다른 경로 입력 감지·표시, 관리자 해제·확인(누가·언제·사유), 숨김 적용·해제(앱 = 행위자 없음, 사유 코드), 삭제 예정·강등·삭제 실행(참고 사본 지문), 통제 스위치·관문 기록은 이미 설정 감사에 있으므로 링크만.
- 관리자 해제·확인 resolver 는 **사유 입력 필수**(짧은 텍스트, 서버는 사람이 읽을 문구를 만들지 않음 — 사용자 입력 사유는 저장 가능, 로그에 남기지 않음).
- 감사 > 워크로그 변경 탭에 함께 표시(행 종류 구분), 엑셀 포함. 불변식 7(이슈 열람 재확인·hiddenCount) 동일 적용.
- 보관: 인증과 같이 무기한 기본(정책으로 연 단위 변경 가능), 정리는 R3 흐름.

### R2 워크로그 변경 이력 보관 분리 (Q132)
- 정책 키 신설: 워크포스 연결 워크로그 이력 보관 기간(기본 36개월, 선택지 12/24/36/60/무기한). 기존 `worklogHistoryRetentionMonths`(기본 12)는 일반분.
- 연결 여부는 이력 행의 `wf_linked`(기록 당시) 기준.

### R3 기간 경과 기록의 파일 보장 (Q132)
- **모든 기록 종류**(결재·워크로그 이력 일반/연결분·인증·통제 이력)에 대해: 기간이 지나도 **서버 내보내기 세션으로 실제 내보낸 뒤 확정한 것만** 삭제(기존 approval/worklogHistory 흐름 재사용·일반화). 내보내기 확정 전에는 절대 삭제 안 함.
- **삭제 없이 내려받기만** 언제든 가능(기간 무관, 기간 필터).
- 설정 > 데이터 관리에 종류별 "기간 지난 기록 N건 — 내려받기 필요" 표시(조회 시점 계산, 유휴 SQL 0).
- 인증 기록·통제 이력은 무기한 기본이므로 "기간 경과"는 정책을 바꿨을 때만 생김.

### R4 인증 즉시 게시 (Q134 가)
- 인증·재인증·본인 인증·인증 상태 전이(MISMATCH/DELETED) 시 워크포스 게시 큐 작업을 **이벤트로** 넣는다(새 scheduledTrigger 금지, 기존 큐 `approval-sweep-queue`/consumer 재사용 또는 같은 패턴). 같은 사용자×월이 짧은 시간에 여러 번 인증되면 합쳐서 1회 게시(디바운스 — 큐 지연 몇십 초 + 아웃박스 touch).
- 워크포스 미연결이면 아무것도 넣지 않음(기존 NOT_LINKED 관문). 유휴 SQL 변화 0, idleSqlBudget 유지.
- AGENTS "워크포스 PUT 은 스윕에서만" → "큐 작업에서만"으로 리더가 갱신(보고서에 문구 초안).
- 재게시 화면 문구: "다음 일일 동기화" → 인증 시 즉시(수 분), 그 외 일일.

### R5 인증 문서 계약 보강 (Q135)
- 인증 문서 항목 중 **삭제 상태(flag 비트 2)인 항목에만** 원래 이슈 id 필드 추가(짧은 키). 32KB/30,000B 한도 재계산(최악 1,000건 전부 삭제 가정 포함). 상한 초과 시 규칙.
- `contract.js`·`certificationDoc.js`·validator·`vectors.json`(인증 문서 벡터 갱신). **워크포스 리포의 복사본 9개 파일과 바이트 동일 유지**가 전제 — 승인 앱 쪽 변경 후 워크포스 에이전트가 복사.
- 가능하면 워크포스 보고서 요청 1번(`contract.js` 가 도메인 파일을 import 하지 않게 정리 → 복사 대상 축소)도 함께. 깨지는 테스트 없이.

### R6 `ctx.linked` 칸 분리 (검증 권고)
- 기간 창 판정용 연동 상태와 통제 연동 상태를 다른 필드로. 불명(unavailable)이 통제 제한 대상으로 잡히지 않음을 테스트로.

## 2. 워크포스 요구 (별도 에이전트, 브랜치 RFC-220)
- W1 인증 문서 읽기를 asApp 으로(Q133) — 서명 검증 후 계산에만, 원문 미노출. 워크포스 AGENTS asApp 예외 목록에 추가.
- W2 삭제 항목의 이슈 id 로 프로젝트를 찾아 "유지" 정책대로 원가 반영(Q135).
- W3 원가 화면에 "확정 원가(인증분)"·"예상 원가(미인증 포함)" 나란히(Q134 나).
- W4 월 귀속 보정(인증 모델 검증 V5): 인증 뒤 작업일이 다른 달로 옮겨진 건을 worklogId 로도 찾는다.
- W5 계약 파일 9개(또는 R5 로 줄어든 수) 재복사·바이트 대조.
- W6 worklog-control 워크포스 작업 WF-7~13(`_workspace/worklog-control/01_architect_design.md` §12): 연동 모드 asApp 본인 워크로그 조회(작성자 일치·승인 앱 통제분 증명), 작성 출처 서명(`movesRms.origin`), 수정·삭제는 승인 앱 넘김, 진단.

## 3. 완료 기준
- 불변식 1~10, 유휴 SQL 불변(미연동 27·연동 38), 새 스케줄 0, 마이그레이션은 칼럼·테이블이 인덱스보다 앞(현재 마지막 v059).
- 두 리포 테스트·빌드·lint 통과, 계약 바이트 대조 통과.
