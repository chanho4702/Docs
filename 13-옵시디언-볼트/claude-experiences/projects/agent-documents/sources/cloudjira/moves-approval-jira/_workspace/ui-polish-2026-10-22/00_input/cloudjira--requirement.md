# 이슈 패널·설정 화면 UI/UX 정리 (2026-10-22)

사용자: "지라 이슈 패널에 붙은 UI/UX 가 별로", "설정 쪽도 디자인 구리고 배치랑 검색바가 너무 길다".
프론트 전용. 서버 응답·resolver·manifest·SQL 변경 없음. testId·쿼리키·동작은 유지(필요하면 테스트 갱신).

## dev 실측(2026-10-22, 1524px 폭 화면)에서 본 문제

### A. 이슈 오른쪽 패널(jira:issueContext, `entries/issue.jsx` compact + `features/transition/StatusChangeApprovalCard`)
- 위: 안내 문장 + 폭 전체 "작업 시간 기록" 버튼. 아래 구분선, "상태 변경 승인" 제목 + "승인되면 이슈 상태가 바뀝니다."
- 규칙 행: `→ Selected for Development` [사용됨] [검사에서 자동으로 요청함] + 파란 primary "상태 변경 승인 요청" 버튼이 한 줄에 빽빽, 밑에 "Jira 적용 상태: Jira 적용 확인"(중복·의미 불명).
- "최근 요청 [사용됨] → Selected for Development [검사에서 자동으로 요청함] 2026. 10. 21." 한 줄 + 그 아래 "상세", "전체 보기" 가 버튼처럼 안 보이고 들여쓴 텍스트 두 줄로 떠 있음, 아래 빈 공간 큼.
- 개선 방향: 좁은 사이드 패널(약 500px)에 맞춘 컴팩트 카드. 배지는 핵심 1개만(상태), 보조 정보는 subtle 작은 글씨. 요청 버튼은 default/작게(primary 남발 금지), "상세"·"전체 보기"는 subtle link 버튼을 한 줄 오른쪽 정렬. 최근 요청은 상태 배지 + 날짜만, 목적 상태가 규칙과 같으면 반복하지 않음. 빈 공간 없앰(높이는 내용이 정함 — 100vh 금지).
- 워크로그 안내 문장은 짧게, 기록 버튼은 폭 전체 말고 일반 크기.

### B. 이슈 활동 탭 Work log(issuePanel/issueActivity, `features/worklog/WorklogTab`)
- 위: "작업 시간 기록"(primary) ↔ 오른쪽 "새로고침" 이 버튼 같지 않은 텍스트.
- "이 이슈의 기록 규칙: 미래 날짜 기록 허용 끔 [사이트 기본값] 하루 최대 기록 시간 720분 [사이트 기본값] 한 주 최대 기록 시간 3120분 [사이트 기본값]" 가 한 줄로 길게, 출처 칩 반복. 분 단위(720분)는 읽기 어려움 → 시간(12시간, 52시간).
- 그 밑 "설정: Jira 프로젝트 설정 › Moves Approval", "2026.10.12.부터 변경 이력을 기록합니다. · 승인·인증된 작업 로그의 잠금은…" 작은 글씨 두 줄.
- 개선: 툴바 한 줄(기록 버튼 + 새로고침 아이콘 버튼), 규칙은 요약 한 줄(출처가 모두 같으면 칩 하나) + 상세는 details/툴팁, 안내 문구는 하나로.

### C. 설정(adminPage, `features/settings/*`)
1. **같은 카드 반복**: "Workforce 연동 모드" 카드(승인 대상·승인자 원천·정책 관리 + "워크포스 연동 설정에서 모드 변경")와 "내 Workforce 결재자 구성" 카드가 **기본 승인 규칙·승인 기간·팀(정책 탭)·결재 구성** 세 페이지 맨 위에 똑같이 나옴. "연동 이슈 승인 정책"도 기본 승인 규칙과 승인 기간·팀에 중복. → 모드 상세 카드는 한 곳(기본 승인 규칙 또는 워크포스 연동 페이지)만, 나머지 페이지는 한 줄 모드 표시(배지 + 링크) 또는 제거. 결재자 구성 카드도 한 곳.
2. **검색바·입력 폭**: 적용 프로젝트 — 검색 입력이 오른쪽 위에 있고 "검색" 버튼이 그 밑 줄로 떨어짐. 감사 — 행위자/요청자/프로젝트 셀렉트가 들쭉날쭉, 종류·결과 체크박스가 두 줄로 길게. 기본 승인 규칙 — "언제 승인 요청하나요?" 셀렉트가 카드 폭 전체(~1100px). → 검색은 입력+버튼(또는 Enter) 한 줄, 입력 폭 상한(약 320px). 폼 컨트롤 폭 상한(셀렉트 ≤ 360~480px, 긴 폼 720px 규약 유지). 감사 필터는 날짜·사람·프로젝트를 한 줄 그리드로, 종류·결과는 다중 셀렉트 또는 접히는 칩.
3. **상태 변경 승인 페이지**: 소개 문장 밑에 `[상태 변경 승인] 승인되면 이슈 상태가 바뀝니다.` 배지 행이 따로 떠 있고 바로 아래 카드에서 같은 설명 반복 → 제거.
4. **설정 관리자**: 계정 열에 accountId 원문(712020:…) 노출 → 열 제거(또는 이메일 없으면 생략). "저장" 버튼이 표 밑에 따로 떠 있음 → 카드 헤더 우측 또는 변경 있을 때만.
5. **감사 표**: 대상 셀에 "같은 사람·같은 기간 보기 · 인증 · 워크로그 변경 · 설정 변경" 링크가 매 행 반복돼 행이 3~4줄 → 행 메뉴(••• 또는 하나의 "관련 기록" 버튼)로 접기. 시각 열 줄바꿈("2026. 10. 21. 오후 / 3:56") → nowrap·짧은 형식.
6. 전반: 페이지 회색 배경 + 흰 카드 + 카드 안 또 회색 표 헤더… 계층이 많음. 카드 제목/설명 간격, 배지 크기 일관. 토큰만 쓰고 하드코딩 px 금지(`typographyRules.contract.test` 유지).
