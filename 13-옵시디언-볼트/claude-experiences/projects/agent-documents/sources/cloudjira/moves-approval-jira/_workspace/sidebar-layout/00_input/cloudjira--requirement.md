# 화면 탐색을 Workforce 형식의 사이드 패널로 전환

- 요청일: 2026-10-06
- 사용자 요청: “야 이거 워크포스처럼 화면 구조 사이드 패널로 빼줘”
- 참조: `C:\CloudJira\moves-workforce\static\ui\src\layout\Sidebar.jsx`, `sidebar.css`.

## 요구사항

업무함의 상단 탐색 탭과 우측 설정 진입 버튼을 좌측 접기/펼치기 sidebar로 옮긴다. 설정에 들어가도 업무함 메뉴가 유지되며, 설정의 하위 항목도 같은 sidebar에 펼친다. 독립 Jira 관리 화면 역시 공통 AppShell과 같은 설정 메뉴 정의를 사용한다.

## 완료 기준

- 기존 업무함 항목·아이콘·배지·팀장 전용 노출 조건을 보존한다.
- 설정은 하나의 sidebar 아래 하위 메뉴로 노출하며 본문 상단 설정 탭을 제거한다.
- sidebar 펼침 240px, 접힘 56px; 760px 이하 화면에서는 아이콘 rail로 축소한다.
- 기존 `tab` query와 목록 필터·기간·팀 URL 계약 및 뒤로/앞으로 이동을 유지한다.
- 업무함 설정 하위 선택은 `setting` query로 복원한다. 잘못된 값은 `policy`를 선택한다.
- 타임시트 등 기능 내부의 탭은 유지한다.
- 본문 `min-width: 0`, 긴 메뉴 스크롤, 키보드 조작, 한·영 접근성 문구, Atlaskit 테마 토큰을 적용한다.
- 백엔드·데이터 범위·권한·manifest·배포·커밋은 변경하지 않는다.
- 기존 사용자 변경을 보존하며 모든 에이전트 완료 후 지정 검증 순서를 실행한다.
