# 워크포스 API 팀 조회 임시 재개

사용자 요청: “우리 임시로 워크포스 api 팀 조회 로직 열거야 이거 진행해줘”

- 보존된 관리자 전용 3LO API 팀 조회를 임시로 활성화한다.
- 설정 > 워크포스 연동에서 연동 ON일 때 연결·조회 화면을 제공한다.
- 승인 권한과 자동 승인자 선택은 기존 서명 검증 조직 명부를 계속 사용한다.
- 팀 화면, 승인 원장, 자동 연동, Workforce 저장소는 변경하지 않는다.
- 기존 사용자 문서 변경을 보존한다. 커밋·푸시는 하지 않는다.

2026-10-15 재요청: 사용자가 원복 뒤 “야 복구하자”라고 요청했다. 직전 구현을 동일하게 복구하고 다시 검증하며 배포는 하지 않는다.
