# English Guide

[English Guide](cloudjira--00-index.md) · [한국어](../ko/cloudjira--00-index.md)

Moves Approval lets you request **step-by-step approval** for Confluence Cloud pages, or for specific areas inside a page, and records every approval, rejection, expiry, and withdrawal. Approval status appears in the page itself as a **stamp box** (steps, approvers, and stamps), and finished approvals can be downloaded as an **approval certificate PDF**.

## Get started in five minutes

1. **Site administrator** — Install Moves Approval from the Atlassian Marketplace. → [Installation and first-time setup](cloudjira--02-installation.md)
2. **Administrator** — Open **Moves Approval** in Confluence settings and review the global policy and enabled spaces. → [Administrator guide](cloudjira--06-admin-guide.md)
3. **Requester** — Select **Request approval** below a page title, choose approvers in order, and submit. By default, a stamp box is added to the top of the page as well. → [Requester guide](cloudjira--03-requester-guide.md)
4. **Approver** — Open **Apps** → **Moves Approval** (the approval inbox) → **My turn**, then approve or reject. → [Approver guide](cloudjira--04-approver-guide.md)
