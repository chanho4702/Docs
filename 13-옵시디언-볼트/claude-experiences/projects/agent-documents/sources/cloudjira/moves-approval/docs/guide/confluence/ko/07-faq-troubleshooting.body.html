메뉴·화면

페이지에 "승인 요청"이 보이지 않습니다

  • 페이지 제목 아래 항목은 모든 열람자에게 보이지만, ••• 메뉴의 승인 요청은 편집 권한이 있을 때만 보입니다.
  • 요청하려면 편집 권한이 필요합니다. 승인 창에서 요청 버튼이 없으면 편집 권한을 확인하세요.
  • 관리자가 일부 스페이스만 켰다면 이 스페이스가 적용 스페이스인지 확인하세요.
  • 관리자가 등록된 사용자만 앱 사용을 켰다면 승인자 명부나 설정 관리자에 등록되어야 합니다.

앱 화면이 비어 있거나 "화면을 불러오지 못했습니다"가 보입니다

브라우저를 새로 고치세요. 앱이 막 업데이트된 직후에는 이전 화면이 캐시되어 한 번 새로 고쳐야 할 수 있습니다. 계속되면 다른 브라우저나 시크릿 창에서 확인하고 지원 요청 시 알려 주세요.

매크로 아래쪽이 잘려 보입니다

결재란이나 영역 매크로에서 이름·서명 이미지가 늦게 표시될 때 아래가 잘리던 문제는 수정되었습니다. 그래도 잘려 보이면 이전 화면이 캐시된 것이므로 페이지를 새로 고치세요.

프로필 사진 대신 이니셜이 보입니다

브라우저나 조직 보안 설정으로 프로필 이미지를 불러오지 못하면 이니셜 아바타를 표시합니다. 기능에는 영향이 없습니다.

요청

요청이 만들어지지 않습니다

메시지 해결
이미 진행 중인 승인 요청이 있습니다 한 대상에는 진행 중인 요청이 하나만 있을 수 있습니다. 기존 요청을 확인하거나 회수하세요. 기존 요청의 마감이 이미 지났다면 다시 요청할 때 이전 요청이 자동으로 만료되고 새 요청이 걸립니다.
이 페이지를 볼 수 없는 사용자가 결재선에 있습니다 승인자를 바꾸거나 페이지·스페이스 권한을 주세요.
등록된 승인자만 결재선에 넣을 수 있습니다 승인자 명부에 있는 사람을 고르거나 관리자에게 등록을 요청하세요.
결재선 구성이 올바르지 않습니다 빈 단계, 단계 인원보다 많은 필요 승인 수, 그룹과 사용자가 섞인 단계가 없는지 확인하세요.
이 스페이스에서는 승인을 사용할 수 없습니다 관리자에게 적용 스페이스 추가를 요청하세요.

결재선에서 사람을 찾을 수 없습니다

이름 또는 계정을 두 글자 이상 입력하세요. 결과가 많으면 일부만 보이므로 더 입력해 좁히세요. 관리자가 승인자 명부를 운영 중이면 명부 밖의 사람은 넣을 수 없습니다.

요청 후 페이지를 고쳤습니다

요청은 그대로 진행됩니다. 고친 내용까지 승인받으려면 승인 창의 새 버전으로 다시 상신을 누르세요. → 요청자 가이드

영역 매크로에 "한 번 편집·저장해야 결재를 걸 수 있습니다"가 보입니다

매크로를 편집 화면에서 한 번 열었다가 저장하고, 페이지를 게시하세요. 영역 식별자가 기록된 뒤 요청할 수 있습니다.

"같은 페이지에 중복된 영역 식별자가 있습니다"

영역 매크로를 복사해 붙이면 식별자가 겹칠 수 있습니다. 뒤쪽 매크로를 지우고 새로 삽입한 뒤 내용을 옮겨 저장하세요.

결재란

결재란이 문서에 생기지 않습니다

요청 폼의 문서 맨 위에 결재란 추가를 켠 채 요청하면 앱이 문서 맨 위에 결재란을 넣습니다. 생기지 않았다면 다음을 확인하세요.

원인 설명
정책이 꺼져 있음 관리자가 승인 요청 시 문서 맨 위에 결재란 자동 추가를 꺼 두면(전역 또는 스페이스별) 요청 폼의 체크박스가 처음부터 해제되어 있습니다. 건별로 다시 켤 수 있습니다.
체크를 해제함 요청할 때 문서 맨 위에 결재란 추가를 끈 경우입니다.
영역 결재 영역 결재에는 이 체크박스가 없습니다. 영역 매크로 패널 아래에 같은 결재란이 붙습니다.
편집 권한 없음 결재란은 요청자 권한으로 넣습니다. 페이지 제한 등으로 본문을 고칠 수 없으면 넣지 못합니다.
이미 있음 문서에 결재란이 이미 있으면(템플릿에 넣어 둔 경우 등) 다시 넣지 않습니다.
동시 저장 요청하는 순간 다른 사람이 페이지를 저장했다면 넣지 못합니다.

넣지 못한 경우에도 요청은 결재란 없이 정상 진행됩니다. 결재란이 필요하면 편집기에서 / 를 눌러 Moves 결재란 매크로를 직접 넣으세요.

요청했더니 페이지 버전이 올라갔습니다

결재란 자동 추가 때문입니다. 앱이 요청자 권한으로 문서 맨 위에 결재란을 넣으므로 페이지 버전이 하나 오르고, 페이지 이력에 요청자가 "Moves Approval" 메시지로 남습니다. 결재는 이 오른 버전을 기준으로 걸리므로 "요청 이후 수정됨"으로 표시되지 않습니다. 버전을 올리고 싶지 않으면 요청할 때 문서 맨 위에 결재란 추가를 끄세요.

결재란에 "승인 이후 문서가 수정되었습니다"가 보입니다

승인된 뒤 문서가 고쳐져 현재 버전은 승인되지 않은 상태라는 뜻입니다. 고친 내용도 승인받으려면 다시 요청하세요.

결정

승인 업무함에 요청이 보이지 않습니다

  • 앞 단계가 끝나지 않았다면 내 차례가 아니라 진행 중 탭에 있습니다.
  • 대상 페이지를 볼 권한이 없으면 목록에서 제외됩니다.
  • 필터가 적용되어 있지 않은지 확인하세요(모두 지우기).
  • 목록은 나눠서 불러옵니다. 목록 아래 더 보기를 눌러 나머지를 불러오세요.

승인·반려 버튼이 없습니다

  • 아직 내 차례가 아니거나, 이미 결정했거나, 요청이 끝났을 수 있습니다.
  • 마감이 지났습니다가 보이면 더 이상 결정할 수 없습니다. 요청자가 다시 상신해야 합니다. 승인 창을 띄워 둔 채 마감을 넘겨도 30초 안에 버튼이 사라집니다.

일괄 승인에서 일부 요청을 고를 수 없습니다

마감이 지난 요청은 일괄 승인 대상에서 빠지고 체크박스가 막힙니다.

잘못 승인(반려)했습니다

확정한 결정은 되돌릴 수 없습니다. 요청이 아직 진행 중이면 요청자에게 회수 후 다시 요청하도록 알리세요. 이미 승인 완료·반려 등으로 종료됐다면 새 요청을 만드세요. 이전 결정과 이력은 남습니다.

마감

마감이 지났는데 아직 목록에 있습니다

마감 경과 만료는 하루 한 번 실행되는 정기 작업이 처리합니다(실행 시각은 Atlassian 플랫폼이 정합니다). 그래서 마감이 지난 요청이 목록에서 정리되기까지 최대 하루가 걸리고, 그동안 업무함과 승인 창에는 기한 초과, 페이지 제목 아래에는 ⌛ 기한 초과로 표시됩니다.

그 사이에도 결과에는 영향이 없습니다.

  • 승인·반려 버튼이 사라지고, 누가 결정을 시도해도 서버가 거절하고 그 자리에서 요청을 만료시킵니다.
  • 요청자가 같은 문서에 다시 요청하면 이전 요청이 자동으로 만료되고 새 요청이 걸립니다.

마감 임박 알림이 설정보다 일찍 왔습니다

마감 임박 여부도 하루 한 번 확인합니다. 그래서 관리자가 **마감 임박 기준(시간)**을 24시간보다 짧게 정해도, 알림은 마감 최대 하루 전에 갈 수 있습니다. 같은 요청의 같은 단계에는 한 번만 갑니다.

결재 증명서

결재 증명서 PDF 버튼이 보이지 않습니다

결재 증명서 PDF는 승인 창 제목 옆에 있으며, 끝난 결재(승인·반려·만료·회수 등)에서만 보입니다. 진행 중인 요청에는 없습니다. 페이지를 볼 수 있는 사람이면 누구나 받을 수 있습니다. "증명서를 만들지 못했습니다"가 보이면 잠시 후 다시 시도하세요.

증명서 PDF에서 글자가 검색되지 않습니다

증명서의 한글 본문은 이미지로 들어가므로 PDF 안에서 검색하거나 복사할 수 없습니다. 대신 요청 ID와 문서 지문은 각 쪽 아래에 텍스트로 들어 있고, PDF 문서 속성(키워드)에도 들어 있어 복사할 수 있습니다. 다크 테마를 쓰더라도 증명서는 흰 종이로 만들어집니다.

문서 지문은 어떻게 검증하나요?

문서 지문은 결재 대상 버전 본문(Confluence 문서 형식, ADF)의 SHA-256 값입니다. Confluence의 버전 내용은 나중에 바뀌지 않으므로, 같은 버전을 다시 받아 계산한 값이 증명서의 값과 같으면 증명서가 가리키는 내용이 그대로라는 뜻입니다.

  1. 증명서에서 페이지 ID와 결재 대상 버전을 확인합니다.
  2. 그 페이지를 볼 수 있는 계정으로 Confluence REST API GET /wiki/api/v2/pages/{페이지 ID}?version={결재 대상 버전}&body-format=atlas_doc_format 을 호출합니다.
  3. 응답의 body.atlas_doc_format.value 문자열을 고치지 않고 그대로(UTF-8) SHA-256으로 계산합니다.
  4. 결과(16진수)를 증명서의 문서 지문과 비교합니다.

영역 결재의 증명서도 그 영역이 들어 있는 페이지 버전 전체의 지문입니다. 증명서를 만들 때 그 버전 본문을 읽을 수 없었다면 "이 버전의 본문을 읽을 수 없어 지문을 계산하지 못했습니다"가 표시되고 지문은 생략됩니다.

데이터 관리(관리자)

보관 기간이 지난 기록을 삭제할 수 없습니다

"보관 기간이 지난 기록을 먼저 엑셀로 내보내야 삭제할 수 있습니다"가 보이면 설정 → 데이터 관리 → 결재 기록 보관에서 먼저 엑셀로 내보내기를 하세요.

  • 내보내기는 파일이 실제로 내려받아진 뒤에만 기록됩니다. 다운로드가 브라우저에서 막혔다면 다시 내보내세요.
  • 삭제는 마지막으로 내보낸 범위만 합니다. "마지막 내보내기 이후 N건이 새로 기간을 넘겼습니다"가 보이면 다시 내보내야 그 기록도 함께 삭제할 수 있습니다.
  • 삭제는 되돌릴 수 없습니다. 삭제된 요청의 결재선·감사 이력·업무함 항목·관련 알림도 함께 지워집니다.
  • 진행 중인 요청은 보관 기간 대상이 아닙니다.

저장 공간이 "주의" 또는 "위험"입니다

설정 → 데이터 관리 → 저장 공간에서 앱이 쓰는 저장 용량을 볼 수 있습니다. 사용량이 80% 이상이면 주의, 90% 이상이면 위험으로 표시됩니다. 한도(1 GiB 기준)를 넘으면 새 결재를 저장할 수 없으므로, 보관 기간이 지난 결재 기록을 내보낸 뒤 삭제해 공간을 확보하세요. 테이블별 크기·행 수는 데이터베이스 통계를 바탕으로 한 추정치입니다. 정리한 뒤에는 새로 고침으로 다시 확인하세요.

알림

이메일이 오지 않습니다

앱은 이메일을 직접 보내지 않습니다. 앱 내 알림이 기본이고, 관리자가 Confluence 알림으로도 보내기를 켜면 대상 페이지에 @멘션 댓글을 남깁니다. 이메일은 Confluence가 그 멘션을 각자의 Confluence 알림 설정에 따라 보낼 때 전달됩니다. 마감 임박·독촉·만료는 앱 내 알림으로만 갑니다.

페이지에 댓글이 자꾸 달립니다

Confluence 알림으로도 보내기 정책 때문입니다. 원하지 않으면 관리자가 전역 정책 또는 스페이스별 정책에서 끌 수 있습니다.

예전 알림이 사라졌습니다

앱 내 알림은 180일이 지나면 자동으로 삭제됩니다. 결재 결과와 이력은 승인 창의 감사 타임라인에 그대로 남습니다.
