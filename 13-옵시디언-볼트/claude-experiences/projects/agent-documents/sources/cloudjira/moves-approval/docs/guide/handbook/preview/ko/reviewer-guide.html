Marketplace 심사 안내

심사자가 설치부터 문서 승인·권한·기록 보관까지 재현하는 절차입니다. 아래 표는 기대 결과이며 실제 실행 결과나 심사 통과 보고서가 아닙니다.

앱과 문서

Moves Approval for Confluence는 Confluence Cloud 페이지 또는 특정 영역에 순차 승인을 요청하고 결정·버전별 이력을 기록합니다. 결재선·승인 그룹·참조·위임·서명 PIN·일괄 승인·결재란·PDF 증명서를 지원합니다.

사용 안내는 빠른 시작, 설치는 설치와 준비, 데이터 항목과 권한은 데이터·보안을 확인합니다. 이 앱의 문서를 Jira 또는 Confluence Data Center용 안내로 사용하지 않습니다.

실제 스테이징 배포본의 승인 업무함. My turn, In progress, My requests, Handled, Cc, Notifications, My signature, My delegation 탭과 Excel 내보내기 진입점을 한 화면에서 확인할 수 있습니다.

실행과 기대 결과

각 종료 시나리오는 별도 요청으로 실행하고, 바꾼 정책은 다음 테스트 전에 원래 조건으로 복원합니다.

확인 실행 기대 결과
진입·설치 업무함, 페이지 승인 창, 관리자 설정 열기 화면이 로드되며 기본 페이지 편집도 정상 동작
순차 승인 A가 B → C 순서로 요청하고 각각 승인 C는 먼저 결정할 수 없고 최종 단계 뒤 승인 완료
반려·회수 별도 요청에서 B 반려, 다른 요청에서 A 회수 각 종료 상태·사유·처리 이력 기록
문서 수정 진행 중 편집 후 새 버전으로 다시 상신 편집만으로 종료되지 않으며 재상신 시 이전 요청 종료·새 요청 생성
영역 영역 요청 후 매크로 삭제 페이지 전체와 별도 상태, 영역 제거 시 자동 회수
권한 D가 목록과 상세 접근 시도 제한 문서 정보가 노출되지 않음
마감 준비한 기한 초과 요청에서 결정·새 요청 시도 결정 거절, 새 요청 시 지난 요청 만료
PIN·위임 PIN 필수와 유효한 위임으로 각각 결정 PIN 확인, 원 승인자와 실제 대리 처리자 기록
참조·알림 참조 지정 후 생성·결과와 댓글 확인 참조는 결정 불가, 댓글 권한 실패가 결정 기록을 되돌리지 않음
일괄 승인 현재 차례인 여러 요청 선택 후 처리 요청별 성공·실패 건수 확인
파일 종료 요청 PDF, 업무함 Excel 다운로드 대상 버전·요청 ID 확인, 목록 내보내기 범위 확인
기록 정리 기간 지난 기록 내보내기 후 삭제 확정한 내보내기 범위만 삭제, 진행 중 요청 제외
언어 한국어·영어 설정의 계정으로 확인 같은 기능과 대응 문서 이용 가능
라이선스 유료 출시 구성에서 비활성 상태 확인 모든 화면(설정 포함)과 매크로에 구매 안내, 모든 기능 호출 거절. 영역 매크로 본문과 byline 상태는 유지

실행자는 제출 버전, 날짜·시간대, 계정 역할, 실제 결과와 화면 증빙을 기록합니다. 마감·보관 테스트를 위해 운영 데이터 날짜를 변경하지 않습니다.

제출 자료 확인

  • 공개 Documentation URL과 한·영 페이지·이미지를 로그아웃 상태에서도 열 수 있는지 확인합니다.
  • 실제 응답하는 지원 채널, 운영 주체, 개인정보처리방침, 고객 이용약관(EULA) URL을 리스팅에 입력합니다. 버전의 Links에서 Atlassian Standard Agreement를 선택하거나 법률 검토를 마친 자체 EULA URL을 제공하고 선택 결과를 기록합니다. 초안·사내 주소·자리표시자는 제출하지 않습니다.
  • 앱 이름·설명·Cloud 제품·가격·평가판·권한·이미지를 실제 제출 버전과 맞추고, 심사자가 설치할 수 있는 링크와 접근 절차를 제공합니다.
  • Privacy & Security 탭에서 데이터 저장·외부 전송, PAT 또는 공유 비밀 사용 여부, 요청 scope의 근거와 개인정보처리방침을 이 문서의 기술 설명과 일치시킵니다.
  • 신규 앱이면 앱·파트너 보안 설문, 1회성 partner 신원·사업자 검증, 자동 취약점 스캔과 Marketplace 수동 심사까지 완료합니다. Critical 또는 일부 High 결과가 나오면 수정 버전을 다시 제출합니다.
  • 제출 버전·사이트·계정 역할·실행 시각·실제 결과·화면 증빙을 심사 티켓에 남깁니다. 문서의 기대 결과를 실행 증빙으로 대신하지 않습니다.

제출 중단 조건

다음 중 하나라도 남으면 심사 제출을 보류합니다.

  • 공개 문서, 이미지, 지원, 개인정보처리방침 또는 EULA 링크가 로그인·권한·404로 막힘
  • 리스팅 설명이나 캡처가 제출한 앱의 메뉴·기능·권한과 다름
  • 심사 계정이 설치·관리자 설정·요청·승인·파일 다운로드를 재현할 수 없음
  • Privacy & Security 답변과 실제 Forge 저장소·Sentry 전송·scope가 서로 다름
  • 영역 매크로, 라이선스, 제한 문서, 마감·보관 시나리오 중 하나가 무한 로딩 또는 설명과 다른 결과를 보임
  • 보안 설문·partner 검증·취약점 조치 또는 심사 티켓의 요청 자료가 미완료

최종 제출 조건은 Atlassian 앱 심사 가이드, 신규 보안 심사 절차, Privacy & Security 탭 안내와 데이터 개인정보 가이드를 기준으로 확인합니다. 문서를 게시했다는 사실만으로 심사나 보안 인증이 완료되는 것은 아닙니다.
