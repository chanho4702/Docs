## 문의할 때 알려 주실 내용

- Confluence 사이트 주소(`이름.atlassian.net`)와 앱 버전
- 무엇을 하다가 어떤 화면·메시지가 나왔는지, 재현 순서
- 가능하면 화면 캡처. **결재 내용·개인정보가 보이지 않게 가려 주세요.**

회사는 고객 사이트의 앱 데이터에 접근하지 않으므로, 문제 확인에 필요한 정보는 고객이 직접 전달해 주셔야 합니다. 비밀번호·API 토큰은 절대 보내지 마십시오.

## 보안 취약점 신고

보안 문제는 [security@dmove.kr 또는 support@dmove.kr, 제목에 "[보안]"]으로 알려 주십시오. 영업일 기준 [2일] 안에 접수를 확인하고, 조치가 끝날 때까지 진행 상황을 알려 드립니다. 확인 전에는 내용을 공개하지 말아 주십시오.
