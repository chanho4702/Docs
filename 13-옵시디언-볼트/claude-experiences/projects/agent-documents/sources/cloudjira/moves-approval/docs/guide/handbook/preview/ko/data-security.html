데이터·보안·개인정보

보안 검토 담당자와 관리자를 위한 앱의 데이터 처리 안내입니다. Moves Approval은 Atlassian Forge에서 실행하며, 현재 구성은 앱 데이터를 Forge SQL과 Key-Value Store에 저장합니다. 결재 데이터는 외부로 보내지 않으며, 별도 고객 서버 연결도 사용하지 않습니다. 외부 전송은 아래 오류 진단 하나뿐입니다.

어떤 정보를 저장하나요

데이터 내용과 목적
요청·결정 페이지 ID·제목·버전, 영역 식별자·해시, 요청자·승인자 계정 ID, 단계·상태·시각·마감
요청 메모·사유 검토 요청 내용, 반려·회수 사유와 감사 이력
업무함·알림 계정별 역할과 요청·결과를 알리는 데이터
서명·PIN 서명 이미지, 솔트 처리된 PIN 해시와 실패 횟수. PIN 원문은 저장하지 않습니다.
위임 원 승인자·대리인 계정 ID, 기간과 메모
설정·변경 이력 정책, 스페이스, 결재선, 그룹·명부·관리자, 보관 설정과 변경 기록

사용자 이름·이메일·프로필 사진은 앱 저장소에 보관하지 않고 화면을 표시할 때 Confluence에서 조회합니다. 페이지 본문도 보관하지 않습니다. 버전·영역 변경 확인과 증명서 지문 계산에 필요한 본문은 읽어 처리합니다.

권한과 Confluence 변경

사용자 작업은 해당 사용자의 Confluence 권한을 따릅니다. 업무함과 요청 상세는 볼 수 있는 페이지로 제한됩니다. 사용자 없이 실행되는 정기 점검·페이지 수정 감지는 앱 권한으로 읽을 수 있지만 그 본문을 사용자에게 반환하지 않습니다.

Confluence 변경 실행 조건 실행 권한
페이지에 결재란 추가 요청자가 자동 삽입을 선택하고 기존 결재란이 없는 경우 요청자. 삽입되면 페이지 버전이 오릅니다.
@멘션 댓글 Confluence 알림 정책이 켜진 경우 해당 동작을 수행한 사용자. 댓글 작성 권한이 필요합니다.

댓글은 페이지 열람자에게 보이며 앱을 제거해도 남을 수 있습니다. 앱 접근 제한을 켜도 이미 작성된 Confluence 댓글의 가시성이 달라지는 것은 아닙니다.

저장 기간과 내려받은 파일

종료 기록은 기본 3년이며 무기한·1·3·5·10년을 선택할 수 있습니다. 기간이 지나도 자동 삭제하지 않고, 관리자가 내보낸 범위를 직접 삭제합니다. 진행 중 요청은 제외됩니다. Confluence 에서 완전히 삭제된 페이지의 기록도 대상이 되며, 이때 제목·메모·사유는 비워서 내보냅니다(앱까지 막는 제한이 걸린 페이지도 Confluence 가 삭제된 페이지와 구분해 주지 않아 같이 처리됩니다). 앱 내 알림은 180일, 설정 변경 이력은 1년 후 정리됩니다. 서명·PIN·위임은 사용자가 변경·삭제할 수 있고, Atlassian 계정이 폐쇄되면 자동으로 지워집니다.

Excel과 PDF에는 사용자 이름, 요청 메모와 사유가 포함될 수 있습니다. 다운로드 후 보관·공유·폐기는 고객이 관리합니다. 앱은 증명서 PDF 사본을 보관하지 않습니다. 앱 제거 후 저장 데이터 처리는 Forge 플랫폼 정책을 따릅니다.

오류 진단

Sentry DSN을 설정한 경우 앱 화면에서 처리되지 않은 오류를 Sentry(미국 리전)로 보냅니다. 클라이언트는 사용자 정보, 요청 URL·본문, 쿠키, 추가 데이터와 이동 기록을 제거하고 콘솔 로그 수집은 켜지 않습니다. 다만 오류 메시지와 스택 추적은 남기므로 오류 자체에 개인정보나 페이지 데이터가 들어 있으면 함께 전송될 수 있습니다. 이 잔여 위험을 수용하거나 오류 내용을 추가로 제거하기 전에는 DSN을 설정하지 마세요. DSN이 없으면 Sentry를 초기화하지 않습니다.

개인정보 관련 요청

서명·PIN과 위임은 해당 개인 화면에서 관리합니다. 승인 기록은 조직의 감사 기록으로, 사용자가 개별 결정을 수정·삭제할 수 없습니다. 앱은 저장한 계정 ID를 Atlassian 개인정보 보고 API로 7일마다 보고하고, 폐쇄된 계정의 서명·PIN·위임·받은 알림을 지우며 승인자 명부·설정 관리자에서 뺍니다. 결재·감사 기록 속 계정 ID는 보관 기간 정책을 따릅니다. 기타 요청은 사이트 관리자를 통해 지원 채널에 문의하세요. 이 안내는 제품의 기술적 처리 설명이며 운영 주체의 공개 개인정보처리방침과 이용약관은 별도로 확인해야 합니다.
