# Moves Approval 개인정보처리방침

> **초안 — 법무 검토 전.** `[ ]` 표시는 확정이 필요한 항목입니다.
> 시행일: [2026-MM-DD]

주식회사 디무브(이하 "회사")는 Atlassian Confluence Cloud 용 앱 **Moves Approval**(이하 "앱")을 제공하면서 처리하는 정보와 그 보호 방법을 다음과 같이 알립니다.

## 1. 적용 범위

이 방침은 Atlassian Marketplace 를 통해 설치한 Moves Approval for Confluence Cloud 에 적용됩니다. 회사 웹사이트(dmove.kr) 이용에는 웹사이트의 별도 방침이 적용됩니다.

## 2. 회사는 고객 데이터를 보관하지 않습니다

앱은 Atlassian Forge 에서 실행되며("Runs on Atlassian"), 앱 데이터는 고객 사이트에 연결된 Atlassian 의 Forge 저장소(Forge SQL·Key-Value Store)에만 저장됩니다. **회사가 운영하는 서버로 고객 데이터가 전송되지 않으며, 회사 직원은 고객 사이트의 앱 데이터에 접근하지 않습니다.** 저장 위치와 데이터 거주(data residency)는 Atlassian 의 정책을 따릅니다.

## 3. 앱이 처리하는 정보

| 구분 | 내용 |
| --- | --- |
| 사용자 식별자 | Atlassian 계정 ID(요청자·승인자·참조자·대리인·관리자) |
| 결재 기록 | 페이지 ID·제목·버전, 스페이스 키, 영역 식별자와 내용 해시, 결재선, 승인·반려 결정과 시각, 요청 메모, 반려·회수 사유 |
| 서명 | 사용자가 직접 그리거나 올린 서명 이미지 |
| 서명 PIN | 솔트를 적용한 PBKDF2 해시와 실패 횟수(PIN 원문은 저장하지 않습니다) |
| 위임·알림·설정 | 위임 기간과 메모, 앱 내 알림, 앱 설정과 설정 변경 이력 |

앱은 사용자 **이름·이메일·프로필 사진과 페이지 본문을 저장하지 않습니다.** 이름 등은 화면을 표시할 때마다 사용자의 권한으로 Confluence 에서 읽습니다.

## 4. 처리 목적

결재 요청·진행·기록 관리, 결재 화면과 알림 표시, 결재 증명서 생성, 앱 설정 적용과 감사 이력 유지에만 사용합니다. 광고·프로파일링·판매에 사용하지 않습니다.

## 5. 외부 전송 — 오류 진단

앱 화면에서 처리되지 않은 오류가 나면 원인 파악을 위해 **Sentry**(Functional Software, Inc., 미국)로 오류 정보를 보냅니다.

- 보내는 것: 오류 종류·메시지·스택 트레이스, 앱 환경, 브라우저·OS 종류
- 보내지 않는 것: 계정 ID·이름·이메일, 페이지 주소·제목·본문, 결재 내용·사유·메모, 쿠키·요청 헤더, 콘솔 로그, 클릭·이동 기록
- Sentry 프로젝트는 IP 주소를 저장하지 않도록 설정합니다.

그 밖에 고객 데이터를 제3자에게 제공하거나 위탁하지 않습니다.

## 6. 보유 기간과 파기

| 정보 | 보유 기간 |
| --- | --- |
| 끝난 결재 기록 | 고객 관리자가 정한 보관 기간(기본 3년). 관리자가 내보낸 뒤 삭제할 때 파기 |
| 앱 내 알림 | 180일 후 자동 삭제 |
| 설정 변경 이력 | 1년 후 자동 삭제 |
| 서명·PIN·위임 | 사용자가 삭제할 때까지. Atlassian 계정이 폐쇄되면 자동 삭제 |

앱은 저장한 계정 ID를 Atlassian 의 Personal data reporting API 로 주기적으로 보고하고, 폐쇄된 계정의 서명·PIN·위임·알림을 삭제합니다. 결재·감사 기록 속 계정 ID는 고객 조직의 감사 기록이므로 위 보관 기간을 따릅니다. 앱을 제거한 뒤의 데이터 처리는 Atlassian Forge 의 데이터 보존 정책을 따릅니다.

고객이 엑셀로 내보내거나 내려받은 결재 증명서 PDF 는 고객이 관리하는 사본입니다.

## 7. 역할

고객 사이트의 앱 데이터에 대해 고객(사이트를 운영하는 조직)이 개인정보의 처리 목적과 범위를 정합니다. 회사는 데이터를 보관하지 않는 앱 공급자입니다. [법무 확인: 처리자/수탁자 지위 표현]

## 8. 정보주체의 권리

사용자는 앱의 **내 서명**·**내 위임** 화면에서 자신의 서명·PIN·위임을 직접 삭제할 수 있습니다. 결재 기록의 열람·정정·삭제 요청은 소속 조직의 사이트 관리자에게 하시고, 그 밖의 문의는 아래 연락처로 보내 주십시오.

## 9. 안전성 확보 조치

모든 기능 호출을 서버에서 권한 확인한 뒤 실행하고, 사용자가 볼 수 없는 페이지의 정보는 앱을 통해서도 보이지 않습니다. PIN 은 해시로만 저장하며 반복 실패 시 잠깁니다.
