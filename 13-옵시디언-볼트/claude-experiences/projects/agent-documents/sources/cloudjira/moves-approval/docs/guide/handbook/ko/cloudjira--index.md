# 한국어 가이드

[가이드 홈](cloudjira--index.md) · [English](../en/cloudjira--index.md)

처음이라면 **빠른 시작**, 사이트를 준비한다면 **관리자 초기 설정**부터 읽으세요.

## 문서의 승인 흐름

요청 준비 → 단계별 검토 → 승인 또는 반려 → 버전과 이력 확인. 문서가 바뀌면 현재 버전을 새로 승인받습니다.
