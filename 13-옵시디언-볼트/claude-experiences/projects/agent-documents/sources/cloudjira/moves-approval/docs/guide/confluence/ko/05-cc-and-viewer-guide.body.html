한국어 가이드 · English

대상: 참조(CC)로 지정된 사람, 문서의 승인 상태를 확인하려는 모든 열람자

참조자(CC)

요청자가 나를 참조로 지정하면 결정 권한 없이 진행 상황을 지켜볼 수 있습니다.

  • 어디서 보나요 — 승인 업무함(상단 앱 → Moves Approval)의 참조 탭
  • 무엇을 받나요 — 앱 내 알림으로 요청 생성, 최종 승인, 반려, 회수, 만료를 받습니다. 중간 단계의 승인 소식은 보내지 않습니다. Confluence 알림이 켜져 있으면 최종 승인 때 페이지 댓글로도 @멘션됩니다.
  • 할 수 없는 일 — 승인·반려, 회수
  • 그룹으로 참조된 경우, 요청 시점의 그룹 구성원이 참조자가 됩니다. 이후 그룹에 들어온 사람은 포함되지 않습니다.
  • 참조자도 대상 페이지를 볼 권한이 있어야 상세 내용을 볼 수 있습니다.

페이지 열람자: 승인 상태 읽기

페이지 제목 아래 항목이 현재 상태를 알려 줍니다.

표시 뜻
승인 요청 이 페이지에는 아직 승인 요청이 없습니다.
⏳ 승인 대기 · 2/3단계 진행 중 3단계 중 2단계를 진행 중입니다.
⏳ 법무 검토 중 · 2/3단계 단계 이름이 있는 경우의 진행 표시입니다.
✅ 승인 완료 모든 단계가 승인했습니다.
❌ 반려됨 승인자가 반려했습니다.
⌛ 기한 초과 마감이 지났습니다. 더 이상 승인·반려할 수 없고, 하루 안에 만료됨으로 바뀝니다.
⌛ 만료됨 마감이 지나 종료되었습니다.
↩️ 회수됨 요청자가 회수했습니다.

관리자가 상태의 표시 이름을 조직 용어로 바꿨다면 위와 다르게 보일 수 있습니다.

항목을 누르면 승인 창에서 다음을 볼 수 있습니다(페이지 보기 권한만 있으면 됩니다).

  • 승인 진행과 승인 순서와 결정(누가 언제 결정했는지, 서명 도장, 대리 결재 여부)
  • 감사 타임라인 — 요청·승인·반려·회수·만료가 일어난 순서와 사유
  • 버전별 승인 이력 — 이전 요청과, 각 요청이 어느 버전을 승인했는지
  • 마감 — 마감 3일 전부터 D-n·오늘 마감, 지나면 기한 초과 배지

문서의 결재란 읽기

문서 안에 결재란(Moves 결재란 매크로)이 있으면 승인 창을 열지 않아도 종이 결재판처럼 결재 상황을 볼 수 있습니다. 요청할 때 문서 맨 위에 자동으로 들어가거나, 작성자가 직접·템플릿으로 넣어 둔 것입니다.

위치 보이는 것
위 칸 단계 이름. 이름이 없으면 "1단계", "2단계"처럼 보입니다. 지금 차례인 단계는 강조됩니다.
가운데 칸 도장
아래 칸 결재자 이름과 결정 날짜. 대리 결재는 날짜 앞에 "(대)"가 붙습니다.
도장 뜻
이름이 들어간 원형 인장 승인. 결재자가 서명을 등록했고 관리자가 서명 사용을 켜 두었으면 그 서명 이미지가 대신 찍힙니다.
각진 "반려" 인장 반려
점선 원 안의 "대기" 아직 결정하지 않았습니다.
  • "아직 결재 요청이 없습니다."가 보이면 이 문서에는 요청이 없습니다. 편집 권한이 있으면 옆의 승인 요청 버튼으로 바로 요청할 수 있습니다.
  • "승인 이후 문서가 수정되었습니다 — 현재 버전은 승인되지 않았습니다."가 보이면 도장은 이전 버전에 대한 것입니다. 아래 "현재 버전 미승인"이란을 보세요.
  • 결재 상세 열기를 누르면 승인 창이 열립니다.
  • 결재란은 페이지 승인을 보여 줍니다. 영역 승인의 결재란은 각 영역 승인 상자 아래에 따로 붙습니다.

결재 증명서 PDF 받기

끝난 결재(승인 완료·반려됨·만료됨·회수됨)는 승인 창 제목 옆의 결재 증명서 PDF 버튼으로 증명서를 내려받을 수 있습니다. 페이지를 볼 수 있는 사람이면 누구나 받을 수 있고, 진행 중인 결재에는 버튼이 없습니다.

증명서에 들어가는 내용:

  • 문서 정보 — 문서, 스페이스, 페이지 ID, 대상(페이지 전체 / 문서 내 영역), 결재 상태, 요청자, 요청 일시, 종료 일시, 요청 메모
  • 버전 — 결재 대상 버전과 현재 버전(같은지, 결재 이후 문서가 수정되었는지)
  • 결재란 — 단계별 결재자와 도장
  • 결재 이력 — 시각·내용·처리자·사유
  • 문서 지문 — 결재 대상 버전 본문의 SHA-256 값
  • 발급 일시·발급자·요청 ID

알아 둘 점:

  • 증명서 본문은 PDF 안에 이미지로 들어가므로(한글이 깨지지 않게) 검색·복사가 되지 않습니다. 요청 ID와 문서 지문은 각 쪽 아래에 텍스트로 들어 있고, PDF 문서 속성(키워드)에도 있어 복사할 수 있습니다.
  • 다크 테마를 쓰고 있어도 증명서는 흰 종이로 나옵니다.
  • 해당 버전의 본문을 읽을 수 없으면 지문 없이 발급되고 "이 버전의 본문을 읽을 수 없어 지문을 계산하지 못했습니다."가 표시됩니다.
  • 영역 결재의 지문도 해당 버전 페이지 전체 본문으로 계산합니다.

문서 지문 검증하기

Confluence 는 이미 저장된 버전의 내용을 바꾸지 않습니다. 그래서 증명서에 적힌 버전의 본문을 다시 받아 같은 방식으로 계산했을 때 값이 같으면, 증명서가 가리키는 내용이 그대로라는 뜻입니다.

  1. 증명서에서 페이지 ID, 결재 대상 버전(예: v5), 문서 지문 값을 확인합니다.
  2. 해당 페이지를 볼 수 있는 계정으로 Confluence REST API 에서 그 버전 본문을 ADF 형식으로 받습니다. GET https://<사이트>.atlassian.net/wiki/api/v2/pages/<페이지 ID>?version=<버전 번호>&body-format=atlas_doc_format
  3. 응답의 body.atlas_doc_format.value 문자열을 그대로(UTF-8, 줄바꿈 추가 없이) SHA-256 으로 계산합니다.
  4. 결과(16진수)가 증명서의 지문과 같으면 내용이 바뀌지 않은 것입니다.

예시(API 토큰 사용, jq 필요):

curl -s -u you@example.com:<API 토큰> \
  "https://<사이트>.atlassian.net/wiki/api/v2/pages/<페이지 ID>?version=<버전 번호>&body-format=atlas_doc_format" \
  | jq -j '.body.atlas_doc_format.value' | sha256sum

"현재 버전 미승인"이란

승인은 특정 버전에 대한 기록입니다. 승인 뒤 페이지가 수정되면 "v5 기준 승인 · 현재 버전 미승인"이 표시됩니다. 지금 보고 있는 내용이 승인받은 내용과 다를 수 있다는 뜻이므로, 승인된 버전이 필요하면 페이지 기록에서 해당 버전을 확인하세요.

영역 승인 표시

페이지 안의 영역 승인 상자는 그 부분만의 승인 상태를 보여 줍니다. 페이지 전체 상태와 별개입니다. 내용 변경됨이 보이면 승인 기준 이후 그 영역의 내용이 바뀌었다는 뜻입니다. 요청이 있는 영역은 상자 아래 칸에 그 영역의 결재란이 붙으며, 결재란 접기/결재란 보기로 접고 펼칠 수 있습니다.
