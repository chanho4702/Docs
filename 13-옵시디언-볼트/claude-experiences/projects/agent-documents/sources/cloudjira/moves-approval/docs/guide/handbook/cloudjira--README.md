## 구성과 디자인

- 한·영 24쌍: 시작 3, 사용자 기능 10, 관리자 7, 지원·심사 3, 언어별 목차 1.

- 상세는 좌측 문서 목록, 중앙 본문, 우측 문서 내 목차와 상단 검색·언어 전환을 제공합니다. 작은 화면에서는 단일 본문과 접이식 목차로 전환합니다.

## 페이지 계층

공간 홈 바로 아래에 한국어 가이드와 English Guide를 둡니다. `(KR) Moves Approval → 한국어 가이드`처럼 언어 단계를 반복하지 않습니다. 각 언어의 하위 구조는 같습니다.

```text
가이드
├─ 빠른 시작
├─ 설치와 사용 준비
├─ 개념과 상태
├─ 페이지 승인 요청
│  ├─ 영역 승인
│  └─ 수정·회수·재상신과 버전 이력
├─ 승인 업무함
│  └─ 참조와 알림
├─ 승인·반려와 일괄 승인
│  ├─ 내 서명과 PIN
│  └─ 결재 위임과 대리 결재
├─ 문서의 결재란
│  └─ 결재 증명서 PDF
├─ 관리자 초기 설정
│  ├─ 전역 정책과 상태 표시명
│  ├─ 적용 스페이스와 개별 정책
│  ├─ 결재선 관리
│  ├─ 승인 그룹 관리
│  ├─ 사용자·관리자와 접근 권한
│  └─ 데이터 보관·내보내기와 변경 이력
├─ 문제 해결과 지원
├─ 데이터·보안·개인정보
└─ Marketplace 심사 안내
```

`editorial/pages.json`은 주제와 계층, `editorial/publication-queue.json`은 실제 게시 ID·부모·검증 결과의 기록입니다. 기존 20개 가이드 주소를 재사용하고 새 주제 28페이지를 추가했습니다. 기존 소개 문서 `204505109`는 본문과 버전을 유지한 채 한국어 가이드 아래로 이동했습니다.

## 검토와 현재 상태

- 참고: 실제 Workforce 정본의 목차·빠른 시작·My Work·관리자 설정. 원본 위치는 `C:\CloudJira\moves-workforce\Moves_Workforce_사용자_매뉴얼\confluence`입니다.
- Approval의 locale, UI와 정책·권한·결정·증명서 소스를 대조했습니다. 남아 있는 번역 키가 실제 버튼의 존재를 보장하지 않는다는 점을 확인했습니다.
- 독자 검토에서 발견한 스페이스 즉시 저장, 전역 PIN/위임/서명, 이전 이력과 PDF 대상 차이, 결재선 마감 상속을 수정했습니다.
- 한영 대응 24쌍, 미리보기 49페이지, 링크·앵커·리소스 1,779개 검사에 오류가 없습니다.
- 스테이징 실제 화면 캡처 17장을 확보해 한·영 본문 36곳에 연결했습니다. MA-02·04·12·21·22 다섯 장면은 각각 단계 진행 데이터, 영역 매크로 로딩, PDF, 식별자 비식별화, 설치 화면 검증 뒤 보완합니다.
- Confluence 실제 게시 49페이지, 가이드 본문 1,974항목·원고 링크 288개·렌더된 내부 링크 300개 검증을 통과했습니다. 가이드 48페이지의 본문 전체 일치와 부모 관계를 검사했습니다.
- 2026-10-23 반영 직전 40페이지의 본문·버전·부모와 첨부 목록을 별도 백업했습니다. 실제 이미지 첨부 36개가 공개 본문에서 렌더되고 누락 첨부·깨진 링크·미해결 링크가 0개임을 확인했습니다. 홈의 기존 텍스트 18개 구간과 panel·매크로 4개 설정을 보존했습니다.
- 실제 Confluence 홈·한국어·영어 목차 화면을 확인했습니다. `_workspace/handbook-publication/`에 전후 원문·검증 결과·화면 증빙을 보관합니다. 과거 로컬 미리보기의 GPU 렌더 실패와 실제 게시 화면 검증을 구분합니다.

## 게시 재개

현재 게시가 완료된 상태입니다. 이전 `prepare-publication.py`로 큐를 초기화하지 않습니다. 이후 수정 전에도 현행 본문·첨부를 다시 읽고 보존합니다. 공개 재검증: `node docs/guide/handbook/editorial/verify-publication.cjs`.

1. 로그인된 MW·MA에서 최신 본문·이미지·사용자 변경을 확인하고 보존합니다.
2. 기존 20페이지 ID를 재사용하고 새 28페이지 ID를 받은 뒤 링크를 Confluence 주소로 변환합니다.
3. 위 계층과 제목·본문·상호 언어 링크를 적용합니다.
4. 실제 제품 테스트 화면을 촬영하고 첨부가 확인된 위치만 자리 표시를 교체합니다.
5. Confluence의 제목·정보 패널·2열 언어 링크·표·이미지 너비로 배치합니다. 로컬 CSS가 Confluence에 그대로 적용된다고 가정하지 않습니다.
6. 상세 → 목차 → 홈 순서로 게시하고 부모 위치·본문·이미지·링크·공개 열람을 확인합니다.
7. 기존 소개 문서는 보존합니다. 빈 언어 폴더 두 개는 휴지통으로 이동했으며 복구 가능합니다. 접근 불가였던 초안과 대체 게시 ID는 큐에 기록했습니다.

## 원고 수정

정본은 `ko/*.md`, `en/*.md`입니다. 제목·계층은 `editorial/pages.json`, 탐색은 `editorial/navigation.json`입니다. 과거 작성용 `editorial/write-*.py`를 재실행하면 검토 교정이 덮일 수 있으므로 사용하지 않습니다.

```text
node docs/guide/handbook/render.cjs
python docs/guide/handbook/validate.py
```

미리보기 생성은 서버를 바꾸지 않습니다. 앱 코드·배포·커밋은 변경하지 않았습니다.
