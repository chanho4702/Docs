# 결재선 관리

[가이드 홈](cloudjira--index.md) · [English](../en/cloudjira--admin-lines.md)

자주 반복되는 승인 순서를 저장해 요청자가 한 번에 선택하도록 합니다. 예를 들어 기술 문서의 `담당 검토 → 책임 승인` 순서를 결재선으로 등록합니다.

**경로:** 설정 → **결재선**.

## 결재선 만들기

1. **결재선 추가**를 누르고 이름과 설명을 입력합니다.
2. 첫 단계의 승인자를 고릅니다. **단계 추가**로 다음 단계를 만들고 순서를 정합니다.
3. 단계 이름과 필요한 승인 수를 확인합니다. 승인 그룹을 쓸 단계에는 그 그룹만 넣습니다.
4. 기본 마감일수와 적용 스페이스, 사용 여부를 정하고 저장합니다.
5. 대상 스페이스의 문서에서 **승인 요청 → 결재선 사용**을 열어 새 결재선을 선택합니다. 단계와 마감이 의도대로 채워지는지 확인합니다.

## 입력 항목

| 항목 | 조건 | 확인할 점 |
| --- | --- | --- |
| 이름 | 필수, 255자 이하 | 요청자가 목적을 구분할 수 있는 이름을 씁니다. |
| 설명 | 선택 | 대상 문서나 사용 상황을 안내합니다. |
| 기본 마감일수 | 1~365일. 비우면 대상 스페이스의 적용 정책(개별 설정이 없으면 전역값) | 날짜 자체가 아니라 요청 후 일수입니다. |
| 결재 단계 | 단계·승인자·필요 승인 수 | 순서대로 열리며 빈 단계는 사용할 수 없습니다. |
| 적용 스페이스 | 비우면 전체 | 지정하면 해당 스페이스의 요청 폼에서만 보입니다. |
| 사용 | 새 요청의 선택지 노출 | 끄더라도 이미 생성된 요청은 유지됩니다. |

## 수정·삭제 후 확인

결재선은 요청이 만들어질 때 복사됩니다. 저장된 결재선을 수정하거나 삭제해도 진행 중 요청의 승인자와 순서를 바꾸지 않습니다. 수정 후에는 새 요청 폼에서, 기존 요청은 상세에서 각각 확인하세요.

검색되지 않으면 사용 여부 → 적용 스페이스 → 승인자 명부와 대상 문서 접근 권한을 확인합니다. 그룹 구성은 [승인 그룹](cloudjira--admin-groups.md)에서 관리합니다.
