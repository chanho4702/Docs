# 설치와 첫 설정

[한국어 가이드](cloudjira--00-index.md) · [English](../en/cloudjira--02-installation.md)

> 대상: Confluence Cloud 사이트 관리자

## 사전 조건

- Confluence Cloud 사이트의 **사이트 관리자** 권한
- 조직의 Marketplace 앱 구매·승인 절차(필요한 경우)
- 앱은 Atlassian 인프라(Forge) 위에서 실행되므로 별도 서버, 방화벽 설정, 외부 계정이 필요 없습니다.

## 설치

1. Confluence 상단의 **앱** → **새 앱 찾아보기**(또는 Atlassian Marketplace)를 엽니다.
2. **Moves Approval**을 검색해 앱 페이지를 엽니다.
3. **앱 받기**(무료 평가판 또는 구매)를 선택합니다.
4. 설치할 Confluence 사이트를 고르고, 앱이 요청하는 권한을 검토한 뒤 승인합니다. 각 권한의 용도는 [데이터·보안·개인정보](cloudjira--08-data-security-privacy.md#요청하는-권한과-용도)에 있습니다.
5. 설치가 끝나면 앱이 데이터 저장소를 자동으로 준비합니다. 첫 화면을 열었을 때 "앱 저장소를 준비하는 중입니다"가 보이면 잠시 후 새로 고치세요.

## 첫 설정 체크리스트 (권장 순서)

**Confluence 설정 → Moves Approval** 에서 진행합니다. 탭별 자세한 설명은 [관리자 가이드](cloudjira--06-admin-guide.md)에 있습니다.

1. **전역 정책** — 기본 마감일수(기본 7일), 반려 사유 필수, 알림 방식, 서명·PIN, 위임, 독촉을 조직 규정에 맞춥니다. **승인 요청 시 문서 맨 위에 결재란 자동 추가**(기본 켬)도 여기서 정합니다. 켜 두면 요청 폼에 결재란 추가가 미리 체크되고, 요청할 때 문서 버전이 하나 오릅니다. 문서 본문을 앱이 건드리지 않길 원하면 끕니다(요청자는 건별로 다시 켤 수 있습니다).
2. **적용 스페이스** — 처음에는 모든 스페이스에서 쓸 수 있습니다. 일부 스페이스에서만 쓰려면 해당 스페이스를 켭니다. **하나라도 켜면 나머지 스페이스는 모두 꺼집니다.**
3. **설정 관리자** — Confluence 관리자가 아닌 운영 담당자에게 설정 권한을 줍니다.
4. **승인자** — 결재선에 오를 수 있는 사람을 제한하려면 명부를 등록합니다. 비워 두면 누구나 승인자가 될 수 있습니다.
5. **승인 그룹**·**결재선** — 자주 쓰는 승인 순서를 등록해 요청자의 수고를 줄입니다.
6. **데이터 관리** — 끝난 결재 기록의 **보관 기간**(기본 3년)이 조직의 기록 보존 규정과 맞는지 확인합니다. 기간이 지난 기록은 자동으로 지워지지 않으며, 관리자가 엑셀로 내보낸 뒤에만 삭제할 수 있습니다.
7. **시험 운영** — 테스트 페이지에서 요청 → 승인, 요청 → 반려, 요청 → 회수를 한 번씩 해 보고 알림이 오는지, 문서 맨 위에 결재란이 생기고 도장이 찍히는지 확인합니다. 끝난 요청에서 **결재 증명서 PDF**도 한 번 받아 보세요.

> **접근 제한을 켤 계획이라면** 먼저 승인자·설정 관리자를 등록하고, 일반 사용자 계정으로 접속을 시험한 뒤 켜세요. 등록되지 않은 사용자는 승인 업무함과 요청 화면을 열 수 없게 됩니다.

## 사용자 안내

사용자에게 다음 문서를 공유하면 따로 교육하지 않아도 대부분 바로 쓸 수 있습니다.

- 요청하는 사람 → [요청자 가이드](cloudjira--03-requester-guide.md)
- 승인하는 사람 → [승인자 가이드](cloudjira--04-approver-guide.md)

## 업데이트

Moves Approval은 Atlassian을 통해 자동으로 업데이트됩니다. 새 버전이 **추가 권한**을 요청하는 경우에만 사이트 관리자가 Confluence의 **앱 관리** 화면에서 업데이트를 승인해야 합니다. 업데이트 중에도 기존 요청·결정·이력은 그대로 유지됩니다.

## 라이선스

라이선스가 만료되거나 비활성화되면 승인 화면에 "앱 라이선스가 활성화되어 있지 않습니다"가 표시되고 새 요청·결정을 할 수 없습니다. 관리자가 상태를 확인할 수 있도록 **설정 화면은 계속 열립니다.** 라이선스를 다시 활성화하면 기존 데이터 그대로 이어서 쓸 수 있습니다.

## 제거

**Confluence 설정 → 앱 관리**에서 Moves Approval을 제거합니다.

- 제거하면 페이지의 승인 표시, 승인 업무함, **Moves Approval Region** 매크로의 승인 기능, **Moves 결재란** 매크로의 표시가 사라집니다. 매크로 안의 본문 내용은 페이지에 그대로 남습니다.
- 대상 페이지에 남긴 @멘션 댓글은 Confluence 콘텐츠이므로 제거 후에도 남습니다.
- 앱 데이터(요청·결정·이력·설정)의 보관과 삭제는 Atlassian Forge 플랫폼의 데이터 보관 정책을 따릅니다. 승인 기록을 보존해야 한다면 제거 전에 승인 업무함의 **엑셀로 내보내기**로 필요한 목록을 받아 두세요. 중요한 결재는 **결재 증명서 PDF**로 따로 보관해 둘 수 있습니다. 업무함 Excel은 현재 탭·필터에 맞는 요청 목록을 최대 5,000건 내보내며, 개별 결정과 감사 이력 전체의 백업은 아닙니다.
