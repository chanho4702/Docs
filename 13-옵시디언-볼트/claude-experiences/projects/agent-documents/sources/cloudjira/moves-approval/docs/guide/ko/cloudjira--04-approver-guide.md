# 승인자 가이드

> 대상: 결재선에 오른 승인자, 다른 승인자의 결재를 맡은 대리인

## 내 차례 찾기

승인할 일이 생기면 다음 중 한 곳에서 알 수 있습니다.

- **앱 내 알림** — 요청이 만들어지면 결재선의 모든 승인자가 "{요청자}님이 {문서} 승인을 요청했습니다"를 받습니다. 내가 뒤 단계라면 이 알림을 받은 뒤 앞 단계가 끝날 때까지 기다리게 됩니다.
- **Confluence 알림** — 관리자가 켰다면(기본 켬) **내 단계가 시작될 때** 대상 페이지 댓글에서 나를 @멘션합니다. Confluence 알림·이메일 설정에 따라 전달됩니다.
- **Confluence 홈** 오른쪽 패널의 Moves Approval 요약
- **승인 업무함** — 상단 **앱** → **Moves Approval** → **내 차례** 탭

앞 단계가 끝나지 않았다면 내 요청은 **진행 중** 탭에 있고, 결정 버튼이 보이지 않습니다("아직 결정할 차례가 아닙니다").

## 승인 업무함

| 탭 | 내용 |
| --- | --- |
| 내 차례 | 지금 내가(또는 나에게 위임한 사람이) 결정해야 하는 요청 |
| 진행 중 | 내가 결재선에 있지만 앞 단계의 결정을 기다리는 요청 |
| 내 요청 | 내가 요청한 승인 |
| 처리한 건 | 내가 이미 결정한 요청 |
| 참조 | 참조자로 지정된 요청 |

- **필터** — 상태, 페이지 제목, 스페이스, 요청자, 요청일(오늘·최근 7일·최근 30일·기간 직접 지정), 마감(마감 임박만·기한 초과만·마감 없음), 내 차례만.
- **마감 표시** — 마감 열에 마감이 3일 이내면 `D-2`처럼, 당일이면 **오늘 마감**, 지났으면 **기한 초과**가 붙습니다. 승인 상세에도 같은 표시가 나옵니다.
- **문서 이름** — 문서 이름은 링크입니다. 누르면 그 문서로 이동하고, Ctrl(Mac은 Cmd)·Shift를 누른 채 누르거나 가운데 버튼으로 누르면 새 탭에서 열립니다. 행의 다른 곳을 누르면 승인 상세가 열립니다. 알림 목록의 문서 이름도 같습니다.
- **표 다루기** — 열 머리의 경계를 끌어 열 너비를 바꾸고, 두 번 눌러 원래대로 되돌립니다. 목록 아래에 "N건 표시 중"이 보이며, 더 있으면 **더 보기**로 이어서 불러옵니다.
- **엑셀로 내보내기** — 현재 탭과 필터에 맞는 조회 가능한 요청 목록을 최대 **5,000건**까지 Excel로 받습니다. 화면에서 아직 불러오지 않은 항목도 포함될 수 있습니다. 이 파일은 요청 목록이며, 개별 결정과 감사 이력 전체의 백업은 아닙니다.
- 목록은 내가 볼 수 있는 페이지만 보여 줍니다. 그래서 탭의 건수(권한 확인 전 건수)가 실제 목록보다 많을 수 있습니다.

## 승인하기

1. 목록에서 요청을 눌러 **승인 상세**를 엽니다. 페이지에서 제목 아래 항목이나 문서의 결재란에서 **결재 상세 열기**를 눌러도 같은 창이 열립니다.
2. 내용을 확인합니다.
   - **요청 메모**, **승인 진행**(지금 몇 단계인지), **승인 순서와 결정**
   - **요청 이후 페이지가 수정되었습니다** 안내가 있다면 **변경 보기** 링크로 요청 버전과 현재 버전의 차이를 확인하세요. 이 요청은 요청 당시 버전에 대한 승인입니다.
   - 영역 승인이면 영역 본문 미리보기(이미지·첨부·다른 매크로는 페이지에서 확인)
3. **승인**을 누릅니다. PIN이 필요한 사이트라면 **서명 PIN**을 입력합니다.

내 단계에 필요한 승인 수가 모이면 다음 단계로 넘어가고, 마지막 단계가 끝나면 요청이 **승인 완료**됩니다.

> 승인 창의 버튼은 항상 같은 자리에 있습니다. **취소**·**뒤로**는 왼쪽 끝, **승인**·**반려** 같은 실행 버튼은 오른쪽 끝입니다. 결과가 없거나 오류가 난 화면에서도 왼쪽 끝 버튼으로 창을 닫을 수 있습니다.

## 반려하기

1. 승인 상세에서 **반려**를 누릅니다.
2. **반려 사유**를 입력합니다(관리자 정책상 기본 필수). 사유는 요청자에게 전달됩니다.
3. 확정합니다. PIN이 필요하면 입력합니다.

> 반려하면 요청이 **즉시 종료**됩니다. 같은 단계의 다른 승인자나 뒤 단계를 기다리지 않습니다.
>
> Confluence 알림이 켜져 있으면 반려 사실이 페이지 댓글로도 남아 페이지 열람자에게 보일 수 있습니다. 민감한 내용은 사유에 쓰지 마세요.

## 여러 건 한꺼번에 승인하기

**내 차례** 탭에서 체크박스로 여러 건을 고른 뒤 **선택 N건 승인**을 누릅니다.

- 한 번에 최대 **50건**까지 처리합니다.
- PIN이 필요한 사이트라도 **묶음당 한 번만** 입력합니다.
- 마감이 지난 요청은 일괄 승인 대상에서 빠지며 체크박스를 고를 수 없습니다.
- 결과는 "승인 N건 · 실패 M건"으로 표시됩니다. 실패한 건(다른 사람이 먼저 처리했거나 그 사이 마감이 지난 경우 등)은 개별로 다시 확인하세요.
- 반려는 사유를 건별로 남겨야 하므로 일괄 처리하지 않습니다.

## 마감이 지난 요청

마감이 지나면 승인 상세에 **마감이 지났습니다**가 표시되고 승인·반려 버튼이 사라집니다. 창을 열어 둔 채 마감 시각을 넘겨도 30초 안에 반영됩니다. 마감 직전에 띄운 화면에서 결정을 보내더라도 서버가 받아들이지 않고, 그 자리에서 요청을 **만료**시킵니다. 그래서 마감 이후의 승인·반려는 생기지 않습니다.

- 만료 처리는 하루 한 번 백그라운드에서 이루어지므로, 목록에서 **만료됨**으로 정리되기까지 최대 하루가 걸릴 수 있습니다. 그동안 업무함에는 **기한 초과**로, 페이지 제목 아래 항목에는 "⌛ 기한 초과"로 표시됩니다.
- 여전히 필요하면 요청자가 다시 요청해야 합니다. 새 요청이 걸리면 마감이 지난 이전 요청은 자동으로 만료됩니다.

## 결재란과 도장

요청자가 문서에 **결재란**을 넣었다면(요청할 때 자동으로 들어가거나 템플릿·편집기에서 미리 넣어 둔 경우) 페이지에서 결재 진행을 종이 결재판처럼 볼 수 있습니다.

- 칸마다 위에 **단계 이름**(없으면 "N단계"), 가운데에 **도장**, 아래에 **결재자 이름과 결정 날짜**가 있습니다. 지금 차례인 단계의 머리는 강조됩니다.
- 도장 모양
  - **승인** — 둥근 인장. **내 서명**에 서명 이미지를 등록했다면 그 이미지가 찍힙니다.
  - **반려** — 각진 "반려" 인장
  - **대기** — 점선 원
  - 대리인이 결정한 칸에는 "(대)"가 붙습니다.
  - 관리자가 서명·도장 표시를 끈 사이트에서는 도장 대신 글자로 표시됩니다.
- 승인 이후 문서가 수정되면 결재란에 "승인 이후 문서가 수정되었습니다 — 현재 버전은 승인되지 않았습니다."가 표시됩니다.
- 결재란의 **결재 상세 열기**로 승인 창을 열 수 있습니다.
- 영역 승인이라면 영역 패널 아래 칸에 같은 결재란이 붙습니다. **결재란 보기**/**결재란 접기**로 펼치고 접습니다(기본은 펼침).

## 결재 증명서 PDF

끝난 결재(승인 완료·반려됨·만료됨·회수됨 등)는 승인 상세의 제목 옆 **결재 증명서 PDF** 버튼으로 증명서를 받을 수 있습니다. 진행 중인 요청에는 버튼이 없으며, 그 페이지를 볼 수 있는 사람이면 누구나 받을 수 있습니다.

- **담기는 내용** — 문서·스페이스·페이지 ID·대상(페이지 전체/문서 내 영역)·결재 상태·요청자·요청 일시·종료 일시·요청 메모, 결재 대상 버전과 현재 버전(같은지, 결재 이후 수정됐는지), **결재란**(도장), **결재 이력**(시각·내용·처리자·사유), **문서 지문**, 발급 일시·발급자·요청 ID.
- **문서 지문** — 결재 대상 버전 본문의 SHA-256 값입니다. Confluence의 지난 버전은 바뀌지 않으므로, 나중에 같은 버전 본문으로 다시 계산해 값이 같으면 증명서가 가리키는 내용이 그대로라는 뜻입니다. 그 버전의 본문을 읽을 수 없으면 지문 없이 발급됩니다.
- 한글 본문은 PDF 안에 이미지로 들어가므로 검색·복사가 되지 않습니다. 요청 ID와 지문은 각 쪽 아래에 텍스트로 들어가고 PDF 문서 속성(키워드)에도 담겨 복사할 수 있습니다.
- 다크 테마를 쓰더라도 증명서는 흰 종이로 만들어집니다.

## 내 서명과 서명 PIN

승인 업무함의 **내 서명**에서 설정합니다.

- **서명** — **서명 그리기**로 직접 그리거나, **이미지 업로드**로 PNG·JPEG(2MB 이하)를 올립니다. 결정할 때 **승인 순서와 결정** 표의 내 결정 옆과 문서의 결재란에 도장으로 찍힙니다. 등록하지 않으면 이름으로 만든 **자동 도장**이 쓰입니다. 표에서 높이 32px로 보이므로 가로로 긴 서명이 가장 잘 보입니다.
- **서명 PIN** — 4~12자리 숫자. 관리자가 "승인·반려 확정에 서명 PIN 요구"를 켰다면 결정 전에 반드시 등록해야 합니다.
  - 5회 틀리면 15분 동안 잠깁니다.
  - PIN을 바꾸거나 삭제하려면 현재 PIN이 필요합니다. 앱에는 관리자용 PIN 초기화 기능이 없습니다. PIN을 잊었다면 사이트 관리자와 지원 채널에 처리 방법을 문의하세요.

## 결재 위임 (자리를 비울 때)

관리자가 결재 위임을 허용한 경우 승인 업무함의 **내 위임**에서 설정합니다.

1. **대리인**을 고릅니다.
2. **시작일**과 **종료일**, 필요하면 **메모**를 입력하고 저장합니다.
3. 일찍 끝내려면 **위임 해제**를 누릅니다.

기간 동안 대리인은 내 차례인 요청을 대신 결정할 수 있습니다. 승인 순서표에는 **내 이름**으로 기록되고, 실제로 결정한 사람이 "대리 결재 · {대리인}"으로 함께 남습니다.

## 대리인이라면

**내 위임** 화면의 **나에게 결재를 맡긴 사람**에서 누가 맡겼는지 봅니다. 위임 기간 동안 맡긴 사람의 차례가 내 **내 차례** 탭에 `대리: {이름}` 표시와 함께 나타나며, 평소처럼 승인·반려하면 됩니다.

## 자주 만나는 메시지

| 메시지 | 뜻과 해결 |
| --- | --- |
| 아직 결정할 차례가 아닙니다 | 앞 단계가 끝나면 **내 차례**로 옮겨집니다. |
| 이미 결정한 요청입니다 | 새로 고쳐 최신 상태를 확인하세요. 결정은 바꿀 수 없습니다. |
| 이미 종료된 승인 요청입니다 | 다른 승인자의 반려, 회수, 만료 등으로 끝났습니다. 마감이 지난 요청에 결정을 보냈을 때도 이 메시지가 나옵니다. |
| 다른 사용자가 먼저 요청을 변경했습니다 | 같은 순간 다른 결정이 들어왔습니다. 새로 고친 뒤 다시 시도하세요. |
| 서명 PIN 이 등록되어 있지 않습니다 | **내 서명**에서 PIN을 먼저 등록하세요. |
| PIN 이 잠겼습니다 | 15분 뒤 다시 시도하세요. |

> 확정한 결정은 되돌릴 수 없습니다. 요청이 아직 진행 중이면 요청자에게 회수 후 다시 요청하도록 알리세요. 이미 승인 완료·반려 등으로 종료됐다면 새 요청을 만드세요. 이전 결정과 이력은 남습니다.
