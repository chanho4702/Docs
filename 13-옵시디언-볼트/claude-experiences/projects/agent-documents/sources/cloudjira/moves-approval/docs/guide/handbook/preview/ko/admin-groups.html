승인 그룹 관리

한 단계에서 여러 사람이 승인할 수 있는 그룹을 만듭니다. 전원이 승인해야 하는 그룹과 한 명만 승인하면 되는 그룹을 구분할 수 있습니다.

경로: 설정 → 승인 그룹.

그룹 등록하기

  1. 그룹 등록 창에서 Confluence 그룹 또는 직접 구성을 선택합니다.
  2. Confluence 그룹이면 사용할 그룹을 찾습니다. 직접 구성이면 그룹 이름을 정하고 사용자를 구성원으로 추가합니다.
  3. 통과 조건을 켜면 전원 승인, 끄면 1인 승인입니다. 실제 운영 규칙과 맞는지 확인합니다.
  4. 요청자가 선택해야 한다면 결재선 검색에 노출을 켜고 저장합니다.
  5. 구성원 보기로 구성원을 확인한 뒤 새 요청 폼에서 그룹을 한 단계로 선택해 봅니다.

그룹 선택 시 주의

항목 동작 확인할 점
Confluence 그룹 구성원은 Confluence에서 관리 현재 그룹 구성원을 확인합니다.
직접 구성 앱 안에서 구성원을 선택 비활성 사용자와 동명이인을 확인합니다.
통과 조건 전원 또는 1인 승인 그룹은 같은 단계의 다른 선택과 섞을 수 없습니다.
검색에 노출 끄기·삭제 새 요청의 검색 대상에서 제외 이미 이 그룹으로 시작한 요청은 유지됩니다.

그룹을 바꾼 뒤에는 새 요청의 펼쳐진 승인자 목록을 확인합니다. 그룹 이름만 보고 현재 요청의 승인자가 함께 바뀌었다고 판단하지 않습니다. 참조 그룹은 결정 그룹과 다르며 참조와 알림을 확인하세요.
