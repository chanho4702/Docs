가이드 홈 · English

Moves Approval은 Confluence Cloud에서 실행합니다. 설치는 사이트 관리자가 진행하고, 일반 사용자는 설치된 사이트의 앱 메뉴와 문서에서 접근합니다.

설치하기

  1. 설치 대상 Confluence Cloud 사이트와 설치 가능한 관리자 계정을 확인합니다.
  2. Atlassian Marketplace 또는 사이트의 앱 관리에서 Moves Approval for Confluence를 찾습니다. 앱 이름·제공자·지원 제품과 표시된 설치 조건을 확인합니다.
  3. 설치할 사이트를 선택하고 권한 요청을 읽은 뒤 설치를 완료합니다.
  4. 심사용 비공개 버전을 사용하는 경우에는 제출 담당자가 제공한 설치 경로를 사용합니다. 공개 리스팅의 설치 경로와 구분합니다.

화면 위치 · MA-22 — 실제 설치 화면에서 앱 이름·지원 제품·대상 사이트와 권한 안내.

세 곳에서 설치 확인

위치 확인할 것 열리지 않을 때
앱 → Moves Approval 승인 업무함 설치된 사이트와 계정, 앱 접근 정책 확인
게시된 페이지 제목 아래 승인 상태 또는 요청 진입점 페이지 권한·적용 스페이스 확인
Confluence 설정 → Moves Approval 관리자 설정 Confluence 관리자 또는 설정 관리자 여부 확인

설정이 처음이라면 관리자 초기 설정을 따르고, 사용자에게는 빠른 시작을 안내합니다. 외부 계정을 새로 만들거나 별도 고객 서버를 설치할 필요는 없습니다.

업데이트와 라이선스

업데이트 안내나 추가 권한 승인이 나타나면 사이트 관리자가 앱 관리에서 내용을 확인합니다. 업데이트 뒤에는 새 요청 폼과 기존 요청 이력을 함께 점검합니다.

라이선스가 비활성이면 새 요청·결정이 차단되고, 앱의 모든 화면(설정 포함)과 문서 속 매크로에 구매 안내가 표시됩니다. 영역 승인 매크로 안의 본문과 페이지 제목 아래 결재 상태 표시는 그대로 보입니다. 라이선스 상태는 Confluence 설정 → 앱 관리에서 확인합니다. 가격과 평가판 조건은 실제 리스팅의 값을 기준으로 확인합니다.

제거 전 확인

필요한 종료 요청은 증명서 PDF로, 목록은 업무함 Excel로 보관합니다. 업무함 내보내기는 최대 5,000건의 요청 목록이며 전체 이력 백업은 아닙니다. 기간이 지난 기록의 내보내기는 데이터 관리를 확인하세요.

앱을 제거하면 앱 화면과 매크로 표시가 동작하지 않습니다. 페이지에 남긴 @멘션 댓글과 매크로 자체는 Confluence 콘텐츠로 남을 수 있습니다. 앱 데이터의 제거 후 보관·삭제는 Forge 플랫폼 정책을 따릅니다.
