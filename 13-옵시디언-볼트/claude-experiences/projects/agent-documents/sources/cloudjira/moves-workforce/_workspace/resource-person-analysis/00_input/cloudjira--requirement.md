# 개인 종합 분석

- 사용자 확정: 인력 현황의 사이드 패널에 상세보기 버튼을 추가하고 선택한 인원 종합 분석으로 이동한다.
- 별도 전사 인력 분석 탭은 만들지 않는다.
- 기존 데이터에 기반한 기간별 투입 추이, 프로젝트별 투입 구성, 이슈/워크로그 근거와 현재 작업·스킬·경험을 제공한다.
- 프로젝트/팀 권한을 서버에서 적용하고 급여·원가는 포함하지 않는다. 미래 계획 데이터 없이 예측 지표를 만들지 않는다.
- 직접 URL 진입, 기간 변경, 빈 데이터, 조회 실패, 권한 밖 인원, 목록 복귀를 처리한다.
- 구현 및 필수 테스트/CI 빌드/Forge lint까지 수행한다. 배포·커밋·푸시는 요청 범위에 없다.
