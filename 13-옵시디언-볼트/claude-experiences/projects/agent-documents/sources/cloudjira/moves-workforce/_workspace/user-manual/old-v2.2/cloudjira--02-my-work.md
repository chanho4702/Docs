# 2. My Work — 내 작업 화면

## 🔐 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 (`/myWork`) | **권한 불필요** — 사이드바에 항상 표시됩니다 |
| 워크로그 작성·수정·삭제 | **권한 불필요** (본인 데이터) |
| 다른 사람의 워크로그 | **수정·삭제 불가** — 작성자 본인만 가능(조회만) |

- 이 화면의 데이터는 서버에서 **본인 계정 기준으로만** 조회됩니다. 권한 세트와 무관하게 남의 기록이 보이거나 편집되지 않습니다.
- 목표 시간 계산에 쓰는 근무시간·공휴일 값은 전역 설정이라 별도 권한 없이 읽힙니다.

---

**언제 쓰나** — 로그인 후 기본으로 열리는 화면입니다. **내 작업 시간을 기록**하고, 이번 주/이번 달 얼마나 일했는지 확인할 때 씁니다.

> 워크로그는 **본인 데이터**라 별도 권한 없이 작성할 수 있습니다.

## 2.1 상단 요약 지표

화면 상단에 5개의 카드가 표시됩니다.

| 카드 | 의미 | 예시 |
|---|---|---|
| 이번 달 누적 작업 시간 | 이번 달 기록한 시간 / 목표 시간 | 125h 3m / 164h |
| 이번 주 누적 작업 시간 | 이번 주 기록한 시간 / 목표 시간 | 66h 45m / 40h |
| 오늘 작업 시간 | 오늘 기록한 시간 / 목표 시간 | 16h 52m / 8h |
| 담당 및 협업 이슈 수 | 내가 담당자 또는 협업자로 연결된 이슈 수 | 11 |
| 참여 프로젝트 수 | 내가 속한 프로젝트 수 | 2 |

### 목표 시간은 이렇게 계산됩니다

[설정 > 일반 설정](07-%EC%84%A4%EC%A0%95/cloudjira--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md)의 **1Day 근무 시간**(기본 `8h`, `1MD = 8h`)을 하루 기준으로 삼고, [휴일 관리](07-%EC%84%A4%EC%A0%95/cloudjira--09-%ED%9C%B4%EC%9D%BC-%EA%B4%80%EB%A6%AC.md)에 등록된 **공휴일과 주말을 제외한 근무일 수**를 곱합니다.

```
오늘 목표 = 1일 근무 시간 (예: 8h)
주 목표   = 이번 주 근무일 수 × 1일 근무 시간 (예: 5일 × 8h = 40h)
월 목표   = 이번 달 근무일 수 × 1일 근무 시간
```

## 2.2 My 프로젝트

내가 참여 중인 프로젝트가 카드로 나열됩니다. 상단 검색창으로 빠르게 찾을 수 있습니다.

각 카드에 표시되는 정보:

- 프로젝트 이름과 상태(예: `IN PROGRESS`)
- 시작일 / 종료일
- 내 **역할**(예: Data Engineer)과 **등급**(예: Mid-level)

> 역할·등급은 프로젝트 상세의 [인력 관리](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md) 탭에서 그 멤버에게 부여한 값이 그대로 표시됩니다. 값이 비어 있으면 프로젝트 관리자에게 지정을 요청하세요.

## 2.3 My 업무

내가 맡은 작업과 기록한 워크로그를 보는 영역입니다. 오른쪽 위 버튼으로 **캘린더 / 테이블** 뷰를 전환합니다.

### 캘린더 뷰

- **월간 / 주간** 보기 전환, `<` `오늘` `>` 로 기간 이동
- 날짜 칸에 그날 기록한 워크로그가 이슈 키·시간과 함께 표시됩니다

| 조작 | 결과 |
|---|---|
| 날짜 클릭 | 그 날짜로 워크로그(업무일지) 추가 창이 열립니다 |
| 이슈 클릭 | 해당 Jira 이슈로 이동 |
| 이벤트 클릭 | 이벤트 수정 |
| 워크로그를 다른 날짜로 **드래그** | 작업 일자가 변경됩니다(시작 시각·소요 시간은 유지) |
| 우측 위 **+ 일정 추가** | 워크로그 추가 창 열기 |

### 테이블 뷰

이슈 단위로 작업 현황을 표로 봅니다.

| 컬럼 | 설명 |
|---|---|
| 이슈 키 | Jira 이슈 키 (예: SAMPLE-50) |
| 요약 | 이슈 제목 |
| 상태 | 해야 할 일 / 진행 중 / 완료 |
| 담당자 | 이슈 담당자(Assignee) |
| 동료 | 함께 일하는 협업자 |
| 작업 시간 | 그 이슈에 누적된 작업 시간 (예: 11d, 2h 7m) |
| 기한 / 작업 일 | 이슈 기한 또는 워크로그 작업 일자 |
| 작업 | 부모 이슈는 **+ 추가**, 개별 워크로그는 **수정** |

- 이슈 왼쪽의 펼침(`>`) 아이콘을 누르면 그 이슈에 기록된 **개별 워크로그**가 날짜별로 펼쳐집니다.
- 부모 이슈 행의 **+ 추가**로 새 워크로그를, 개별 워크로그 행의 **수정**으로 기존 워크로그를 편집합니다. 수정 창 안의 **삭제** 버튼으로 지울 수 있습니다.

> **수정·삭제 권한:** 워크로그는 **작성자 본인만** 수정·삭제할 수 있습니다. 다른 사람이 쓴 워크로그는 버튼이 비활성화되어 조회만 됩니다.

> **동료(협업자)란?** Jira 이슈에 함께 저장되는 **협업자 목록**입니다. 담당자(1명)와 별개로 한 이슈를 함께 수행하는 사람을 여러 명 지정할 수 있고, 동료로 지정되면 그 사람의 My Work에도 "협업 이슈"로 집계됩니다. 자세한 내용은 [5.3 담당자·동료 관리](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--03-%EC%9E%91%EC%97%85-%EA%B4%80%EB%A6%AC.md#532-담당자동료-관리)를 참고하세요.

## 2.4 업무일지(워크로그) 추가하기

`+ 추가`, `+ 일정 추가`, 또는 캘린더의 날짜를 클릭하면 **업무일지 추가** 창이 열립니다. 입력 방식은 두 가지 탭입니다.

### 방법 1 — 시간 입력 (단건)

특정 날짜에 한 건을 기록합니다.

| 항목 | 필수 | 설명 |
|---|---|---|
| 프로젝트 정보 | | 대상 프로젝트 (자동 표시) |
| 업무 | ✅ | 워크로그를 기록할 이슈 선택 |
| Worklog 작성자 | | 작성자 (미지정 시 "할당되지 않음") |
| 담당자 / 동료 | | 선택한 이슈의 담당자·협업자 표시 |
| 날짜 | ✅ | 작업한 날짜 |
| 시작 시간 | ✅ | 작업 시작 시각 |
| 소요 시간 | ✅ | Jira 표준 형식 — `8h`, `1d`, `30m`, `1d 4h` |
| 업무 설명 | | 마크다운 서식 편집기 |

> **업무 설명 편집기**는 제목·목록·인용·링크·코드 블록 등 마크다운 서식을 지원하며, 내용은 Jira 워크로그에 ADF 형식으로 저장됩니다.

### 방법 2 — 기간 입력 (일괄)

날짜 범위에 대해 워크로그를 **한 번에 여러 건** 생성합니다.

| 항목 | 필수 | 설명 |
|---|---|---|
| 업무 | ✅ | 대상 이슈 |
| 시작일 / 종료일 | ✅ | 기록할 기간 |
| 하루 시작 시간 / 종료 시간 | ✅ | 매일 적용할 근무 시간대 (예: 09:00~17:00) |
| 주말 제외 | | 토·일 제외 |
| 공휴일 제외 | | [휴일 관리](07-%EC%84%A4%EC%A0%95/cloudjira--09-%ED%9C%B4%EC%9D%BC-%EA%B4%80%EB%A6%AC.md)에 등록된 휴일 제외 |
| 연차/휴가 제외 | | 연차·휴가일 제외 |
| 업무 설명 | | 상세 내용 |

- 입력값에 따라 하단에 **"워크로그 N개 생성 · 하루 8h · 총 8.0h"** 처럼 결과가 미리 표시됩니다.
- **일괄 생성이 중간에 실패하면 이미 만든 것까지 모두 취소(롤백)** 됩니다. 일부만 기록된 상태가 남지 않습니다.

마지막에 **추가**로 저장, **닫기**로 취소합니다.

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 목표 시간이 예상과 다릅니다 | [일반 설정](07-%EC%84%A4%EC%A0%95/cloudjira--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md)의 1Day 근무 시간과 [휴일 관리](07-%EC%84%A4%EC%A0%95/cloudjira--09-%ED%9C%B4%EC%9D%BC-%EA%B4%80%EB%A6%AC.md)의 공휴일 등록 상태를 확인하세요 |
| 워크로그 수정 버튼이 눌리지 않습니다 | 다른 사람이 작성한 워크로그입니다. 작성자 본인만 수정할 수 있습니다 |
| My 프로젝트에 프로젝트가 안 보입니다 | 그 프로젝트의 [인력 관리](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md)에 본인이 등록돼 있어야 합니다 |
| 이슈 목록에 내 작업이 없습니다 | 담당자 또는 동료로 지정돼 있어야 합니다 |
