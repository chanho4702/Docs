# Dashboard 프로젝트 삭제 실패 처리 감사 후속

기능 감사에서 확인된 P1 위험을 해결한다. Dashboard에서 프로젝트 삭제 요청이 실패·부분 완료·비동기 재시도 상태일 때 UI와 cache가 잘못된 성공 상태를 표시하거나 사용자를 막지 않는지 조사하고 최소 범위로 보완한다.

- 삭제 invoke 응답과 error 경로를 확인한다.
- 낙관적 cache 변경·modal 닫힘·toast·refetch의 순서를 검증한다.
- retryable deletion 상태 및 실패 응답 계약을 소비하는 화면을 식별한다.
- 영향 범위, 응답 계약, 테스트 계획을 문서화한다.
