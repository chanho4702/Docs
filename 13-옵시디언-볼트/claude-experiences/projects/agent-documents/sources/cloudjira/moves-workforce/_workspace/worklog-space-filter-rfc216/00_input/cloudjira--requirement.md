# RFC-216 워크로그 생성 스페이스 필터

사용자 요청: RFC-213~215 완료 후, 워크로그 생성 시 나에게 할당된 이슈를 선택하는 목록에 스페이스 필터 추가. 앞선 작업의 커밋 요청을 이어 RFC-216도 검증 후 별도 커밋한다. 푸시·배포는 하지 않는다.

기본은 전체 스페이스, 선택 시 해당 Jira 스페이스에 속한 할당 이슈만 조회한다. 기존 사용자/할당자 범위와 권한을 넓히지 않는다. 필터 해제, 검색, 페이지 이동, 빈 결과, 실패, 선택된 이슈 전환 및 생성/수정의 공유 소비자를 확인한다.

스페이스 후보 출처와 서버 필터/페이지 계약은 실제 코드를 조사해 확정한다. 필터링 후 일부 페이지만 남겨 결과를 누락시키지 않는다. 기존 공용 필터와 queryKey 팩토리를 재사용한다. 시간 입력·저장 API·기존 편집 의미는 변경하지 않는다.

시작 HEAD: `9f8aaf5`. 이전 협업모드 미커밋 변경과 PPT/custom-scopes/LeaderTeamBackfill은 제외·보존한다. 현재 staged 파일은 없다.
