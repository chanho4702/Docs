# 4. 프로젝트 관리

## 🔐 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 메뉴 노출 (`/project`) | **권한 불필요** — 사이드바에 항상 표시됩니다 |
| **프로젝트 목록** 탭 | `PROJECT` 읽기 (없으면 탭이 보이지 않습니다) |
| 프로젝트 추가·수정·삭제 | `PROJECT` 쓰기 |
| **칸반 보드** 탭 | `KANBAN` 읽기 |
| 칸반 카드 드래그·컬럼 추가·삭제 | `KANBAN` 쓰기 |

- 두 탭은 **권한이 서로 다릅니다.** `PROJECT`만 있으면 목록만, `KANBAN`만 있으면 칸반만 보입니다.
- 보이는 프로젝트 **범위**는 권한 세트의 조회 범위(`ALL` / `MEMBER_ONLY` / `TEAM_ONLY`)를 따릅니다 — [1.4 참고](cloudjira--01-%EA%B0%9C%EC%9A%94.md#14-권한의-기본-개념--세-가지만-기억하세요).

---

**언제 쓰나** — 프로젝트를 **만들고, 상태를 관리하고, 상세로 진입**하는 출발점입니다.

좌측 **프로젝트 관리** 메뉴로 진입하며 상단에 두 탭이 있습니다: **프로젝트 관리**(목록), **칸반 보드**.

> **조회 범위 주의:** 권한 묶음의 조회 범위가 "소속 프로젝트만"이면 목록·칸반·상세 모두 **내가 인력으로 등록된 프로젝트만** 표시됩니다([1.4 참고](cloudjira--01-%EA%B0%9C%EC%9A%94.md#14-권한의-기본-개념--세-가지만-기억하세요)).

## 4.1 프로젝트 목록

| 컬럼 | 설명 |
|---|---|
| 프로젝트 이름 | 클릭 시 [프로젝트 상세](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--README.md)로 이동 |
| 프로젝트 상태 | 예: To Do / IN PROGRESS / DONE ([7.7에서 정의](07-%EC%84%A4%EC%A0%95/cloudjira--07-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%ED%83%9C-%EA%B4%80%EB%A6%AC.md)) |
| 시작일 / 종료일 | 프로젝트 기간 |
| 프로젝트 비용 | 프로젝트 등록 시 입력한 예산값. 급여 정책으로 계산하는 **계획 인건비와는 별개** |
| 추가 작업 | 수정 / 삭제 |

- 상단 **프로젝트 이름** 입력 후 **검색**으로 필터링, 새로고침 아이콘으로 목록 갱신
- 우측 위 **+ 프로젝트 추가**로 새 프로젝트 등록

### 프로젝트 추가 / 수정

| 항목 | 필수 | 설명 |
|---|---|---|
| 프로젝트 이름 | ✅ | |
| 프로젝트 상태 | ✅ | 프로젝트 상태 관리에서 정의한 값 중 선택 |
| 시작일 | ✅ | |
| 종료일 | ✅ | |
| 프로젝트 비용 | ✅ | 숫자(천 단위 콤마 자동). 비용 분석의 계획 인건비와는 별개 |

> 수정 모드에서는 생성자/생성일시·수정자/수정일시가 읽기 전용으로 함께 표시됩니다.

> ⚠️ **기간 입력을 빠뜨리지 마세요.** 프로젝트 시작일·종료일이 없으면 **인건비 환산(투입 개월수)과 진척률 계산이 모두 0**이 됩니다([5.2](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md#인건비가-0원으로-나올-때), [5.5](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--05-%EB%B6%84%EC%84%9D-%EB%B0%8F-%EB%A6%AC%ED%8F%AC%ED%8A%B8.md#554-진척률--일정-대비-진짜로-얼마나-끝났나) 참고).

## 4.2 칸반 보드

프로젝트를 **상태 컬럼별 카드**로 보여주며 드래그로 상태를 바꾸는 보드입니다.

- **컬럼 = 프로젝트 상태**([프로젝트 상태 관리](07-%EC%84%A4%EC%A0%95/cloudjira--07-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%ED%83%9C-%EA%B4%80%EB%A6%AC.md)에서 정의한 순서)
- **카드 = 프로젝트**(프로젝트명, 기간, 담당 아바타)

| 하고 싶은 일 | 조작 |
|---|---|
| 상태 변경 | 카드를 다른 컬럼으로 **드래그** (즉시 반영) |
| 프로젝트 수정 | 카드 클릭 → 추가/수정 모달 |
| 이름만 빠르게 변경 | 카드 제목 **인라인 편집** |
| 프로젝트 삭제 | 카드 메뉴 → 삭제 |
| 상태 컬럼 추가 | 우측 끝 **+** 버튼 |
| 상태 이름 변경 | 컬럼 헤더 인라인 수정 |
| 상태 삭제 | 컬럼 메뉴 → 삭제 (최소 1개 필요, 이전 상태가 있어야 가능) |
| 그 상태로 프로젝트 신규 등록 | 각 컬럼 하단 **+ 프로젝트 추가** |
| 과거 프로젝트 더 보기 | 마지막(완료) 컬럼 하단 **더보기** |

> 쓰기 권한(`KANBAN` write)이 없으면 드래그·추가·삭제·이름 변경이 비활성화되고 **조회만** 가능합니다.
