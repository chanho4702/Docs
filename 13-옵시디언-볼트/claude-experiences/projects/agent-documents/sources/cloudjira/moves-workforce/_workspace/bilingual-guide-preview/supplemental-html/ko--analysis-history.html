작업이 이 프로젝트에 언제 누구에 의해 편입됐는지와 이후 변경 이력을 확인합니다. 등록일·등록자는 자동 기록되는 읽기 전용 값이며, 자동 편입 이슈는 등록자가 "구독" 으로 표시됩니다.

버튼·입력 항목과 처리 결과 상세

편입 이력은 Jira 이슈 생성 시점과 앱 프로젝트에 들어온 시점을 구분합니다.

버튼·입력 항목 기능·사용 조건·변경 대상 결과 확인과 문제 대응
등록 이력 검색·필터·페이지 필터는 등록 이력 표에 적용됩니다. 상단 번업·인사이트는 프로젝트 전체 기준을 유지합니다. 필터 후 표와 차트 합계가 같아야 한다고 가정하지 않습니다.
편입 날짜·등록자·번업 앱에 연결될 때 저장된 날짜·등록자를 보고 범위 확대를 해석합니다. 추적 정보 없는 과거 이슈는 정확한 편입일을 알 수 없을 수 있습니다. 추적 없음 안내를 Jira 생성일로 자동 치환하지 않습니다. 큰 프로젝트의 집계 범위 제한도 확인합니다.
