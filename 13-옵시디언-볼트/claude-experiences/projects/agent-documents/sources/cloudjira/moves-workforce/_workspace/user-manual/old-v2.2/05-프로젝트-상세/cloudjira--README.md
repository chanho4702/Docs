# 5. 프로젝트 상세

## 🔐 접근 권한

프로젝트 상세는 **탭마다 권한이 다릅니다.** 권한이 없는 탭은 목록에 나타나지 않습니다.

| 탭 / 서브탭 | 조회 | 편집(쓰기) |
|---|---|---|
| **대시보드** | `DASHBOARD` 읽기 | `DASHBOARD` 쓰기 (차트 추가·레이아웃) |
| **인력 관리** > 인력 목록 | `PROJECT` 읽기 | `PROJECT` 쓰기 또는 `RESOURCE_MANAGEMENT` 쓰기 |
| **인력 관리** > 급여 관리 | `PROJECT_COST` 읽기 | `PROJECT_COST` 쓰기 |
| **인력 관리** > 작업 배정 | `PROJECT` 읽기 또는 `RESOURCE_MANAGEMENT` 읽기 | `PROJECT` 쓰기 또는 `RESOURCE_MANAGEMENT` 쓰기 |
| **작업 관리** (목록·트리·간트) | `PROJECT` 읽기 | `PROJECT` 쓰기 |
| **프로젝트 캘린더** | `PROJECT` 읽기 | — |
| **분석 및 리포트** > 작업·인력 분석 | `REPORT` 읽기 | — |
| **분석 및 리포트** > 팀 | `REPORT` 읽기 **+** `PROJECT` 읽기 | — |
| **분석 및 리포트** > 진척률 | `REPORT` 읽기 | — |
| **분석 및 리포트** > 비용 | `PROJECT_COST` 읽기 | — |
| **분석 및 리포트** > 작업 이력 | `PROJECT` **쓰기** (탭 노출 조건) | — |

- **프로젝트 상세에 진입하는 것 자체**는 `PROJECT` 읽기와 조회 범위 통과가 전제입니다. 범위 밖 프로젝트는 URL로 접근해도 거부됩니다.
- 총 인건비·급여·비용은 `PROJECT_COST`가 없으면 **0원이 아니라 항목 자체가 사라집니다.**
- 작업 관리의 편집은 앱 권한 외에 **Jira 자체 권한**(이슈 편집·일정 변경·담당자 지정·이슈 연결)도 필요합니다.

---

프로젝트 목록이나 칸반에서 프로젝트를 클릭하면 상세 화면(`/project/:id`)으로 이동합니다.
