# Jira 이슈 패널

[가이드 홈](cloudjira--index.md) · [English](../en/cloudjira--issue-panel.md)

> 검토 초안: staging의 Jira 이슈 화면에서 패널 제공 여부를 확인해야 합니다.

설치된 앱 버전이 Jira 이슈 패널을 제공한다면 앱 프로젝트에 연결된 이슈에서 계획 작업량·실제 투입을 확인하고 워크로그를 기록할 수 있습니다. 패널이 보이지 않으면 **Jira → 앱 → Moves Workforce → My Work**에서 시간을 기록하고 프로젝트 화면에서 결과를 확인합니다.

## 필요한 조건

- Jira에서 해당 이슈를 볼 수 있어야 합니다.
- 워크로그 작성에는 Work On Issues와 시간 추적 활성화가 필요합니다.
- 본인 기록 수정·삭제에는 각각 Edit Own Worklogs·Delete Own Worklogs가 필요합니다.
- 프로젝트 이름과 앱 이동 링크에는 앱의 프로젝트 권한과 조회 범위가 적용됩니다.

## 사용 순서

1. 앱 프로젝트에 연결된 Jira 이슈를 엽니다.
2. **Moves Workforce** 컨텍스트 패널에서 요약을 확인하거나 활동 탭에서 상세를 엽니다.
3. 날짜·시작·종료·소요 시간을 확인하고 작업 내용을 입력합니다.
4. 저장 후 최근 워크로그 목록과 KPI를 확인합니다.
5. 고칠 내용이 있으면 본인 항목의 수정·삭제를 사용합니다.

> 이미지 후보 IMG-17: Jira 이슈의 요약 패널과 활동 탭 위치. 예시 이슈를 사용합니다.

## 지표와 제한

계획 작업량은 Jira 추정 시간, 투입 공수는 워크로그를 기준으로 합니다. **내 몫**은 본인이 기록한 시간이며 최근 기록만 조회하는 화면에서는 근사치입니다. 목록에 전체 기록이 보인다고 가정하지 마세요.

패널에서 저장한 워크로그는 Jira 및 My Work와 같은 기록입니다. 활동 탭에서 기록했다고 별도의 복사본이 만들어지지는 않습니다.

## 패널이 없거나 안내만 보일 때

| 상태 | 조치 |
|---|---|
| 패널이 없음 | 앱 프로젝트 연결과 패널이 포함된 설치 버전을 확인 |
| 기록 권한 안내 | 해당 이슈의 Jira 권한과 시간 추적 확인 |
| 프로젝트 링크가 없음 | 앱의 프로젝트 읽기 권한·조회 범위 확인 |
| 내 몫 확인 불가 | 워크로그 조회 오류·부분 목록 안내 확인 |
| 라이선스 안내 | 관리자에게 앱 라이선스 상태 확인 요청 |

## 버튼·입력 항목과 처리 결과 상세

Jira 이슈 화면의 패널은 설치 버전과 프로젝트 연결·표시 조건에 따라 나타납니다. 아래는 패널이 제공되는 경우의 사용 설명입니다.

| 버튼·입력 항목 | 기능·사용 조건·변경 대상 | 결과 확인과 문제 대응 |
|---|---|---|
| 작업 시간 입력·날짜·시작·종료·설명 | 현재 이슈에 Jira 워크로그를 등록합니다. 종료가 시작보다 뒤여야 하며 Work On Issues와 시간 추적이 필요합니다. | 저장 성공과 최근 기록을 확인합니다. 같은 업무를 My Work에서 다시 기록하지 않습니다. |
| 입력 초기화·기록 수정·삭제 | 초기화는 입력값을 되돌립니다. 본인 기록 수정·삭제는 각각 Jira 권한을 필요로 하며 삭제는 원본 기록을 제거합니다. | 설명 조회 실패 시 저장하지 않고 다시 불러옵니다. 지원하지 않는 원문 설명은 날짜·시간만 수정하며 원문을 보존할 수 있습니다. |
| 프로젝트 요약·앱에서 열기 | 현재 이슈의 연결 프로젝트와 허용된 KPI를 확인하고 전체 앱으로 이동합니다. | 연결 없음·조회 실패·라이선스 안내를 구분합니다. 패널이 없으면 Jira Apps → My Work와 프로젝트 화면에서 확인합니다. |
