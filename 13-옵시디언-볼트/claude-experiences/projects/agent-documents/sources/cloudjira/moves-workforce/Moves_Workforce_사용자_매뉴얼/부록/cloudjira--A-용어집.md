# 부록 A. 용어집

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 이 페이지 | **권한 불필요** — 용어 설명 문서입니다 |

---

| 용어 | 의미 |
|---|---|
| 워크로그 / 업무일지 | 특정 이슈에 기록하는 작업 시간 항목. Jira 워크로그와 같은 데이터 |
| 담당자(Assignee) | 이슈를 책임지는 사람(1명) |
| 동료(coworker) | 이슈를 함께 수행하는 협업자. 이슈 단위로 여러 명 지정 가능 |
| 역할(Role) | 인력의 직무 (Data Engineer 등) |
| 등급(Level) | 인력 레벨 (Junior / Mid-level / Senior / Lead 등) |
| MD (Man-Day) | 작업량 단위. 1 MD = 한 사람이 하루(= 1Day 근무 시간, 기본 8h) 동안 하는 일의 양 |
| MM (Man-Month) | 인월. MM = MD ÷ (1MM 근무일 수) |
| 1Day 근무 시간 | `1MD`에 해당하는 시간([일반 설정](../07-%EC%84%A4%EC%A0%95/cloudjira--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md), 기본 8h) |
| 가동률 | 실제 일한 양(MD) ÷ 일할 수 있었던 양(근무일 − 연차·공휴일). 1.0 = 100% |
| 실효 가용 MD | 기간 근무일에서 연차·공휴일을 뺀 실제 출근 가능 일수. 가동률의 분모 |
| 완성 진척 | 계획공수 가중 진행률. "얼마나 끝났나" |
| 일정 진척 | 경과 근무일 ÷ 전체 근무일. "시간이 얼마나 흘렀나" |
| 공수 진척 | 워크로그 누적 공수 소진. "얼마나 일했나" |
| 처리율 | 작업의 진행 정도(%). Jira 시간 추적(기록 시간·잔여 추정) 기반 |
| 계획 작업량 | Jira Original Estimate 기반 계획 공수(MD) |
| 내 몫 | 여러 명이 참여한 이슈에서 한 사람에게 귀속되는 부분. 화면에 따라 **내가 기록한 워크로그**(이슈 패널) 또는 **남은 작업량의 균등 분할**(인력 현황)로 계산되는 근사치 |
| 확정 지연 | 완료된 이슈의 (실적일 − 기한) 평균. 회고 지표 |
| 예측 지연 | 남은 공수 추세로 본 예상 종료일 − 종료 예정일. 예보 지표(낙관 근사치) |
| 총 인건비 | 참여 인력의 급여 기준으로 산정된 프로젝트 인건비 합계 |
| 급여 정책 | 인원별(개인 금액) 또는 등급 기반(등급 대표값) |
| 투입 급여 | 특정 프로젝트에 그 사람을 쓰는 데 잡는 금액 |
| 등급 급여 밴드 | 등급별 하한·상한·대표값. **대표값**이 계산에 쓰임 |
| 투입 개월수 | 총 달력일수 ÷ 30.4375. 연봉 환산의 기준 |
| 미산정 인원 | 인건비가 0원으로 계산된 인원 |
| 담당 팀 | 프로젝트의 계획·책임 팀. 실제 인력 명단과 별개 |
| 팀장 | 팀을 이끄는 사람. **반드시 그 팀 소속**이며 한 사람이 한 팀만 이끕니다 |
| 팀 권한 상속 | 개인 권한 대신 소속 팀(없으면 상위 팀)의 권한 세트를 따르는 설정 |
| 프로젝트 조회 범위 | 전체 프로젝트 / 소속 프로젝트만 / 내 팀만 — 권한 세트가 볼 수 있는 프로젝트 범위 |
| 상위 지정(WBS) | 앱이 저장하는 작업 계층. Jira 3단계 제약 없이 중첩 가능 |
| 폴더 | 간트·트리·맵의 앱 전용 작업 묶음. Jira에는 없음 |
| 선후행 | 작업 간 의존 관계. Jira 이슈 링크(Blocks)로 저장 |
| 마일스톤 | 시작일과 종료일이 같은 작업. 간트에서 마름모로 표시 |
| 계층 보기 / 평면 보기 | 작업 목록에서 Jira 상위–하위로 묶어 보기 / 한 줄씩 나열 |
| 일괄 적용 | 목록에서 선택한 여러 작업에 시작일·기한·계획 작업량을 한 번에 넣는 기능 |
| 맵 보기 | 프로젝트 → 폴더 → 작업을 위에서 아래로 그린 읽기 전용 조직도 |
| 프로젝트 구독 / 자동 편입 | Jira 스페이스 조건에 맞는 이슈를 자동 편입하는 규칙 |
| 백필 | 구독 설정 시 기존 이슈를 소급해 가져오는 처리 |
| 소유권 | 이슈는 앱 프로젝트 하나에만 속함. 다른 프로젝트로 가져가면 공수·비용도 함께 이동 |
| 토폴로지 | 프로젝트–스페이스–상태–이슈(전사) 또는 이슈–하위–연결(프로젝트)을 그린 관계망 위젯 |
| 커스텀 필터 위젯 | 담당자·상태·타입·우선순위·기한·계획 공수 조건을 직접 지정해 이슈를 모아 보는 대시보드 위젯 |
| 적합도 | 프로젝트 필요 스킬 대비 인력 보유 스킬의 일치 정도 |
| 스페이스 | Jira 프로젝트. 이 앱의 "프로젝트"와 구분하기 위한 표현 |
| 딥링크 / 링크 복사 | 탭·보기까지 담긴 화면 주소. 링크 복사 버튼으로 복사해 공유 |
| 이슈 패널 | Jira 이슈 화면의 활동 탭·컨텍스트 패널에 나타나는 Moves Workforce 영역 |

> 전사 공통 용어 정의는 [용어집 문서](../../cloudjira--Moves_Workforce_%EC%9A%A9%EC%96%B4%EC%A7%91.md)를 함께 참고하세요.
