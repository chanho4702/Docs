# 용어집

[가이드 홈](cloudjira--index.md) · [English](../en/cloudjira--glossary.md)

> 검토 초안: 지정된 staging 환경의 실제 화면·배포 버전 확인 전입니다.

두 언어의 가이드에서 같은 뜻으로 사용하는 용어입니다. 영어 UI는 배포 버전에 따라 일부 표현이 다를 수 있어 실제 메뉴를 함께 확인합니다.

| 한국어 | English | 의미 |
|---|---|---|
| 앱 프로젝트 | Moves Workforce project | 인력·작업·기간·예산을 묶는 앱의 관리 단위 |
| Jira 스페이스 | Jira space / project | Jira 이슈가 속한 공간. 앱 프로젝트와 별개 |
| 작업 / 이슈 | Work item / issue | 프로젝트에 연결해서 관리하는 Jira 이슈 |
| 워크로그 / 업무일지 | Worklog | 이슈에 기록한 작업 날짜·시간·내용 |
| 담당자 | Assignee | Jira 이슈의 책임자 한 명 |
| 동료 / 협업자 | Coworker / collaborator | 이슈를 함께 수행하도록 지정한 사람 |
| 담당 팀 | Responsible team | 프로젝트의 책임 조직. 인력 등록과 별개 |
| 프로젝트 인력 | Project member | 앱 프로젝트에 참여자로 등록된 사람 |
| 역할 | Role | 직무 분류 |
| 등급 | Level | 조직의 인력 수준 분류 |
| MD | Person-day | 작업 시간 ÷ 조직의 1일 근무시간. 기존 표기 Man-Day와 같은 단위 |
| MM | Person-month | MD ÷ 해당 화면의 1MM 기준 근무일 수. 기존 표기 Man-Month와 같은 단위 |
| 실효 가용 MD | Effective available MD | 기간 중 실제 근무 가능량 |
| 가동률 | Utilization | 투입 MD를 실효 가용 MD로 나눈 비율 |
| 계획 작업량 | Planned effort | Jira Original Estimate에 기반한 계획 공수 |
| 완성 진척 | Completion progress | 계획 공수를 가중치로 고려한 완료 정도 |
| 일정 진척 | Schedule progress | 프로젝트 근무 기간 중 경과한 비율 |
| 공수 소진 | Effort consumption | 실제 기록한 공수의 누적 |
| 프로젝트 예산 | Project budget | 프로젝트에 직접 입력한 금액 |
| 인건비 | Labor cost | 급여 정책과 투입 조건으로 계산한 금액 |
| 투입 급여 | Project allocation amount | 해당 프로젝트에 지정한 개인의 금액 |
| 등급 급여 밴드 | Level salary band | 등급의 하한·상한·대표 금액 |
| 내 몫 | My share | 화면별 정의가 다름. 이슈 패널은 본인 기록, 자원 현황은 배분 근사치일 수 있음 |
| 상위 지정 / WBS | Work breakdown structure | 작업의 상하위 구조 |
| 폴더 | Folder | 앱에서 작업을 묶는 단위 |
| 선후행 | Dependency | 작업 간 선행·후행 관계 |
| 마일스톤 | Milestone | 일정에서 강조하는 같은 날 시작·종료 작업 |
| 구독 / 자동 편입 | Subscription / automatic inclusion | 조건에 맞는 Jira 이슈를 프로젝트에 연결하는 규칙 |
| 스킬 적합도 | Skill match | 필요 스킬과 보유 스킬의 일치 정도 |
| 프로젝트 조회 범위 | Project visibility scope | 사용자가 볼 수 있는 앱 프로젝트의 범위 |
| 팀 권한 상속 | Team permission inheritance | 소속 팀 또는 상위 팀의 권한 세트를 따르는 방식 |

MD·MM은 조직 설정에 따라 환산합니다. 예시의 8시간이나 월 근무일 수를 모든 고객의 고정값으로 사용하지 않습니다. 비율의 차이는 `%p`(percentage points)로 표현합니다.
