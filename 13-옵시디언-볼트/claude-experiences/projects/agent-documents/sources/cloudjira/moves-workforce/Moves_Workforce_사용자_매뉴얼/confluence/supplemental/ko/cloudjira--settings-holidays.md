## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 메뉴 노출 (사이드바) | 「권한 관리」 읽기 |
| 휴일 추가·수정·삭제 | 「휴일 관리」 쓰기 |
| 휴일 목록 자체 | 전역 공개 — 근무일 계산에 쓰이므로 모든 화면에서 읽힙니다 |

> **알려진 불일치:** 메뉴 노출과 편집 판정이 서로 다른 항목을 씁니다. 「휴일 관리」만 가진 사용자는 **사이드바에 메뉴가 보이지 않아** 휴일 관리 화면 주소로 직접 접근해야 합니다(관리자에게 링크 복사를 요청하세요).


**언제 쓰나** — 근무일·가용 MD 계산의 기준이 되는 **공휴일**을 등록할 때.

> **[이미지 삽입 위치 · 추가 캡처 필요]** 휴일 관리 — ① 월별 1MM 기준(자동 계산) ② 휴일 표(이름·날짜·가용률) ③ 휴일 추가.


## 목록 컬럼

| 컬럼 | 설명 |
|---|---|
| 이름 | 예: 설날 |
| 날짜 | 휴일 날짜 |
| 가용률 | 그날의 근무 가능 비율 |
| 작업 | 수정·삭제 |

**휴일 추가**로 이름·날짜·가용률을 입력해 등록합니다.

## 가용률 이해하기

| 값 | 의미 | 차감 |
|---|---|---|
| 0 | 완전 휴무 | **1 MD 차감** |
| 0.5 | 반일 근무 | **0.5 MD 차감** |
| 1 | 정상 근무 | 차감 없음 |

## 계산 규칙

- **주말(토·일)에 등록된 공휴일은 가용 MD 차감에서 제외됩니다.** 기준 작업일(월 기준 MD)이 이미 주말을 빼고 있기 때문입니다.
- **개인 휴가는 별도로 반영**됩니다 — 연차 1일당 1 MD, 반차 0.5 MD 차감, '기타'(가용률 1)는 차감 없음.

## 월별 1MM 기준

상단에 공휴일과 평일을 기준으로 **자동 계산된 월별 1MM(근무일/시간)** 이 표시됩니다. 휴일을 등록·수정하면 **즉시 반영**됩니다.

## 버튼·입력 항목과 처리 결과 상세

휴일은 근무 가능 비율과 월별 MM 계산에 반영됩니다. 개인 휴가 일정과 조직 휴일은 다른 데이터입니다.

| 버튼·입력 항목 | 기능·사용 조건·변경 대상 | 결과 확인과 문제 대응 |
|---|---|---|
| 연도 선택·월별 1MM 표 | 해당 연도의 휴일과 평일을 기준으로 월별 근무일·시간을 확인합니다. 월별 1MM은 자동 계산 결과입니다. | 1MM을 임의 상수로 입력하는 것으로 가정하지 않습니다. 연도와 1일 근무시간을 함께 확인합니다. |
| 휴일 추가·이름·날짜·근무 비율 | 조직 휴일의 날짜와 근무 가능 비율을 정합니다. 0=종일 휴무, 0.5=반일 가용, 1=정상 근무일입니다. | 중복 날짜·이름 안내를 확인하고 저장합니다. 근무 비율을 실제 기록 시간으로 해석하지 않습니다. |
| 수정·삭제·월 기준 확인 | 수정·삭제는 해당 조직 휴일 기준을 변경하고 월 근무일 계산에 영향을 줍니다. | 저장 후 휴일 목록·월별 MM 표를 확인합니다. 집계 기반 목표·가동률은 집계 시각도 확인합니다. |
