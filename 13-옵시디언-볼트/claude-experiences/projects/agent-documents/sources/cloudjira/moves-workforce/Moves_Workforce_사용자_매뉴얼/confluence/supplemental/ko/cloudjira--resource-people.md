## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | 「자원관리」 읽기 |
| 인력 상세 드로어 | 「자원관리」 읽기 |
| 보유 스킬 편집 | 「자원관리」 쓰기 (자기 팀원에 한해 **팀장**도 가능) |

- 보이는 인원은 관리자·PMO·PM이면 전사, **팀장이면 자신이 이끄는 팀 인원**입니다.
- 스킬 선택지는 [7.6 스킬 관리](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/173408343)에서 「스킬 관리」 권한으로 정의합니다.


**언제 쓰나** — **개인 단위로** 누가 바쁘고 누가 여유인지, 어떤 스킬을 가졌는지 확인할 때.

> **[이미지 삽입 위치 · 추가 캡처 필요]** 인력 현황 — ① 요약 카드(총 인원·여유·적정·과부하)와 마지막 집계 ② 필터(스킬·직무·등급·팀·직군·투입가능만) ③ 인력 표(가동률 밴드·완수율·작업량) ④ 행 클릭으로 열린 인력 상세 드로어.


## 상단 요약

**총 인원 · 여유 · 적정 · 과부하** 카드와 **마지막 집계** 시각이 표시됩니다.

> 가동률은 **배치 집계** 값입니다. 방금 등록한 인원이나 방금 쌓인 워크로그는 다음 집계 전까지 반영되지 않습니다. "집계 데이터가 오래되었습니다" 안내가 뜨면 그 시점 기준으로 해석하세요.

## 목록 컬럼

| 컬럼 | 의미 |
|---|---|
| 인력 | 이름·아바타 |
| 팀 / 직무 / 등급 | 소속과 직무 정보 |
| 가동률 | 배치 집계 기준. 밴드(여유/적정/과부하 주의/과부하/실적없음)로 색 구분 |
| 완수율 | `소비시간 ÷ (소비 + 남은 작업량)`. **완료 상태이며 최근 26주 안에 수정된 이슈만** 집계 |
| 작업량 | 처리 / 남은 / 할당. 진행도 % = 처리 ÷ 할당 |
| 할당 이슈 | 담당·협업으로 연결된 이슈 수 |
| 참여 프로젝트 | 참여 중(미종료) 프로젝트 수 |
| 보유 스킬 | 등록된 스킬 태그 |

**필터**: 스킬 · 직무 · 등급 · 팀 · 직군 · **투입가능만**

> 가동률 밴드의 경계값(과소 / 과부하 / 심한 과부하)은 [7.1 일반 설정](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/173342802)에서 조정합니다.

## 인력 상세 드로어

행을 클릭하면 오른쪽에 상세가 열립니다.

| 구역 | 내용 |
|---|---|
| **부하** | 진행중 이슈 수, 남은 작업량(시간) |
| **진행 중 작업** | 이슈별 상태·프로젝트·마감·참여 형태(담당/협업)·**내 몫** |
| **경험** | 프로젝트 참여 이력(역할·기간·상태) |

> **"내 몫"은 근사치입니다.** 여러 명이 참여한 이슈는 남은 작업량을 **참여 인원으로 균등 분할**한 1인 기대 몫으로 계산합니다. 실제 분담 비율과 다를 수 있습니다.

## 스킬 편집

드로어의 **스킬 편집**으로 보유 스킬을 지정합니다(쓰기 권한 필요).

- 선택지는 [7.6 스킬 관리](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/173408343)에서 정의한 사전을 따릅니다.
- 여기 등록한 값이 [6.4 프로젝트 배정](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/173408318)의 **적합도** 계산에 쓰입니다.
- 본인 스킬은 [마이페이지](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/172326921)에서도 직접 편집할 수 있고, 팀장은 마이페이지의 **내 팀**에서 팀원 스킬을 편집할 수 있습니다.

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 가동률이 "데이터 없음"입니다 | 아직 집계 전이거나 해당 기간 워크로그 실적이 없습니다 |
| 일부 인원만 보입니다 | 팀장 권한이면 자신이 이끄는 팀 인원만 보입니다 |
| 스킬 필터에 원하는 스킬이 없습니다 | [7.6 스킬 관리](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/173408343)에서 사전에 먼저 등록해야 합니다 |
| 완수율이 낮게 나옵니다 | 완료 상태 이슈 중 **최근 26주 안에 수정된 이슈만** 집계합니다. 완료일이 아닌 수정일 기준입니다 |

## 버튼·입력 항목과 처리 결과 상세

인력 현황은 허용된 사람들의 현재 부하·스킬과 프로젝트 이력을 확인하는 조회 화면입니다.

| 버튼·입력 항목 | 기능·사용 조건·변경 대상 | 결과 확인과 문제 대응 |
|---|---|---|
| 역할·레벨·스킬·팀·하위 팀·가용만 | 필터를 조합해 후보를 좁힙니다. 가용만은 현재 가동률·부하 기준이며 계정 접근 범위를 넓히지 않습니다. | 전체 열람 또는 담당 팀 범위를 확인하고 필터를 풀어 결과를 비교합니다. |
| 이름·인력 상세·작업·경험 | 선택한 사람의 부하 요약, 진행 작업, 참여 프로젝트 이력을 엽니다. | 진행 작업의 분담 추정과 실제 워크로그를 구분합니다. 프로젝트 수는 종료 여부에 따라 다릅니다. |
| 스킬 편집·저장 | 허용된 대상의 보유 스킬만 변경합니다. 역할·급여·권한을 바꾸는 동작은 아닙니다. | 저장 후 대상 이름과 스킬 목록을 확인합니다. 사전 항목 추가는 설정에서 별도로 수행합니다. |
| 가동률·업무량·완료율 | 현재 부하 신호를 읽습니다. 자원 화면 완료율은 spent÷(spent+remaining) 기준이며 My Page의 이슈 개수 완료율과 다릅니다. | 완료 상태 작업은 최근 26주 안에 수정된 이슈를 대상으로 하며 완료일 기준 필터가 아닙니다. 공유 작업 분담 추정도 확인하고 업무량·생산성을 같은 의미로 해석하지 않습니다. |
