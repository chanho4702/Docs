# 그림 캡처 계획 — 한국어·영어 가이드

매뉴얼 본문의 `그림 N-M` 자리에 들어갈 화면 캡처 목록입니다. **파일명은 본문이 참조하는 이름 그대로** 저장해야 그림이 연결됩니다. 현재 목록은 51종이며 ★ 표시 후보는 27종입니다. 비교 화면을 합성하는 항목은 원본 캡처가 여러 장 필요할 수 있습니다.

> **준비 상태 (2026-10-04):** 이 폴더에는 아직 실제 화면 이미지가 없습니다. 아래 목록은 촬영 후보이며, 전체를 한 번에 준비할 필요는 없습니다. 문서에 사용할 기능과 배포 환경을 확인한 뒤 필요한 항목부터 요청합니다.

## 이미지가 필요한 기준

- 화면에서 버튼이나 영역의 위치를 찾기 어렵거나, 조작 전후의 차이를 보여줘야 하면 캡처를 사용합니다.
- 간트·차트·권한 설정처럼 글만으로 결과를 이해하기 어려운 화면은 핵심 영역을 보여줍니다.
- 단순한 입력 항목·용어·수치는 표와 예시로 설명합니다. 모든 절에 이미지를 넣지는 않습니다.
- 개념과 업무 흐름은 도식으로 설명할 수 있습니다. 실제 앱 화면을 설명할 때는 해당 환경에서 촬영한 캡처를 사용합니다.

## 한국어·영어 이미지 관리

- 한국어 UI 캡처는 기존 파일명을 유지해 이 폴더에 저장합니다. 영어 UI 캡처는 `en/` 하위에 같은 파일명으로 저장합니다. 실제 문서 위치에 맞춰 상대 경로를 연결합니다.
- 두 언어는 같은 앱 버전·데모 데이터·기간·권한으로 촬영합니다. 메뉴·버튼이 중요한 화면은 언어별 캡처를 사용합니다.
- 번호 표식은 이미지 안에서 공통으로 사용하고, 번호 설명·캡션·대체 텍스트는 각 문서의 언어로 작성합니다.
- 언어별 UI 표기는 `locales/kr/*.json`·`locales/en/*.json`을 참고하고 대상 환경의 실제 화면에서 확인합니다. 문서 번역 중 발견한 UI 번역 문제는 별도 수정 항목으로 기록합니다.
- 영어 캡처가 없으면 편집용 초안에만 미확보 상태를 표시합니다. 한국어 화면을 임시로 사용할 경우 한국어 UI임을 명시합니다.
- 이미지가 없는 초안에는 깨진 이미지 링크 대신 아래와 같은 캡처 요청을 적습니다. 공개할 때는 캡처를 넣거나, 이미지 없이 따라갈 수 있도록 본문을 완성한 뒤 요청 표시를 제거합니다.

## 캡처 요청 양식

문서 담당자가 아래 정보를 채워 요청합니다. 촬영자는 지정된 상태의 원본을 제공하면 됩니다. 개인정보가 포함된 원본은 공유 전에 가립니다.

> **이미지 필요: `02-worklog-modal-simple.png`**  
> 위치: My Work → 워크로그 기록 절차 다음  
> 목적: 시작·종료 시각을 입력하면 작업 시간이 계산되는 모습을 설명  
> 화면 상태: 데모 이슈 선택, 시작 09:00·종료 12:30 입력, 계산 결과 표시  
> 환경·권한: 문서 기준 사이트와 배포 버전, 일반 사용자, 본인 계정  
> 언어: 한국어·영어 UI 각각  
> 강조: ① 이슈 선택 ② 날짜 ③ 시작·종료 시각 ④ 계산 결과  
> 대체 텍스트: 워크로그 추가 창에 시작 09:00와 종료 12:30을 입력해 작업 시간 3시간 30분이 표시된 모습

## 공통 촬영 규칙

| 항목 | 규칙 |
|---|---|
| 환경 | 문서에서 설명하는 배포 버전과 일치하는 데모 환경. 실제 인명·급여·이메일이 보이면 공유 전에 **마스킹** |
| 브라우저 | 크롬, 창 폭 **1440px**, 배율 100%, Jira **라이트 테마**. 다크 모드는 그림 1-2에만 별도 |
| 사이드바 | 펼친 상태(그림 1-2 제외 시 접어도 무방하나 통일을 위해 펼침) |
| 계정 | 문서의 독자와 설명하는 권한에 맞는 계정 사용. 일반 사용자·팀장·관리자 화면을 구분하고, 전체 메뉴 소개처럼 Admin이 필요한 캡처에는 이를 명시 |
| 범위 | 화면 전체가 아니라 **설명 대상 영역만** 잘라내기. 브라우저 탭·주소창은 그림 1-3에만 포함 |
| 번호 표식 | 원본은 표식 없이 보관. 편집본에 ①②③ 번호를 겹치지 않게 배치하고 캡션 순서와 일치시킴 |
| 형식 | PNG, 폭 1440px 이하, 파일당 1MB 이하 |
| 파일명 | `장번호-슬러그.png` (아래 표). 대소문자 그대로 |
| 상태 | 로딩 스켈레톤·빈 상태가 아닌 **데이터가 채워진 상태**. 표는 5행 이상, 차트는 값이 보이게 |

**전체 화면 촬영을 위한 데모 데이터 예시**: 프로젝트 3개 이상(진행 중·지연·완료 각 1) · 인력 10명 이상(팀 2단계, 팀장 지정) · 워크로그가 최근 2주에 분포 · 계획 작업량이 있는 이슈 · 구독 1개 · 폴더가 있는 간트 · 필요 스킬이 있는 프로젝트 · 등급 급여 밴드. 처음에는 요청한 캡처에 필요한 데이터만 준비합니다.

## 검토 시 함께 볼 것

- 캡션의 번호와 이미지 표식이 어긋나면 대상 환경의 실제 화면을 기준으로 잘못된 쪽을 수정합니다. 표식만 틀렸다면 원본을 다시 촬영할 필요는 없습니다.
- 화면이 매뉴얼 설명과 다르면 버튼 이름·위치와 배포 버전을 확인합니다. 코드에만 있고 해당 환경에 없는 기능을 현재 제공 기능으로 설명하지 않습니다.
- Confluence에 올린 뒤 이미지가 표시되는지, 번호·캡션·대체 텍스트가 맞는지, 한국어·영어 페이지의 이미지가 올바르게 연결되는지 확인합니다.
- 다크 모드 확인용 캡처(1-2)를 제외한 모든 그림은 라이트 테마입니다.
