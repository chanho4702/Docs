Prepare scope and policy so users can complete their first approval. Verify the basic flow with a test page before adding PIN, delegation, or access restrictions.

Location: Confluence settings → Moves Approval, or approval inbox → Settings. Available to Confluence administrators and app settings administrators.

Setup order

Order Task Completion check
1 Verify installation Inbox, page approval dialog, and settings open.
2 Enable spaces The target pages are included.
3 Set global policy Deadlines, notifications, and rejection rules match your process.
4 Approval lines and groups Requesters can select them on actual pages.
5 Users and administrators Requesters, approvers, and operators can access the required functions.
6 Run the first approval Regular accounts complete the process end to end.
7 Data management Retention and an operations owner are defined.

Test with regular accounts

An administrator opening a screen does not prove users are ready. A requester needs an editable page; an approver needs a viewable page and an active turn. Also check that an account without access to a restricted page cannot see its request in the inbox.

Before requiring PINs, explain registration. Before restricting app access, include requesters in the user list. Before excluding a space, check open requests.

Ready for operation

  • The test page's order, status, version, and history match expectations.
  • Users understand in-app notices and optional comment notifications.
  • You decided whether to include stamp boxes in templates.
  • Owners for support and retained-record cleanup are assigned.
