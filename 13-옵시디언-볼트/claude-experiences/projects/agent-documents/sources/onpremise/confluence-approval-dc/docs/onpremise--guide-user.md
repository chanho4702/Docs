# 승인(결재) 사용자 가이드

DMOVE Approvals는 Confluence 페이지와 페이지 안의 특정 콘텐츠 영역에 **결재 절차**를 붙여 주는 앱입니다. 문서를 다른 도구로 옮기지 않고 Confluence 페이지 그대로 승인을 올리고, 지정된 결재자가 순서대로 승인하거나 반려하며, 그 결과가 페이지 상단의 상태 표시와 **승인 업무함**에 남습니다. 이 문서는 결재를 올리는 사람과 승인·반려하는 사람을 위한 사용 안내입니다. 관리자 설정 항목은 다루지 않습니다.

## 1. 승인은 어디에 보이나요

### 페이지 전체를 결재하는 경우

승인이 적용된 스페이스의 페이지를 열면, 페이지 제목 위 영역에 **상태 pill**이 하나 표시됩니다. 아직 요청이 없으면 `승인 요청 없음`으로 보입니다.

```
┌───────────────────────────────────────────────┐
│  [ ● 승인 대기 · 1 / 3단계 진행 중 ]           │  ← 상태 pill (클릭하면 상세 모달)
│                                               │
│  페이지 제목                                   │
└───────────────────────────────────────────────┘
```

페이지를 편집할 권한이 있으면 페이지 상단 액션에 **`승인 요청`** 버튼이 함께 나타납니다.

한 페이지에는 열려 있는 승인 요청을 **한 번에 하나만** 만들 수 있습니다.

### 페이지 안의 특정 게시글(영역)만 결재하는 경우

본문에 `approval-region` 매크로를 넣고 결재받을 내용을 그 안에 넣으면, 그 영역만 따로 결재할 수 있습니다. 영역에는 **`콘텐츠 승인`** 제목과 함께 그 영역 전용 상태 pill이 붙고, 조작 방식은 페이지 결재와 같습니다.

- **한 페이지에 여러 개**를 넣을 수 있고, 영역마다 독립적으로 결재가 진행됩니다.
- 매크로의 `key` 값은 **적지 않아도 됩니다.** 비워 두면 영역이 자동으로 구분됩니다.
- 직접 `key`를 적을 수도 있으며, 같은 페이지에서 같은 `key`를 두 번 쓰면 "같은 페이지에 동일한 key가 있습니다"라는 경고가 뜹니다(그 두 영역은 같은 결재를 공유하게 됩니다).

### 승인 UI가 아예 보이지 않는 스페이스

승인 기능은 **관리자가 적용한 스페이스에서만** 동작합니다. 적용되지 않은 스페이스에서는 상태 pill도, `승인 요청` 버튼도, 영역 매크로의 승인 틀도 나타나지 않고 매크로 본문 내용만 보입니다. 쓰고 있는 스페이스에 승인을 적용하고 싶다면 관리자에게 문의하십시오.

## 2. 상태의 종류

| 상태(기본 표시명) | 의미 |
|---|---|
| `승인 대기` | 결재를 기다리는 중 |
| `승인 완료` | 모든 단계가 승인함 |
| `반려` | 한 명이라도 반려함 |
| `만료` | 마감이 지나 끝남 |
| `회수` | 요청자가 거둬들임 |

상태 표시명은 조직에서 쓰는 용어로 바꿀 수 있으므로, 실제 화면에는 위와 다른 이름이 보일 수 있습니다(예: `승인 대기` 대신 `결재중`). 이름만 달라질 뿐 결재 흐름 자체는 같습니다.

진행 중일 때 pill에는 `1 / 3단계 진행 중`처럼 지금 몇 번째 단계인지도 함께 표시됩니다.

## 3. 승인 요청 올리기

### 3.1 요청 모달 열기

- 페이지 전체 결재: 페이지 상단 액션의 **`승인 요청`** 버튼 → **`페이지 승인 요청`** 모달
- 영역 결재: 그 영역의 머리글에 있는 **`승인 요청`** 버튼 → **`영역 승인 요청`** 모달

### 3.2 결재선 정하기

모달 위쪽 **`승인자 지정 방식`**에서 두 가지 중 하나를 고릅니다.

**① `승인자 직접 지정`**

`승인자 추가`에서 **`사용자`** / **`그룹`** 을 전환하며 검색해 추가합니다. 사용자 목록은 처음부터
표시하지 않으며, 이름 또는 계정을 **2글자 이상** 입력했을 때만 검색 결과가 나타납니다.
여러 명을 한 번에 고르려면 **`상세 검색`**을 누르고, 열린 창에서 검색 결과를 여러 개 선택한 뒤
**`선택한 사용자 추가`**를 누르십시오. 추가한 순서가 그대로 **`승인 순서`** 목록에 쌓이고,
**`위로` / `아래로`** 로 순서를 바꾸고 **`빼기`** 로 제외할 수 있습니다.

```
승인 순서
 1. 김결재 (사용자)
 2. 그룹: 팀장단      ← 그룹은 한 단계로 묶입니다
 3. 박최종 (사용자)
 총 3단계 · 위에서 아래 순서로 승인합니다.
```

- **순서가 곧 단계입니다.** 앞 단계가 통과해야 다음 단계 사람의 차례가 됩니다.
- **그룹은 한 단계로 묶입니다.** 그룹 구성원은 **요청을 만드는 시점**의 활성 구성원으로 확정되며, 이후 구성원이 바뀌어도 진행 중인 결재에는 영향이 없습니다. 한 명만 승인하면 통과할지, 구성원 전원이 승인해야 통과할지는 그룹마다 정해져 있고 검색 결과와 미리보기에 `그룹 · 전원 승인` / `그룹 · 한 명 승인`으로 표시됩니다.
- 같은 사람을 여러 단계에 넣으면 **앞 단계에만** 남습니다.
- 결재선에 올릴 수 있는 그룹은 미리 등록된 그룹뿐입니다. 찾는 그룹이 검색되지 않으면 관리자에게 문의하십시오.

**② `승인 Flow 사용`**

관리자가 미리 만들어 둔 결재선 템플릿을 고르는 방식입니다. `Flow를 선택하세요`에서 하나를 고르면 아래에 **단계와 담당자, 마감일 조건이 미리보기**로 표시됩니다.

### 3.3 참조자(CC) 지정하기 — 선택

**`참조자 추가`** 에서 사용자나 그룹을 참조자로 지정할 수 있습니다(라벨에 `선택 · 열람과 알림만`이라고 표시됩니다).

- 참조자는 **결재 권한이 없습니다.** 승인·반려 버튼이 생기지 않습니다.
- 참조자는 **요청이 생성될 때**와 **최종 결정이 났을 때** 알림을 받고, 업무함 **`참조`** 탭에서 해당 건들을 모아 볼 수 있습니다.

### 3.4 요청 메모 남기기 — 선택

**`요청 메모`**(`선택 · 최대 500자`)에 결재자에게 전달할 내용을 적을 수 있습니다. 이 메모는 상세 모달, 승인 업무함 목록, 알림 메일에 함께 표시됩니다.

### 3.5 요청 만들기

아래쪽 **`승인 요청`** 버튼을 누르면 요청이 만들어지고, pill이 `1 / n단계 진행 중`으로 바뀝니다. 1단계 승인자에게 알림이 갑니다.

> 요청을 만드는 도중 다른 사람이 먼저 같은 대상에 요청을 올렸거나 그 영역 본문을 수정했다면, 화면이 제멋대로 새로고침되지 않고 **안내 문구와 `새로고침` 버튼**이 나타납니다. 작성 중이던 결재선과 메모는 그대로 남아 있으므로, 최신 상태를 확인한 뒤 다시 요청하면 됩니다.

## 4. 승인하거나 반려하기

### 4.1 상세 모달 열기

승인할 페이지(또는 영역)의 **상태 pill을 클릭**하면 상세 모달이 열립니다. 모달에는 다음이 들어 있습니다.

- **`승인 순서와 결정`** — 단계별 승인자와 각자의 결정 상태(`미결정` / `승인` / `반려`)
- **`감사 타임라인`** — 요청 생성, 각 승인·반려, 만료, 회수가 시각과 함께 남습니다. 위임을 받은 사람이 대신 누른 결정에는 `(대신 결재: OOO)`이 함께 붙습니다([10장](#10-내-위임-결재-위임이-켜져-있을-때) 참고)
- **`참조`** — 참조자로 지정된 사람들
- **`버전별 승인 이력`** — 어느 버전이 언제 승인됐는지
- 요청 메모와 마감 시각
- **지금 내 차례일 때만** 나타나는 **`승인`** / **`반려`** 버튼

지금이 내 차례가 아니면 버튼 대신 `앞 단계를 기다리는 중입니다.` 안내가 보입니다.

### 4.2 승인하기

**`승인`** 을 누르면 결정이 기록되고, 다음 단계가 있으면 그 단계 담당자의 차례가 됩니다. 마지막 단계까지 통과하면 상태가 `승인 완료`로 바뀌고, 어느 버전 기준으로 승인됐는지가 `v3 기준 승인`처럼 표시됩니다.

**전자서명이 켜져 있는 경우:** 승인 결정 옆에 내 도장이나 등록한 서명 이미지가 함께 표시됩니다([9장](#9-내-서명-전자서명이-켜져-있을-때) 참고).

**서명 PIN 검증이 켜져 있는 경우:** `승인`을 누르면 모달 안에 **`승인 PIN 확인`** 단계가 이어서 열립니다. `서명 PIN`을 입력하고 **`승인 확정`** 을 누르면 승인이 완료됩니다. 잘못 입력하면 남은 시도 횟수를 알려 주고, 5회 실패하면 15분간 잠깁니다. PIN을 아직 등록하지 않았다면 먼저 업무함의 **`내 서명`** 에서 등록해야 합니다.

### 4.3 반려하기

**`반려`** 를 누르면 브라우저 팝업 대신 모달 안에서 **`반려 확인`** 단계가 열립니다. **`반려 사유`** 를 적고(관리자가 "반려 사유 필수"로 설정했다면 반드시 입력해야 합니다) **`반려 확정`** 을 누릅니다. PIN 검증이 켜져 있으면 같은 화면에서 PIN도 함께 입력합니다.

**반려는 한 명만 해도 요청 전체가 즉시 종료됩니다.** 남은 단계는 진행되지 않고 상태가 `반려`가 되며, 요청자에게 사유와 함께 알림이 갑니다. 되돌릴 수 없으므로, 다시 결재를 받으려면 요청을 새로 올려야 합니다.

## 5. 요청 회수하기

진행 중인 요청은 **요청자 본인**(또는 관리자)이 회수할 수 있습니다.

- **상세 모달에서:** **`요청 회수`** → **`요청 회수 확인`** 단계에서 회수 사유(선택)를 적고 **`회수 확정`**
- **업무함 `내 요청` 탭에서:** 진행 중인 행에서 바로 회수 폼을 열어 처리

회수하면 진행 중이던 요청이 종료되고 **지금까지 받은 승인은 무효가 되며 되돌릴 수 없습니다.** 아직 결정하지 않은 승인자와 요청자에게 알림이 갑니다. 회수 기록은 감사 타임라인에 영구히 남습니다.

> 매크로 영역을 통째로 지운 채 페이지를 저장하면, 그 영역에서 진행 중이던 결재는 자동으로 회수됩니다.

## 6. 페이지를 수정했을 때

승인 앱은 **"어느 버전이 승인됐는가"** 를 기록으로 남깁니다.

### 이미 승인이 끝난 뒤에 수정한 경우

- **승인 완료 기록은 지워지지 않습니다.** "v3은 승인됐다"는 사실은 영구 기록입니다.
- 다만 페이지가 승인된 버전보다 새로워지면 pill이 **`v3 승인 · v4 미승인`** 형태로 바뀌어, 현재 버전은 아직 승인되지 않았음을 알려 줍니다.
- 상세 모달에서 **승인 버전과의 차이 보기(diff)** 링크로 무엇이 바뀌었는지 확인할 수 있습니다.
- **`같은 결재선으로 재승인 요청`** 버튼을 누르면 이전과 같은 결재선으로 새 요청이 한 번에 만들어집니다. 결재선에 그룹이 있으면 **재요청 시점의 구성원**으로 다시 펼쳐집니다. 그 사이 그룹이 삭제되거나 사용할 수 없게 됐다면 결재선을 다시 구성하라는 안내가 나옵니다.
- 이전 버전들의 승인 기록은 **`버전별 승인 이력`** 에 남아 있고, 항목을 펼치면 그 버전의 감사 타임라인까지 볼 수 있습니다.

### 결재가 진행 중일 때 수정한 경우

진행 중인 요청은 **수정되는 순간 무효가 됩니다.** 낡은 버전을 대상으로 한 승인이 남지 않게 하기 위한 동작입니다. "승인이 진행되는 중에 페이지가 수정되어 요청이 무효가 되었습니다. 지금까지 받은 승인은 초기화되었습니다."라는 안내가 표시되며, 다시 받으려면 승인 요청을 새로 올려야 합니다.

**영역(매크로) 결재는 그 영역의 내용이 실제로 바뀐 경우에만** 무효가 됩니다. 같은 페이지의 다른 게시글만 고쳤다면 그 영역 결재는 그대로 진행됩니다.

### 마감

요청에는 마감 시각이 있을 수 있습니다(관리자 설정이나 Flow에 따라 자동으로 정해집니다). 마감이 지나면 **진행 중인 요청만** `만료`로 끝납니다. 이미 `승인 완료`된 기록은 마감으로 무효가 되지 않습니다. 마감이 가까워지면 `마감 임박` 알림을 받습니다.

## 7. 승인 업무함

**승인 업무함**은 내 결재 업무를 한곳에 모아 보는 화면입니다. 화면 어디서든 상단 헤더의 **`승인`** 아이콘을 눌러 열리는 바로가기에서 **`승인 업무함 열기`** 로 들어갑니다. 헤더 아이콘에는 **내 차례인 건수 배지**가 붙고, 바로가기에는 `내 차례` / `마감 임박` / `읽지 않은 알림` 건수와 `내 서명` 링크가 함께 표시됩니다.

업무함은 일반 Confluence 페이지처럼 열리며, 왼쪽에 접이식 사이드바가 있습니다.

```
┌──────────────┬────────────────────────────────────────┐
│ 업무함        │  내 차례                    12건        │
│  내 차례      │  [상태 칩 레일]                [필터]   │
│  진행 중      │  ┌──────────────────────────────────┐  │
│  내 요청      │  │ 대상 │상태│요청자│요청 시각│마감│Flow│ │
│  참조         │  └──────────────────────────────────┘  │
│  처리한 건    │            더 보기                      │
│ 알림과 설정   │                                        │
│  알림         │                                        │
│  내 서명      │                                        │
│  내 위임      │                                        │
└──────────────┴────────────────────────────────────────┘
```

### 7.1 탭(사이드바 항목)

| 항목 | 보이는 내용 |
|---|---|
| **`내 차례`** | 지금 내가 결정해야 하는 결재 |
| **`진행 중`** | 내가 승인자이지만 아직 앞 단계를 기다리는 결재 |
| **`내 요청`** | 내가 올린 승인 요청 |
| **`참조`** | 내가 참조자로 지정된 결재 |
| **`처리한 건`** | 내가 이미 승인하거나 반려한 결재 |

스페이스 안에서 업무함으로 들어오면 사이드바 위쪽에 원래 스페이스로 돌아가는 링크가 붙습니다.

### 7.2 목록 보기

- 목록은 **대상 / 상태 / 요청자 / 요청 시각 / 마감 / Flow** 열로 표시되고, 행마다 **`상세`** 와 **`페이지 열기`** 버튼이 있습니다.
- 한 번에 50건씩 보여 주고 아래 **`더 보기`** 로 이어서 불러옵니다. 제목 옆에는 조건에 맞는 **총건수**가 표시됩니다.
- **`내 요청`** 탭의 진행 중인 행에서는 그 자리에서 바로 **요청 회수**를 할 수 있습니다.

### 7.3 필터

목록 위의 **상태 칩 레일**을 클릭하면 그 상태만 바로 걸러집니다. 회수·마감 임박·기한 지남 칩은 해당하는 건이 있을 때만 나타나고, 칩에 적힌 건수는 지금 보고 있는 탭 기준입니다.

**`필터`** 버튼을 누르면 더 구체적인 조건을 쓸 수 있습니다.

- `페이지 제목 검색`
- **`스페이스`**, **`요청자`**, **`Flow`**
- **`요청일`** — `오늘` / `최근 7일` / `최근 30일` / `직접 지정`(`시작`·`끝` 날짜)
- **`마감`** — `임박만` / `지남만` / `마감 없음`
- **`내 차례만`** 체크박스
- **`전체 해제`** 로 한 번에 초기화

적용한 필터는 목록 위에 태그로 표시되며 하나씩 뺄 수 있습니다. 필터 상태는 주소(URL)에 유지되므로 새로고침하거나 링크를 공유해도 같은 조건으로 열립니다.

### 7.4 Excel 다운로드

필터 영역의 **`Excel 다운로드`** 버튼은 **지금 보고 있는 탭과 필터 조건 그대로** 목록을 Excel용 CSV 파일로 내려받습니다. 한 번에 최대 10,000건까지 받을 수 있으며, 넘으면 필터를 더 걸어 달라는 안내가 나옵니다.

### 7.5 시각 표기

모든 시각은 **접속한 사람의 로컬 시간**으로 `2026-08-19 14:30:05 (UTC+9)` 형식으로 표시됩니다. 업무함 표에서는 열 머리에 시간대 표기가 한 번만 붙습니다.

## 8. 알림

다음 시점에 알림을 받습니다.

- 승인 요청이 생성됐을 때(승인자·참조자)
- 승인 / 반려 / 만료 / 회수가 일어났을 때
- 마감이 가까워졌을 때(`마감 임박`)
- 내 차례가 된 지 오래됐을 때(`결재 독촉`)

### 결재 독촉

관리자가 독촉 알림을 켜 두면, **내 차례가 된 지 정해진 날수가 지나도록 결정하지 않은 건**에 대해 알림이 다시 옵니다. 그 뒤에도 결정하지 않으면 정해진 주기마다 한 번씩 반복됩니다. 알림 목록과 메일 제목에는 `결재 독촉`으로 표시됩니다.

독촉은 **지금 차례인 결재자 본인에게만** 갑니다. 상급자나 요청자에게 대신 알려 주지는 않습니다. 승인하거나 반려하면 그 건의 독촉은 더 이상 오지 않습니다. 첫 독촉까지의 날수와 반복 주기는 관리자가 정하며, 관리자가 이 기능을 꺼 두었다면 독촉 알림은 오지 않습니다.

알림은 업무함 사이드바의 **`알림`** 화면에 쌓입니다. 읽지 않은 항목은 `읽지 않음` 표시가 붙고, **`모두 읽음`** 으로 한 번에 정리할 수 있습니다. 헤더 `승인` 아이콘의 바로가기에서도 읽지 않은 알림 건수를 볼 수 있습니다.

이메일 알림은 관리자가 켜 두고 메일 서버가 설정되어 있을 때만 발송됩니다.

## 9. 내 서명 (전자서명이 켜져 있을 때)

전자서명은 **관리자가 켜야 쓸 수 있는 기능이며 기본은 꺼져 있습니다.** 꺼져 있는 동안 업무함의 **`내 서명`** 화면에는 "관리자가 전자 서명 기능을 켜면 사용할 수 있습니다."라고만 표시됩니다.

켜져 있으면 승인·반려 결정 옆에 도장이나 서명이 함께 남고, `내 서명` 화면에서 다음을 관리할 수 있습니다.

### 자동 도장

따로 등록하지 않아도 **이름을 바탕으로 만든 도장**이 자동으로 쓰입니다(`자동 도장 사용 중 · 오른쪽에서 서명을 등록하세요`). `결재란 미리보기`에서 실제로 어떻게 보일지 확인할 수 있습니다.

### 서명 등록

**`REGISTER · 서명 등록`** 에서 두 가지 방식 중 하나로 내 서명을 등록하면, 자동 도장 대신 등록 서명이 쓰입니다(`등록 서명 사용 중`).

- **`직접 그리기`** — 화면에 마우스나 터치로 서명하고 **`그린 서명 저장`**(다시 하려면 `지우기`)
- **`이미지 업로드`** — `PNG/JPEG · 50KB 이하` 파일 선택

등록한 서명은 **`서명 삭제`** 로 지울 수 있으며, 지우면 다시 자동 도장을 씁니다.

### PIN 등록

**`PIN · 서명 비밀번호`** 에서 승인·반려를 확정할 때 쓸 PIN을 등록합니다.

- `4~12자`이며, `새 PIN`과 `PIN 확인` 두 값이 같아야 합니다. 이미 등록했다면 `현재 PIN`도 함께 입력합니다.
- **Confluence 로그인 비밀번호와는 별개**입니다. 다르게 설정하시기 바랍니다.
- 화면 위쪽에 `PIN 미등록` / `PIN 등록됨` 상태가 표시됩니다.
- 관리자가 PIN 검증을 켠 상태라면 "PIN을 등록해야 승인/반려할 수 있습니다"라는 안내가 뜹니다. 이때는 PIN을 먼저 등록해야 결재를 진행할 수 있습니다.
- PIN을 5회 틀리면 15분 동안 잠깁니다. 잠긴 동안에는 기다렸다가 다시 시도하십시오.

## 10. 내 위임 (결재 위임이 켜져 있을 때)

자리를 비우는 동안 내 결재를 대신 처리할 사람을 지정하는 기능입니다. 결재 위임은 **관리자가 켜야 쓸 수 있는 기능이며 기본은 꺼져 있습니다.** 꺼져 있는 동안 업무함의 **`내 위임`** 화면에는 "이 사이트는 결재 위임이 꺼져 있습니다. 관리자에게 문의하세요."라고만 표시됩니다.

켜져 있으면 같은 화면에 "자리를 비우는 동안 대신 결재할 사람을 지정합니다. 결재는 내 이름으로 남고, 실제로 누른 사람은 감사 로그에 기록됩니다."라는 안내와 함께 등록 폼과 두 개의 목록이 나타납니다.

### 10.1 위임 등록하기

| 입력 | 설명 |
|---|---|
| **`대신할 사람`** | 이름이나 계정으로 검색해 고릅니다. **두 글자 이상** 입력해야 결과가 나오고, 고르면 `선택함: 홍길동` 으로 표시됩니다. |
| **`시작일`** / **`종료일`** | **둘 다 선택 사항**입니다. 둘 다 비우면 `기간 제한 없음` 으로 등록되어 직접 해제할 때까지 유효합니다. 종료일을 정하면 **그날까지** 유효합니다. |
| **`메모`** | `예: 연차 휴가` 처럼 사유를 적어 둘 수 있습니다(선택 · 최대 200자). |

**`위임 등록`** 을 누르면 등록되고 아래 목록에 바로 나타납니다.

- **자기 자신에게는 위임할 수 없습니다.** 시도하면 `자신에게는 위임할 수 없습니다.` 라는 안내가 나옵니다.
- **맡길 수 있는 것은 내 결재뿐입니다.** 다른 사람의 결재를 대신 맡겨 줄 수는 없습니다.
- 기간이 겹치지 않게 여러 건을 미리 등록해 둘 수 있습니다.

### 10.2 두 목록과 상태 표기

| 목록 | 보이는 내용 |
|---|---|
| **`내가 맡긴 위임`** | 내 자리에서 대신 결재할 수 있는 사람 |
| **`나에게 온 위임`** | 내가 대신 결재할 수 있는 사람 |

각 줄에는 기간(또는 `기간 제한 없음`), 메모, 그리고 다음 상태가 함께 표시됩니다.

| 상태 | 의미 |
|---|---|
| `지금 유효` | 지금 이 위임으로 대리 결재를 할 수 있습니다 |
| `기간 밖` | 등록돼 있지만 시작일 전이거나 종료일이 지났습니다 |
| `해제됨` | 해제되어 더 이상 쓰이지 않습니다 |

**`해제`** 는 **맡긴 사람과 받은 사람 어느 쪽에서도** 누를 수 있습니다. 한 번 해제한 위임은 다시 켤 수 없으므로, 계속 쓰려면 새로 등록하십시오.

### 10.3 위임을 받은 사람 입장

- 위임받은 건이 **내 업무함에 내 결재와 함께** 보입니다. **`내 차례`** 목록과 헤더 **`승인`** 아이콘의 건수 배지에도 함께 잡힙니다.
- 해당 페이지를 열면 상태 pill 옆에 **`대리 결재 — 홍길동`** 표시가 붙고, 지금 그 사람의 차례라면 상세 모달에 **`승인`** / **`반려`** 버튼이 나타납니다.
- 반려 사유, 서명 PIN 등 나머지 절차는 평소와 같습니다. PIN 검증이 켜져 있으면 **버튼을 누르는 사람 본인의 PIN**을 입력합니다.
- 한 요청에서 두 자리를 동시에 대신할 수는 없습니다. 여러 사람을 대리하는 중이고 그들이 같은 결재선에 있다면, 결재선에서 앞선 자리에 서게 됩니다.

> 대리 결재는 **페이지 전체 결재**에서 동작합니다. 페이지 안의 영역(`approval-region` 매크로) 결재는 위임받은 건도 업무함에는 보이지만, 승인·반려는 결재자 본인만 할 수 있습니다.

### 10.4 결재는 누구 이름으로 남나요 (꼭 확인하십시오)

**위임은 "누가 버튼을 누를 수 있는가"만 바꿉니다. 결재 자체는 원래 결재자의 이름으로 남습니다.**

- **`승인 순서와 결정`** 목록의 그 단계에는 계속 **원래 결재자**의 이름과 결정이 표시됩니다. 결재선의 자리 자체는 위임으로 바뀌지 않습니다.
- 실제로 누른 사람은 **`감사 타임라인`** 에 **`(대신 결재: 김대리)`** 형태로 함께 남습니다. 즉 "누구의 결재인지"와 "누가 대신 눌렀는지"가 모두 기록됩니다.
- 전자서명이 켜져 있으면 결정 옆의 도장·서명도 **원래 결재자**의 것이 표시됩니다.

관리자가 위임 기능을 끄면, 등록된 위임이 남아 있어도 **그 즉시** 대리 결재는 할 수 없게 됩니다.

## 11. 표시 언어와 화면 모드

**표시 언어** — 승인 앱은 **Confluence 사용자 언어 설정을 그대로 따릅니다.** 언어를 한국어로 두면 페이지 패널, 영역 매크로, 각종 모달, 승인 업무함, 알림, 메일 본문까지 한국어로 보입니다. 그 밖의 언어에서는 영어로 표시됩니다. 단, 상태 표시명(`승인 대기` 등)을 관리자가 조직 용어로 바꿔 둔 경우에는 언어와 관계없이 그 이름이 그대로 쓰입니다.

**다크 모드** — 앱에 별도 토글이 없고 **Confluence의 외관(테마) 설정을 그대로 따릅니다.** 외관을 직접 고르면 그 설정을, '자동'으로 두면 운영체제 설정을 따르므로 승인 화면은 언제나 본문과 같은 모드로 보입니다.

## 12. 자주 묻는 상황

**Q. 내 차례라고 들었는데 상세 모달에 `승인` 버튼이 없습니다.**
A. 다음을 확인해 보십시오.
- 아직 **앞 단계가 끝나지 않은** 경우입니다. 이때 모달에는 `앞 단계를 기다리는 중입니다.` 안내가 보입니다. 앞 단계가 통과하면 버튼이 나타납니다.
- 결재선이 아니라 **참조자**로 지정된 경우입니다. 참조자는 열람과 알림만 받고 결재 권한은 없습니다.
- 이미 결정을 마친 경우입니다. `승인 순서와 결정` 목록에서 내 결정이 `승인`/`반려`로 표시돼 있는지 확인하십시오.
- PIN 검증이 켜져 있는데 PIN을 등록하지 않았다면 먼저 업무함의 `내 서명`에서 등록해야 합니다.

**Q. 승인 버튼도 `승인 요청` 버튼도, 상태 표시 자체가 아예 안 보입니다.**
A. 그 스페이스에 승인 기능이 적용되지 않았을 수 있습니다. 적용되지 않은 스페이스에서는 승인 UI가 전혀 나타나지 않습니다. 또한 `승인 요청` 버튼은 그 페이지를 **편집할 권한이 있는 사람**에게만 보입니다. 관리자에게 문의하십시오.

**Q. 제가 승인했는데 왜 아직 `승인 대기`인가요?**
A. 승인은 **순차 진행**입니다. 내 단계를 통과했어도 뒤 단계 결재자가 남아 있으면 전체 상태는 계속 진행 중입니다. pill의 `2 / 3단계 진행 중` 표시로 지금 어느 단계인지 확인할 수 있습니다.
또, 내 단계가 **전원 승인 그룹**이라면 그 그룹 구성원이 모두 승인해야 다음 단계로 넘어갑니다. 상세 모달의 `승인 순서와 결정`에서 아직 `미결정`인 사람이 있는지 확인해 보십시오.

**Q. 페이지를 조금 고쳤더니 상태가 바뀌었습니다.**
A. 의도된 동작입니다.
- **승인이 끝난 페이지**를 고치면 승인 기록은 그대로 남고, pill만 `v3 승인 · v4 미승인`으로 바뀌어 현재 버전이 아직 승인 전임을 알려 줍니다. 상세 모달의 **`같은 결재선으로 재승인 요청`** 으로 곧바로 다시 올릴 수 있습니다.
- **결재가 진행 중이던 페이지**를 고치면 그 요청은 무효가 되고 받은 승인이 초기화됩니다. 승인 요청을 새로 올려 주십시오.
- 영역(매크로) 결재는 **그 영역의 내용이 실제로 바뀐 경우에만** 이렇게 됩니다. 같은 페이지의 다른 부분만 고쳤다면 영향이 없습니다.

**Q. 잘못 올린 요청을 없애고 싶습니다.**
A. 요청자 본인이 **`요청 회수`** 로 종료할 수 있습니다(상세 모달 또는 업무함 `내 요청` 탭의 행에서). 회수하면 지금까지 받은 승인이 무효가 되고 되돌릴 수 없으므로 확인 후 진행하십시오. 회수 기록은 감사 타임라인에 남습니다.

**Q. 결재선에 올리려는 그룹이 검색되지 않습니다.**
A. 결재선에는 **미리 등록된 그룹만** 올릴 수 있습니다. 필요한 그룹의 등록은 관리자에게 요청하십시오. 비활성 사용자는 어느 그룹에서든 결재선에 포함되지 않습니다.

**Q. 요청을 만들려는데 "이미 진행 중인 승인 요청이 있습니다"라고 나옵니다.**
A. 같은 대상에는 열린 요청을 하나만 둘 수 있습니다. 진행 중인 요청이 승인·반려·만료되거나 회수된 뒤에 새 요청을 만들 수 있습니다.

**Q. 승인 요청을 만드는 중에 "영역이 변경되었습니다"라는 안내가 떴습니다.**
A. 작성 중에 다른 사람이 그 영역을 수정한 경우입니다. 화면이 임의로 새로고침되지 않고 작성하던 결재선과 메모는 남아 있으니, 최신 내용을 확인한 뒤 다시 요청하십시오.

**Q. 휴가를 가는데 제 차례에서 결재가 멈추지 않게 하고 싶습니다.**
A. 업무함의 **`내 위임`** 에서 대신할 사람과 기간을 등록해 두십시오([10장](#10-내-위임-결재-위임이-켜져-있을-때) 참고). 위임은 결재선을 바꾸지 않으므로, 돌아온 뒤 위임을 해제하면 원래대로 내가 결재하게 됩니다. `내 위임` 화면에 "이 사이트는 결재 위임이 꺼져 있습니다."라고 나온다면 관리자에게 기능을 켜 달라고 요청하십시오.

**Q. 위임을 받았는데 그 사람의 결재에 `승인` 버튼이 보이지 않습니다.**
A. 다음을 확인해 보십시오.
- `내 위임`의 **`나에게 온 위임`** 목록에서 그 위임이 `지금 유효` 인지 확인하십시오. `기간 밖`이면 시작일 전이거나 종료일이 지난 것이고, `해제됨`이면 이미 해제된 것입니다.
- 아직 **그 사람의 차례가 아닐** 수 있습니다. 순차 승인이므로 앞 단계가 끝나야 합니다.
- 페이지 안의 **영역(매크로) 결재**는 대리 결재를 할 수 없습니다. 결재자 본인이 처리해야 합니다.
- 관리자가 위임 기능을 껐다면 등록된 위임이 있어도 대리 결재는 즉시 막힙니다.

**Q. 제가 대신 승인했는데 이력에는 제 이름이 아니라 원래 결재자 이름이 있습니다.**
A. 의도된 동작입니다. 결재는 **원래 결재자의 이름으로** 기록되고, 실제로 누른 사람은 감사 타임라인에 **`(대신 결재: OOO)`** 으로 함께 남습니다. 두 사실이 모두 남으므로 이력이 사라지지는 않습니다.

**Q. 같은 결재 건에 대해 알림이 다시 왔습니다.**
A. 관리자가 **독촉 알림**을 켜 둔 경우입니다. 내 차례가 된 지 오래된 건은 정해진 주기마다 알림이 다시 옵니다(`결재 독촉`). 승인하거나 반려하면 더 이상 오지 않습니다.
