# Moves Approval Workforce 방식 Confluence 게시 (2026-10-06)

## 결정과 결과

- Moves Workforce 스페이스 홈을 읽고 홈을 언어별 가이드, 설치·심사, 정책·지원의 링크 허브로 구성하며 상세 문서는 언어 폴더에 두는 패턴을 확인했다.
- MA 홈(203818508)에 한·영 가이드, 설치, Marketplace 심사, 보안, FAQ 링크를 추가했고, 기존 Project Tracker·최근 업데이트·기여자 영역은 유지했다.
- 한국어 폴더(203818583)는 색인과 상세 문서 9개를 유지하고 한국어 색인에 링크 목차를 추가했다. 영어 폴더(204570641)는 색인과 상세 문서 9개가 보이도록 보완했다.
- 영어 가이드 작업 중 제목만 있고 본문이 비어 있는 요청자·승인자 초안을 발견해 실제 상세 본문을 채웠다. 신규 페이지는 게시 성공만 보지 말고 게시 후 렌더된 본문의 첫 절 제목과 링크를 확인해야 한다.
- Confluence 편집기에는 Rovo 입력칸과 페이지 본문 입력칸이 함께 존재한다. 편집기 로딩 후 본문 placeholder를 눌러 실제 페이지 편집 영역에 포커스를 두고, 해당 영역 안에서 렌더 결과를 확인한 다음 게시한다. 전체 본문 교체는 기존 페이지 본문에 포커스를 둔 뒤 전체 선택·붙여넣기 후 링크와 제목 구조를 다시 검사한다.
- Workforce 페이지와 비교할 때 폴더 트리만 만들고 홈 소개가 기본 placeholder인 상태는 독자가 문서에 도달하기 어렵다. 루트 홈 링크와 언어별 색인을 함께 검증한다.
- 확인된 게시 문서와 임시 초안은 구분해서 보고한다. 게시 모달 클릭만으로 게시 완료를 주장하지 않는다.
