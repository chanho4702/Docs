# Confluence Approval DC: Marketplace Data Center 심사 차이 분석 (2026-08-20)

- C9/C10 descriptor에는 Data Center compatible 선언이 있으나, 이는 기술 심사 완료를 뜻하지 않는다.
- Marketplace 심사에는 technical review, 1/2/4 node 성능·확장성 결과, PostgreSQL/MySQL/SQL Server/Oracle DB 검증, DC Security Questionnaire와 security scan 대응이 필요하다.
- C10 어댑터가 미완성이므로 현재는 C9 단일 호환 선언만으로 Marketplace Data Center 심사를 통과할 수 없다.
