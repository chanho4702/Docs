# Moves Approval for Jira 마켓플레이스 한·영 가이드 준비

- 2026-10-05 `docs/guide/ko`, `docs/guide/en`에 각 14주제, README·제출 준비표·촬영 목록을 작성했다. Confluence Approval의 파일별 공개 페이지 구조를 맞췄다.
- 단독 사용과 Workforce 선택 연동, 일반 승인·전환 승인·필드 변경·타임시트의 차이를 코드와 실제 locale 기준으로 구분했다.
- 문서 작성 완료와 앱 등록·실환경 재현·스크린샷·공개 게시·심사 제출 완료는 별도 상태로 관리한다. app ID가 등록 전 값이어서 배포하지 않았다.
- 기간 다시 열기는 마감 잠금만 해제하며 제출/승인 잠금은 별도다. 심사 마감 시험은 미제출 기간으로 재현한다.
- 워크로그 설명 원문 보관이 꺼져도 앞 40자 미리보기와 지문이 저장된다. 개인정보 설명에서 이를 누락하지 않는다.
- 독립 독자 검토에서 최소 결재선 예시, 재적용 자격, 실제 화면 문구를 보완했다. 한·영 파일명 대칭과 상대 링크를 검증했다.
