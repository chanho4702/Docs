# 5.4 프로젝트 상세 — 캘린더

## 🔐 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | `PROJECT` 읽기 |
| 워크로그 수정·삭제 | 각 워크로그의 **작성자 본인만** (앱 권한과 무관) |

- 프로젝트 조회 범위(`MEMBER_ONLY` / `TEAM_ONLY`) 밖 프로젝트에서는 열리지 않습니다.
- 여기서 보이는 워크로그는 각자 [My Work](../codex-experiences--02-my-work.md)에서 기록한 것과 같은 데이터입니다.

---

**언제 쓰나** — 프로젝트 전체의 **워크로그와 이벤트를 달력**으로 볼 때. [개인 캘린더](../codex-experiences--02-my-work.md#캘린더-뷰)의 프로젝트 단위 버전입니다.

## 화면 구성

- **작업자 선택 / 작업 선택** 필터로 특정 인원·작업만 볼 수 있습니다.
- **월간 / 주간** 보기와 기간 이동을 지원합니다.
- 날짜 칸에 다음이 표시됩니다.
  - 이슈별 **워크로그** (시간 범위·담당자)
  - **프로젝트 이벤트** (예: "디무브 워크숍")

## 알아두기

- 여기 보이는 워크로그는 [My Work](../codex-experiences--02-my-work.md)에서 각자 기록한 것과 같은 데이터입니다. 캘린더에서 확인하고, 수정은 작성자 본인이 합니다.
- 특정 인원의 투입 추이를 수치로 보려면 [5.5 인력 분석](codex-experiences--05-%EB%B6%84%EC%84%9D-%EB%B0%8F-%EB%A6%AC%ED%8F%AC%ED%8A%B8.md#552-인력-분석--누가-과부하이고-누가-여유인가)이 더 적합합니다.

> ⚠️ **연차·휴가처럼 종료일이 있는 일정을 등록할 때**는 화면에 표시되는 마지막 날짜가 실제 종료일과 맞는지 확인하세요. 종료일 처리 방식 때문에 하루 차이가 나는 사례가 있었습니다.
