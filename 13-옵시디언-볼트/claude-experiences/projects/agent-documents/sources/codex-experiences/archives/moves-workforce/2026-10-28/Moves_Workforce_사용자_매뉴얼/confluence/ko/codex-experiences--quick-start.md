# 빠른 시작

[가이드 홈](codex-experiences--index.md) · [English](../en/codex-experiences--quick-start.md)

> 검토 초안: 2026-10-04 지정된 staging의 영어 화면을 촬영했습니다. 화면 이미지는 한·영 가이드가 공통으로 사용합니다. 배포 버전과 역할별 접근·저장 동작은 아직 검증 중입니다.

이 안내를 따라 내 작업 시간을 기록하고 프로젝트에 반영되는지 확인합니다. 처음 설치한 조직이라면 관리자가 [초기 설정](codex-experiences--admin-setup.md)을 먼저 완료해야 합니다.

## 준비할 것

- 앱을 사용할 Jira 계정과 Moves Workforce 사용자 등록
- 내가 볼 수 있고 작업 시간을 기록할 수 있는 Jira 이슈
- 프로젝트 분석까지 확인하려면 해당 Moves Workforce 프로젝트의 인력 등록과 이슈 연결

## 처음부터 끝까지 따라 하는 예시

아래 이름과 값은 설명용 예시입니다. 실제로 사용할 프로젝트, Jira 이슈와 날짜로 바꾸세요. 이미 준비된 프로젝트가 있으면 새로 만들지 않고 해당 프로젝트를 사용합니다.

| 준비 대상 | 예시 | 준비되지 않았다면 |
|---|---|---|
| 앱 프로젝트 | Demo website launch | 관리자가 [프로젝트](codex-experiences--projects.md)를 만듭니다. |
| 앱 사용자와 프로젝트 인력 | 본인의 Jira 계정 | 관리자가 앱 사용자로 등록하고 [프로젝트 인력](codex-experiences--project-people.md)에 추가합니다. |
| Jira 이슈 | DEMO-12 Write test scenarios | Jira에서 접근 가능한 이슈를 준비한 뒤 [작업 관리](codex-experiences--project-work.md)에서 프로젝트에 연결합니다. |
| 기록할 시간 | 2026-10-05, 09:00–12:30 | 실제 업무 날짜와 시간으로 바꿉니다. |

1. **Jira → Apps → Moves Workforce → 나의 작업(My Work)**을 엽니다. 본인의 화면인지 확인합니다.
2. 기록할 날짜를 선택하고 워크로그 추가 창을 엽니다. 기존 기록을 먼저 확인해 같은 업무를 중복 입력하지 않습니다.
3. 작업 검색에서 준비한 이슈 키를 입력하고 결과의 제목까지 확인한 뒤 선택합니다. 검색이 비어 있으면 Jira에서 그 이슈를 직접 열 수 있는지 확인합니다.
4. 날짜와 시작·종료 시간을 입력합니다. 예시에서는 계산 시간이 **3시간 30분**이어야 합니다. 설명에 수행한 업무를 적고 등록합니다.
5. 창이 닫힌 뒤 해당 날짜의 기록에서 **이슈 키, 날짜, 기록자, 시간**을 확인합니다. 하루 전체 합계에는 다른 기록도 포함되므로 합계가 반드시 3시간 30분일 필요는 없습니다.
6. Jira 이슈의 워크로그에서도 같은 기록을 확인합니다. 같은 업무를 Jira에서 다시 등록하지 않습니다.
7. **프로젝트 관리 → Demo website launch**를 열어 작업 관리에 이슈가, 인력 관리에 본인이 각각 있는지 확인합니다.
8. 조회 권한이 있으면 분석·보고서에서 해당 날짜를 포함하는 기간을 선택합니다. 포트폴리오 등 집계 화면은 마지막 집계 시각도 확인합니다.

**완료 기준:** 본인 워크로그와 프로젝트의 인력·작업 연결을 각각 확인했습니다. 워크로그 저장만으로 인력 등록이나 프로젝트 연결까지 완료되는 것은 아닙니다. 분석 수치가 비어 있으면 기록 날짜 → 작업 연결 → 인력 등록 → 조회 범위 → 집계 시각 순으로 확인하세요.

## 첫 워크로그 기록하기

1. Jira **앱** 메뉴에서 **Moves Workforce**를 엽니다.
2. **My Work**에서 기록할 날짜를 선택하거나 워크로그 추가 버튼을 누릅니다.
3. 업무로 사용할 Jira 이슈를 선택합니다. 예: `DEMO-12 테스트 시나리오 작성`.
4. 날짜와 시작·종료 시각을 입력합니다. 예: 09:00~12:30은 3시간 30분입니다.
5. 수행 내용을 적고 저장합니다.
6. 같은 날짜의 워크로그와 작업 시간 합계가 갱신됐는지 확인합니다.

이 기록은 Jira 워크로그입니다. 같은 작업 시간을 Jira와 앱 양쪽에서 각각 새로 등록하면 중복 기록이 생기므로 기존 기록을 먼저 확인하세요.

## 프로젝트 확인하기

1. **프로젝트 관리**에서 참여 프로젝트를 엽니다.
2. **작업 관리**에서 기록한 이슈가 프로젝트에 연결돼 있는지 확인합니다.
3. **인력 관리**에서 본인이 프로젝트 인력으로 등록돼 있는지 확인합니다.
4. 권한이 있다면 **분석 및 리포트**에서 해당 날짜를 포함한 기간을 선택합니다.

Jira 이슈 담당자 지정, 프로젝트 인력 등록, 프로젝트 이슈 연결은 각각 다른 설정입니다. 한 항목만 설정했다고 나머지가 자동으로 채워지지는 않습니다.

## 완료 확인

| 확인할 것 | 예상 결과 |
|---|---|
| 내 기록 | 선택한 이슈·날짜·시간으로 워크로그가 있음 |
| 내 프로젝트 | 권한과 배정 범위에 맞는 프로젝트가 보임 |
| 프로젝트 분석 | 선택 기간과 대상 인력·이슈를 확인할 수 있음 |
| 통합 대시보드 | 마지막 집계 시각을 확인한 뒤 결과를 해석함 |

메뉴가 없거나 이슈를 선택할 수 없다면 [FAQ](codex-experiences--faq.md)를 확인하세요. 처음부터 모든 설정을 변경할 필요는 없습니다.
