상단 조망 차트

차트 내용
산정 정확도 완료 이슈의 계획 대비 실제 비율 분포. 완료됐고 계획 작업량이 있는 이슈만 계산하며, 계획이 없는 이슈와 미완료 이슈는 제외 수로 표시됩니다
담당자별 계획 대비 실적 담당자별 계획 MD 합 vs 실제 MD 합. 담당자 없는 이슈는 "미배정"으로 묶이고, 최대 15명까지 표시됩니다. 인원이 많으면 아래 표에서 확인하세요

이슈 표

이슈를 계획 공수(MD)와 실투입 공수(MD) 관점에서 비교합니다. 상단 필터(스페이스/담당자/상태/이슈 타입 등)로 범위를 좁히고 엑셀 내보내기로 현재 결과를 저장할 수 있습니다.

컬럼 의미
상태 / 담당자 / 작업 인원 누가 몇 명이 매달려 있는지
시작일 / 기한 일정
계획 작업량(MD) 계획 공수(Original Estimate)
예상 완료일 계획 공수·작업 인원·근무일로 추정한 종료일
실투입(MD) 누적 워크로그 + 진행 바와 초과율 배지(100% 초과 시)
편차 완료 이슈만 표시. 계획 대비 실제(+ 초과, − 절감)

색으로 위험을 읽습니다 초록 = 계획 이내(≤100%) / 주황 = 초과(100~130%) / 빨강 = 심한 초과(130% 이상)

활용

  • 추정 정확도: 계획보다 공수를 훨씬 많이/적게 쓴 이슈 → 견적 역량 점검
  • 공수 초과: 빨강 막대·큰 +편차 이슈는 비효율 또는 범위 누락(scope creep) 후보
  • 완료 회고: 편차 컬럼으로 끝난 이슈의 계획 정확도를 사후 검증
  • 일정 리스크 예고: 예상 완료일이 기한을 넘는 이슈를 미리 발견

상세 차트 (이슈 클릭)

선택 이슈의 누적 공수 S-curve입니다.

  • 파란 실선 = 실제 누적 투입 / 회색 점선 = 시작~기한 균등 분배한 이상적 계획선
  • 오늘·기한·예측 종료일 마커와 편차 막대(실제−계획)
  • 실선이 점선보다 가파르면 계획보다 빨리 소진(초과 위험), 완만하면 지연 신호. 아래 워크로그 원본으로 "언제 누가 얼마나" 투입했는지 추적

버튼·입력 항목과 처리 결과 상세

작업 분석은 프로젝트 작업의 계획과 누적 실적을 비교하고 상세 워크로그로 원인을 확인합니다.

버튼·입력 항목 기능·사용 조건·변경 대상 결과 확인과 문제 대응
검색·스페이스/작업 필터·페이지 작업 목록을 좁히고 페이지를 이동합니다. 이슈 목록 조회 조건이며 워크로그를 수정하지 않습니다. 필터 결과와 프로젝트 전체 수치를 같은 것으로 보지 않습니다.
계획 MD·실제 MD·편차·예상 완료일 계획은 Original Estimate, 실적은 Jira 워크로그 기준입니다. 예상 완료일은 인원·계획·근무일 기반 추정이며 확정 기한이 아닙니다. 완료 이슈의 초과·미달 편차와 계획 없는 이슈를 구분합니다. 숫자는 시간 설정에 따라 환산됩니다.
행 선택·분석 보기·확대·닫기 선택 이슈의 분석 차트와 기록 상세를 서랍에서 보고 확대합니다. 닫기는 원본 데이터 삭제가 아닙니다. 선택한 키와 상세 제목을 확인하고 실제 기록자·시간을 대조합니다.
Excel 내보내기 분석 목록의 데이터를 파일로 내보냅니다. 전사 워크로그 추출과 같은 기능은 아닙니다. 필터·대상·단위를 확인하고 부분 조회 안내가 있으면 파일도 해당 범위로 해석합니다.
