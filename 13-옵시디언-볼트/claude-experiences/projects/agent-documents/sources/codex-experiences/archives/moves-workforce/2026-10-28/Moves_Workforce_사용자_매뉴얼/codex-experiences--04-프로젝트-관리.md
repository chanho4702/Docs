# 4. 프로젝트 관리

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 메뉴 노출 | **권한 불필요** — 사이드바에 항상 표시됩니다 |
| **프로젝트 목록** 탭 | 「프로젝트 관리」 읽기 (없으면 탭이 보이지 않습니다) |
| 프로젝트 추가·수정·삭제, 필요 스킬 편집 | 「프로젝트 관리」 쓰기 |
| **칸반 보드** 탭 | 「칸반 보드」 읽기 |
| 칸반 카드 드래그·컬럼 추가·삭제 | 「칸반 보드」 쓰기 |

- 두 탭은 **권한이 서로 다릅니다.** 「프로젝트 관리」만 있으면 목록만, 「칸반 보드」만 있으면 칸반만 보입니다.
- 보이는 프로젝트 **범위**는 권한 세트의 조회 범위(전체 / 소속 프로젝트만 / 내 팀만)를 따릅니다 — [1.4 참고](codex-experiences--01-%EA%B0%9C%EC%9A%94.md#14-권한의-기본-개념).

---

**언제 쓰나** — 프로젝트를 **만들고, 상태를 관리하고, 상세로 진입**하는 출발점입니다.

좌측 **프로젝트 관리** 메뉴로 진입하며 상단에 두 탭이 있습니다: **프로젝트 관리**(목록), **칸반 보드**. 선택한 탭은 주소에 남아 새로고침해도 유지됩니다.

## 4.1 프로젝트 목록

![그림 4-1 프로젝트 목록과 상세 드로어](./images/04-project-list-drawer.png)
*그림 4-1. 프로젝트 목록 — ① 이름 검색 ② + 프로젝트 추가 ③ 행 클릭으로 열린 상세 드로어(기간·참여 인력·요구 스킬·상세 페이지 열기).*

| 컬럼 | 설명 |
|---|---|
| 프로젝트 이름 | **이름을 클릭**하면 [프로젝트 상세](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/codex-experiences--README.md)로 이동 |
| 프로젝트 상태 | 색 라벨. 예: To Do / IN PROGRESS / DONE ([7.7에서 정의](07-%EC%84%A4%EC%A0%95/codex-experiences--07-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%ED%83%9C-%EA%B4%80%EB%A6%AC.md)) |
| 시작일 / 종료일 | 프로젝트 기간 |
| 프로젝트 비용 | 프로젝트 등록 시 입력한 예산값. 급여 정책으로 계산하는 **계획 인건비와는 별개** |
| 추가 작업 | 수정 / 삭제 |

- 상단 **프로젝트 이름** 입력 후 **검색**으로 필터링, 새로고침 아이콘으로 목록 갱신
- 우측 위 **+ 프로젝트 추가**로 새 프로젝트 등록
- **행의 빈 곳을 클릭**하면 오른쪽에 **상세 드로어**가 열립니다. 상세 페이지로 들어가지 않고 기간·참여 인력·요구 스킬을 훑어보고, **수정 / 삭제 / 상세 페이지 열기**로 이어갈 수 있습니다.

### 프로젝트 추가 / 수정

![그림 4-2 프로젝트 추가 창](./images/04-project-modal.png)
*그림 4-2. 프로젝트 추가 창 — ① 기본 정보 ② 필요 스킬(직군 필터·검색·선택 목록) ③ 저장.*

| 항목 | 필수 | 설명 |
|---|---|---|
| 프로젝트 이름 | 필수 | |
| 프로젝트 상태 | 필수 | 프로젝트 상태 관리에서 정의한 값 중 선택 |
| 시작일 / 종료일 | 필수 | |
| 프로젝트 비용 | 필수 | 숫자(천 단위 콤마 자동). 비용 분석의 계획 인건비와는 별개 |
| **필요 스킬** | | 이 프로젝트에 필요한 스킬을 [스킬 사전](07-%EC%84%A4%EC%A0%95/codex-experiences--06-%EC%8A%A4%ED%82%AC-%EA%B4%80%EB%A6%AC.md)에서 고릅니다. 직군으로 좁히거나 이름으로 검색해 선택하며, 나중에 바꿀 수 있습니다 |

> 수정 모드에서는 **등록·수정 정보**(생성자/생성일시·수정자/수정일시)가 읽기 전용으로 함께 표시됩니다.

> **필요 스킬은 프로젝트 저장 시 함께 반영됩니다.** 기본 정보는 저장됐는데 스킬 저장이 끝나지 않으면 "다시 저장해 주세요" 안내가 뜨며 선택 내역은 유지됩니다. 여기서 정한 스킬이 [6.4 프로젝트 배정](06-%EC%9E%90%EC%9B%90-%EA%B4%80%EB%A6%AC/codex-experiences--04-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EB%B0%B0%EC%A0%95.md)의 **적합도** 계산 기준이 됩니다.

> **기간 입력을 빠뜨리지 마세요.** 프로젝트 시작일·종료일이 없으면 **인건비 환산(투입 개월수)과 진척률 계산이 모두 0**이 됩니다([5.2](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/codex-experiences--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md#인건비가-0원으로-나올-때), [5.5](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/codex-experiences--05-%EB%B6%84%EC%84%9D-%EB%B0%8F-%EB%A6%AC%ED%8F%AC%ED%8A%B8.md#554-진척률) 참고).

### 프로젝트 삭제

프로젝트를 삭제하면 소속 인력·대시보드·간트·스킬 매핑 등 관련 데이터가 함께 삭제되며 되돌릴 수 없습니다. 확인 후 **삭제 진행** 창이 열려 단계별 진행 상태(이슈 연결 해제 → 간트 연결 정리 → 스킬 정리 → …)를 보여줍니다.

- **Jira 이슈 자체는 삭제되지 않습니다.** 이슈에 남아 있던 이 프로젝트와의 연결만 해제됩니다.
- 중간에 실패하면 진행 상태가 보존되어 **삭제 재시도**로 이어서 진행할 수 있습니다.
- "연결된 Jira 이슈에 접근할 수 없어 삭제를 완료할 수 없습니다"가 뜨면, 그 이슈를 볼 수 있는 관리자에게 재시도를 요청하세요. 삭제는 실행자의 Jira 권한으로 이슈를 정리하기 때문입니다.

## 4.2 칸반 보드

프로젝트를 **상태 컬럼별 카드**로 보여주며 드래그로 상태를 바꾸는 보드입니다.

![그림 4-3 칸반 보드](./images/04-kanban-board.png)
*그림 4-3. 칸반 보드 — ① 상태 컬럼 ② 프로젝트 카드(드래그 중) ③ 컬럼 하단 + 프로젝트 추가 ④ 우측 끝 컬럼 추가.*

- **컬럼 = 프로젝트 상태**([프로젝트 상태 관리](07-%EC%84%A4%EC%A0%95/codex-experiences--07-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%ED%83%9C-%EA%B4%80%EB%A6%AC.md)에서 정의한 순서)
- **카드 = 프로젝트**(프로젝트명, 기간, 담당 아바타)

| 하고 싶은 일 | 조작 |
|---|---|
| 상태 변경 | 카드를 다른 컬럼으로 **드래그** (즉시 반영) |
| 프로젝트 수정 | 카드 클릭 → 추가/수정 모달 |
| 이름만 빠르게 변경 | 카드 제목 **인라인 편집** |
| 프로젝트 삭제 | 카드 메뉴 → 삭제 (목록과 같은 삭제 진행 창) |
| 상태 컬럼 추가 | 우측 끝 **+** 버튼 |
| 상태 이름 변경 | 컬럼 헤더 인라인 수정 |
| 상태 삭제 | 컬럼 메뉴 → 삭제 (최소 1개 필요, 이전 상태가 있어야 가능) |
| 그 상태로 프로젝트 신규 등록 | 각 컬럼 하단 **+ 프로젝트 추가** |
| 과거 프로젝트 더 보기 | 마지막(완료) 컬럼 하단 **더보기** |

> 쓰기 권한(「칸반 보드」 쓰기)이 없으면 드래그·추가·삭제·이름 변경이 비활성화되고 **조회만** 가능합니다.
> 상태 변경은 서버에서도 검증합니다. 거부되면 카드가 원래 컬럼으로 되돌아가고 사유가 표시됩니다.

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 목록 탭 또는 칸반 탭이 없습니다 | 각각 「프로젝트 관리」 읽기, 「칸반 보드」 읽기 권한이 없습니다 |
| 내가 참여하는 프로젝트가 안 보입니다 | 조회 범위가 "소속 프로젝트만"인데 [인력 관리](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/codex-experiences--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md)에 등록돼 있지 않습니다 |
| 칸반이 비어 있습니다 | 상태 컬럼이 하나도 없습니다. [7.7](07-%EC%84%A4%EC%A0%95/codex-experiences--07-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%ED%83%9C-%EA%B4%80%EB%A6%AC.md)에서 상태를 먼저 만드세요 |
| 삭제가 중간에 멈췄습니다 | 삭제 진행 창의 **삭제 재시도**를 누르세요. Jira 이슈 접근 권한이 없어 멈춘 경우 권한 있는 관리자가 재시도해야 합니다 |
