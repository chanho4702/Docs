# 7.5 설정 — 등급 관리

## 🔐 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 (`/backoffice/level`) | `LEVEL_MANAGEMENT` 읽기 |
| 등급 추가·수정·삭제·빠른 추가 | `LEVEL_MANAGEMENT` 쓰기 |
| 급여 밴드(하한·상한·대표값) 입력 | `LEVEL_MANAGEMENT` 쓰기 |

- 등급 **목록**은 `USER_MANAGEMENT` 읽기 또는 `SETTINGS` 읽기로도 조회됩니다(인력 화면의 선택지, 급여 정책 카드의 "밴드 미설정 등급 수" 계산에 필요).
- 급여 밴드는 급여 정책이 `LEVEL_BAND`일 때 인건비 계산에 쓰입니다([7.1](codex-experiences--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md)).

---

**언제 쓰나** — 인력 **등급(Level)** 을 정의하고, 등급 기반 급여 정책을 쓴다면 **급여 밴드**를 채울 때.

## 목록 컬럼

| 컬럼 | 설명 |
|---|---|
| 등급 / 설명 | 등급명과 설명 (예: Senior / 10년차 이상) |
| 급여 범위 | 하한 ~ 상한 |
| 대표값 | **인건비 계산에 실제로 쓰이는 값** |

## 등록 방법 두 가지

| 방법 | 설명 |
|---|---|
| **등급 추가** | 이름·설명·급여 밴드를 입력해 하나씩 등록 |
| **빠른 추가** | 직급 체계 프리셋에서 골라 한 번에 등록 |

**프리셋 종류**: 일반(Junior/Senior) · 등급제(G1~G5) · 한국식 직급 · Band 체계

## 급여 밴드 입력 규칙

급여 정책이 `LEVEL_BAND`(등급 기반)일 때 사용됩니다.

| 항목 | 규칙 |
|---|---|
| 하한 / 상한 | 0 이상. **하한이 상한보다 크면 저장 거부** |
| **대표값** | **계산에 쓰이는 값.** 비워 두면 **중앙값**(`(하한 + 상한) ÷ 2`)이 자동 입력됩니다 |

- **중앙값 계산** 버튼으로 대표값을 채울 수 있습니다.
- 대표값이 하한~상한 범위를 벗어나도 **저장은 허용**됩니다(관리자 판단 존중). "대표값이 급여 범위를 벗어났습니다. 그대로 저장할 수 있습니다" 경고만 표시됩니다.

> 급여 정책이 '인원별'이면 **"급여 밴드는 사용되지 않습니다"** 안내와 함께 [설정으로 이동하는 링크](codex-experiences--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md)가 표시됩니다.

## 밴드를 비워 두면 생기는 일

등급 기반 정책에서 **밴드(대표값)가 없는 등급**의 인원은 **인건비가 0으로 계산**됩니다.

- [7.1 일반 설정](codex-experiences--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md)에서 정책을 전환할 때 "등급 N개에 급여 밴드가 없습니다" 경고가 표시됩니다.
- 비용 화면의 [**미산정 인원**](../05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/codex-experiences--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md#인건비가-0원으로-나올-때) 지표로도 확인할 수 있습니다.
