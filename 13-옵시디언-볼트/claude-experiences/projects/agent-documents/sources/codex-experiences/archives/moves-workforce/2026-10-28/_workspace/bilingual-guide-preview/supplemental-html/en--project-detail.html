What you can do in project details

Select a project from the project list, Kanban, or My Work. Each tab follows its own read and write permissions. A direct link does not grant access to projects outside your visibility scope.

  • Screens and access
  • Project dashboard
  • People and labor cost
  • Work and schedules
  • Project calendar
  • Analysis and reports
  • Linking Confluence documents

Set up a new project

Add project members, link existing Jira work items, and review dates and planned effort. Link design documents or meeting notes to the project or its work items. Use progress analysis and the dashboard for weekly reporting.
