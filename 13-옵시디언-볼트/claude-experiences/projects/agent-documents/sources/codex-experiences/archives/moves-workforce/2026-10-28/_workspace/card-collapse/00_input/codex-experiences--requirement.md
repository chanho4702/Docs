# 요구사항: 분석 카드 우측 상단 버튼 정리 — 접기/확장 + 리플로우

> 2026-08-12. 사용자 원문 요지: "자원관리 팀 분석 쪽 카드 우측 상단 버튼이 동작을 안 함. 새로고침 버튼은 필요 없고, 접기 버튼이랑 확장 버튼만 있으면 될 듯. 접기 버튼은 접혀서 공간이 생기면 아래 카드가 올라와야 해. 통합 대시보드에도 적용해줘."

## 문제 (설계 시 실코드로 원인 확정할 것)

1. **자원관리(/resource) > 팀 분석 탭** 카드들의 우측 상단 버튼이 **동작하지 않는다** — 어떤 버튼들이 왜 죽어 있는지 원인 확정 필수 (새로고침·확장 등 무엇이 렌더되고 핸들러가 어디서 끊기는지).

## 요구

1. 카드 우측 상단 버튼을 **접기 + 확장(전체화면) 2개로 정리**. 새로고침 버튼은 제거.
2. **접기**: 카드 본문을 접어 헤더만 남기고, **비워진 공간만큼 아래 카드가 위로 올라와야 한다**(그리드 리플로우). 다시 펼치기 가능. 상태는 새로고침 후에도 유지되면 좋음(localStorage — 패널 레이아웃 전례).
3. **확장**: 기존 전체화면 확장(CardFullscreen 계열)이 실동작해야 한다.
4. **적용 화면 2곳**: 자원관리 팀 분석 탭 + **통합 대시보드(/dashboard, portfolio)**. 두 화면의 카드 셸이 다르면 공용 지점으로 수렴(RFC-178 원칙 — components/card·chart 공용 컴포넌트 우선).
5. 접기/확장 UI는 이번에 만든 관례와 일관되게(chevron 계열 아이콘, aria-disabled 패턴 등 — ResizablePanels/PanelToggleButton 전례 참고).

## 제약

- 데이터 로직·쿼리 훅 무변경(레이아웃/셸만). 신규 외부 의존성 금지.
- 카드 접힘 리플로우는 각 화면의 그리드 구조(BentoGrid 등) 안에서 자연스럽게 — 그리드 메커니즘 교체 같은 대수술 금지. 구조상 리플로우가 불가한 배치가 있으면 사유와 함께 설계에서 명시.
- Atlaskit 토큰만(다크 테마), i18n kr/en + merge 규약.
- 프로젝트 상세 대시보드(react-grid-layout)는 **범위 밖** — 이번엔 팀 분석 + 통합 대시보드 2곳만.

## 검증 포인트

- 죽은 버튼의 원인과 해소, 새로고침 버튼 제거
- 접기 → 아래 카드 상승(리플로우), 펼치기 복귀, 상태 유지
- 확장 실동작 (두 화면 모두)
- 데이터 훅·쿼리 무회귀, 전체 테스트·CI 빌드·번들 예산
