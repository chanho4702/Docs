# Storage 프로젝트 사용량 귀속 감사 후속

기능 감사에서 확인된 P1 위험을 해결한다. Storage/KVS에서 프로젝트별 사용량을 계산하거나 정리하는 경로가 다른 프로젝트 데이터를 잘못 포함·제거·집계하지 않는지 조사하고 최소 범위로 보완한다.

- 프로젝트 경계가 있는 모든 Storage/KVS 조회·삭제·집계 진입점을 식별한다.
- key prefix, entity index, payload 기반 귀속을 검증한다.
- 잘못된 귀속은 fail-close 또는 정확한 프로젝트 predicate로 보정한다.
- 영향 범위, 응답 계약, 테스트 계획을 문서화한다.
