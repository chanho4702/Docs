# 6.2 조직 현황

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | 「자원관리」 읽기 |
| 조직 계층·팀장·팀원 **편집** | 이 화면에서는 불가 — [7.3 팀 관리](../07-%EC%84%A4%EC%A0%95/codex-experiences--03-%ED%8C%80-%EA%B4%80%EB%A6%AC.md)에서 「팀 관리」 쓰기로 수행 |

- 이 화면은 **조회 전용**입니다. 팀 생성·이동·팀원 배치는 설정 화면에서 합니다.
- 보이는 팀·인원 범위는 관리자면 전사, 팀장이면 자신이 이끄는 팀과 하위 팀입니다.

---

**언제 쓰나** — **조직도 관점**에서 팀 구성과 팀별 인원·가동률을 볼 때.

![그림 6-3 조직 현황](../images/06-resource-org.png)
*그림 6-3. 조직 현황 — ① 팀 트리(팀장·직속/누적 인원) ② 직속 인원만 보기 토글 ③ 선택 팀의 팀원 목록(팀장 배지·가동률·보유 스킬).*

## 화면 구성

**왼쪽 — 팀 트리**

- 전사 → 팀 → 하위 팀 계층
- 팀별 **팀장**, **인원 수** 표시 — `직속 N명 / 누적 M명`
- **직속 인원만 보기** 토글로 하위 팀 인원 포함 여부를 전환

**오른쪽 — 팀원 목록**

| 컬럼 | 내용 |
|---|---|
| 팀원 | 이름·아바타. 팀장은 맨 앞에 **팀장** 배지와 함께 |
| 팀 | 소속 팀 |
| 직무 / 등급 | 직무 정보 |
| 가동률 | 배치 집계 기준 |
| 보유 스킬 | 등록된 스킬 태그 |

## 알아두기

- 아직 집계되지 않은 인원이 있으면 **"N명은 아직 집계 전이라 합계에서 제외되었습니다"** 가 표시됩니다. 팀 합계를 읽을 때 이 안내를 함께 확인하세요.
- 표시할 팀원이 없으면 빈 상태 안내가 나옵니다. 팀에 사람을 배치하려면 [7.3 팀 관리](../07-%EC%84%A4%EC%A0%95/codex-experiences--03-%ED%8C%80-%EA%B4%80%EB%A6%AC.md)의 **팀원 배치**를 사용합니다.
- 조직 계층 자체(상위 팀·팀장·팀 권한)는 이 화면이 아니라 [7.3 팀 관리](../07-%EC%84%A4%EC%A0%95/codex-experiences--03-%ED%8C%80-%EA%B4%80%EB%A6%AC.md)에서 편집합니다.
- 팀장은 항상 그 팀의 소속 인원으로 세어집니다([7.3 규칙](../07-%EC%84%A4%EC%A0%95/codex-experiences--03-%ED%8C%80-%EA%B4%80%EB%A6%AC.md#팀장-규칙)).

## 이 화면과 팀 분석의 차이

| | 조직 현황 | [팀 분석](codex-experiences--03-%ED%8C%80-%EB%B6%84%EC%84%9D.md) |
|---|---|---|
| 보는 단위 | **사람** (팀에 속한 개인 목록) | **팀** (팀 간 비교·롤업) |
| 쓰는 때 | "이 팀에 누가 있지?" | "어느 팀이 과부하지?" |
