## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | 「자원관리」 읽기 |
| 조직 계층·팀장·팀원 **편집** | 이 화면에서는 불가 — [7.3 팀 관리](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/172916876)에서 「팀 관리」 쓰기로 수행 |

- 이 화면은 **조회 전용**입니다. 팀 생성·이동·팀원 배치는 설정 화면에서 합니다.
- 보이는 팀·인원 범위는 관리자면 전사, 팀장이면 자신이 이끄는 팀과 하위 팀입니다.


**언제 쓰나** — **조직도 관점**에서 팀 구성과 팀별 인원·가동률을 볼 때.

> **[이미지 삽입 위치 · 추가 캡처 필요]** 조직 현황 — ① 팀 트리(팀장·직속/누적 인원) ② 직속 인원만 보기 토글 ③ 선택 팀의 팀원 목록(팀장 배지·가동률·보유 스킬).


## 화면 구성

**왼쪽 — 팀 트리**

- 전사 → 팀 → 하위 팀 계층
- 팀별 **팀장**, **인원 수** 표시 — `직속 N명 / 누적 M명`
- **직속 인원만 보기** 토글로 하위 팀 인원 포함 여부를 전환

**오른쪽 — 팀원 목록**

| 컬럼 | 내용 |
|---|---|
| 팀원 | 이름·아바타. 팀장은 맨 앞에 **팀장** 배지와 함께 |
| 팀 | 소속 팀 |
| 직무 / 등급 | 직무 정보 |
| 가동률 | 배치 집계 기준 |
| 보유 스킬 | 등록된 스킬 태그 |

## 알아두기

- 아직 집계되지 않은 인원이 있으면 **"N명은 아직 집계 전이라 합계에서 제외되었습니다"** 가 표시됩니다. 팀 합계를 읽을 때 이 안내를 함께 확인하세요.
- 표시할 팀원이 없으면 빈 상태 안내가 나옵니다. 팀에 사람을 배치하려면 [7.3 팀 관리](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/172916876)의 **팀원 배치**를 사용합니다.
- 조직 계층 자체(상위 팀·팀장·팀 권한)는 이 화면이 아니라 [7.3 팀 관리](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/172916876)에서 편집합니다.
- 팀장은 항상 그 팀의 소속 인원으로 세어집니다([7.3 규칙](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/172916876)).

## 이 화면과 팀 분석의 차이

| | 조직 현황 | [팀 분석](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/173178915) |
|---|---|---|

## 버튼·입력 항목과 처리 결과 상세

조직 현황은 팀 계층과 허용된 구성원을 확인합니다. 조직 설정 편집과 별개입니다.

| 버튼·입력 항목 | 기능·사용 조건·변경 대상 | 결과 확인과 문제 대응 |
|---|---|---|
| 팀 선택·전사·직속만 | 허용된 트리에서 선택하고 직속 또는 하위 팀 포함 명단을 확인합니다. 전사 표시는 전사 열람 가능한 계정에서만 전체 범위입니다. | 팀장 열람은 담당 팀·하위 팀으로 제한될 수 있습니다. 조직 이름이 같아도 계정별 총인원은 다를 수 있습니다. |
| 구성원·역할·레벨·스킬·가동률 | 현재 소속과 기준 정보를 조회하고 집계된 가동률을 확인합니다. | 미집계를 0으로 판단하지 않습니다. 팀 이동과 권한 변경은 설정의 관리 화면에서 수행합니다. |
