사용자는 작업 진행 시 선택지를 묻거나 승인을 기다리지 말고, 합리적인 기본값을 골라 끝까지 실행하기를 원한다. ("이제부터 나한테 묻지 말고 다 실행하셈")

**Why:** 사용자가 빠른 진행을 우선시하며, 의사결정 왕복으로 인한 지연을 싫어함.

**How to apply:** 의존성 충돌·버전 선택 등에서 옵션을 나열하고 멈추지 말 것. 가장 합리적인 방향(예: 최신 호환 버전으로 업그레이드)을 스스로 정해 적용하고, 설치·빌드 검증까지 마친 뒤 결과를 보고한다. 되돌리기 어렵거나 외부에 영향을 주는 작업만 예외적으로 확인한다.
