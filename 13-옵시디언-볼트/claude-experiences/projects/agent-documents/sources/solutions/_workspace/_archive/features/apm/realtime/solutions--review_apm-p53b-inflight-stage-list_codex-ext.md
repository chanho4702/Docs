### 효율성 총평

평상시 tracker는 무락 CAS 기반이며 상한과 ABA 안전성은 양호하다.  
다만 정상 HTTP 시작의 다중 volatile write와 자식 작업별 boxing·Context 할당은 고빈도 고객 JVM에서 줄일 여지가 크다.  
가장 우선할 사항은 목록 생성의 절대 크기 제한, 종료 시 참조 scrub, 초기화 실패 시 listener 비활성화다.  
최대 설정에서는 초당 세 번의 1M 배열 순회가 가능하므로 단일 순회와 현실적인 설정 상한이 필요하다.
