## 1. 호스트 관리
**화면**: 목록 2탭(호스트 / 호스트 그룹) → 호스트명 클릭 시 **드릴다운 상세**(정보·아이템·트리거·디스커버리·매크로 5탭). 등록/수정은 드로어, 삭제는 이름 타이핑 확인 모달.
**할 수 있는 것**
- 필터: 검색어, 호스트 그룹(다중), 적용 템플릿(다중), 활성/비활성, 장비 분류
- 행에서 바로: 활성/비활성 **스위치**, 아이템·트리거·디스커버리 개수 클릭 → 해당 탭, 템플릿 칩 클릭 → 템플릿 상세
- **호스트 등록**: 기술명/표시명, 그룹(즉석 신규 그룹), 인터페이스(IP/DNS·포트), 템플릿 연결/해제(해제 시 데이터 삭제 여부 선택), 모니터링 주체(서버/프록시), 장비 분류, 태그. 등록 직후 **라이브체크**(ping/agent) 결과와 agent 불가 시 트러블슈팅 안내
- **일괄**: 선택 호스트 장비 분류 일괄 지정(부분 실패는 실패 건만 선택 유지)
- 상세 › 정보: 메타·인터페이스 표(유형·주소·기본·가용성), 수정/삭제/상태 토글
- 그룹 탭: 그룹 생성 / 이름 수정 / 다건 삭제
**제약**: 장비 분류 필터는 현재 페이지 내 클라이언트 필터. 그룹/템플릿 필터 후보는 로드된 호스트에서 집계.

## 2. 템플릿 관리
**화면**: 목록 2탭(템플릿 / 템플릿 그룹) → 템플릿 상세(정보·아이템·트리거·디스커버리·매크로 — 호스트 상세와 대칭).
**할 수 있는 것**
- 목록: 검색·템플릿 그룹 필터, **템플릿 생성**, 다건 삭제, 아이템 수 → 상세 아이템 탭, 트리거 수 → 트리거 렌즈(템플릿 필터 적용), 연결 호스트 수 → 상세
- 상세 › 정보: 수정/삭제, **호스트 연결(link, 다중)** / **개별 해제(unlink, 데이터 삭제 옵션)**
- 템플릿 그룹: 생성 / 이름 수정 / 삭제, 개수 클릭 → 포함 템플릿 드로어(읽기)
**제약**: 목록에서는 생성·다건 삭제만, 개별 수정과 link/unlink는 상세에서.

### 2-A. 호스트/템플릿 상세 공통 탭
- **아이템 탭**: 목록(이름/키·정의처·유형·값 타입·주기·상태), 검색·상태·정의처 템플릿 필터. **생성**(키 카탈로그 자동완성, 유형, 값 타입, 인터페이스, 마스터 아이템, 주기, 단위, 설명) / 수정 / 개별·다건 삭제 / 상태 토글. ⚠️ **상속 아이템은 수정·삭제 불가(상태 토글은 가능)**, 디스커버리 생성분은 토글도 불가.
- **트리거 탭**: 목록(이름+표현식·대상·심각도·상태). **생성**(키 참조 선택 시 `last(/호스트/키)` 스니펫 자동 삽입, 복구 모드/표현식, 심각도) / 수정 / 삭제 / 토글. 표현식 오류는 Zabbix 원문 그대로 표시. ⚠️ **상속 트리거는 토글까지 불가**.
- **디스커버리 탭(LLD)**: 규칙 목록(이름/키·유형·주기·생성물 수·상태·정의처). 생성 / 수정 / 삭제 / 토글, 행 클릭 → 상세 드로어(정보·**프로토타입(아이템/트리거/그래프/호스트) 편집**·발견된 항목). ⚠️ 상속 규칙은 수정·삭제 불가(토글만).
- **매크로 탭**: §7 참조.

## 3. 아이템 관리(아이템 렌즈)
**화면**: 단일 목록 + 필터 바 + **뷰 세그먼트(정의 / 전체)** + [아이템 생성](대상 호스트/템플릿 선택 → 생성 드로어).
**할 수 있는 것**
- 필터: 호스트 그룹·호스트·템플릿(다중), 유형, 상태, 원천(일반/디스커버리 — 전체 뷰), 검색
- 뷰: **정의**(정의 원본만, 기본) / **전체**(상속 사본·디스커버리 생성분 포함)
- 컬럼: 이름/키(+상속·디스커버리 뱃지), 컨테이너(호스트/템플릿 링크), **정의처**, **전파(N개 호스트 → Popover로 목록·상세 이동)**, 유형, 상태
- 수정 / 개별·다건 삭제 / 상태 토글, 상단 생성
**제약**: 상속본 수정·삭제 불가(토글 가능), 디스커버리 생성분 전부 불가. 5만 건 초과 시 `truncated` 배너와 탐색 상한.

## 4. 트리거 관리(트리거 렌즈)
아이템 렌즈와 동형. 차이: 필터에 **심각도**(유형/원천 대신), 컬럼에 심각도 태그, **상속 행은 토글까지 차단**. [트리거 생성] → 대상 선택 → 트리거 드로어.

## 5. 네트워크 디스커버리
**화면**: 규칙(drule) 목록 + [규칙 생성]. 행 클릭 → 상세 드로어(정보 / **발견된 장비** / **연결된 액션**). 생성·수정 드로어는 **기본 / 액션** 2탭.
**할 수 있는 것**
- 목록: 이름(+실행 오류 원문), IP 범위·IP 개수, 스캐너(서버/프록시), 주기, 동시 검사 수, 검사 종류 태그, 상태
- **액션 연계 컬럼**: 액션 0건이면 "액션 없음" 경고(클릭 → 그 규칙의 액션 탭), 연결 N건/전역 N건 → 알림 관리 디스커버리 액션 목록, **호스트를 만드는 오퍼레이션이 없으면 "발견만 하고 끝" 경고**
- 규칙 생성/수정(IP 범위·주기·프록시·동시 검사 수·**검사(dcheck) 목록 편집**), 상태 토글, 삭제
- 폼 › 액션 탭: 디스커버리 액션 **체크로 연결/해제 → 적용**, **표준 액션 빠른 생성**(이름 + 호스트 그룹/템플릿 선택). 규칙 생성 완료 시 자동으로 액션 탭 재오픈
**제약**: SNMPv3 암호는 조회로 안 내려와 편집 시 비어 있음(비우면 유지). 그 규칙이 유일 조건인 액션은 해제 시 BE가 거부(`ACTION_UNLINK_MAKES_GLOBAL`, 전역 액션화 방지). IP 개수 `null`=계산 불가.

## 6. 알림 관리 (3탭)
### 6-1. 액션
- eventsource 5종 세그먼트(장애 / 디스커버리 / 자동 등록 / 내부 / 서비스) + 종류별 설명 배너
- 목록: 이름, 조건 요약, 오퍼레이션 요약(호스트를 안 만드는 디스커버리/자동등록 액션은 경고), 상태 토글, 수정/삭제
- 생성/수정 드로어: 액션(이름·활성·억제 중 일시정지·증상 이벤트 일시정지·취소 알림·**조건 편집기 And/Or**) / 오퍼레이션(에스컬레이션 단계·기본 단계 시간) / 복구 오퍼레이션 / 업데이트 오퍼레이션
- 오퍼레이션 종류: 메시지(사용자/그룹·미디어), 원격 명령/스크립트, 호스트 추가·삭제·활성·비활성, 호스트 그룹 추가/제거, 템플릿 연결/해제, 인벤토리 모드, 호스트 태그 추가/제거
- 딥링크: 디스커버리 화면에서 `?source=1&create=1&druleid=N`(규칙 조건 프리필), `?edit=actionid`
- 제약: 조건 없음 = 모든 이벤트 대상. 종류마다 허용 오퍼레이션이 다름. 저장 시 조건/오퍼레이션은 **전체 교체**.
### 6-2. 미디어 타입
- 목록: 이름/설명, 종류(이메일/스크립트/SMS/웹훅), 종류별 대상 요약(SMTP 서버:포트 / 스크립트 경로 / 모뎀 / 웹훅 파라미터 수), **사용 중 액션 수**, 상태 토글, 수정/삭제
- 드로어: 종류별 폼(이메일 SMTP·보안·인증, 스크립트 경로, SMS 모뎀, 웹훅 파라미터·스크립트·타임아웃) + 동시 세션/재시도/간격/설명
- 제약: **사용 중이면 삭제 불가**(버튼 비활성+툴팁, BE `MEDIA_TYPE_IN_USE`). 비밀번호는 비우면 유지. **테스트 발송 없음**(Zabbix 7.0에 `mediatype.test` API 부재 — 안내 문구).
### 6-3. 점검 기간(Maintenance)
- 목록: 이름/설명, 상태(진행 중/예정/만료)+지금 점검 중 호스트 수, 유효 기간, 기간 요약, 대상(그룹/호스트/태그), 유형(수집 유지/중단), 수정/삭제
- 드로어: 이름, 유형, 유효 기간, 대상 그룹/호스트, **기간 편집기(1회/일/주/월 반복)**, 태그 조건
- 제약: 상태·요약·호스트 수는 BE 계산. 검색/상태 필터는 클라이언트, 페이지네이션 없음.

## 7. 매크로 관리
**전역 페이지**: 설명 배너 + 검색 + [매크로 생성] + 표. 값 유형 **텍스트 / 비밀(secret) / Vault**. 조회(클라이언트 검색)·생성·수정·삭제.
**호스트/템플릿 매크로 탭**(상세 › 매크로): 3구간 — **소유**(직접 정의: 생성/수정/삭제) · **템플릿 상속**(출처·깊이 표시, [재정의]=같은 이름 소유 매크로 생성) · **전역**(재정의 또는 전역 관리로 이동). 우선순위 소유→링크 템플릿(가까운 순)→전역, 적용 안 되는 줄은 흐리게.
**제약**: 상속·우선순위 계산은 BE. **비밀 값은 조회로 안 내려옴**(수정 시 비우면 유지, 비밀→일반 전환 시 값 필수). `MACRO_NAME_INVALID`/`MACRO_DUPLICATE` 등은 서버 메시지 그대로.

## 8. 사용자 관리 (3탭)
- **사용자**: 목록(사용자명·역할·유형·그룹·생성 플랫폼·이메일·시각·상태), 상태 필터·검색, **계정 생성**, 이름 클릭 → 수정 모달, 다건 삭제. ⚠️ SUPER_ADMIN 사용자는 선택·삭제 불가.
- **역할**: 목록 + 생성/편집(별도 화면 `/user-management/roles/:utility`) — 사용자 유형 + **DMove 권한 / Zabbix 권한 모듈별 체크 매트릭스**, 다건 삭제
- **사용자 그룹**: 목록 + 상태 필터 + 생성 + 수정 모달 + 다건 삭제

## 공통 규칙
- 상속(inherited) 항목: 아이템·LLD 규칙은 수정/삭제 불가·토글 가능, 트리거는 토글까지 불가. FE 차단은 1차, BE도 거부.
- 업무 오류(권한·검증)는 HTTP 200 + body code → 화면은 토스트. Zabbix 원문 오류(표현식·사용 중 등)는 그대로 노출.
- 탭·필터·페이지는 전부 URL 쿼리(뒤로가기·공유 가능).
- 구 경로(`/configuration`, `/item-template-management`, `/trigger-management`, `/maintenance-management`, `/connection-info`)는 새 위치로 자동 이동.
