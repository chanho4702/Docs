# MovesEye 제품 정리
출처: MovesEye 프로젝트 설계서·포트폴리오 종합(`_workspace/guides/notion_moveseye-portfolio.md`, `CLAUDE.md`) 정리일: 2026-08-25

## 1. 제품 개요

MovesEye는 DMOVE(Dmove Inc.)가 개발한 **Zabbix 기반 설치형(on-prem) 인프라 모니터링 대시보드**입니다. Zabbix API 위에서 동작하며, 특정 데이터소스에 고정되지 않도록 수집 엔진을 포트 단위로 분리해두어 향후 Prometheus·Datadog·Elastic 등 **다중 데이터소스**로 확장할 수 있는 구조를 갖췄습니다. 사용자 수 기준이 아니라 **에디션(일반/프리미엄) 기준**으로 라이선스를 판매하며, 라이선스는 기간제 또는 영구로 발급되고 갱신은 등록일 기준으로 계산됩니다.

조직의 인프라가 커질수록 Zabbix 원본 화면만으로는 장애 원인 파악·자산 비용 추적·반복 운영 업무가 버거워집니다. MovesEye는 이 세 가지를 자동화된 UX와 AI로 대신합니다.

핵심 목적 세 가지:
- **인프라 모니터링 통합** — Zabbix의 어렵고 낯선 화면·용어를 쉬운 대시보드로 감쌉니다. 새 기능을 붙일 때도 "이거 Zabbix에 있나?"를 먼저 묻고, Zabbix가 못 해주는 계산값·마스킹·안내 문구만 보탭니다.
- **자산 · 비용 가시화** — 인프라 자산을 등록·추적하고, 감가상각까지 계산해 비용 관점에서 관리합니다.
- **AI로 운영 작업 자동화** — 채팅으로 명령하면 조회·설정·조치를 대신 수행하는 AI 어시스턴트를 제공합니다(쓰기 작업은 사람의 확인을 거칩니다).

### 설치 정보
| 항목 | 내용 |
|---|---|
| 배포 형태 | 설치형(on-prem). BE(:3000)·AI 서버(:3100) 별도 프로세스로 구성 |
| 라이선스 | 일반 에디션 / 프리미엄 에디션, 기간제 또는 영구(RS256 키 기반, 갱신은 등록일 기준) |
| 만료 정책 | 만료 후 30일은 실시간 조회 유지(EXPIRED) → 이후 DB 열람만 가능(ARCHIVED), 단계적 차단 |
| 문의 | 사내 영업/기술 담당 채널 |

## 2. 주요 기능

### 2.1 인프라 모니터링 (Zabbix 래핑)
| 하위 기능 | 설명 |
|---|---|
| 호스트 관리 | 목록/검색, 태그·분류(device_type) 관리, 라이브체크(ping/agent 헬스체크) |
| 호스트 그룹 모니터링 | 가용성·건강도 추이 등 시계열 관점으로 재구성된 그룹 상세 화면 |
| Zabbix 관리 (컨테이너 드릴다운) | 호스트/템플릿 → [정보·아이템·트리거·디스커버리] 서브탭, 액션·미디어·매크로·Maintenance CRUD |
| 전파 가시성(엔티티 렌즈) | 아이템/트리거가 어느 템플릿에서 내려왔는지 한 번에 추적 |
| 이벤트·알림 이력 | 알림 발생 이력 조회, 알림 액션·배달 경로 설정 |

### 2.2 지도 (네트워크 맵 · 지리 맵)
| 하위 기능 | 설명 |
|---|---|
| 네트워크 맵 | draw.io식 작도 도구(React Flow), 스텐실 45종, 문서형 저장으로 자유롭게 구성도를 그려 인프라를 시각화 |
| 지리 맵 | MapLibre 기반 지도 위에 호스트를 배치, 좌표는 Zabbix 인벤토리와 연동해 원천 데이터를 그대로 반영 |

### 2.3 자산 · 비용 관리
| 하위 기능 | 설명 |
|---|---|
| 자산 관리 | Zabbix 등록 항목을 스냅샷으로 가져오거나 커스텀 자산을 등록, 동기화 버튼으로 최신화, 삭제는 이력 보존형(soft delete) |
| 비용(감가상각) | 정액법·정률법 감가상각 엔진(한국 세무 기준, 월할 계산), 기기 유형별 기본값 + 자산별 예외 설정 |

### 2.4 대시보드 · 리포트
| 하위 기능 | 설명 |
|---|---|
| 홈 위젯 대시보드 | 사용자별로 배치를 바꿀 수 있는 위젯 14종 + 항상 고정되는 시스템 위젯 3종 |
| 리포트 관리 | 주별·월별 자원/알람 리포트 자동 생성(배치 스냅샷), 보관 기간(retention) 설정 후 자동 삭제 |

### 2.5 사용자 · 권한 관리
사용자/역할 등록·수정, 호스트 등록 관리, 변경 이력을 남기는 감사 로그로 누가 언제 무엇을 바꿨는지 추적합니다.

### 2.6 AI 어시스턴트
채팅으로 명령하면 MovesEye 설정·운영 작업을 대신 수행합니다. 예: "web-01 CPU 90% 넘으면 높음 심각도 트리거 만들어줘" → 대상 탐색 → 트리거 생성 확인 카드 → 사용자 승인 → 실행 → 결과 보고.

| 구분 | 내용 |
|---|---|
| 실행 범위 | 조회(READ)는 즉시 응답, 설정 변경(WRITE)·삭제(DESTRUCTIVE)는 확인 카드를 거쳐 사람이 승인해야 실행 |
| 권한 | AI 서버 자체 권한 없음 — 사용자의 로그인 권한을 그대로 상속(화면에서 못 하는 일은 AI로도 못 함) |
| 제공 범위 | 조작 가능 툴 52개, 빠른 진입 '/' 명령 26개, 지금 화면에서 뭘 할 수 있는지 안내하는 화면 가이드 |
| 안전장치 | 턴당 툴 호출 상한, 대화당 동시 실행 제한, 월 사용 예산 상한, 대화·툴 호출 기록 30일 보존, 설정 토글이나 라이선스 회수로 즉시 전체 중단 가능 |
| 외부 연동 | Claude Desktop 등 외부 AI 클라이언트가 MovesEye에 연결할 수 있는 MCP 서버 제공(기본은 꺼짐, 켜면 계정별 조회/쓰기 권한 부여) |

### 2.7 클라우드(AWS) 모니터링
AWS EC2·CloudWatch를 연동해 클라우드 자원도 함께 모니터링합니다. CloudWatch 과금이 부담스러운 고객을 위해 스냅샷 기반의 과금 0 옵션과 예산 가드를 제공합니다.

### 2.8 프리미엄 라이선스
GPU 모니터링, AI 어시스턴트 등 일부 기능은 프리미엄 에디션에서만 활성화됩니다. 라이선스가 만료되면 즉시 차단하지 않고 30일간 실시간 조회는 유지한 뒤 DB 열람만 가능한 상태로 전환해, 운영 중인 모니터링 화면이 갑자기 먹통이 되는 상황을 막습니다.

## 3. 누가 필요한가
| 대상 | 필요한 이유 |
|---|---|
| 인프라/IT 운영 담당자 | Zabbix 원시 화면을 오가지 않고도 대시보드에서 장애 원인을 빠르게 파악해야 함 |
| 자산·비용 관리 담당자 | 서버·장비 등 인프라 자산의 취득가·감가상각을 세무 기준으로 추적해야 함 |
| 보안/컴플라이언스 담당자 | 설정 변경 이력을 감사 로그로 추적하고, 역할 기반으로 접근을 통제해야 함 |
| 경영진/의사결정권자 | 인프라 현황과 비용을 한 화면(홈 대시보드)에서 요약해서 보고 싶음 |
| 반복 운영 업무가 많은 실무자 | 트리거 생성, 알림 확인 같은 반복 작업을 매번 여러 화면을 거치지 않고 채팅 명령으로 처리하고 싶음 |

## 4. 왜 필요한가

**Zabbix는 강력하지만 화면이 어렵다** Zabbix 자체 UI는 강력하지만 용어가 낯설고, "이 서버 왜 느려?" 하나를 알기 위해 호스트→아이템→트리거→이벤트를 따로 뒤져야 합니다. MovesEye는 이 과정을 대시보드 하나로 압축합니다.

**인프라 자산도 비용이다** 서버·장비를 사고 나면 그 자산의 감가상각을 추적할 방법이 마땅치 않습니다. MovesEye는 자산 등록과 동시에 세무 기준 감가상각을 계산해, 인프라를 비용 관점에서도 관리할 수 있게 합니다.

**반복 조회·설정 업무는 자동화가 답이다** 알림 확인, 트리거 생성처럼 매일 반복되는 조작을 매번 화면을 오가며 처리하는 대신, 채팅 한 줄로 요청하고 AI가 대신 수행하되 변경은 반드시 사람이 승인합니다.

**하나의 데이터소스에 갇히지 않아야 한다** 기업 고객은 Zabbix만 쓰지 않습니다. 수집 엔진을 포트 단위로 미리 분리해둬, 향후 Prometheus 등 다른 모니터링 소스가 추가돼도 화면과 API는 그대로 유지됩니다.

## 5. 언제 사용하는가
- **장애 대응 시점** — 알림이 발생하면 대시보드에서 호스트→아이템→트리거→이벤트 흐름으로 원인을 추적합니다.
- **정기 리포트·예산 검토 시점** — 주간/월간 리포트와 자산 비용 대시보드로 현황을 확인하고 다음 예산을 결정합니다.
- **신규 장비 도입·폐기 시점** — 자산을 등록·제외하고, 감가상각 값을 갱신합니다.
- **인프라 배치 변경 시점** — 네트워크 맵·지리 맵으로 구성도를 다시 그리고 배치를 시각화합니다.
- **일상 운영 시점** — AI 어시스턴트에 "/문제 web-01" 같은 빠른 명령으로 반복 조회·설정 작업을 맡깁니다.
- **라이선스 갱신 시점** — 프리미엄 기능 사용 현황을 확인하고 에디션·기간을 결정합니다.
