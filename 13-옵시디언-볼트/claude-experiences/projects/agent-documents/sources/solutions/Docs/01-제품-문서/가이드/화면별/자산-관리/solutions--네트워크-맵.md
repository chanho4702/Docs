# 네트워크 맵

> **사이드바** 자산 관리 > 맵 > 네트워크 맵
> **경로** `/asset/network-map` → 편집 `/asset/network-map/:id`

## 무엇을 하는 화면인가

논리 구성도를 직접 그리고, 노드에 **실제 호스트를 연결해 현재 상태가 반영되는 구성도**를 만드는 화면이다.

파워포인트 구성도가 항상 낡는 이유는 그것이 그림이기 때문이다. 여기서 만든 맵은 노드가 실제 호스트에 연결돼 있어 상태가 살아 있다.

## 화면 구성

### 목록

- 맵 이름 검색
- 맵별 **노드 수 · 연결 수** 표시
- **메인** 표시 — 대표 맵 하나를 지정한다
- 아키텍처 생성 / 삭제

### 편집기

드래그로 노드를 배치하고 연결선을 그린다.

- 노드에 실제 호스트를 연결
- 그룹으로 묶기
- 노드·연결선에 설명 추가
- **자동 저장**

## 사용 흐름

1. 목록에서 **아키텍처 생성**.
2. 편집기에서 노드를 배치하고 호스트를 연결한다.
3. 연결선으로 관계를 표현한다.
4. 대표 구성도라면 **메인**으로 지정한다.
5. 라이브 뷰에서 현재 호스트 상태가 반영된 모습을 확인한다.

## 주의할 점

### 동시 편집 충돌

🔴 **여러 사람이 같은 맵을 열면 충돌한다.** 다른 사용자가 먼저 저장하면 이런 안내가 뜬다.

> "다른 곳에서 변경되었습니다. 자동 저장이 중단되었습니다."

이때 선택지는 둘이다.

| 선택 | 결과 |
|---|---|
| **서버 버전 불러오기** | 남의 변경을 가져온다. **내 로컬 변경은 사라진다** |
| **내 변경으로 덮어쓰기** | 내 것을 저장한다. **남의 변경이 사라진다** |

어느 쪽이든 한쪽 작업이 없어지므로, 큰 편집 전에는 담당자를 정해 두는 편이 안전하다.

### 저장 제한

- 다이어그램 크기 상한은 **1MB**다. 초과하면 저장되지 않는다. 노드가 아주 많다면 맵을 분리한다.
- 자동 저장이지만 **저장 전 이탈 시 경고**가 뜬다. "나가기"를 누르면 변경이 사라진다.

### 기타

- **메인 맵은 하나만** 유지된다. 다른 맵을 메인으로 지정하면 이전 것은 해제된다.
- 삭제는 **영구적이며 되돌릴 수 없다.**
