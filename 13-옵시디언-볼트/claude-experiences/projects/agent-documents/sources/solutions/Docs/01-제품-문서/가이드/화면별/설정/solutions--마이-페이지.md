# 마이 페이지

> **사이드바** 설정 > 마이 페이지
> **경로** `/setting/my-page`

## 무엇을 하는 화면인가

본인 계정 정보를 확인하고 수정하는 화면이다. 모든 사용자가 접근할 수 있다.

## 화면 구성

| 영역 | 항목 |
|---|---|
| **사용자 정보** | 이름, 성, 이메일, 사용자 이름(ID) |
| **알림** | 알림 관련 설정 |
| **비밀번호 변경** | |

기본은 읽기 상태이며 **편집** 버튼으로 수정 모드로 전환한다.

## 주의할 점

### 비밀번호는 Zabbix와 함께 바뀐다

🔴 화면에 이렇게 안내된다.

> "Dmove 계정의 비밀번호를 입력하면 해당 Zabbix 계정의 비밀번호도 업데이트됩니다."
> "여기서 변경한 내용은 Zabbix 계정 비밀번호와 동기화됩니다."

즉 **제품 비밀번호만 바뀌는 것이 아니라 연결된 Zabbix 계정 비밀번호도 함께 바뀐다.** Zabbix에 직접 로그인해서 쓰던 계정이라면 그쪽 로그인 정보도 달라진다는 뜻이다.

Zabbix 콘솔을 병행해서 쓰는 사용자는 이 점을 알고 변경한다.

### 비밀번호를 바꾸면 다른 기기는 로그아웃된다 (ZM-157, 소스 반영·배포 전)

비밀번호를 바꾸면 같은 계정으로 로그인해 있던 **다른 기기와 다른 브라우저는 곧바로 로그아웃**된다. 연결된 앱(MCP)의 연결은 비밀번호 변경으로 끊기지 않으므로, 비밀번호 유출이 의심되면 ⚙ 설정의 연결된 앱 화면에서 연결도 해제한다.

현재 소스 기준으로 이 화면에서 비밀번호를 바꾸면 **지금 쓰는 기기도 다시 로그인해야 할 수 있다**(실환경 미확인). 저장 후 로그인 화면으로 돌아가면 새 비밀번호로 로그인한다.

### 권한 (ZM-157 기준)

현재 이 화면의 조회·저장은 **관리자 계정에서만 동작한다.** 일반 계정은 "이 작업을 수행할 권한이 없습니다." 안내가 뜨고 정보가 채워지지 않을 수 있다. 일반 사용자의 비밀번호 변경은 관리자에게 요청한다. 일반 사용자도 이 화면에서 직접 바꿀 수 있게 하는 개선이 예정돼 있다.

### 관리자 계정의 이메일

기본 관리자 계정의 이메일이 초기 설치값이면 업데이트 때 비워진다. 이메일이 없으면 비밀번호 찾기를 쓸 수 없으므로, 관리자는 이 화면에서 실제로 받을 수 있는 이메일을 등록한다. 이메일을 바꾸면 이전에 받은 인증 코드는 모두 무효가 된다. → [관리자 가이드 §3-11](../../solutions--%EA%B4%80%EB%A6%AC%EC%9E%90-%EA%B0%80%EC%9D%B4%EB%93%9C.md)

### 이메일 중복

이미 등록된 이메일로는 바꿀 수 없다. "이 이메일 주소는 이미 존재합니다" 안내가 뜬다.

### Zabbix 계정 연결이 끊긴 경우

"Zabbix에서 사용자를 찾을 수 없습니다" 오류가 나면 제품 계정과 연결된 Zabbix 계정이 사라졌거나 이름이 바뀐 것이다. 관리자에게 문의한다.
