# 라이선스

> **사이드바** 설정 > 라이선스
> **경로** `/setting/license` → 적용 `/setting/license/apply`

## 무엇을 하는 화면인가

제품 라이선스를 등록·교체·해지하고 현재 상태를 확인하는 화면이다.

## 화면 구성

### 상태 화면

| 항목 | 내용 |
|---|---|
| **라이선스 유형** | 기간제 / 영구 |
| **접근 모드** | 현재 기능 사용 범위 |
| **실시간 조회** | 허용 / 차단 |
| **만료 시각** | 기간제인 경우. 영구는 '만료 없음' |
| **기간제 수명주기** | 만료까지 남은 일수 |
| **프리미엄 모듈** | GPU·DB 모니터링·APM의 포함 / 미포함 |

동작: **라이선스 적용** · **라이선스 교체** · **라이선스 해지**

### 적용 화면

두 가지 방법을 지원하며 **같은 검증 절차**를 거친다.

| 방법 | 조건 |
|---|---|
| **.lic 파일** | UTF-8, 최대 **64KB** |
| **키 붙여넣기** | 발급받은 키 전체 |

적용하면 **서버 재기동 없이 즉시 반영**된다.

## 온프레미스 신뢰 모델

화면에 명시돼 있다.

> "라이선스는 **외부 서버 호출 없이** 제품에 포함된 공개키로 검증됩니다."

폐쇄망에서도 문제없이 동작하며, 라이선스 확인을 위해 외부와 통신하지 않는다.

## 유효 기간은 등록일부터

기간제 라이선스의 수명은 **발급일이 아니라 등록일**부터 계산된다. 발급받고 며칠 뒤에 등록해도 손해가 없다.

## 만료 시 동작

즉시 잠기지 않는다. 운영자가 장애 상황을 볼 수단을 잃으면 안 되기 때문에 단계적으로 좁힌다.

| 단계 | 상태 |
|---|---|
| 정상 | 전 기능 |
| **만료 후 약 30일** | **읽기 전용** — 실시간 조회 유지, 쓰기 차단 |
| 그 이후 | 저장된 데이터만 조회, 외부 수집 중단 |

정리 배치는 어느 단계에서도 계속 돈다.

## 🔴 해지는 즉시 잠금이다

"라이선스 해지"를 누르면 확인창이 이렇게 경고한다.

> "즉시 **LOCKED** 상태가 되어 라이선스 등록 외 기능을 사용할 수 없습니다."

만료와 달리 **유예 없이 바로 잠긴다.** 교체가 목적이라면 해지 후 등록이 아니라 **"라이선스 교체"** 를 쓴다.

## 사용 흐름

### 최초 등록

1. 발급받은 키 또는 `.lic` 파일을 준비한다.
2. **라이선스 적용**에서 파일 업로드 또는 키 붙여넣기.
3. 상태 화면에서 유형·만료일·프리미엄 모듈 포함 여부를 확인한다.

### 갱신

1. 만료 30일 전부터 준비한다 — 상태 화면이 남은 일수를 표시한다.
2. **라이선스 교체**로 새 키를 적용한다.
3. 만료 구간에 들어가면 쓰기가 막히므로, 진행 중인 편집 작업을 먼저 마무리한다.

## 등록이 거부될 때

| 원인 | 확인 |
|---|---|
| 키에 줄바꿈·공백이 섞임 | 전체를 정확히 복사했는가 |
| 이미 사용된 키 | 다른 설치본에서 등록한 키가 아닌가 (재사용 방지) |
| 파일 크기 초과 | 64KB 이하인가 |
| 발급 도구와 제품의 정의 불일치 | 공급사에 문의 |

상태를 불러오지 못하면 "백엔드 라이선스 API와 네트워크 상태를 확인한 뒤 다시 시도하세요" 안내가 나온다.
