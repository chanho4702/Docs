# 홈

> **사이드바** 홈
> **경로** `/home`

## 무엇을 하는 화면인가

로그인 직후 진입하는 화면이다. 전체 상태를 훑고 **어디를 자세히 봐야 할지 방향을 정하는 곳**이다.

> 홈에서 원인 분석을 끝내려 하지 않는다. 이상한 수치를 발견하면 해당 호스트 그룹이나 Problem 상세로 내려가는 것이 정상적인 흐름이다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| 전체 요약 | 감시 대상과 상태의 집계 수치 |
| 활성 Problem | 현재 열려 있는 장애 |
| 호스트 그룹별 문제 | 그룹 단위로 묶은 문제 현황 |

각 영역의 수치는 **내 권한 범위 안의 데이터만** 집계한다. 다른 사람과 숫자가 다르게 보이는 것은 정상이며, 호스트 그룹 권한이 다르기 때문이다.

## 사용 흐름

1. 활성 Problem 수를 먼저 본다. 평소보다 많으면 그쪽부터 확인한다.
2. 호스트 그룹별 문제에서 **특정 그룹에 몰려 있는지** 확인한다. 한 그룹에 몰려 있으면 공통 원인(네트워크·전원·템플릿 변경)을 의심한다.
3. 이상 지점을 찾으면 해당 그룹 또는 Problem 상세로 이동한다.

## 주의할 점

- 홈이 비어 보인다면 장애가 없는 것일 수도, **볼 수 있는 호스트 그룹이 없는 것**일 수도 있다. 모니터링 메뉴에서 목록이 나오는지 확인해 구분한다.
- 요약 수치는 조회 시점 기준이다. 자동 갱신을 기다리기보다 새로고침으로 최신 상태를 확인한다.
