현재 상태

두 메뉴 모두 "준비 중" 안내만 표시한다. 화면을 열면 제목과 준비 중 문구가 나오고 데이터는 없다.

메뉴상태
DB 모니터링준비 중
GPU 모니터링준비 중

고장이 아니다. 메뉴는 있지만 기능이 아직 구현되지 않은 상태다.

왜 메뉴가 먼저 있는가

두 기능은 상위 에디션(PREMIUM)에 포함될 예정이며, 라이선스 체계에서 이미 개별 기능으로 정의돼 있다(DB_MONITORING, GPU_MONITORING). 메뉴 자리와 라이선스 정의가 먼저 자리를 잡은 것이다. 같은 방식으로 자리를 잡았던 APM은 구현이 끝나 별도 문서로 옮겨 갔다.

언제 제공되는가

구체적 일정은 확정되지 않았다.

  • DB 모니터링의 경계: 앱 입장에서 본 DB(커넥션 풀, 앱이 겪는 DB 호출 지연)는 이미 어플리케이션 모니터링의 런타임·트랜잭션 탭이 다룬다. DB 인스턴스 내부(세션·락·복제·버퍼)가 이 메뉴의 몫이다.
  • GPU 모니터링: 수집 방식 미정.

지원 담당자를 위한 안내

고객이 "메뉴를 눌렀는데 아무것도 없다"고 문의하면:

  • 오류나 권한 문제가 아니라 미구현 기능임을 안내한다
  • 계약에 이 기능이 포함돼 있는지 확인한다 (포함돼 있다면 제공 일정 확인이 필요하다)
  • 현재 제공되는 대체 수단이 있는지 검토한다 (예: DB 서버의 자원 사용률은 서버 모니터링에서, 앱이 겪는 DB 호출 지연·커넥션 풀은 어플리케이션 모니터링에서 확인 가능)
  • 어플리케이션 모니터링 메뉴가 잠겨 있다는 문의는 준비 중이 아니라 라이선스 문제다 → 어플리케이션 모니터링 — 지원 담당자를 위한 안내
