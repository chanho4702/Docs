# DC 승인 앱(approval-confluence9) 기능 인벤토리 — Cloud 격차 비교용

작성: 2026-08-31 (Explore 에이전트 조사 결과를 압축). 기준선은 `approval-confluence9` 단독(C10 어댑터는 미완성).
경로 접두어: `J9 = approval-confluence9/src/main/java/kr/dmove/confluence/approval/c9`, `R9 = .../src/main/resources`.

## 1. 요청 폼
| 기능 | DC 동작 | Cloud 상태(2026-08-31) |
|---|---|---|
| 진입점 | 편집 버튼 옆 `승인 요청`(web-item + JS 강제 이동) | byline 항목 클릭 → 모달(헤더 슬롯 모듈 없음) ✅ |
| 결재선 지정 | 탭: 직접 선택 / 승인 Flow 사용 | ✅ (Flow 탭은 활성 Flow 있을 때만) |
| 승인자 검색 | 사용자(2자↑, 10건 페이저) / 등록 승인 그룹 | ✅ 사용자·Confluence 그룹·승인 그룹 통합 검색 |
| 상세 검색 다이얼로그 | 표(이름/계정/이메일) 다중 선택 | ❌ |
| 단계 구성 | 선택 순서 = 단계(순차 전용), ↑↓ | ✅ + 단계 내 병렬(필요 승인 수) 상위 호환 |
| 그룹 단계 | 그룹 1개 = 1단계, 통과 조건은 그룹 설정 | ✅ `agroup:` 확장 |
| 마감일 | 폼에 없음. `expiresAt → Flow 기본 → 전역 기본 → 없음` | ✅ 폼에 있되 같은 우선순위로 **미리 채움** |
| 참조(CC) | 사용자/그룹, 열람·알림만 | ✅ 사용자만(2026-08-31) — 업무함 참조 탭·상세·알림 |
| 요청 메모 | 500자 카운터 | ✅ |
| Flow 미리보기 | 단계·승인자·기본 마감 | ✅ |
| 재승인 결재선 재사용 | 프리필 + 안내 | ✅ |
| 409 동선 | 자동 새로고침 금지, 작성 중 보존 | △ 오류 문구만 |

| 기능 | DC | Cloud |

| 배너 pill + 진행 + v{n} 스탬프 | ✅ | byline 제목 문구(pill 없음) |

| 감사 타임라인, 버전별 승인 이력 | ✅ | ✅ 타임라인·버전별 이력 카드·Confluence 버전 비교 링크 |
| 요청 메모·참조 섹션 | ✅ | ✅ |

## 4. 업무함
DC: 탭 5(내 차례/진행 중/내 요청/참조/처리한 건)+보조(알림/내 서명/내 위임/설정), 배지 카운트, 8축 필터 URL 보존, 칩 레일, CSV 내보내기(10,000행), 전역 헤더 popover.
Cloud: 업무함·필터·서버 페이징·참조 탭·CSV 내보내기·스페이스/유형/요청일 열 ✅. 헤더 popover 없음(모듈 부재는 homepageFeed 로 보완), 필터 URL 보존 부분.

## 5. 알림
DC: 인앱+이메일(outbox drain), 이벤트별 수신자 규칙(행위자 제외, 편집 무효 시 기승인자 포함, CC 는 최종 승인만), 마감 임박·독촉(차례인 결재자+대리인).
Cloud: 인앱 + **코멘트 @멘션으로 네이티브 알림**(REQUESTED/단계 전진/최종 승인/반려/회수). 마감 임박 ✅(5분 스윕, DUE_SOON) · 독촉(REMINDER) ❌.

## 6. 설정
DC 6탭: 전역 정책(마감·sweep·임박·반려 사유·서명/PIN·위임·독촉·일괄 승인·알림·보존·상태 표시명), 적용 스페이스, Flow, 승인 그룹, 관리자(설정 관리자 ≠ Confluence 관리자), 변경 이력.
Cloud: 정책/스페이스/결재선(Flow, 단계 이름)/승인 그룹/**승인자 명부**/관리자 ✅. 앱 접근 제한·승인자 페이지 권한 확인·PIN 정책 추가. 변경 이력 ❌.

## 7. 기타
- DC 에는 라이선스 검사 코드가 없다 → Forge `LicenseGuard` 는 새 설계.
- i18n 은 en/ko 2벌. 관리자 지정 상태 표시명은 번역하지 않음(Cloud 동일).
- 접근성: Esc 닫기, 포커스 복귀, aria 역할 — Cloud 는 Atlaskit 기본에 의존.
