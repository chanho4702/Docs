가이드 홈 · English

프로젝트 관리에서 Moves Workforce 프로젝트를 만들고 기간·예산·상태를 관리합니다. 하나의 앱 프로젝트에는 여러 Jira 스페이스의 이슈를 연결할 수 있습니다.

필요한 권한

목록과 상세는 프로젝트 관리 읽기, 생성·수정·삭제는 프로젝트 관리 쓰기가 필요합니다. 칸반은 별도의 칸반 보드 읽기·쓰기를 사용합니다. 표시할 프로젝트는 개인의 조회 범위에 따라 달라집니다.

예시 프로젝트를 만들고 결과 확인하기

경로: Jira → Apps → Moves Workforce → 프로젝트 관리 → 프로젝트 추가. 이 앱 프로젝트는 여러 Jira 스페이스의 작업을 묶는 관리 단위입니다. 새 Jira 스페이스를 만드는 절차와는 다릅니다.

입력 항목

	

예시와 의미




이름

	

Demo website launch. 목록에서 다시 찾을 수 있는 이름을 씁니다.




상태

	

조직에 등록된 상태 중 시작 단계에 해당하는 것을 선택합니다. 상태 이름은 사이트 설정에 따라 다릅니다.




시작·종료일

	

2026-10-05 / 2026-10-30. 프로젝트의 계획 기간입니다.




프로젝트 비용

	

조직 통화로 정한 예산입니다. 실제 급여 기반 인건비가 자동 입력되는 항목은 아닙니다.




필요 스킬

	

인력 배정 시 비교할 요구 스킬입니다. 해당 스킬이 준비된 경우 선택합니다.

추가 창에서 이름·상태·기간과 필요한 항목을 입력합니다. 필수 항목 표시와 오류 안내를 확인합니다.

저장하고 목록에서 입력한 이름을 검색합니다. 같은 이름으로 다시 추가하기 전에 기존 항목이 있는지 확인합니다.

프로젝트 이름을 눌러 상세 페이지를 엽니다. 목록의 행 빈 영역은 요약 서랍을 열 수 있으므로 상세 화면과 구분합니다.

상세에서 이름·상태·기간·예산과 선택한 스킬이 저장되었는지 확인합니다.

프로젝트 인력에 사람을 추가하고 작업 관리에서 기존 Jira 이슈를 연결합니다. 생성 직후 두 목록이 비어 있어도 이 단계가 아직 수행되지 않은 것일 수 있습니다.

스킬 저장 재시도 안내가 나오면 기본 프로젝트 정보가 이미 저장되었을 수 있습니다. 열린 창의 안내에 따라 재시도하고 기존 프로젝트를 확인하세요. 새 프로젝트를 반복 생성하면 같은 업무의 관리 단위가 중복될 수 있습니다.

프로젝트 만들기

프로젝트 관리 → 프로젝트 추가를 엽니다.

이름·상태·시작일·종료일을 입력합니다.

프로젝트 비용에 프로젝트 예산을 입력합니다. 이 값은 급여로 계산하는 인건비와 별개입니다.

필요한 스킬을 선택합니다. 이 스킬은 인력 배정 시 적합도 비교에 사용됩니다.

저장 후 상세 화면에서 인력과 작업을 추가합니다.

프로젝트 목록에서 행을 눌러 상세 드로어를 연 상태. 프로젝트 이름을 누르면 상세 페이지로 이동합니다.

 

기본 정보는 저장됐지만 스킬 저장을 다시 요청하는 안내가 나오면 선택 상태와 저장 결과를 확인한 뒤 재시도합니다.

목록과 칸반 사용하기

목록에서 이름을 검색하고 프로젝트 이름을 눌러 상세로 들어갑니다. 행의 빈 영역을 누르면 요약 드로어를 볼 수 있습니다.

칸반의 카드 하나는 프로젝트 하나입니다. 카드를 다른 컬럼으로 옮기면 프로젝트 상태가 바뀝니다.

허용되지 않은 상태 변경은 거부될 수 있습니다. 카드가 되돌아오면 오류 안내와 상태 흐름을 확인합니다.

완료 컬럼에 더보기 버튼이 있으면 이전 프로젝트를 추가로 불러올 수 있습니다.

프로젝트 삭제 전 확인

프로젝트 삭제는 앱의 관련 인력·설정·연결 데이터를 정리하는 작업이며 복구할 수 없습니다. Jira 이슈 자체를 삭제하는 기능은 아닙니다.

삭제할 프로젝트 이름과 영향을 확인합니다.

삭제 진행 창에서 완료 여부를 확인합니다.

실패했다면 오류 사유를 확인하고 삭제 재시도를 사용합니다.

연결된 Jira 이슈의 열람 권한 부족이 원인이면 그 이슈에 접근 가능한 관리자에게 재시도를 요청합니다.

버튼·입력 항목과 처리 결과 상세

프로젝트 목록·칸반은 Moves Workforce 프로젝트를 관리합니다. Jira 스페이스 또는 Jira 워크플로 상태와 구분하세요.

버튼·입력 항목

	

기능·사용 조건·변경 대상

	

결과 확인과 문제 대응




이름 검색·조건 해제·페이지 이동

	

목록의 프로젝트를 검색하고 이전·다음 페이지로 이동합니다. 조건 해제는 프로젝트 삭제가 아닙니다.

	

검색 조건과 조회 범위를 확인한 뒤 목록 누락을 판단합니다.




프로젝트 이름 / 행 빈 영역

	

이름은 상세 페이지로, 행 빈 영역은 요약 서랍으로 들어가는 동작입니다.

	

서랍의 상세 페이지 열기로 전체 기능에 진입합니다.




프로젝트 추가·저장

	

이름·상태·시작일·종료일은 필수입니다. 예산은 선택값이며 프로젝트의 계획 금액입니다.

	

필드 오류를 수정하고 저장합니다. 프로젝트 생성만으로 인력·작업이 자동 등록되지는 않습니다.




필요 스킬: 분류·검색·선택·제거

	

후보 사전에서 요구 스킬을 선택합니다. 선택 목록의 제거는 프로젝트 요구 사항에서만 빼며 스킬 사전을 삭제하지 않습니다.

	

현재 사전에 없는 기존 선택은 이름 불명 표시로 남을 수 있습니다. 조회 실패를 빈 목록으로 간주해 기존 요구를 지우지 않습니다.




수정·다시 불러오기·부분 저장 재시도

	

저장된 프로젝트를 수정합니다. 기본 정보 또는 스킬 조회 실패 시 저장이 잠길 수 있습니다. 기본 정보 저장 후 스킬 실패는 전체 생성 실패와 다릅니다.

	

열린 창의 재시도 안내를 따르고 기존 프로젝트를 확인합니다. 새 프로젝트를 반복 생성하지 않습니다.




칸반 카드 이동

	

허용된 상태 흐름에 따라 앱 프로젝트 상태를 변경합니다. Jira 이슈 상태를 일괄 바꾸는 동작은 아닙니다.

	

카드가 원래 위치로 돌아오면 상태 전이와 쓰기 권한을 확인합니다. 완료 목록의 더보기는 과거 프로젝트를 추가 조회합니다.




프로젝트 삭제·삭제 재시도

	

확인 후 앱의 인력 배정·담당 팀·구독·대시보드·간트 구조·스킬 연결 등 프로젝트 관련 데이터를 제거합니다. Jira 원본 이슈는 보존됩니다.

	

복구할 수 없습니다. 진행 창의 실패 단계·접근 불가 이슈를 확인하고 권한 문제를 해결한 뒤 삭제 재시도를 사용합니다. 일부 단계가 완료되었을 수 있습니다.

삭제 진행 상태와 창의 닫기 가능 여부를 확인하세요. 창을 닫는 동작이 이미 완료된 삭제 단계를 되돌리는 것은 아닙니다.
