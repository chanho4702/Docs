급여 밴드 입력 규칙

급여 정책이 등급 기반일 때 사용됩니다.

항목 규칙
하한 / 상한 0 이상. 하한이 상한보다 크면 저장 거부
대표값 계산에 쓰이는 값. 비워 두면 중앙값((하한 + 상한) ÷ 2)이 자동 입력됩니다
  • 중앙값 계산 버튼으로 대표값을 채울 수 있습니다.
  • 대표값이 하한~상한 범위를 벗어나도 저장은 허용됩니다(관리자 판단 존중). "대표값이 급여 범위를 벗어났습니다. 그대로 저장할 수 있습니다" 경고만 표시됩니다.

급여 정책이 '인원별'이면 "급여 밴드는 사용되지 않습니다" 안내와 함께 설정으로 이동하는 링크가 표시됩니다.

밴드를 비워 두면 생기는 일

등급 기반 정책에서 밴드(대표값)가 없는 등급의 인원은 인건비가 0으로 계산됩니다.

  • 7.1 일반 설정에서 정책을 전환할 때 "등급 N개에 급여 밴드가 없습니다" 경고가 표시됩니다.
  • 비용 화면의 미산정 인원 지표로도 확인할 수 있습니다.

버튼·입력 항목과 처리 결과 상세

레벨은 인력 기준과 등급 기반 비용 계산을 연결합니다. 급여 밴드는 연간 금액이며 월급·만원 단위로 축약 입력하지 않습니다.

버튼·입력 항목 기능·사용 조건·변경 대상 결과 확인과 문제 대응
레벨 추가·이름·설명 조직의 등급을 등록합니다. 인원별 정책에서도 레벨은 사용할 수 있지만 밴드는 비용 기준으로 사용되지 않습니다. 정책 안내와 목록을 확인합니다. 밴드 입력만으로 조직 급여 정책이 변경되지는 않습니다.
하한·상한 0 이상의 숫자이며 하한≤상한이어야 합니다. 빈 값은 금액 미설정·해제 의미이고 0과 다릅니다. 금액은 통화의 기본 단위로 정수만 입력합니다. 소수점·음수 기호·문자는 입력 과정에서 제거되므로 표시된 숫자와 보조 금액을 반드시 확인합니다. 하한이 상한보다 크면 저장할 수 없습니다.
대표값·중앙값 사용 대표 연간 금액이 비용 계산에 사용됩니다. 대표값이 비고 하한·상한이 유효하면 중앙값이 채워집니다. 대표값이 범위 밖이면 경고하지만 저장은 가능합니다. 의도된 조직 기준인지 확인합니다.
Quick Add·수정·삭제 경력 단계 예시를 선택해 추가하거나 기존 기준을 수정·삭제합니다. 이미 있는 예시는 건너뜁니다. 사용 중인 레벨 삭제는 거부될 수 있습니다. 금액을 지우기 전 영향받는 비용과 미산정 표시를 확인합니다.
