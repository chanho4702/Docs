인력-한-명-추가하기인력 한 명 추가하기

  1. 인력 추가를 누릅니다.
  2. Jira 사용자를 이름 또는 이메일로 검색해 선택합니다.
  3. 직무 역할·등급·권한을 지정합니다.
    • 권한을 선택하지 않으면 Member 권한으로 자동 등록됩니다.
    • 팀 권한을 따르게 하려면 팀 권한 상속을 선택합니다().
  4. 정책이 인원별이면 연봉을 입력할 수 있습니다.

팀장의-팀-이동-제한팀장의 팀 이동 제한

수정 창에서 팀을 바꿀 수 있지만, 그 사람이 어떤 팀의 팀장이면 그 팀 밖으로 옮길 수 없습니다. "팀장은 이끄는 팀 밖으로 옮길 수 없습니다. 팀장 지정을 먼저 해제하세요"가 표시됩니다. 에서 팀장을 바꾼 뒤 이동하세요.

그림 7-4 엑셀 일괄 업로드

그림 7-4. 일괄 업로드 — ① 템플릿 다운로드 ② 파일 드롭 영역 ③ 진행률 ④ 결과 요약(전체/등록/중복/미존재/실패) ⑤ 실패 목록 버튼.
  1. 일괄 업로드 → 템플릿 다운로드로 양식을 받습니다.
  2. 양식을 채워 xlsx로 저장합니다. 최대 5MB, xlsx만 가능합니다.
  3. 파일을 드래그하거나 파일 선택으로 올립니다.
  4. 처리는 백그라운드로 진행되며 진행률이 표시됩니다.
  5. 결과가 전체 / 등록 / 중복 / 미존재 / 실패로 요약됩니다.
  6. 실패 건이 있으면 일괄 업로드 실패 목록 버튼으로 사유를 확인합니다.

  • 사용자를 삭제하면 복구할 수 없습니다. 삭제 전 확인 창이 표시됩니다. 삭제된 사람이 팀장이던 팀은 팀장이 비워집니다.
