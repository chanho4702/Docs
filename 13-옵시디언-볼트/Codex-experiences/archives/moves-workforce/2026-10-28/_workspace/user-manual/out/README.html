Jira(Atlassian)에 설치되는 Moves Workforce 앱의 사용 안내서입니다. 작업 시간(워크로그) 기록과 프로젝트별 인력·작업·인건비 관리, 진척·가동률 분석을 한 곳에서 처리할 수 있는 워크포스 관리 도구입니다.

기준선 주의: 이 매뉴얼은 2026-09-28 개발 소스를 기준으로 하며, 운영 환경의 배포 시점에 따라 일부 화면이 아직 없을 수 있습니다. 실제 제공 기능은 릴리스 노트와 대상 환경의 배포 상태를 확인하세요.

그림에 대하여: 각 페이지의 그림 N-M은 캡처 예정 자리입니다. 캡처 목록·촬영 조건은 images/README.md에 있습니다. 파일이 아직 없으면 그림 자리에 깨진 이미지가 표시됩니다.

권한 표기 규칙

권한 이름은 화면에 표시되는 항목명을 「 」 안에 그대로 씁니다.

표기 의미
「프로젝트 관리」 읽기 그 항목의 읽기(Read) 체크가 있어야 화면이 보입니다
「프로젝트 관리」 쓰기 쓰기(Write) 체크가 있어야 추가·수정·삭제 버튼이 나타납니다
A 또는 B 둘 중 하나만 있어도 됩니다
A + B 둘 다 있어야 합니다
권한 불필요 본인 데이터이거나 전역 공개 정보입니다
Jira 권한 앱 권한과 별개로 Jira 자체 권한이 필요합니다

권한이 없으면 대부분 버튼·탭·메뉴가 아예 보이지 않습니다. 서버에서도 같은 검사를 하므로 화면을 우회해도 거부됩니다.

이-문서를-읽는-법이 문서를 읽는 법

각 페이지는 다음 순서로 구성됩니다.

  1. 접근 권한 — 이 화면을 보고 편집하는 데 필요한 권한
  2. 언제 쓰나 — 이 화면이 해결하는 문제
  3. 화면 구성 — 어디에 무엇이 있는지 (그림 포함)
  4. 절차 — 단계별 절차
  5. 알아두기 / 주의 — 오해하기 쉬운 규칙
  6. (필요 시) 문제 해결 — 증상과 원인
