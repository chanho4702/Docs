접근-권한접근 권한

구분 필요 권한
화면 조회 「프로젝트 상태 관리」 읽기
상태 추가·수정·삭제 「프로젝트 상태 관리」 쓰기
상태 연결(흐름) 편집 「프로젝트 상태 관리」 쓰기
칸반 화면에서 컬럼 추가·이름 변경·삭제 「칸반 보드」 쓰기
  • 같은 상태를 두 곳에서 만질 수 있습니다. 설정 화면은 「프로젝트 상태 관리」, 칸반 화면은 「칸반 보드」 권한을 씁니다.

언제 쓰나 — 프로젝트의 상태(칸반 컬럼) 와 상태 전이 흐름을 정의할 때.

기본 시드 상태는 To Do → IN PROGRESS → DONE 입니다.

그림 7-9 프로젝트 상태 관리와 상태 흐름 편집

그림 7-9. 프로젝트 상태 관리 — ① 상태 표(이름·색) ② 상태 추가 ③ 상태 연결 편집(노드와 화살표로 흐름 정의, 연결되지 않은 상태 표시).

상태-추가수정상태 추가·수정

  1. 상태 추가를 누릅니다.
  2. 상태 이름(예: 진행중)과 색상을 지정합니다.
  3. 행에서 수정·삭제할 수 있습니다.

여기서 정의한 상태가 의 상태 선택지와 의 컬럼이 됩니다. 칸반 화면에서도 컬럼 추가·이름 변경·삭제를 할 수 있습니다. 상태 색은 목록·칸반·My Work 카드의 상태 라벨에 그대로 쓰입니다.

상태-흐름-편집상태 흐름 편집

상태 연결 편집을 누르면 상태 간 이동 흐름을 시각적으로 정의합니다.

규칙

  • 각 상태는 다음 상태 하나, 이전 상태 하나만 가질 수 있습니다(1:1 연결).
  • 순환 연결은 허용되지 않습니다.
  • 연결되지 않은 상태는 "연결되지 않은 상태입니다"로 표시됩니다.
  • 칸반에서 카드를 옮기거나 프로젝트 상태를 바꿀 때 서버가 이 흐름과 상태 존재 여부를 검증합니다. 거부되면 원래 상태로 되돌아가고 사유가 표시됩니다.

삭제-제약삭제 제약

제약 이유
최소 1개의 상태가 필요합니다 상태가 하나도 없으면 프로젝트를 만들 수 없고 칸반이 비어 보입니다
이전 상태가 없으면 삭제할 수 없습니다 삭제 시 그 상태의 프로젝트를 옮길 곳이 필요합니다

삭제하면 그 상태에 있던 프로젝트는 이전 상태로 변경됩니다(프로젝트가 삭제되지 않습니다).
