# 5.1 프로젝트 상세 — 대시보드

## 🔐 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | `DASHBOARD` 읽기 |
| 차트 추가·레이아웃 편집·삭제 | `DASHBOARD` 쓰기 |
| **총 인건비** 카드 | `PROJECT_COST` 읽기 (없으면 **카드 자체가 표시되지 않음**) |
| 급여 분포 차트 | `PROJECT_COST` 읽기 |

- 급여 정책이 **등급 기반**이면 `PROJECT_COST`가 있어도 총 인건비 카드가 숨겨집니다([7.1](../07-설정/01-일반-설정.md)).
- 대시보드 데이터는 프로젝트 단위라 **조회 범위 밖 프로젝트**에서는 열리지 않습니다.

---

**언제 쓰나** — 프로젝트 현황을 **한 화면에서 요약**해 보고할 때.

> `DASHBOARD` 권한으로 제어됩니다.

## 상단 요약 카드

- **프로젝트 참여 인력** (예: 5명)
- **프로젝트 기간** (예: 2026-04-01 ~ 2026-06-30)
- **총 인건비** — `PROJECT_COST` 읽기 권한이 있는 사용자에게만 표시됩니다. 권한이 없으면 **0원으로 표시되는 것이 아니라 카드 자체가 나타나지 않습니다.** 급여 정책이 [등급 기반](./02-인력-관리.md#계산-방식은-급여-정책이-결정합니다)일 때도 숨겨집니다.

## 차트 위젯

| 위젯 | 내용 |
|---|---|
| 역할 분포 | 참여 인력의 역할별 비율 (도넛) |
| 등급 분포 | 등급별 비율 (도넛) |
| 담당자 분포 | 담당자별 비율 (도넛) |
| 작업 분포 | 이슈별 작업 분포 |
| 급여 분포 | 급여 구간별 인원 (막대) |
| 히트맵 | 기간 선택 + 일자별 작업 시간 강도 (0h / 0~1h / 1~4h / 4~8h / 8h+) |
| 라인차트 | 기간·작업자 선택 + 일자별 작업 시간 추이 |

각 위젯은 **차트/표 전환 토글**, **펼치기**, **새로고침** 아이콘을 제공합니다.

## 대시보드 꾸미기

1. 우측 위 **편집**을 누릅니다.
2. 위젯을 **드래그해 재배치**하거나 모서리를 끌어 **크기를 조정**합니다.
3. **차트 추가**로 위젯을 늘립니다.
   - **추천(템플릿)**: 미리 구성된 차트 묶음에서 선택
   - **커스텀**: 데이터 유형을 고른 뒤 그에 맞는 차트 종류를 선택
4. 배치는 **프로젝트별로 저장**됩니다.

## 알아두기

- 담당자 분포는 [담당자·동료 지정](./03-작업-관리.md#532-담당자동료-관리) 결과를 그대로 반영합니다.
- 역할·등급 분포는 [인력 관리](./02-인력-관리.md)에서 각 멤버에게 부여한 값 기준입니다. 값이 비어 있는 인원은 분포에서 빠집니다.
- 더 깊은 분석(계획 대비 실적, 가동률, 진척률)은 [5.5 분석 및 리포트](./05-분석-및-리포트.md)를 사용하세요.
