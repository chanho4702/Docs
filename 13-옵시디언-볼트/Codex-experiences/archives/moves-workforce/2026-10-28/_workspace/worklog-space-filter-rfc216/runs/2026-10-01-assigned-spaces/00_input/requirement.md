# RFC-216 후속: 내 이슈의 스페이스만 표시

사용자 요청: 워크로그 생성 필터에 선택 해제와 내 할당 이슈의 스페이스만 있으면 된다. 전체 접근 가능 스페이스는 필요 없다.

변경 계약: 기존 워크로그 검색과 같은 RMS 연결·선택 RMS 프로젝트·본인 담당자/공동작업자 JQL을 사용하여 `fields: ['project']`만 모든 커서 페이지에서 수집한다. 후보 조회에는 검색어·선택 스페이스를 넣지 않는다. 중복 프로젝트는 합치되 같은 프로젝트만 나오는 다음 페이지도 정상 처리한다. 이슈 목록 검색당 100건 계약, Jira 사용자 자격, 저장/편집 계약은 유지한다.

캐시는 사용자와 정규화한 RMS 프로젝트 집합별 신규 키로 분리한다. 드롭다운의 빈 선택 트리거는 '스페이스', 해제 항목은 '선택 해제'로 표시한다. 선택 변경/해제는 이슈 선택만 비우고 날짜·시간·코멘트는 보존한다. 조회 오류·로딩 중에도 선택 해제는 가능하며 저장 중에는 잠근다. 다른 공용 필터의 기본 라벨은 유지한다.

작은 frontend 후속 수정이므로 리더가 구현하고 backend·schema·권한 변경은 생략한다. 기존 미추적 PPT 3개, custom-scopes.yaml, LeaderTeamBackfill.test.js는 보존한다.
