**언제 쓰나** — "이 프로젝트에 누구를 넣을까"를 현재 권한으로 조회 가능한 인력 후보에서 고를 때.

## 화면 구성

| 영역 | 내용 |
|---|---|
| **배정 대상 프로젝트** (좌) | 프로젝트 카드 — D-day, 미배정·임박·지연 작업 수. 검색·상태 필터, **종료·일정오버 포함** 토글 |
| **작업 현황** (중) | 선택 프로젝트의 열린 작업과 **배정 인원 N명** |
| **전사 인력** (우) | 권한 범위로 제한된 후보 목록 — 직무/등급 · 스킬 · **적합도** · 신호 · 배정 버튼 |

세 패널은 카드 헤더의 접기 버튼과 경계선 드래그로 폭을 조절할 수 있습니다. 프로젝트 카드에는 `D-7`, `D-DAY`, `D+3 지연` 같은 일정 배지와 종료·일정 오버 표시가 붙습니다.

## 배정하는 법

1. 왼쪽에서 프로젝트를 선택합니다. (선택 전에는 "프로젝트를 선택하면 적합도가 표시됩니다")
2. 오른쪽 인력 목록의 허용 범위 안에서 **적합도**와 **신호**(부하 상태)를 확인합니다.
3. **배정**을 눌러 맡길 작업을 고르거나, 배정할 작업이 없으면 **프로젝트 인력으로만** 배정합니다.
4. 팀 단위로 넣으려면 팀을 선택한 뒤 **팀 전체 배정**을 사용합니다.

> **적합도**는 프로젝트 **필요 스킬** 대비 후보의 보유 스킬 일치도입니다. 필요 스킬은 [프로젝트 추가/수정 창](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/171573335)의 필요 스킬 영역 또는 이 화면의 **요구 스킬 편집**으로, 보유 스킬은 [6.1 인력 현황](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/173703169)에서 지정합니다. 둘 중 하나가 비어 있으면 적합도가 의미를 갖지 못합니다.

> 백오피스에 등록되지 않은 Jira 사용자는 배정할 수 없습니다 — 먼저 [7.2 인력 관리](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/173342810)에서 등록하세요.

## 팀 전체 배정 규칙

- **이미 배정된 인원은 대상에서 제외**됩니다. 실행 전 "{팀} {N}명을 [{프로젝트}]에 배정합니다"로 확인합니다.
- 되돌리려면 배정 명단에서 **한 명씩 취소**해야 합니다(일괄 취소 없음).
- 배정 취소 시 **이미 할당된 작업의 담당은 해제되지 않습니다** — 해당 건수가 안내됩니다.

## 배정 관계도

프로젝트–팀–담당자 3레이어 관계를 그래프로 보여줍니다.

> **[이미지 삽입 위치 · 추가 캡처 필요]** 배정 관계도 — ① 프로젝트 노드 ② 팀 노드 ③ 담당자 노드(여러 프로젝트에 선이 이어진 중복 배정 강조) ④ 진행 상태·프로젝트 필터, 종료 프로젝트 포함 토글.


> **링크 기준은 "프로젝트 인력 배정 명단"이지 워크로그 투입이 아닙니다.** 배정만 되고 아직 착수하지 않은 인원도 표시됩니다. 실제 기여도는 [5.5 팀 분석](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/173178897)이나 [5.5 인력 분석](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/173178897)에서 확인하세요.

- 배정 인원이 많으면 상위 N개 프로젝트만 표시되며 **전체 표시**로 펼칠 수 있습니다.
- 진행 상태·프로젝트 필터, **종료 프로젝트 포함** 토글을 제공합니다.
- 노드를 클릭하면 해당 인력의 상세 드로어가 열립니다.
- 같은 관계도를 [통합 대시보드 > 자원 서브탭](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/173015041)의 **전사 배정 관계도**에서도 볼 수 있습니다.

## 버튼·입력 항목과 처리 결과 상세

프로젝트 배정은 허용된 후보를 프로젝트 명부에 추가하거나 Jira 작업 담당자·동료로 지정합니다. 두 종류의 배정은 별개입니다.

| 버튼·입력 항목 | 기능·사용 조건·변경 대상 | 결과 확인과 문제 대응 |
|---|---|---|
| 프로젝트 검색·상태·종료 포함 | 배정할 프로젝트를 고릅니다. 종료·기한 초과 포함 옵션은 프로젝트 후보를 넓힙니다. | 다른 프로젝트를 선택하면 적합도 기준도 바뀝니다. 프로젝트 읽기 범위를 확인합니다. |
| 후보 팀·하위 팀·스킬 적합도 | 허용된 인력 범위에서 소속과 필요 스킬 대비 적합도를 비교합니다. 화면 제목이 Company resources여도 전체 명부 접근을 보장하지 않습니다. | 적합도·현재 부하·미등록 사용자 표시를 함께 확인합니다. |
| 프로젝트 배정·팀 전체 배정 | 선택 인력 또는 팀의 미배정 구성원을 프로젝트 명부에 추가합니다. 이미 있는 사람은 제외됩니다. | 실제 대상 명단을 확인하고 저장 결과를 검토합니다. 되돌리려면 개별 명부 제거가 필요합니다. |
| 담당자 지정·동료 추가·확인 | 작업 선택 창에서 이슈를 고르고 Jira 담당자 또는 동료를 저장합니다. 프로젝트 인력 등록을 자동 대신하지 않습니다. | 미등록 경고가 있어도 Jira 작업 배정을 진행할 수 있지만 프로젝트 명부는 자동 추가되지 않습니다. 명부 등록도 필요하면 별도로 추가하고 두 결과를 확인합니다. 담당자 지정과 동료 속성 변경의 Jira 권한은 다릅니다. |
| 명부 제거·배정 관계도·전체 보기 | 명부 관계를 제거하거나 프로젝트·팀·인력의 배정 연결을 확인합니다. 관계도는 실제 워크로그가 아니라 명부 기준입니다. | 투입 전 사람도 그래프에 보일 수 있습니다. 제거 후 Jira 담당자 관계는 별도로 확인합니다. |
