## What settings manage

Settings entries follow read permissions. Changes require the corresponding write permission. Job roles are separate from access permissions.

## Before operating the app

Set working hours, salary policy, and reference data. Configure permissions, people, and teams. Check project statuses and holidays, then verify read and write scope using actual user accounts. See the [administrator guide](https://dmove-addons.atlassian.net/wiki/spaces/MW/pages/203751476) for installation and operational checks.
