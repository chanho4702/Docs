# 워크로그 추출

[가이드 홈](./index.md) · [English](../en/worklog-export.md)

> 검토 초안: 지정된 staging 환경의 실제 화면·배포 버전 확인 전입니다.

Jira에서 볼 수 있는 워크로그를 검색해 Excel로 내려받습니다. Moves Workforce 프로젝트에 연결된 이슈만 추출하는 기능은 아닙니다.

## 필요한 권한과 범위

워크로그 추출 읽기가 필요합니다. 결과는 본인의 Jira 접근 권한을 따르며, 앱의 프로젝트 조회 범위와 같지 않을 수 있습니다. 앱 프로젝트 분석과 합계를 비교할 때는 대상 이슈와 작성자를 먼저 맞춥니다.

## 추출 절차

1. **워크로그 추출**에서 작업 시작일 기준 기간을 선택합니다.
2. Jira 스페이스·작성자를 지정합니다. 필요하면 추가 JQL로 조건을 좁힙니다.
3. 검색하고 이슈 검색·워크로그 수집 진행을 확인합니다.
4. 완료 메시지와 부분 실패·상한 도달 여부를 확인합니다.
5. 요약과 미리보기를 확인한 뒤 **Excel 다운로드**를 누릅니다.

예를 들어 이번 달 특정 팀의 기록을 정산하려면 기간과 작성자를 명시합니다. 작성자를 비우면 접근 가능한 다른 작성자의 기록도 포함될 수 있습니다.

> 이미지 후보 IMG-16: 검색 조건·진행 결과·요약·다운로드가 함께 보이는 화면.

## 파일을 공유하기 전에

| 확인 | 이유 |
|---|---|
| 취소 또는 부분 실패 여부 | 다운로드 가능한 결과라도 수집이 완전하지 않을 수 있음 |
| 검색 상한 안내 | 기간이나 스페이스를 나눠 다시 추출해야 할 수 있음 |
| 미리보기와 파일의 차이 | 미리보기는 일부 행만, 파일은 실제 수집한 전체 행을 포함 |
| 작성자·코멘트 | 공유 대상에 적합한 내용인지 확인 필요 |
| MD 기준 시간 | 다른 보고서와 단위를 맞춰야 함 |

**수집한 전체**는 **Jira에 존재하는 전체**와 다릅니다. 취소·권한·상한·실패로 누락된 기록은 다운로드에도 들어 있지 않습니다.

검색이 느리면 먼저 기간·스페이스를 좁힙니다. 누락된 스페이스는 Jira에서 직접 열 수 있는지 확인하고, JQL 오류는 추가 조건을 제거해 원인을 구분합니다.

## 버튼·입력 항목과 처리 결과 상세

워크로그 추출은 접근 가능한 Jira 데이터의 조회·파일 다운로드 기능입니다. 앱 프로젝트 인력 명부와 동일한 범위로 제한된 보고서라고 가정하지 마세요.

| 버튼·입력 항목 | 기능·사용 조건·변경 대상 | 결과 확인과 문제 대응 |
|---|---|---|
| 프로젝트·작성자 | 프로젝트와 기록자를 선택합니다. 비우면 현재 Jira 권한으로 조회 가능한 프로젝트 또는 전체 작성자를 대상으로 합니다. | 이슈 담당자와 워크로그 작성자는 다릅니다. 다른 사람이 기록한 시간을 찾으려면 작성자 조건을 확인합니다. |
| 시작·종료 날짜 | 워크로그 기록 날짜를 제한합니다. 실제 기록을 날짜·작성자 조건으로 다시 걸러 결과를 구성합니다. | 날짜 순서와 실제 업무 날짜를 확인합니다. 이슈 생성 날짜와 혼동하지 않습니다. |
| 추가 JQL | 프로젝트·날짜·작성자 조건과 AND로 결합할 Jira 검색 조건을 입력합니다. 예: issuetype = Bug. | 400 오류는 JQL 문법·필드 이름을 확인하고, 결과가 적으면 추가 조건을 제거해 비교합니다. |
| 검색 | 조건에 맞는 이슈를 찾고 각 이슈의 워크로그를 수집합니다. 새 검색은 기존 결과를 새 실행 결과로 대체합니다. | 진행 상태와 실패 이슈를 확인합니다. 일부 실패·상한 안내가 있으면 전체 결과로 해석하지 않습니다. |
| 취소 | 진행 중 조회를 중단합니다. 지금까지 수집한 행은 남기며 Jira 기록을 취소·삭제하는 버튼이 아닙니다. | 취소 상태의 결과와 다운로드는 부분 데이터입니다. 전체 결과가 필요하면 조건을 조정해 다시 검색합니다. |
| 초기화 | 필터 입력을 기본 상태로 되돌립니다. 이미 만들어진 Jira 워크로그는 변경하지 않습니다. | 새 조건에 따른 결과가 필요하면 검색을 다시 실행합니다. 입력 초기화와 데이터 삭제를 구분합니다. |
| 이슈 수·워크로그 수·시간 합계 | 현재 수집 결과의 규모를 요약합니다. 화면에 실패·취소·잘림이 있으면 요약 역시 그 부분 결과를 반영합니다. | 원본 이슈의 전체 누적 시간과 기간·작성자 필터를 적용한 합계는 다를 수 있습니다. |
| Excel 다운로드 | 현재 수집된 행을 파일로 만듭니다. 최초 실행은 파일 생성 모듈 로딩으로 잠시 걸릴 수 있습니다. | 기간·작성자·건수·총시간과 MD 기준을 확인합니다. Jira 오류 429는 잠시 후 더 좁은 조건으로 재시도합니다. |
