# 6.3 팀 분석

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 탭 진입 | 「리포트」 읽기 또는 「자원관리」 읽기 또는 「팀 관리」 읽기 |
| 가동률·인원 축 | 위 진입 권한만으로 표시 |
| 공수·진척·리스크 축 | 「리포트」 읽기 |
| 인건비 | 「비용」 읽기 (+ 급여 정책 스냅샷 정합성) |

- 「리포트」가 없어도 **탭 전체가 막히지는 않습니다.** 가동률·인원 축만 보이고 나머지 축은 안내와 함께 숨겨집니다.
- 보이는 팀 범위는 서버가 판정합니다 — 전사 조직 조회 권한과 "전체 프로젝트" 범위를 가지면 전 팀, 팀장은 자신이 이끄는 팀과 하위 팀입니다.

---

**언제 쓰나** — 여러 팀·프로젝트를 가로질러 **팀 단위 자원 지표**를 비교할 때.

![그림 6-4 팀 분석](../images/06-resource-team-analytics.png)
*그림 6-4. 팀 분석 — ① 팀·프로젝트 필터 ② KPI ③ 프로젝트별 팀 투입 ④ 가동률 분포·팀 간 비교 ⑤ 가동률-규모 산점도 ⑥ 계층 롤업.*

## 제공 위젯

| 위젯 | 내용 |
|---|---|
| KPI | 팀 단위 핵심 지표 요약 |
| 프로젝트별 팀 투입 | 어느 팀이 어느 프로젝트에 얼마나 투입됐는지 |
| 가동률 분포 | 팀별 가동률 밴드 분포 |
| 팀 간 비교 | 팀을 나란히 두고 지표 비교 |
| 인력 구성 | 직무·등급 구성 |
| 가동률-규모 산점도 | 팀 규모 대비 가동률 위치 |
| 계층 롤업 | 하위 팀을 합산한 상위 팀 지표 |

**필터**: 팀 · 프로젝트

## 보이는 범위는 서버가 판정합니다

| 사용자 | 범위 |
|---|---|
| 전사 조직 조회 신호 + "전체 프로젝트" 범위 | 전 팀 |
| 팀장 | 자신이 이끄는 팀과 하위 팀 |

## 권한에 따른 축 제한

- 「리포트」 권한이 없으면 **탭 전체를 막지 않고 가동률·인원 축만** 제공합니다. 공수·진척·리스크 축은 안내와 함께 숨겨집니다.
- **인건비**는 「비용」 권한과 급여 정책 스냅샷 정합성이 **모두** 충족돼야 표시됩니다.

## 알아두기

- 인원이 **500명을 초과**하면 팀 필터와 팀별 보기를 사용할 수 없습니다.
- 팀 분석은 **현재 소속 기준**입니다. 과거에 다른 팀이었던 인원의 실적도 **지금 소속된 팀**에 집계됩니다(소급하지 않습니다).
- 미래 기간은 가동률 계산에서 제외됩니다.
- "N개 프로젝트는 아직 집계 전이라 제외되었습니다"가 뜨면 다음 배치 이후 포함됩니다.

## 세 개의 팀 화면 구분

| 화면 | 답하는 질문 | 범위 |
|---|---|---|
| [마이페이지 → 내 팀](../03-마이페이지.md#32-내-팀-팀장-전용) | 내가 이끄는 조직의 업무 현황은? | 본인이 팀장인 팀과 하위 팀 |
| [프로젝트 상세 → 팀 분석](../05-프로젝트-상세/05-분석-및-리포트.md#553-팀-분석) | 이 프로젝트의 담당 조직과 실제 기여가 일치하는가? | 현재 프로젝트 |
| **자원 관리 → 팀 분석** (이 화면) | 여러 팀·프로젝트의 자원 지표와 계층 롤업은? | 허용된 전 팀 또는 리딩 팀 |
