# 6.1 인력 현황

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | 「자원관리」 읽기 |
| 인력 상세 드로어 | 「자원관리」 읽기 |
| 보유 스킬 편집 | 「자원관리」 쓰기 (자기 팀원에 한해 **팀장**도 가능) |

- 보이는 인원은 관리자·PMO·PM이면 전사, **팀장이면 자신이 이끄는 팀 인원**입니다.
- 스킬 선택지는 [7.6 스킬 관리](../07-설정/06-스킬-관리.md)에서 「스킬 관리」 권한으로 정의합니다.

---

**언제 쓰나** — **개인 단위로** 누가 바쁘고 누가 여유인지, 어떤 스킬을 가졌는지 확인할 때.

![그림 6-2 인력 현황](../images/06-resource-people.png)
*그림 6-2. 인력 현황 — ① 요약 카드(총 인원·여유·적정·과부하)와 마지막 집계 ② 필터(스킬·직무·등급·팀·직군·투입가능만) ③ 인력 표(가동률 밴드·완수율·작업량) ④ 행 클릭으로 열린 인력 상세 드로어.*

## 상단 요약

**총 인원 · 여유 · 적정 · 과부하** 카드와 **마지막 집계** 시각이 표시됩니다.

> 가동률은 **배치 집계** 값입니다. 방금 등록한 인원이나 방금 쌓인 워크로그는 다음 집계 전까지 반영되지 않습니다. "집계 데이터가 오래되었습니다" 안내가 뜨면 그 시점 기준으로 해석하세요.

## 목록 컬럼

| 컬럼 | 의미 |
|---|---|
| 인력 | 이름·아바타 |
| 팀 / 직무 / 등급 | 소속과 직무 정보 |
| 가동률 | 배치 집계 기준. 밴드(여유/적정/과부하 주의/과부하/실적없음)로 색 구분 |
| 완수율 | `소비시간 ÷ (소비 + 남은 작업량)`. **완료 이슈는 최근 6개월분만** 집계 |
| 작업량 | 처리 / 남은 / 할당. 진행도 % = 처리 ÷ 할당 |
| 할당 이슈 | 담당·협업으로 연결된 이슈 수 |
| 참여 프로젝트 | 참여 중(미종료) 프로젝트 수 |
| 보유 스킬 | 등록된 스킬 태그 |

**필터**: 스킬 · 직무 · 등급 · 팀 · 직군 · **투입가능만**

> 가동률 밴드의 경계값(과소 / 과부하 / 심한 과부하)은 [7.1 일반 설정](../07-설정/01-일반-설정.md)에서 조정합니다.

## 인력 상세 드로어

행을 클릭하면 오른쪽에 상세가 열립니다.

| 구역 | 내용 |
|---|---|
| **부하** | 진행중 이슈 수, 남은 작업량(시간) |
| **진행 중 작업** | 이슈별 상태·프로젝트·마감·참여 형태(담당/협업)·**내 몫** |
| **경험** | 프로젝트 참여 이력(역할·기간·상태) |

> **"내 몫"은 근사치입니다.** 여러 명이 참여한 이슈는 남은 작업량을 **참여 인원으로 균등 분할**한 1인 기대 몫으로 계산합니다. 실제 분담 비율과 다를 수 있습니다.

## 스킬 편집

드로어의 **스킬 편집**으로 보유 스킬을 지정합니다(쓰기 권한 필요).

- 선택지는 [7.6 스킬 관리](../07-설정/06-스킬-관리.md)에서 정의한 사전을 따릅니다.
- 여기 등록한 값이 [6.4 프로젝트 배정](./04-프로젝트-배정.md)의 **적합도** 계산에 쓰입니다.
- 본인 스킬은 [마이페이지](../03-마이페이지.md)에서도 직접 편집할 수 있고, 팀장은 마이페이지의 **내 팀**에서 팀원 스킬을 편집할 수 있습니다.

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 가동률이 "데이터 없음"입니다 | 아직 집계 전이거나 해당 기간 워크로그 실적이 없습니다 |
| 일부 인원만 보입니다 | 팀장 권한이면 자신이 이끄는 팀 인원만 보입니다 |
| 스킬 필터에 원하는 스킬이 없습니다 | [7.6 스킬 관리](../07-설정/06-스킬-관리.md)에서 사전에 먼저 등록해야 합니다 |
| 완수율이 낮게 나옵니다 | 완료 이슈를 **최근 6개월분만** 집계합니다. 오래된 완료 이슈는 분자에서 빠집니다 |
