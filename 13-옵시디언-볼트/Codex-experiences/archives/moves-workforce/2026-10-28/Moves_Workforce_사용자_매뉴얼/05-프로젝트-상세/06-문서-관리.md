# 5.6 문서 관리

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | 「프로젝트 관리」 읽기 |
| 문서 연결·분류 변경·연결 해제 | 「프로젝트 관리」 쓰기 |
| 작업에 연결·해제 | 위 권한 **+** Jira 권한: 그 작업의 Edit Issues |
| 문서 검색·최신 정보 확인 | Confluence 권한: 본인이 Confluence에서 볼 수 있는 페이지만 검색되고 표시됩니다 |
| 분류·오래된 문서 기준 설정 | 「일반 설정」 쓰기 ([7.1](../07-설정/01-일반-설정.md#문서-설정)) |

- 프로젝트 조회 범위(소속 프로젝트만 / 내 팀만) 밖 프로젝트에서는 열리지 않습니다.
- Jira 편집 권한이 없는 작업은 저장할 때 그 작업만 **실패**로 표시되고, 나머지 작업은 그대로 저장됩니다.

---

**언제 쓰나** — 프로젝트의 설계서·회의록·산출물 같은 **Confluence 문서를 작업(Jira 이슈)이나 프로젝트에 연결**해 두고, 문서가 없는 작업이나 오래 손대지 않은 문서를 한눈에 찾을 때.

## Jira와 Confluence의 역할

Moves Workforce의 모든 화면은 **Jira 안에** 있습니다. Confluence는 이 탭에서 문서를 찾아 연결하는 **문서 출처로만** 쓰입니다.

| 제품 | 필수 여부 | 역할 |
|---|---|---|
| **Jira** | 필수 | 앱 설치 위치. 메뉴·화면 전부가 Jira에 있습니다 |
| **Confluence** | 선택 | **앱 화면이 없습니다.** 이 탭이 Confluence 페이지를 검색하고 제목·스페이스·최종 수정일을 읽어 옵니다 |

- Confluence에서 앱을 찾을 필요는 없습니다. 문서 연결은 언제나 **Jira → 앱 → Moves Workforce → 프로젝트 관리 → 프로젝트 → 문서 관리 탭**에서 합니다.
- 앱은 Confluence의 **검색 기능만** 사용하고, Confluence에 아무것도 쓰지 않습니다. 연결 정보는 Jira 쪽(작업의 속성, 프로젝트 문서는 앱 저장소)에 저장됩니다.
- 검색과 표시는 **본인 계정의 Confluence 권한**으로 이뤄집니다. 동료가 연결한 문서라도 본인에게 볼 권한이 없으면 「끊김」으로 보입니다.

### Confluence가 연결되지 않은 경우

사이트에 Confluence가 없거나 앱이 Confluence에 추가되지 않았으면 탭 위에 **「Confluence에 연결되지 않았습니다」** 안내가 뜹니다.

- 이미 연결된 문서 목록은 **마지막으로 저장된 정보로** 계속 보입니다.
- 새 문서 연결과 문서 상태 확인(최종 수정일·끊김)은 할 수 없습니다.
- 나머지 Moves Workforce 기능은 Confluence와 무관하게 모두 동작합니다.

이 사이트에서 Confluence를 쓰고 있다면 Jira 관리자에게 **Moves Workforce 앱을 Confluence에도 추가**해 달라고 요청하세요. 이미 추가돼 있다면 본인 계정에 Confluence 접근 권한이 있는지 확인하세요.

![그림 5-17 문서 관리 탭 문서 보기](../images/05-documents-view.png)
*그림 5-17. 문서 관리 탭(문서 보기) — ① 문서 / 작업 보기 전환 ② 요약 카드 5개 ③ 필터 ④ 문서 목록 ⑤ 문서 연결 버튼.*

## 화면 구성

탭 위쪽의 **문서 / 작업** 전환으로 두 가지 보기를 오갑니다. 두 보기 모두 **문서 연결** 버튼이 있습니다(「프로젝트 관리」 쓰기 권한자만).

### 요약 카드

문서 보기 맨 위에 작은 카드 5개가 한 줄로 표시됩니다. 카드를 누르면 해당 조건으로 목록이 걸러집니다.

| 카드 | 뜻 | 누르면 |
|---|---|---|
| **연결 문서 수** | 이 프로젝트에 연결된 문서 수 | 문서 필터 해제 |
| **문서 없는 작업** | 연결된 문서가 하나도 없는 작업 수 | 작업 보기로 바뀌고 「문서 없는 작업만」이 켜짐 |
| **오래된 문서** | 기준 일수(기본 90일) 넘게 수정되지 않은 문서 | 상태 = 오래됨 |
| **끊긴 링크** | 삭제됐거나 본인이 볼 권한이 없는 문서 | 상태 = 끊김 |
| **누락된 필수 분류** | 필수로 지정한 분류인데 프로젝트에 그 분류의 문서가 하나도 없음 | (분류 이름만 표시) |

- 경고 카드(오래된 문서·끊긴 링크·누락된 필수 분류)는 0이면 흐리게, 1 이상이면 경고 색으로 표시됩니다.
- Confluence에 연결되지 않아 확인할 수 없는 값은 0이 아니라 **확인 불가**로 표시됩니다.

### 문서 보기

연결된 **문서 한 건이 한 줄**입니다.

| 열 | 내용 |
|---|---|
| 제목 | 누르면 Confluence 페이지가 새 창으로 열립니다 |
| 스페이스 | 스페이스 아이콘과 이름 |
| 분류 | 연결할 때 고른 분류. 없으면 「미분류」 |
| 연결 작업 | 이 문서가 연결된 작업. 작업 없이 연결한 문서는 **프로젝트 문서** 배지 |
| 최종 수정일 | Confluence에서 마지막으로 수정된 날짜 |
| 상태 | **정상** / **오래됨** / **끊김** / **확인 불가** |
| 동작 | **분류 변경**, **연결 해제** (쓰기 권한자만) |

필터: 검색어(제목·스페이스·작업 키·요약), 작업(여러 개 고르면 하나라도 연결된 문서), 분류, 상태.

### 작업 보기

프로젝트의 **작업 한 건이 한 줄**입니다.

| 열 | 내용 |
|---|---|
| 키 | 이슈 유형 아이콘과 이슈 키 |
| 요약 / 상태 | Jira 이슈 요약과 상태 |
| 문서 | 연결된 문서 제목 링크 3개까지, 나머지는 「외 N건」. 문서 수로 정렬됩니다 |
| 동작 | **문서 연결** — 이 작업을 대상으로 연결 창을 엽니다 |

필터: 검색어(키·요약·문서 제목), **문서 없는 작업만**.

## 절차

### 문서 연결하기

![그림 5-18 문서 연결 창](../images/05-documents-link-modal.png)
*그림 5-18. 문서 연결 창 — ① 스페이스 선택 ② 검색어·본문 포함 ③ 검색 결과(선택한 문서는 체크 유지) ④ 작업 선택 ⑤ 분류.*

1. **문서 연결**을 누릅니다.
2. **① 문서** — 문서를 찾아 고릅니다.
   - 제목을 입력하거나 Confluence **페이지 주소를 붙여 넣어** 찾습니다. **본문 포함**을 켜면 본문 내용까지 검색합니다.
   - **스페이스**를 고르면 검색어 없이도 그 스페이스의 문서가 최근 수정 순으로 나옵니다(25건씩 **더 보기**).
   - 여러 문서를 한 번에 고를 수 있습니다(최대 30건). **이 목록 모두 선택 / 해제**는 지금까지 불러온 결과 전체가 대상입니다.
3. **② 작업** — 문서를 연결할 작업을 고릅니다(여러 개 가능).
   - **작업을 고르지 않으면** 특정 작업이 아니라 **이 프로젝트의 문서**(프로젝트 문서)로 연결됩니다. 프로젝트 전체에 해당하는 계획서·회의록에 쓰세요.
4. **③ 분류** — 분류를 고릅니다(선택). 분류 목록은 [일반 설정](../07-설정/01-일반-설정.md#문서-설정)에서 정합니다.
5. 저장하면 **작업별 성공·실패 결과**가 표시됩니다.

### 분류 바꾸기 · 연결 해제하기

문서 보기의 **동작** 열에서 **분류 변경** 또는 **연결 해제**를 누릅니다. 문서가 여러 작업에 연결돼 있으면 **적용할 작업을 고른 뒤** 저장하고, 결과는 작업별로 표시됩니다.

연결 해제는 연결만 끊습니다. **Confluence 페이지는 지워지지 않습니다.**

## 알아두기

- **한 작업에 연결할 수 있는 문서는 30건까지**입니다. 넘으면 그 작업은 실패로 표시됩니다.
- 같은 문서를 같은 작업에 다시 연결하면 새로 추가되지 않고 **분류만 갱신**됩니다.
- 목록의 제목·스페이스는 연결 당시 값을 저장해 두고, 화면을 열 때 Confluence에서 최신 정보로 다시 확인합니다. Confluence에서 제목을 바꾸면 다음에 열 때 반영됩니다.
- 작업이 아주 많은 프로젝트는 앞쪽 일부 작업만 불러오며, 이때 「작업이 많아 일부만 표시합니다」 안내가 뜹니다. 연결 문서가 500건을 넘으면 그 이후 문서는 최신 정보를 확인하지 않고 「확인 불가」로 표시됩니다.
- 작업을 [프로젝트에서 제외](./03-작업-관리.md#일괄-적용과-제외)해도 그 작업에 연결된 문서 정보는 Jira 작업에 남습니다. 다시 편입하면 그대로 보입니다.

## 문제 해결

| 증상 | 원인 | 조치 |
|---|---|---|
| 「Confluence에 연결되지 않았습니다」가 뜬다 | 사이트에 Confluence가 없거나, 앱이 Confluence에 추가되지 않았거나, 본인에게 Confluence 권한이 없음 | Jira 관리자에게 앱을 Confluence에 추가해 달라고 요청하거나 본인의 Confluence 접근 권한을 확인 |
| **문서 연결** 버튼이 없다 | 「프로젝트 관리」 쓰기 권한 없음 | 권한 관리자에게 요청 |
| 일부 작업만 실패한다 | 그 작업의 Jira 편집 권한이 없거나 한 작업에 30건이 넘음 | 결과 창의 실패 사유를 확인 |
| 동료에게는 보이는 문서가 나에게는 「끊김」이다 | 본인이 그 Confluence 페이지를 볼 권한이 없음 | Confluence 스페이스 관리자에게 권한 요청 |
| 찾는 문서가 검색되지 않는다 | 본인이 볼 수 없는 페이지이거나 검색어가 제목과 다름 | **본문 포함**을 켜거나 페이지 주소를 붙여 넣어 검색 |
