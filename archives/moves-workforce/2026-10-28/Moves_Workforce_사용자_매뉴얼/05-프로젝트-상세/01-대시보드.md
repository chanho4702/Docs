# 5.1 대시보드

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | 「대시보드」 읽기 |
| 위젯 추가·레이아웃 편집·삭제·커스텀 필터 편집 | 「대시보드」 쓰기 |
| **총 인건비** 카드, 급여 분포·비용 소진 위젯 | 「비용」 읽기 (없으면 **항목 자체가 표시되지 않음**) |
| 상태별 분포·계획 대비 실적·진척 추이·지연 이슈 등 분석 위젯 | 「리포트」 읽기 (없으면 위젯 자리에 "분석 리포트 열람 권한이 필요합니다" 안내) |

- 급여 정책이 **등급 기반**이면 「비용」이 있어도 총 인건비 카드와 급여 분포 위젯이 숨겨집니다([7.1](../07-설정/01-일반-설정.md)).
- 대시보드 데이터는 프로젝트 단위라 **조회 범위 밖 프로젝트**에서는 열리지 않습니다.

---

**언제 쓰나** — 프로젝트 현황을 **한 화면에서 요약**해 보고할 때. 위젯을 골라 프로젝트마다 다른 대시보드를 꾸밀 수 있습니다.

![그림 5-2 프로젝트 대시보드 전체](../images/05-dashboard-overview.png)
*그림 5-2. 대시보드 — ① 요약 카드 6개 ② 위젯 그리드 ③ 편집 / 차트 추가 버튼. "전부 추가" 직후의 기본 배치로 캡처.*

## 상단 요약 카드

| 카드 | 의미 |
|---|---|
| 프로젝트 참여 인력 | [인력 관리](./02-인력-관리.md)에 등록된 인원 수 |
| 프로젝트 기간 | 시작일 ~ 종료일 |
| 총 인건비 | 「비용」 읽기 권한자에게만. 급여 정책이 [등급 기반](./02-인력-관리.md#계산-방식은-급여-정책이-결정합니다)이면 숨김 |
| 진척률 | 완성 진척(계획 공수 가중). [5.5.4 진척률](./05-분석-및-리포트.md#554-진척률)과 같은 값 |
| 남은 기간 | 종료일까지 D-day. 기간이 없으면 "기간 미설정" |
| 지연 이슈 | 기한이 지났는데 완료되지 않은 이슈 수 |

> 이슈가 아주 많은 프로젝트는 "이슈가 많아 일부만 집계했습니다"가 함께 표시됩니다. 실제 값은 표시된 값보다 큽니다.

## 위젯 종류

**차트 추가**에서 고를 수 있는 데이터 유형입니다. 유형마다 어울리는 차트 종류가 정해져 있습니다.

| 데이터 유형 | 차트 | 무엇을 보여주나 |
|---|---|---|
| 역할 분포 / 등급 분포 / 팀 분포 | 도넛·바 | 참여 인력의 역할·등급·소속 팀 구성 비율 |
| 담당자 분포 | 도넛·바 | 이슈 담당자별 분포 |
| 작업 분포 | 도넛·바 | 이슈별 참여 인원 분포 |
| 급여 분포 | 바 | 인건비 구간별 인원 (「비용」 권한) |
| 워크로그 | 히트맵 · 멀티 라인 | 일자별 작업 시간 강도(히트맵은 **일일 용량** 대비 0h / 0~1h / 1~4h / 4~8h / 8h+ 단계) 또는 작업자별 일별 추이 |
| 상태별 분포 | 도넛 | 완료 / 진행 중 / 할 일. **건수 기준 ↔ 공수 기준** 전환 |
| 계획 대비 실적 | 바 | 계획 공수(MD) 합계 vs 실투입 공수 |
| 지연·임박 이슈 | 목록 | 기한 초과·임박 미완료 이슈를 위험한 순서로. 전체/지연/임박 필터, 클릭 시 Jira로 이동 |
| 이슈 규모 | 트리맵 | 어느 이슈가 작업량을 많이 차지하는지 면적으로 비교. **실투입 ↔ 계획** 전환 |
| 관계 토폴로지 | 관계망 | 이슈–하위 이슈–연결 이슈–워크포스 상위 관계를 그래프로. 원 크기 = 투입 시간, 색 = 소속 Jira 프로젝트. "관계 있는 이슈만" 토글 |
| 진척 추이 | S-curve | 계획 누적 vs 실적 누적 공수. [진척률 탭](./05-분석-및-리포트.md#554-진척률)과 같은 데이터 |
| 비용 소진 | 번업 | 월별 누적 인건비 vs 예산선 (「비용」 권한). [비용 탭](./05-분석-및-리포트.md#555-비용)과 같은 데이터 |
| 커스텀 필터 | 목록 | 담당자·상태·이슈 타입·우선순위·기한·계획 공수 조건을 직접 지정해 원하는 이슈만 모아 봄 |

각 위젯은 **차트/표 전환**, **펼치기**, **새로고침**, **계산식 안내(ⓘ)** 를 제공합니다. 조회가 무거운 위젯(토폴로지·진척 추이·비용 소진 등)에는 **무거움** 배지가 붙고, 이슈가 많은 프로젝트에서는 로딩이 오래 걸릴 수 있습니다.

![그림 5-3 차트 추가 창](../images/05-dashboard-add-chart.png)
*그림 5-3. 차트 추가 — ① 추천(템플릿) ② 직접 선택(데이터 유형 → 차트 타입) ③ 전부 추가(추가 예정 수·건너뛸 수 안내).*

## 대시보드 꾸미기

1. 우측 위 **편집**을 누릅니다.
2. 위젯을 **드래그해 재배치**하거나 모서리를 끌어 **크기를 조정**합니다.
3. **차트 추가**로 위젯을 늘립니다.
   - **추천(템플릿)**: 목적별 묶음 — 인력 분석(역할·등급) / 비용 분석(급여) / 업무 분석(작업·담당자) / **프로젝트 건강**(상태별 분포·지연 임박·계획 대비 실적) / **작업 규모**(이슈 규모·상태별 분포) / **일정·비용 심층**(진척 추이·비용 소진)
   - **직접 선택**: 데이터 유형을 고른 뒤 그에 맞는 차트 종류와 이름을 지정
   - **전부 추가**: 지금 권한으로 볼 수 있는 위젯을 **한 번에** 추가합니다. 이미 있는 위젯은 건너뛰며, 배치는 정해진 줄 순서로 채워집니다
4. **편집 완료**를 누르면 배치가 **프로젝트별로 저장**됩니다.

### 커스텀 필터 위젯 쓰기

1. 커스텀 필터 위젯을 추가하면 처음엔 "조건이 설정되지 않아 전체 이슈를 표시합니다" 상태입니다.
2. 위젯의 **필터 편집**에서 담당자(**나** 선택 가능)·상태·이슈 타입·우선순위·기한(기한 초과 / 임박 / 기한 없음)·계획 공수(입력됨 / 미입력)를 조합합니다. 아래에 **현재 조건: N건** 미리보기가 갱신됩니다.
3. 저장하면 조건이 위젯과 함께 프로젝트에 저장되어 다른 사용자에게도 같은 목록이 보입니다.

## 알아두기

- 담당자 분포·지연 이슈 등 이슈 기반 위젯은 [작업 관리](./03-작업-관리.md)에 편입된 이슈만 대상으로 합니다.
- 역할·등급·팀 분포는 [인력 관리](./02-인력-관리.md)에서 각 멤버에게 부여한 값 기준입니다. 값이 비어 있는 인원은 분포에서 빠집니다.
- 「리포트」 권한이 없는 사용자가 대시보드를 열면 분석 위젯 자리에 권한 안내만 보이고 나머지 위젯은 정상 표시됩니다. 위젯이 잘못된 것이 아닙니다.
- 더 깊은 분석(담당자별 계획 대비 실적, 가동률, 지연 원인 이슈)은 [5.5 분석 및 리포트](./05-분석-및-리포트.md)를 사용하세요.
