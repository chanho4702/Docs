# Moves Workforce 사용자 매뉴얼

> **한·영 고객 가이드 편집본:** [Confluence 게시용 검토 초안](./confluence/README.md)에 고객 사용자·관리자 기준으로 재구성한 한국어·영어 21개 주제가 있습니다. 실제 staging 화면과 대조하기 전의 초안이며, [이미지 요청 목록](./confluence/image-requests.md)과 [검증·게시 준비 상태](./confluence/publication.md)를 함께 확인하세요.

| 항목 | 내용 |
|------|------|
| 버전 | v3.1 |
| 최종 현행화 | 2026-10-04 |
| 기준 소스 | `develop` + `RFC-204` 작업 트리 (2026-09-28), `static/ui/src`, `locales/kr`, `src/permission` |

> Jira(Atlassian)에 설치되는 **Moves Workforce** 앱의 사용 안내서입니다.
> 작업 시간(워크로그) 기록과 프로젝트별 인력·작업·인건비 관리, 진척·가동률 분석을 한 곳에서 처리할 수 있는 워크포스 관리 도구입니다.

> **기준선 주의:** 이 매뉴얼은 2026-09-28 개발 소스를 기준으로 하며, 운영 환경의 배포 시점에 따라 일부 화면이 아직 없을 수 있습니다. 실제 제공 기능은 [릴리스 노트](../Moves_Workforce_릴리스노트.md)와 대상 환경의 배포 상태를 확인하세요.

> **그림에 대하여:** 각 페이지의 `그림 N-M`은 캡처 예정 자리입니다. 캡처 목록·촬영 조건은 [images/README.md](./images/README.md)에 있습니다. 파일이 아직 없으면 그림 자리에 깨진 이미지가 표시됩니다.

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 이 목차 페이지 | **권한 불필요** |
| 각 화면의 권한 | 페이지마다 상단의 **접근 권한** 표를 확인하세요 |
| 권한 전체 요약 | [부록 B. 권한별 사용 범위](./부록/B-권한별-사용-범위.md) |
| 내 현재 권한 확인 | [마이페이지 > 내 권한](./03-마이페이지.md#31-내-현황) (권한 불필요) |

**권한 표기 규칙**

권한 이름은 **[설정 > 권한 관리](./07-설정/08-권한-관리.md) 화면에 표시되는 항목명**을 「 」 안에 그대로 씁니다.

| 표기 | 의미 |
|---|---|
| 「프로젝트 관리」 읽기 | 그 항목의 **읽기(Read)** 체크가 있어야 화면이 보입니다 |
| 「프로젝트 관리」 쓰기 | **쓰기(Write)** 체크가 있어야 추가·수정·삭제 버튼이 나타납니다 |
| A 또는 B | 둘 중 **하나만** 있어도 됩니다 |
| A + B | **둘 다** 있어야 합니다 |
| 권한 불필요 | 본인 데이터이거나 전역 공개 정보입니다 |
| Jira 권한 | 앱 권한과 **별개로** Jira 자체 권한이 필요합니다 |

> 권한이 없으면 대부분 **버튼·탭·메뉴가 아예 보이지 않습니다.** 서버에서도 같은 검사를 하므로 화면을 우회해도 거부됩니다.

## 이 문서를 읽는 법

각 페이지는 다음 순서로 구성됩니다.

1. **접근 권한** — 이 화면을 보고 편집하는 데 필요한 권한
2. **언제 쓰나** — 이 화면이 해결하는 문제
3. **화면 구성** — 어디에 무엇이 있는지 (그림 포함)
4. **절차** — 단계별 절차
5. **알아두기 / 주의** — 오해하기 쉬운 규칙
6. (필요 시) **문제 해결** — 증상과 원인
