# 7.2 인력 관리

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | 「인력 관리」 읽기 |
| 인력 추가·수정·삭제 | 「인력 관리」 쓰기 |
| 엑셀 일괄 업로드 | 「인력 관리」 쓰기 |
| Excel 다운로드 | 「인력 관리」 읽기 |
| 연봉 입력·표시 | 「인력 관리」 쓰기 **+** 급여 정책이 **인원별** |
| 권한 세트 지정 | 「인력 관리」 쓰기. 단, **자기 권한을 넘는 세트는 줄 수 없습니다**(Jira 관리자·「권한 관리」 쓰기 보유자는 제한 없음) |

- 역할·등급·팀·권한 **선택지**는 이 화면에서 함께 조회됩니다(「인력 관리」 읽기로 열립니다). 값 자체를 만들려면 각 기준정보 화면의 권한이 필요합니다.
- 급여 정책이 등급 기반이면 연봉 칸이 사라집니다([7.1](./01-일반-설정.md)).

---

**언제 쓰나** — 워크포스 사용자(인력)를 등록·수정할 때. **여기 등록된 사람만** 팀 배치·프로젝트 인력·팀장 지정의 대상이 됩니다.

![그림 7-3 인력 관리](../images/07-users.png)
*그림 7-3. 인력 관리 — ① 권한/역할/등급/팀별 인원 통계 카드 ② 필터와 Excel 다운로드 ③ 인력 추가·일괄 업로드 ④ 인력 표(팀장 배지·권한·연봉).*

## 화면 구성

- 상단에 **권한 / 역할 / 등급 / 팀별 인원 통계** 카드
- 필터: 사용자 검색 · 역할 · 등급 · 권한 · 팀
- **Excel 다운로드**: 설정한 필터 조건 그대로 내려받습니다

| 컬럼 | 설명 |
|---|---|
| 사용자 | 이름·아바타. 소속 팀의 팀장이면 **팀장** 배지 |
| 직무 역할 | [7.4](./04-역할-관리.md)에서 정의한 값 |
| 직무 등급 | [7.5](./05-등급-관리.md)에서 정의한 값 |
| 팀 | 소속 팀 |
| 권한 | 권한 세트 또는 **팀 권한 상속** |
| 연봉 | **급여 정책이 인원별일 때만** 입력·표시 (단위: 만원) |
| 등록일 / 작업 | 등록 시각, 수정·삭제 |

## 인력 한 명 추가하기

1. **인력 추가**를 누릅니다.
2. **Jira 사용자**를 이름 또는 이메일로 검색해 선택합니다.
3. 직무 역할·등급·권한을 지정합니다.
   - **권한을 선택하지 않으면 Member 권한으로 자동 등록**됩니다.
   - 팀 권한을 따르게 하려면 **팀 권한 상속**을 선택합니다([7.8 참고](./08-권한-관리.md#팀-권한-상속)).
4. 정책이 인원별이면 연봉을 입력할 수 있습니다.

## 팀장의 팀 이동 제한

수정 창에서 **팀**을 바꿀 수 있지만, 그 사람이 **어떤 팀의 팀장이면 그 팀 밖으로 옮길 수 없습니다.** "팀장은 이끄는 팀 밖으로 옮길 수 없습니다. 팀장 지정을 먼저 해제하세요"가 표시됩니다. [7.3 팀 관리](./03-팀-관리.md)에서 팀장을 바꾼 뒤 이동하세요.

## 여러 명 한 번에 등록하기 (일괄 업로드)

![그림 7-4 엑셀 일괄 업로드](../images/07-users-bulk-upload.png)
*그림 7-4. 일괄 업로드 — ① 템플릿 다운로드 ② 파일 드롭 영역 ③ 진행률 ④ 결과 요약(전체/등록/중복/미존재/실패) ⑤ 실패 목록 버튼.*

1. **일괄 업로드** → **템플릿 다운로드**로 양식을 받습니다.
2. 양식을 채워 xlsx로 저장합니다. **최대 5MB, xlsx만 가능**합니다.
3. 파일을 드래그하거나 **파일 선택**으로 올립니다.
4. 처리는 백그라운드로 진행되며 진행률이 표시됩니다.
5. 결과가 **전체 / 등록 / 중복 / 미존재 / 실패**로 요약됩니다.
6. 실패 건이 있으면 **일괄 업로드 실패 목록** 버튼으로 사유를 확인합니다.

| 결과 항목 | 의미 |
|---|---|
| 등록 | 정상 등록됨 |
| 중복 | 이미 워크포스에 있는 사용자 |
| **미존재** | **Jira에 없는 계정** — Jira 사용자로 먼저 초대돼 있어야 등록됩니다 |
| 실패 | 그 밖의 오류(실패 목록에서 사유 확인) |

## 알아두기

- 급여 정책이 등급 기반이면 **"개인 연봉은 입력·표시되지 않습니다"** 안내가 표시됩니다([7.1](./01-일반-설정.md)).
- 사용자를 삭제하면 복구할 수 없습니다. 삭제 전 확인 창이 표시됩니다. 삭제된 사람이 팀장이던 팀은 **팀장이 비워집니다.**
- 여기서 등록한 연봉은 프로젝트 인건비 계산 중 **연봉 투입 유형**에서 사용됩니다([5.2 급여 관리](../05-프로젝트-상세/02-인력-관리.md#523-급여-관리)).

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 업로드 결과가 전부 "미존재"입니다 | 대상자들이 Jira 사용자로 초대돼 있지 않습니다 |
| 연봉 칸이 보이지 않습니다 | 급여 정책이 등급 기반입니다 |
| 권한 세트를 고를 수 없습니다 | 내 권한보다 넓은 세트는 배정할 수 없습니다. 「권한 관리」 쓰기 보유자에게 요청하세요 |
| 팀을 바꾸려는데 거부됩니다 | 그 사람이 팀장입니다. [7.3](./03-팀-관리.md)에서 팀장을 먼저 해제하세요 |
| 팀장으로 지정하려는데 목록에 없습니다 | 그 사람을 먼저 여기서 인력으로 등록해야 합니다 |
| 프로젝트 배정 화면에서 "백오피스에 등록되지 않은 사용자"라고 나옵니다 | 같은 이유입니다. 인력으로 먼저 등록하세요 |
