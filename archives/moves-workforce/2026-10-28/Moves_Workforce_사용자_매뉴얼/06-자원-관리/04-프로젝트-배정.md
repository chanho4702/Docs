# 6.4 프로젝트 배정

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회(프로젝트 카드·작업 현황) | 「프로젝트 관리」 읽기 또는 「자원관리」 읽기 |
| **전사 인력 후보 목록** | 「자원관리」 읽기 |
| 배정 실행·팀 전체 배정 | 「프로젝트 관리」 쓰기 또는 「자원관리」 쓰기 **+ Jira 담당자 지정 권한** |
| 프로젝트 필요 스킬 편집 | 「프로젝트 관리」 쓰기 |
| 인력 보유 스킬 편집 | 「자원관리」 쓰기 |

- **조회 전용 자원 관리자(읽기만)는 배정을 실행할 수 없습니다.** 쓰기 권한이 필요합니다.
- 배정 대상 후보는 [7.2 인력 관리](../07-설정/02-인력-관리.md)에 등록된 인원으로 한정됩니다.
- 보이는 프로젝트는 조회 범위(소속 프로젝트만 / 내 팀만)로 필터됩니다.

---

**언제 쓰나** — "이 프로젝트에 누구를 넣을까"를 전사 인력 풀에서 고를 때.

![그림 6-5 프로젝트 배정](../images/06-resource-assignment.png)
*그림 6-5. 프로젝트 배정 — ① 배정 대상 프로젝트 카드(D-day·미배정/임박/지연) ② 작업 현황(배정 인원) ③ 전사 인력 후보(적합도·신호·배정 버튼) ④ 패널 접기 버튼 ⑤ 팀 전체 배정.*

## 화면 구성

| 영역 | 내용 |
|---|---|
| **배정 대상 프로젝트** (좌) | 프로젝트 카드 — D-day, 미배정·임박·지연 작업 수. 검색·상태 필터, **종료·일정오버 포함** 토글 |
| **작업 현황** (중) | 선택 프로젝트의 열린 작업과 **배정 인원 N명** |
| **전사 인력** (우) | 후보 목록 — 직무/등급 · 스킬 · **적합도** · 신호 · 배정 버튼 |

세 패널은 카드 헤더의 접기 버튼과 경계선 드래그로 폭을 조절할 수 있습니다. 프로젝트 카드에는 `D-7`, `D-DAY`, `D+3 지연` 같은 일정 배지와 종료·일정 오버 표시가 붙습니다.

## 배정하는 법

1. 왼쪽에서 프로젝트를 선택합니다. (선택 전에는 "프로젝트를 선택하면 적합도가 표시됩니다")
2. 오른쪽 전사 인력 목록에서 **적합도**와 **신호**(부하 상태)를 확인합니다.
3. **배정**을 눌러 맡길 작업을 고르거나, 배정할 작업이 없으면 **프로젝트 인력으로만** 배정합니다.
4. 팀 단위로 넣으려면 팀을 선택한 뒤 **팀 전체 배정**을 사용합니다.

> **적합도**는 프로젝트 **필요 스킬** 대비 후보의 보유 스킬 일치도입니다. 필요 스킬은 [프로젝트 추가/수정 창](../04-프로젝트-관리.md#프로젝트-추가--수정)의 필요 스킬 영역 또는 이 화면의 **요구 스킬 편집**으로, 보유 스킬은 [6.1 인력 현황](./01-인력-현황.md#스킬-편집)에서 지정합니다. 둘 중 하나가 비어 있으면 적합도가 의미를 갖지 못합니다.

> 백오피스에 등록되지 않은 Jira 사용자는 배정할 수 없습니다 — 먼저 [7.2 인력 관리](../07-설정/02-인력-관리.md)에서 등록하세요.

## 팀 전체 배정 규칙

- **이미 배정된 인원은 대상에서 제외**됩니다. 실행 전 "{팀} {N}명을 [{프로젝트}]에 배정합니다"로 확인합니다.
- 되돌리려면 배정 명단에서 **한 명씩 취소**해야 합니다(일괄 취소 없음).
- 배정 취소 시 **이미 할당된 작업의 담당은 해제되지 않습니다** — 해당 건수가 안내됩니다.

## 배정 관계도

프로젝트–팀–담당자 3레이어 관계를 그래프로 보여줍니다.

![그림 6-6 배정 관계도](../images/06-resource-allocation-graph.png)
*그림 6-6. 배정 관계도 — ① 프로젝트 노드 ② 팀 노드 ③ 담당자 노드(여러 프로젝트에 선이 이어진 중복 배정 강조) ④ 진행 상태·프로젝트 필터, 종료 프로젝트 포함 토글.*

> **링크 기준은 "프로젝트 인력 배정 명단"이지 워크로그 투입이 아닙니다.** 배정만 되고 아직 착수하지 않은 인원도 표시됩니다. 실제 기여도는 [5.5 팀 분석](../05-프로젝트-상세/05-분석-및-리포트.md#553-팀-분석)이나 [5.5 인력 분석](../05-프로젝트-상세/05-분석-및-리포트.md#552-인력-분석)에서 확인하세요.

- 배정 인원이 많으면 상위 N개 프로젝트만 표시되며 **전체 표시**로 펼칠 수 있습니다.
- 진행 상태·프로젝트 필터, **종료 프로젝트 포함** 토글을 제공합니다.
- 노드를 클릭하면 해당 인력의 상세 드로어가 열립니다.
- 같은 관계도를 [통합 대시보드 > 자원 서브탭](../08-통합-대시보드.md#83-비교-서브탭)의 **전사 배정 관계도**에서도 볼 수 있습니다.

## 프로젝트 상세의 작업 배정과 어떻게 다른가

| | 이 화면 (6.4) | [5.2 작업 배정](../05-프로젝트-상세/02-인력-관리.md#524-작업-배정) |
|---|---|---|
| 후보 범위 | **전사 인력** | 이미 등록된 **프로젝트 인력** |
| 출발점 | 여러 프로젝트를 비교하며 사람 고르기 | 이 프로젝트 안에서 작업 나누기 |
| 팀 단위 처리 | **팀 전체 배정** 지원 | 담당 팀에서 팀 전체 추가 |
