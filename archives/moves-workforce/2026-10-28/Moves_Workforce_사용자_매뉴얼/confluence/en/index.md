# English Guide

[한국어](../ko/index.md)

> Review draft: the screens and deployed version on the designated staging site have not yet been verified.

Moves Workforce is a Jira app for assigning people and work to projects and reviewing effort, utilization, progress, and labor cost using recorded work. New users can start with the quick start. Administrators should begin with initial setup.

## Get started

- [Quick start](./quick-start.md): open the app, record your first worklog, and check your project.
- [Administrator setup](./admin-setup.md): prepare the app for your users.
- [Glossary](./glossary.md): distinguish projects and spaces, MD and MM, and progress measures.

## User guide

| What you want to do | Guide |
|---|---|
| Record time and check your schedule | [My Work](./my-work.md) |
| Review your contribution, permissions, skills, and team | [My Page](./my-page.md) |
| Create projects and manage their status | [Project management](./projects.md) |
| Manage teams, members, salary settings, and assignments | [Project people](./project-people.md) |
| Link Jira issues and organize work and schedules | [Work management](./project-work.md) |
| Review a project using widgets | [Project dashboard](./project-dashboard.md) |
| View project schedules and worklogs on a calendar | [Calendar](./calendar.md) |
| Interpret effort, progress, and cost | [Analysis and reports](./analytics.md) |
| Link Confluence documents | [Document management](./documents.md) |
| Compare workload and skills before assigning people | [Resource management](./resources.md) |
| Compare risks across projects | [Portfolio dashboard](./portfolio.md) |
| Export Jira worklogs to Excel | [Worklog export](./worklog-export.md) |
| Record time directly on a Jira issue | [Jira issue panels](./issue-panel.md) |

## Get help

Use the symptom-based checks in the [FAQ](./faq.md). If a menu is missing, check app permissions. If an issue is missing or an update is rejected, also check your Jira permissions for that issue.

Open Moves Workforce from the Jira Apps menu. The Confluence space containing this guide hosts documentation; the app runs in Jira.
