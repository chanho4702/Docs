# Glossary

[Guide home](./index.md) · [한국어](../ko/glossary.md)

> Review draft: the screens and deployed version on the designated staging site have not yet been verified.

These terms carry the same meanings in both language guides. Some English UI labels may vary with the deployed version; check the actual menu as well.

| English | 한국어 | Meaning |
|---|---|---|
| Moves Workforce project | 앱 프로젝트 | The app's unit for grouping people, work, dates, and budget |
| Jira space / project | Jira 스페이스 | The Jira container for issues, separate from an app project |
| Work item / issue | 작업 / 이슈 | A Jira issue linked for management in a project |
| Worklog | 워크로그 / 업무일지 | Work date, duration, and description recorded on an issue |
| Assignee | 담당자 | One person responsible for a Jira issue |
| Coworker / collaborator | 동료 / 협업자 | A person selected to collaborate on an issue |
| Responsible team | 담당 팀 | Project ownership by a team, separate from member registration |
| Project member | 프로젝트 인력 | A person registered as a participant in an app project |
| Role | 역할 | A job-role classification |
| Level | 등급 | An organizational classification of people's levels |
| Person-day, MD | MD | Work hours ÷ standard daily working hours; equivalent to the existing Man-Day label |
| Person-month, MM | MM | MD ÷ the working-day basis for 1MM on that screen; equivalent to Man-Month |
| Effective available MD | 실효 가용 MD | Available working capacity in the period |
| Utilization | 가동률 | Recorded MD divided by effective available MD |
| Planned effort | 계획 작업량 | Effort based on Jira Original Estimate |
| Completion progress | 완성 진척 | Completion weighted by planned effort |
| Schedule progress | 일정 진척 | The elapsed share of the project's working period |
| Effort consumption | 공수 소진 | Accumulated recorded effort |
| Project budget | 프로젝트 예산 | An amount entered directly for the project |
| Labor cost | 인건비 | An amount calculated from salary policy and allocation assumptions |
| Project allocation amount | 투입 급여 | A person's amount specified for a particular project |
| Level salary band | 등급 급여 밴드 | Lower, upper, and representative amounts for a level |
| My share | 내 몫 | Screen-dependent: personal worklogs in issue panels, or an allocation approximation in resource views |
| Work breakdown structure | 상위 지정 / WBS | Parent–child organization of work |
| Folder | 폴더 | An app-specific grouping of work |
| Dependency | 선후행 | A predecessor–successor relationship |
| Milestone | 마일스톤 | Work with the same start and end date, highlighted on a schedule |
| Subscription / automatic inclusion | 구독 / 자동 편입 | A rule linking matching Jira issues to a project |
| Skill match | 스킬 적합도 | The match between required and recorded skills |
| Project visibility scope | 프로젝트 조회 범위 | The app projects a user can see |
| Team permission inheritance | 팀 권한 상속 | Taking a permission set from a team or ancestor team |

MD and MM conversions follow organizational settings. Do not treat example values such as 8 daily hours or a monthly working-day count as universal constants. Differences between percentages are expressed in percentage points (`%p`).
