사용자가 영어 이미지를 공통으로 사용하도록 지정했습니다. 실제 원본은 `images/en/*.jpg`이며 아래 PNG 파일명은 초기 요청 계획입니다. 원본은 1920×855, 영어 UI와 기존 데모 데이터로 촬영했습니다. 현재 로그인 계정의 화면이며 일반 사용자·팀장별 접근 검증을 대신하지 않습니다. 워크로그·권한·설정은 저장하지 않았습니다. 계정 언어도 변경하지 않았습니다.

## 전달 방법과 언어

- 기존 한국어 파일명은 `../images/README.md`의 계획과 동일합니다. 한국어 원본은 기존 매뉴얼의 `images/`, 영어는 `images/en/`에 저장합니다.
- 일반 사용자는 일반 사용자 화면, 팀장은 팀장 화면으로 촬영합니다. 관리자 화면으로 모든 사용자 모습을 대체하지 않습니다.
- 브라우저 주소창·실명·이메일·실제 급여 등 불필요한 정보는 포함하지 않습니다. 실제 정보가 있으면 공유 전에 가립니다.
- 1440px 폭·100% 배율·라이트 테마를 기본으로 하되 대상 영역이 읽히도록 잘라냅니다. 원본과 표식 편집본을 구분합니다.
- 이미지에는 번호만 넣고 설명은 한·영 캡션과 대체 텍스트로 관리하면 두 언어의 대응을 유지하기 쉽습니다.

## 캡션 예시

**한국어:** 워크로그 추가 창. ① 작업 날짜 ② 시작·종료 시각 ③ 자동 계산된 작업 시간. 09:00~12:30은 3시간 30분으로 표시됩니다.

**English:** Worklog dialog. ① Work date ② Start and end times ③ Calculated duration. 09:00–12:30 is shown as 3 hours 30 minutes.

**대체 텍스트:** 워크로그 추가 창에서 시작 09:00와 종료 12:30을 입력한 상태.

**Alt text:** Worklog dialog with a start time of 09:00 and an end time of 12:30.

캡처 후 실제 UI와 다른 문장을 먼저 고친 다음 번호·캡션을 연결합니다. 이미지 요청 ID는 편집 추적용이며 최종 고객 페이지에는 공개하지 않습니다.

## 상세 절차 보강 상태

초기 12장에 워크로그 기간 입력, 구독 목록·조건, 문서 목록·연결·작업 선택, 자원 배정·작업 선택 8장을 추가했습니다. 고객 가이드용 20장과 이슈 패널 미표시 진단 1장으로 총 21장입니다. IMG-10·13·14와 기간 입력 그림도 한·영 본문에 반영했습니다. MWD-46에서 이슈 패널과 앱 활동 탭이 표시되지 않아 진단 화면만 남겼으며, 고객 본문에는 넣지 않았습니다. 구독 신규 조건 미리보기·역할별 화면·나머지 후보는 아직 미확보입니다.
