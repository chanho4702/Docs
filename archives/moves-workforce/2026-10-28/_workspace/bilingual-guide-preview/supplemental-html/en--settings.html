What settings manage

Settings entries follow read permissions. Changes require the corresponding write permission. Job roles are separate from access permissions.

  • Access and setup order
  • General settings
  • People registration and bulk upload
  • Team hierarchy and membership
  • Job roles
  • Levels and salary bands
  • Skill dictionary
  • Project statuses and transitions
  • Permissions and data visibility
  • Holidays and working days

Before operating the app

Set working hours, salary policy, and reference data. Configure permissions, people, and teams. Check project statuses and holidays, then verify read and write scope using actual user accounts. See the administrator guide for installation and operational checks.
