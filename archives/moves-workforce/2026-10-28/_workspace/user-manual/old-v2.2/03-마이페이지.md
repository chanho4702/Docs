# 3. 마이페이지 — 내 현황과 팀장 업무 분석

## 🔐 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 (`/my-page`) | **권한 불필요** — 사이드바에 항상 표시됩니다 |
| 내 프로젝트·작업·워크로그·내 권한 | **권한 불필요** (본인 데이터) |
| 내 스킬 편집 | **권한 불필요** (본인 데이터) |
| **내 팀** 영역 | **팀장으로 등록**돼 있어야 합니다 (권한 키가 아니라 *팀장 관계*로 열립니다) |
| 팀원 스킬 편집 | 팀장 관계 (또는 `RESOURCE_MANAGEMENT` 쓰기) |

- **내 팀**은 권한 세트를 아무리 넓게 줘도 팀장이 아니면 나타나지 않습니다. 반대로 Member 세트여도 팀장이면 보입니다. 팀장 지정은 [7.3 팀 관리](./07-설정/03-팀-관리.md)에서 합니다.
- 팀장은 이 화면에서 **팀원 스킬만** 편집할 수 있습니다. 직무·등급·급여·권한은 관리자 소관입니다.

---

**언제 쓰나** — 기간을 정해 **내 업무 성과를 정리**하거나, 팀장이라면 **팀원 업무 현황을 확인**할 때 씁니다.

기본 기간은 이번 달이며 이번 주·최근 3개월·직접 지정으로 바꿀 수 있습니다.

## 3.1 내 현황

| 영역 | 내용 |
|---|---|
| **요약 KPI** | 처리율, 할당 작업, 진행/완료/남은 작업, 지연, 기간 투입(h/MD), 일평균 투입 |
| **나에게 할당된 프로젝트/작업** | 프로젝트를 선택하면 그 아래 작업·차트·워크로그가 모두 그 범위로 좁혀집니다. 작업은 내가 담당자 **또는 협업자**인 이슈입니다 |
| **기여 차트·워크로그** | 작업 상태 분포, 일별 투입 시간, 작업별 투입 TOP 8, 워크로그 목록과 작업별 합계, Excel 내보내기 |
| **내 권한·내 스킬** | 지금 적용 중인 권한 세트와 프로젝트 조회 범위를 확인하고, 본인의 보유 스킬을 직접 편집합니다 |

> **내 권한 영역이 유용한 순간:** "왜 이 화면이 안 보이지?" 싶을 때 여기서 내 권한 세트와 [조회 범위](./01-개요.md#14-권한의-기본-개념--세-가지만-기억하세요)를 먼저 확인하면 관리자에게 정확히 요청할 수 있습니다.

> **내 스킬**에 등록한 값은 [자원 관리](./06-자원-관리/README.md)의 인력 검색과 [프로젝트 배정 적합도](./06-자원-관리/04-프로젝트-배정.md) 계산에 쓰입니다. 선택지는 [스킬 관리](./07-설정/06-스킬-관리.md)에서 정의한 사전을 따릅니다.

## 3.2 내 팀 (팀장 전용)

팀장으로 등록된 사용자에게만 나타납니다. 자신이 이끄는 팀과 하위 팀을 선택해 다음을 확인합니다.

- 팀원별·팀 소계의 **가동률**, 투입 공수, 완수율
- 이슈 상태 분포, 참여 프로젝트

**규칙**

- 같은 이슈에 여러 팀원이 참여해도 **팀 이슈 건수는 한 번만** 셉니다.
- 팀장은 이 화면에서 **팀원 스킬만** 편집할 수 있습니다. 직무·등급·급여·권한은 관리자 소관입니다.

> 팀장 지정은 [7.3 팀 관리](./07-설정/03-팀-관리.md)에서 합니다. 이 영역이 보이지 않으면 팀장으로 등록돼 있는지 확인하세요.

## 3.3 팀 관련 화면이 세 개인 이유

| 화면 | 답하는 질문 | 범위 |
|---|---|---|
| **마이페이지 → 내 팀** | 내가 이끄는 조직의 업무 현황은? | 본인이 팀장인 팀과 하위 팀 |
| [**프로젝트 상세 → 팀 분석**](./05-프로젝트-상세/05-분석-및-리포트.md#553-팀-분석--담당-조직과-실제-기여가-일치하는가) | 이 프로젝트의 담당 조직과 실제 기여 조직이 일치하는가? | 현재 프로젝트 |
| [**자원 관리 → 팀 분석**](./06-자원-관리/03-팀-분석.md) | 여러 팀·프로젝트의 자원 지표와 계층 롤업은? | 서버가 허용한 전 팀 또는 리딩 팀 |
