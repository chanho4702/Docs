메뉴·화면 진입 「워크로그 추출」 읽기 (없으면 사이드바에 메뉴가 없습니다)
검색·Excel 다운로드 「워크로그 추출」 읽기
조회되는 범위 앱 권한이 아니라 본인의 Jira 권한을 따릅니다. Jira에서 볼 수 있는 이슈의 워크로그만 나옵니다
  • 이 화면은 앱 서버를 거치지 않고 내 계정으로 Jira에 직접 질의합니다. 그래서 앱의 프로젝트 조회 범위(소속 프로젝트만 등)와 무관하고, Jira에서 못 보는 이슈는 여기서도 안 보입니다.
  • 기존 설치 환경에서는 이 권한이 Admin 세트에만 켜져 있습니다. 다른 세트에 열려면 에서 「워크로그 추출」 읽기를 추가하세요.

언제 쓰나 — 앱 프로젝트에 편입됐는지와 무관하게 Jira 전체의 워크로그를 기간·프로젝트·작성자 기준으로 뽑아 정산·보고용 엑셀을 만들 때.

그림 9-1 워크로그 추출 화면

그림 9-1. 워크로그 추출 — ① 검색 조건(프로젝트·작성자·기간·추가 JQL) ② 진행 표시(이슈 검색 → 워크로그 수집, 취소) ③ 결과 요약 카드 ④ 미리보기 표 ⑤ Excel 다운로드.

91-검색-조건9.1 검색 조건

조건 필수 설명
프로젝트 Jira 프로젝트(스페이스). 여러 개 선택 가능. 선택하지 않으면 접근 가능한 모든 프로젝트
작성자 워크로그 작성자. 선택하지 않으면 전체
기간 필수 워크로그 작업 시작일 기준 시작일~종료일. 종료일은 시작일 이후여야 합니다
추가 JQL 위 조건과 AND로 결합됩니다 (예: issuetype = Bug)

조건 초기화로 모두 비웁니다. 기간이 1년을 넘으면 "결과가 많으면 시간이 오래 걸릴 수 있습니다" 경고가 뜹니다.

92-검색과-수집9.2 검색과 수집

  1. 검색을 누르면 두 단계로 진행됩니다.
    • "이슈를 검색하는 중… (N건 확인)" — 조건에 맞는 이슈를 찾습니다.
    • "워크로그를 가져오는 중… (done/total)" — 이슈별 워크로그를 여러 건 동시에 가져옵니다.
  2. 중간에 취소하면 "지금까지 수집한 결과만 표시합니다"로 멈춥니다. 부분 결과도 다운로드할 수 있습니다.
  3. 끝나면 "워크로그 N건을 수집했습니다" 알림과 함께 결과가 표시됩니다.

상한과 경고

안내 의미
결과가 상한(5,000건)에 도달해 일부 이슈만 수집했습니다 이슈 수 상한입니다. 기간이나 프로젝트를 좁혀 다시 검색하세요
N개 이슈의 워크로그를 가져오지 못했습니다 일부 실패. 나머지 결과만 표시합니다
Jira 요청 한도에 걸렸습니다 잠시 후 다시 시도하세요
JQL이 올바르지 않습니다 추가 JQL 문법을 확인하세요

93-결과-확인9.3 결과 확인

요약 카드: 이슈 수 · 워크로그 건수 · 총 시간 · 총 MD(1MD 기준 시간은 의 1Day 근무 시간) · 추출 조건(기간·프로젝트·작성자 수·추가 JQL·추출 시각)

미리보기 표 (상위 500건만 표시, 파일에는 전체 포함)

컬럼 설명
이슈키 / 요약 / 프로젝트키 워크로그가 달린 이슈
작성자 / 작성자 accountId 작성자 표시명과 Jira 계정 ID
시작일시 / 시작일 워크로그의 작업 시작 시각과 날짜
소요시간(초) / 소요시간(시간) 기록된 시간
코멘트 워크로그 본문(서식 제거한 텍스트)
워크로그ID Jira 워크로그 ID

컬럼 헤더로 정렬할 수 있고, 표의 정렬은 파일에 영향을 주지 않습니다.

94-excel-다운로드9.4 Excel 다운로드

Excel 다운로드를 누르면 .xlsx 파일이 내려받아집니다.

시트 내용
워크로그 수집한 워크로그 전체(미리보기 상한과 무관) — 위 컬럼 그대로
요약 추출 조건과 합계(이슈 수·건수·총 시간·총 MD)

파일명에는 기간이 들어갑니다. 파일 생성에 실패하면 "Excel 파일을 만들지 못했습니다"가 표시되니 다시 시도하세요.

알아두기알아두기

  • 프로젝트 상세의 인력 분석·비용 화면과 값이 다를 수 있습니다. 그 화면들은 앱 프로젝트에 편입된 이슈와 등록된 인력만 집계하지만, 여기는 Jira 전체가 대상입니다.
  • 다른 사람의 워크로그 코멘트도 내려받습니다. 파일을 공유할 때 내용을 확인하세요.
  • 특정 프로젝트의 인력별 투입만 필요하다면 의 엑셀 내보내기가 더 빠릅니다.

문제-해결문제 해결

증상 원인과 해결
사이드바에 메뉴가 없습니다 「워크로그 추출」 읽기 권한이 없습니다. 기존 설치에서는 Admin만 기본으로 켜져 있습니다
특정 프로젝트가 결과에 없습니다 Jira에서 그 프로젝트를 볼 권한(Browse Projects)이 없습니다
상한 경고가 계속 뜹니다 기간을 나누거나 프로젝트를 지정해 여러 번 추출하세요
검색이 매우 느립니다 이슈가 많은 조건입니다. 기간·프로젝트를 좁히거나, 진행 중 취소해 부분 결과를 먼저 받으세요
