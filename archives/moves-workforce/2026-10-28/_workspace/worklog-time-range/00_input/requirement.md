# 워크로그 시간 범위 입력

기존의 `1h`, `30m` 같은 Jira duration 문자열 직접 입력을 줄이고, 워크로그 등록과 수정에서 시작 시각과 종료 시각을 선택할 수 있게 한다.

- 동일한 날짜 안에서 시작·종료 시각으로 duration을 자동 계산해 Jira `timeSpentSeconds`로 저장한다.
- 기존 duration 입력 경로와 Jira의 저장 API 호환성을 깨지 않는다.
- 등록과 수정 화면에서 같은 동작을 제공한다.
- 종료 시각은 시작 시각보다 뒤여야 하며, 0분·음수 duration은 저장하지 않는다.
- 자정 넘김 처리, 휴게시간 자동 차감, 타임시트식 다중 구간은 이번 범위에서 제외한다.

후속 UI 조정(2026-09-02): 단일일 입력의 시작 시각과 종료 시각을 같은 한 줄에 배치한다. 시간 선택은 30분 고정 선택지에 제한되지 않고 분 단위로 정확히 지정할 수 있어야 한다.
