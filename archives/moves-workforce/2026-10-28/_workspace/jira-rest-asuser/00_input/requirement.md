# Jira REST helper asUser 기본 경로 감사 후속

기능 감사에서 확인된 P2 위험을 해결한다. Jira product REST helper가 기본적으로 `asUser()`를 사용하고, `asApp()`은 문서화된 플랫폼 예외와 직접 인가 검증이 있을 때만 사용되는지 조사·보완한다.

- Jira REST helper와 직접 호출 전체를 식별한다.
- 호출 주체·권한 근거·데이터 범위를 분류한다.
- 기본 경로의 asApp 우회 또는 누락된 인가를 최소 범위로 수정한다.
- 실제 사용자 권한 부족 시 기존 실패 계약을 보존한다.
