# MovesEye BE — 코드베이스 진단 & 개발 착수 함정 (2026-06-02)

> 개발 재투입 직전 `C:\solutions\moveseye-be`(브랜치 `develop`)를 직접 빌드·테스트하며 점검한 기록.
> 서비스 개요·구조는 [[moveseye-overview]], 실행 환경은 [[2026-06-01-runtime-environment]] 참고.

## 결론
**바로 개발 착수 가능한 안정 상태.** 빌드·테스트 깨끗함.

| 점검 | 결과 |
|---|---|
| `npm run build` | ✅ exit 0 |
| `npm test` | ✅ **22 suites / 222 tests 전부 PASS** (~29s) |
| node_modules / `.env` | ✅ 설치·채워짐(.env 약 37키) |

- 테스트 로그에 `[ZabbixService] Call ZABBIX API error`가 보여도 **에러 케이스 검증용 정상 출력**(실패 아님).
- 규모: **약 26,885 LOC / 258 ts 파일 / 88 라우트.** 큰 동네: `host` 7,381 · `user` 5,211 · `zabbix` 2,840.
- 패키지명은 `be-auth-service`지만 실제론 인증 포함 **통합 모니터링 백엔드**. 이름에 속지 말 것.

## 🚨 개발 착수 함정 (실전 1순위)
1. **`x-visitor-id` 헤더 필수** — `JwtAuthGuard`가 JWT + Redis세션 + `x-visitor-id`를 이중검증. 헤더 빠지면 인증 실패. Postman/FE 테스트 막힐 때 1순위 의심.
2. **글로벌 ValidationPipe 없음** — `main.ts`에 `useGlobalPipes` 미설정. 각 컨트롤러가 개별로 `@Query(new ValidationPipe({transform:true}))`를 붙인다. → **새 엔드포인트에서 빼먹으면 DTO 검증/형변환이 안 됨.** 기존 컨트롤러 패턴 복붙 필수.
3. **에러도 대부분 HTTP 200** — body의 status로 성공/실패 구분. `Unauthorized`/`Forbidden`만 실제 상태코드. FE 연동 시 핵심.
4. **레포 주입은 항상 named connection `'DB_DMOVE'`** — `@InjectRepository(E, 'DB_DMOVE')`. 빼먹으면 런타임 주입 에러.
5. **전역 설정 등록 위치가 흩어짐** — TransformInterceptor=`app.module`, ResponseInterceptor=`main.ts`, exceptions.filter=`common.module`(APP_FILTER), Swagger/static=`main.ts`. 새 전역설정 추가 시 헷갈리지 말 것.
6. **마이그레이션 이중 실행 가능성** — `database.module`의 `migrationsRun:true` + `main.ts`의 수동 `runMigrations()` 둘 다 존재. 이미 적용된 건 스킵되어 보통 무해하나 디버깅 시 기억.

## 🧹 정리 후보 (저위험 첫 PR감)
- **dead code**: `src/entities/host-group.entity.ts` — 참조처 0곳. 정본은 `src/database/models/`. 삭제 후보.
- **파일명 오타**: `src/zabbix/services/zabbox-trend.service.ts` (zabbi**x**→zab**box**). 리네임 후보.
- **기본 관리자 `admin / <마스킹>`** — `admin-user.service.ts:25`에 "프로덕션 전 제거" TODO. 배포 전 필수 제거.
- **거대 서비스** `host.service.ts`(2,017줄)·`user.service.ts`(1,414)·`event.service.ts`(1,190) — 수정 시 사이드이펙트 범위 넓음. 신규는 하위 `services/`로 분리 권장.
- **문서 드리프트**: 루트 `CLAUDE.md`의 일부 버전 표기가 `package.json`과 불일치(예: nodemailer 6.9.11→실제 8.0.10). 버전은 package.json이 정본.

## 향후 작업 (CLAUDE.md 기준)
- **자산관리 `/asset`** (Asset Host `/asset/hosts`) 구현 중 — 컨트롤러 아직 없음. 신규 모듈 스캐폴딩 대상.
- 맵뷰, 커스텀 대시보드, GPU 관리.

## 교훈 / 메모
- 잘 작성된 루트 `CLAUDE.md`가 정본 규약. 단, 버전·일부 디테일은 코드 실측이 우선.
- 워밍업 추천 동선: `docker-compose up -d` → `npm run start:dev` → Swagger `/api` 로그인 → `hosts` 호출로 Zabbix→BE→응답 흐름 한 번 끝까지 따라가기.
