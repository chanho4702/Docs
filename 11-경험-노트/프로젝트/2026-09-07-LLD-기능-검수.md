- 가장 중요한 결함은 lifetime enum 의미의 역전: Zabbix 7.0은 `0=기간 후, 1=하지 않음, 2=즉시`인데 FE 상수·DTO·계약·테스트가 1과 2를 반대로 해석한다. UI “삭제 안 함”이 즉시 삭제 값 2로 제출되는 것을 폼으로 재현했다.

- 비밀 매크로의 write-only value를 빈 문자열로 보완하면 “그대로 저장”이 비밀값 삭제 요청으로 변한다.
- HTTP headers 배열을 문자열 편집기에 넣으면 `[object Object]`로 제출된다.
- SNMP 아이템 프로토타입의 자동 인터페이스 선택이 Agent를 고르고, LLD 생성 폼에는 HTTP URL/SNMP OID 등 필수 필드가 없다.
- 생성 아이템 조회 예외를 빈 목록으로 바꿔 정상 0건과 조회 실패가 구별되지 않는다.
