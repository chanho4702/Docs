## 교훈 / 함정

- **매뉴얼이 두 벌이면 반드시 갈라진다.** 08-20 수정이 단일 파일에만 들어가 폴더판은 그 내용을 못 받았다. 생성 스크립트로 한 방향만 허용해야 한다.
- **"기능 있음"의 근거는 locales/kr가 가장 빠르다.** 화면 문자열이 그대로 있어 버튼 이름·안내 문구·제약(최대 10개, 100시간, 500건)을 코드보다 빨리 확정한다. 단, 낡은 문자열도 남는다(구독 description에 "보드"가 남아 있었지만 `SOURCE_TYPES`는 SPACE뿐) → **번역 파일은 후보, 확정은 코드**.
- **GitHub 앵커는 공백 하나당 하이픈 하나**: "5.3.7 간트 보기 — 일정 조정" → `537-간트-보기--일정-조정`(하이픈 2개). `\s+`로 합치면 검사기가 전부 깨진 걸로 오판한다. `④` 같은 원문자는 `\p{N}`이라 앵커에 남는다.
- **Git Bash heredoc + 한국어 대용량 본문**은 도구 계층에서 따옴표/백슬래시가 깨질 수 있다(`\\` → `\`). 긴 마크다운은 Write 도구로, 스크립트도 Write로.
- 기존 파일을 `cat`으로 읽은 것은 Write/Edit 도구의 "읽음" 판정에 안 잡힌다 → 전면 재작성은 `rm` 후 Write가 빠르다(백업은 `_workspace/user-manual/old-v2.2/`).

## Confluence 발행 (같은 날 추가)

- 매뉴얼은 `dmove-addons.atlassian.net` MW 스페이스 > "Moves Workforce 한글 가이드" > 사용자 가이드 폴더(171573307)에 **손으로 옮겨 적고** 있었다(8페이지, 스크린샷은 expand 안, 인용은 info 패널). Rovo 커넥터는 `dmove.atlassian.net`만 허용돼 API로 못 읽고, 브라우저로 구조만 확인.
- `_workspace/user-manual/publish-confluence.js`: 폴더판 md → 저장 형식(XHTML) → REST v2 로 생성/갱신, images/ PNG 첨부(v1 PUT), 페이지 ID 는 `pages.json`. `--dry-run` 은 토큰 없이 `out/*.html` 만 만든다. `--pull-attachments` 로 기존 스크린샷 회수.
- 함정: **marked 가 한글 href 를 퍼센트 인코딩** → decodeURIComponent 없이는 페이지 링크가 전부 평문으로 죽는다. 이미지+캡션은 한 `<p>` 안에 `\n` 으로 붙는다.
- 문체 정리 `tone-pass.js`: 이모지·"— 부제" 제목·인사이트/기억하세요류 94건 치환, 제목 80개 개명 + 앵커 53개 재작성. 사용자 지시 "AI 스러운 말투 제외".
