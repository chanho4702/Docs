# 2026-08-18 — 파이프라인 밖 코드 1,349줄 QA + 설정 통합 + CSRF 방어

> 사용자 지시로 **이 세션은 Codex 없이 Claude가 직접 구현**. 마지막 커밋 위에 8/14(배치 8d·8e)과
> **8/15(배치 8.5·헤더 진입점·버전 1.0.0)** 미커밋 변경이 24파일 +1,349줄 쌓여 있었고,
> 8/15분은 `_workspace`에 스펙·QA·구현 로그가 **하나도 없었다**.

## 교훈 1 — 하네스를 우회한 코드는 결함 밀도가 높다 (topics 급)

검증 기록 없는 1,349줄을 정독하니 **치명 1 + 높음 3**이 나왔다. 나중에 몰아서 치르게 될 뿐이다.

- **치명**: `out.append("\r\n")` — Java에서 이건 개행이 아니라 백슬래시 4문자 리터럴.
  CSV 전체가 한 줄로 나온다. 헤더 줄만 `"\r\n"`으로 정상이라 코드만 훑으면 눈에 안 띈다.
  **이스케이프 한 겹 차이는 단위 테스트로만 잡힌다** — 회귀 테스트 5건 추가.
- **높음(성능)**: 헤더 popover의 `load()`가 `init()`에서 무조건 실행 → **모든 Confluence 페이지 뷰마다**
  내 요청 전건 순회 + 건별 페이지 권한 조회. 배치 7의 N+1 해소와 정면 충돌.
  → 세션 캐시(2분) + 서버는 PENDING만 순회 + 결재 성공 시 캐시 무효화.
- **높음(데이터)**: 매크로 자동 key `macro:<macro-id>` 도입. 좋은 개선이지만 자동 key 이전의 요청은
  전부 `regionKey="default"`로 저장돼 있어 **기존 문서의 승인 이력이 통째로 끊긴다.**
  → 규칙을 "**첫 자동 영역은 default 유지, 두 번째부터 macro-id**"로 바꿔 호환 확보.
  **자동 식별자 도입은 언제나 기존 데이터의 키를 바꾸는 마이그레이션이다.**

## 교훈 2 — query 파라미터 REST + POST = CSRF 무방비

이 앱의 REST 관례는 "요청 body 없이 query/path 파라미터만". 편하지만,
공격자 페이지의 `<form method="POST" action="https://conf/rest/...?keys=...">` 하나로
로그인된 관리자의 설정 변경·결재 위조가 가능하다(폼 전송은 CORS 제약을 받지 않는다).

→ `ApprovalXsrfFilter`(servlet-filter 모듈, `/rest/approval/*`)로 POST·PUT·PATCH·DELETE에
`X-Atlassian-Token` 헤더를 강제. **커스텀 헤더는 simple request가 아니라 preflight를 거치므로
교차 출처에서 붙일 수 없다** — Atlassian 자체 관례와 같은 방어.
다행히 앱의 모든 클라이언트가 이미 헤더를 보내고 있어 무중단으로 켤 수 있었다.
**확인 순서가 중요**: 먼저 클라이언트 전수가 헤더를 보내는지 grep으로 확인하고 서버 강제를 켠다.

## 교훈 3 — "버튼만 숨기기"는 기능 차단이 아니다

스페이스별 사용 설정이 `canRequest = isSpaceEnabled && hasPermission(EDIT)`로만 구현돼 있었다.
요청 버튼은 사라지지만 상태 pill·배너·매크로 승인 틀은 그대로 렌더된다 — 사용자가 기대한 "적용 안 한
스페이스엔 안 보임"과 어긋난다. **차단은 렌더 진입점에서 끊어야 한다**(패널은 빈 문자열 반환,
매크로는 본문만 렌더). 반대로 정책을 끌 때 **진행 중 결재가 조용히 사라지는** 부작용이 생기므로
409 + 인라인 확인 단계를 뒀다(이 프로젝트는 브라우저 `confirm` 미사용이 관례).

## 설계 결정 (사용자)

- 전역 설정을 **한 화면 5탭**으로 통합: 전역 정책 / 적용 스페이스 / 승인 Flow / 승인 그룹 / 관리자.
  별도 `/approval-space-settings` 폐지, 업무함 사이드바에서 설정 제거, 진입은 헤더 popover 하나.
- **위임 관리자 = Confluence 관리자 동급**. 설정 계열 권한 13곳을 `canAdminister()`로 확장하되
  **결재 개입(타인 요청 회수)은 관리자 전용 유지**. 권한 확산 경로가 생기므로 관리자·적용 스페이스
  변경을 서버 로그에 남긴다 — 사용자가 명시적으로 택한 트레이드오프는 막지 말고 **추적 가능하게** 만든다.
