**Moves UCM(User & Contents Management)** = Dmove Inc.의 Jira/Confluence Cloud 애드온(Jira 5.4.0, Confluence 4.4.0). Marketplace 설치, 30일 무료 체험 후 사용자 수 기반 라이선스. 문의 sales@dmove.kr / support@dmove.kr.

핵심 목적 3가지:
1. 사용자/그룹 라이선스 관리 자동화 — 일괄 활성/비활성, 그룹 마이그레이션(4시간 주기 스케줄러), 엑셀 일괄 작업, 관리 로그
2. 사용 현황 대시보드 — 라이선스 사용률(80/90% 경고), 미접속 분포, Jira/Confluence 콘텐츠 통계, PDF 내보내기
3. 민감정보 보호 — 컨텐츠 필터(주민번호·카드번호·정규식 탐지, 차단 아닌 사후 로그, 1년 보관), 보안 컨텐츠(비밀번호 암호화 블록 최대 10,000자, 감사 로그 6종)

기타: 스케줄러(워크스페이스당 5개, 미접속 N일 초과 라이선스 자동 회수, 관리자 보호·예외 목록), 웹훅, Guard 프로비저닝 그룹은 관리 불가 → 독립 그룹으로 마이그레이션 절차.

타겟: 사이트 관리자·라이선스 비용 담당자·보안/컴플라이언스·Guard 도입 조직·인사.

원문 출처: 2026-08-25 세션(3320cfec) 사용자 붙여넣기, Confluence "(KR) Moves User & Contents Management 사용자 가이드" 정리본(2026-08-24). 그때 같은 구조로 만든 Workforce 소개는 `_workspace/moves-workforce-product-brief.md`.

**How to apply:** 행사·영업 자료에서 두 제품을 함께 소개할 때 참조. Workforce와 겹치는 영역 없음(UCM=관리자·보안, Workforce=PM·인력·원가). 관련: [[project-competitive-analysis]].
