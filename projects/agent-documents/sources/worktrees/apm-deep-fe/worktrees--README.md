# dmove-fe

### Build tools

Node.js 설치가 필요합니다.
yarn 명령어를 통해 종속성 설치 진행.
```
yarn install
```
### Getting started
1. .env 파일을 생성합니다.
   1. backend 서버까지 같이 확인 필요할 때 : .env.server 파일 사용
   2. backend 서버가 필요 없을 때 : .env.example 파일 사용


2. 아래 명령어를 통해 실행 합니다.
```
yarn dev
```
서버는 여기에서 열립니다. : http://localhost:5174

3. 수정 후, compile이 필요 하면 아래 명령어를 사용 해 주세요.
```
yarn build
```
