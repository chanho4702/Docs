관리자 초기 설정

사용자가 첫 승인을 끝까지 처리할 수 있도록 적용 범위와 기본 정책을 준비합니다. 모든 옵션을 한 번에 바꾸기보다 테스트 문서로 기본 흐름을 확인한 뒤 서명·위임·접근 제한을 적용하세요.

경로: Confluence 설정 → Moves Approval, 또는 승인 업무함 → 설정. Confluence 관리자와 앱의 설정 관리자가 사용할 수 있습니다.

설정 순서

순서 할 일 완료 확인
1 설치 확인 업무함·페이지 승인 창·설정이 열립니다.
2 적용 스페이스 승인할 문서가 포함되어 있습니다.
3 전역 정책 마감·알림·반려 사유 규칙이 조직 기준과 맞습니다.
4 결재선과 승인 그룹 요청자가 실제 문서에서 선택할 수 있습니다.
5 사용자와 관리자 요청자·승인자·운영 담당자의 접근이 확인됩니다.
6 첫 승인 시험 일반 사용자 계정으로 요청부터 최종 승인까지 확인합니다.
7 데이터 관리 기록 보관 기간과 정기 확인 담당자를 정합니다.

일반 계정으로 시험하기

관리자 계정에서 화면이 열린다는 것만으로 사용자 준비가 끝난 것은 아닙니다. 요청자는 편집 가능한 문서에서 요청하고, 승인자는 보기 가능한 문서의 자기 차례를 처리해야 합니다. 제한된 문서를 볼 수 없는 계정에는 해당 요청이 목록에 나타나지 않는지도 확인합니다.

PIN을 필수로 바꾸기 전에는 사용자에게 등록 방법을 안내합니다. 접근 제한을 켜기 전에는 요청자까지 명부에 포함했는지 확인합니다. 스페이스를 제외하기 전에는 진행 중 요청이 남았는지 확인합니다.

운영 시작 확인

  • 테스트 문서의 승인 순서·상태·버전·이력이 기대와 일치합니다.
  • 앱 내 알림과 선택적 댓글 알림의 차이를 사용자에게 안내했습니다.
  • 자주 쓰는 문서 템플릿에 결재란을 넣을지 결정했습니다.
  • 오류 문의와 보관 기록 정리를 담당할 사람을 정했습니다.
