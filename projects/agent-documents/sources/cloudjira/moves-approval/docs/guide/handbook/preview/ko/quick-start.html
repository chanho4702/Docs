빠른 시작 — 첫 문서 승인

이 안내에서는 테스트 문서를 두 사람이 차례로 승인합니다. 요청자가 문서를 올리고, 첫 승인자와 최종 승인자가 각각 결정한 뒤 문서에서 결과를 확인합니다. 처음 설치한 사이트는 관리자 초기 설정을 먼저 완료하세요.

준비할 것

준비 대상 이 안내의 예시 확인할 점
문서 제품 운영 절차 — 검토용 게시된 Confluence 페이지이며 요청자가 편집할 수 있어야 합니다.
요청자 작성자 A 문서 편집 권한과 앱 접근 권한이 필요합니다.
승인자 검토자 B, 책임자 C 두 사람 모두 문서를 볼 수 있어야 합니다.
승인 순서 1단계 B → 2단계 C 두 사람을 같은 단계에 넣지 않습니다.
마감 검토 가능한 미래 시각 예시 날짜를 그대로 쓰지 말고 실제 일정을 정합니다.

1. 요청자가 문서 승인 요청하기

  1. 게시된 테스트 문서를 열고 제목 아래 승인 요청을 누릅니다.
  2. 승인자 직접 선택에서 B를 첫 단계에 넣습니다. 단계 추가로 두 번째 단계를 만들고 C를 넣습니다.
  3. 단계 이름을 각각 내용 검토, 최종 승인으로 입력합니다. 각 단계의 필요한 승인 수가 1인지 확인합니다.
  4. 마감일과 요청 메모를 입력합니다. 예: 운영 절차와 담당자 정보를 검토해 주세요.
  5. 문서 안에 진행 상태를 보이려면 문서 맨 위에 결재란 추가를 선택하고 승인 요청을 누릅니다.
  6. 요청이 만들어진 뒤 승인 대상 버전과 1단계 진행 상태를 확인합니다. 결재란이 새로 들어갔다면 페이지 버전이 하나 올라갑니다.

2. 승인자가 차례대로 결정하기

  1. B가 Confluence 앱 → Moves Approval → 내 차례를 엽니다.
  2. 요청 행을 열고 문서 내용, 요청 메모와 승인 대상 버전을 확인한 뒤 승인합니다. PIN 필수 정책이 켜져 있다면 먼저 내 서명과 PIN을 설정합니다.
  3. 상세 화면에서 B의 결정이 기록되고 C의 단계가 열렸는지 확인합니다.
  4. C가 자신의 내 차례에서 같은 요청을 열어 검토하고 승인합니다. C는 첫 단계가 끝나기 전에 결정할 수 없습니다.

3. 요청자가 결과 확인하기

문서를 다시 열어 결재란과 제목 아래의 승인 상태를 확인합니다. 승인 상세에서 두 단계의 처리자·결정 시각을 확인하고, 필요한 경우 결재 증명서 PDF를 내려받습니다.

완료 확인 기대 결과
승인 순서 B가 처리한 뒤 C가 처리했습니다.
최종 상태 승인 완료입니다.
승인 버전 승인 대상 버전이 명시되어 있습니다.
결정 이력 두 사람의 결정과 시각이 남습니다.

승인 뒤 문서를 수정했다면 현재 버전까지 승인된 것은 아닙니다. 수정·회수·재상신을 확인하세요.

진행되지 않을 때

  • B가 요청을 찾지 못하면 내 차례 탭과 필터, 페이지 열람 권한을 확인합니다.
  • C에게 결정 버튼이 없으면 첫 단계가 완료됐는지 확인합니다.
  • 요청이 반려되거나 만료됐다면 종료된 요청을 되돌리지 않고 새 요청을 만듭니다.
  • 결재란이 없어도 요청은 만들어졌을 수 있습니다. 다시 요청하기 전에 승인 상세를 먼저 확인합니다.
