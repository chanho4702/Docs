승인 업무함

내가 처리할 요청, 내가 올린 요청과 참조 요청을 한곳에서 찾습니다. 요청 목록과 알림, 개인 서명·위임 설정으로 이동하는 출발점입니다.

경로: Confluence 앱 → Moves Approval.

화면 읽기

탭 표시 대상 다음 행동
내 차례 지금 내가 또는 나에게 위임한 사람이 결정할 요청 상세를 열어 검토하고 결정합니다.
진행 중 내가 결재선에 있으나 앞 단계를 기다리는 요청 현재 단계와 마감을 확인합니다.
내 요청 내가 만든 요청 진행 상황, 반려 사유와 재요청 필요 여부를 확인합니다.
처리한 건 내가 이미 결정한 요청 내 결정과 현재 전체 상태를 구분해 확인합니다.
참조 내가 참조자로 지정된 요청 진행을 열람합니다. 참조 역할만으로 결정할 수 없습니다.

MA-05 · 2026-10-26 스테이징 최신 배포본의 승인 업무함. 문서 열람 권한이 있는 요청만 목록에 표시됩니다.

원하는 요청 찾기

  1. 목적에 맞는 탭을 선택합니다. 처리할 일이면 내 차례, 내가 올린 문서이면 내 요청입니다.
  2. 문서 제목·스페이스·요청자와 기간 조건으로 목록을 좁힙니다. 마감이 급하면 마감 임박 조건을 사용합니다.
  3. 문서 이름을 누르면 원래 Confluence 페이지가 열립니다. 행의 다른 부분을 누르면 승인 상세가 열립니다.
  4. 아직 불러오지 않은 항목은 더 보기로 이어서 확인합니다. 찾지 못하면 필터를 해제한 뒤 원래 페이지의 열람 권한도 확인합니다.

버튼과 표시

항목 동작 확인할 점
상태·기간·마감 필터 현재 목록의 조회 조건 변경 조건이 남아 있으면 요청이 숨겨질 수 있습니다.
마감 배지 마감 3일 전부터 남은 일수, 오늘 마감, 기한 초과 표시 기한 초과 요청은 결정할 수 없습니다.
열 경계 끌기 표의 열 너비 조정 두 번 누르면 기본 너비로 돌아갑니다.
엑셀로 내보내기 현재 탭·필터에 맞는 조회 가능한 요청 최대 5,000건 화면에 아직 로드되지 않은 요청도 포함될 수 있습니다.
알림·내 서명·내 위임 해당 개인 기능으로 이동 설정은 앱 관리 권한이 있는 사람만 사용합니다.

목록과 내보내기 확인

Excel은 요청 목록이며 개별 결정·감사 이력 전체의 백업이 아닙니다. 종료 요청의 상세 증빙은 증명서, 보관 기간이 지난 기록 정리는 데이터 관리를 사용합니다.

목록은 볼 수 있는 페이지만 보여 줍니다. 탭 건수와 실제 표시 건수가 다르면 필터와 페이지 권한을 먼저 확인하세요. 내 이름이 결재선에 있어도 앞 단계가 끝나지 않았으면 결정할 수 없습니다.
