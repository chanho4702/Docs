# My signature and PIN

[Guide home](cloudjira--index.md) · [한국어](../ko/cloudjira--signature-pin.md)

Your signature controls the stamp shown beside decisions. A PIN confirms approvals and rejections when site policy requires it. Registering a signature image and registering a PIN are separate actions.

**Location:** Approval inbox → **My signature**.

## Register a signature

1. Check the current stamp. Without a registered image, the app uses a name-based stamp.
2. Draw a signature or upload a PNG/JPEG file. The original must be at most 2 MB and is resized to fit within 480×160.
3. Check the preview before saving. Stamps appear at 32 px high in the table, so a wide signature works well.
4. Confirm the current stamp changed. If administrators disable signature display, the saved image is not shown in decision views.

![Signature drawing and upload controls, automatic-name preview, and unset PIN fields](../assets/ma-08-signature-pin.jpg)

*MA-08 · Signature and PIN are managed separately. The screen never displays the saved PIN value.*

## Register or change a PIN

| Field or action | Use | Result to check |
| --- | --- | --- |
| New PIN / confirmation | Enter the same 4–12 digits | Registered status appears. |
| Current PIN | Required to change or remove an existing PIN | Entering a new value alone does not replace it. |
| Remove PIN | Verify the current PIN before removing it | Under mandatory policy, register again before deciding. |

Five failed attempts lock the PIN for 15 minutes. Wait for the lock to expire rather than trying more values. The app has no administrator PIN reset feature. If you forget your PIN, ask your site administrator and support for guidance.

## Completion check

Check the current stamp and PIN status separately. Uploading a signature does not register a PIN. See [approving and rejecting](cloudjira--decisions.md) and [stamp boxes](cloudjira--stamp-box.md) for their use.
