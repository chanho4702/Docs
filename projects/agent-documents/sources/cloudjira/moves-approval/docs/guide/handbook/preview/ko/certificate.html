결재 증명서 PDF

종료된 요청의 대상 버전, 결재선과 결정 이력을 PDF로 보관합니다. 문서 열람 권한이 있는 사용자가 받을 수 있으며, 진행 중 요청에는 발급 버튼이 없습니다.

내려받기

  1. 페이지 또는 업무함에서 종료된 요청의 승인 상세를 엽니다.
  2. 상세에 현재 표시된 요청의 상태·요청 ID·대상 버전을 확인합니다. 버전별 승인 이력을 펼쳐도 PDF 대상이 이전 요청으로 바뀌지는 않습니다.
  3. 제목 옆 결재 증명서 PDF를 누릅니다.
  4. 내려받은 파일을 열어 문서명·요청 ID·버전·결정·발급 시각을 확인합니다.

PDF에서 확인할 내용

내용 읽는 방법
문서·요청 정보 페이지와 요청을 식별하고 요청자·시각·메모를 확인합니다.
대상 버전과 현재 버전 승인 대상이 현재 문서와 같은지 확인합니다.
결재란과 이력 단계별 결정자·결정 시각·대리 처리·사유를 확인합니다.
문서 지문 승인 대상 버전 본문에서 계산한 SHA-256 값입니다. 영역 승인도 페이지 전체 본문을 기준으로 합니다.
발급 정보 발급자·발급 시각·요청 ID를 확인합니다.

알아 둘 제한

대상 버전 본문을 읽을 수 없으면 지문 없이 발급됩니다. 지문이 없다는 사실을 오류 없이 발급됐다는 이유로 놓치지 마세요. PDF 본문은 이미지로 들어가 검색·복사가 제한되며, 요청 ID와 지문은 각 쪽 아래와 문서 속성에 텍스트로 포함됩니다.

지문은 문서 식별을 돕는 값입니다. 증명서만으로 별도 보안 인증이나 법적 전자서명 효력을 주장하지 않습니다. 내려받은 파일에는 이름과 사유가 포함되므로 조직의 기록 보관 위치에 저장합니다.

문제 해결

버튼이 없으면 요청이 종료됐는지와 페이지 권한을 확인합니다. 파일 생성이 실패하면 다시 시도하고, 계속되면 요청 ID·발생 시각·오류 문구를 지원 요청에 포함하세요.
