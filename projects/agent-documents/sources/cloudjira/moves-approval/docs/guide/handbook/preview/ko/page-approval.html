페이지 승인 요청

게시된 페이지 전체를 승인받을 때 사용합니다. 검토 순서를 정하고 마감·참조·메모를 붙여 요청합니다. 일부 내용만 승인받으려면 영역 승인을 사용하세요.

경로: 게시된 페이지 → 제목 아래 승인 요청. 페이지의 ••• 메뉴에서도 열 수 있습니다.

요청 전 확인

페이지를 편집할 수 있어야 하며, 앱의 적용 스페이스와 사용자 접근 정책을 충족해야 합니다. 승인자는 해당 페이지를 볼 수 있어야 합니다(기본 정책). 같은 대상에 진행 중인 요청이 있으면 먼저 기존 요청 처리를 확인하세요.

두 단계로 요청하기

  1. 요청 창에서 승인자 직접 선택을 선택합니다. 이름 또는 계정으로 첫 승인자를 찾아 추가합니다.
  2. 다음 사람이 앞사람의 결정 뒤에 검토해야 한다면 단계 추가를 누릅니다. 같은 단계에 사람을 추가하는 것과 구분하세요.
  3. 단계 이름과 단계 통과에 필요한 승인 수를 확인합니다. 예를 들어 한 단계에 세 명을 넣고 필요한 수를 2로 정하면 두 명의 승인이 필요합니다.
  4. 위로·아래로로 단계 순서를 정합니다. 승인 그룹을 쓰는 단계에는 다른 사용자나 그룹을 섞을 수 없습니다.
  5. 마감·참조·메모와 결재란 옵션을 확인한 뒤 승인 요청을 누릅니다.
  6. 생성된 요청의 단계, 승인 대상 버전과 마감이 입력한 내용과 같은지 확인합니다.

관리자가 결재선을 마련했다면 결재선 사용에서 고릅니다. 선택한 결재선의 승인자와 단계, 기본 마감일을 확인한 뒤 제출하세요.

입력 항목과 처리 결과

항목 입력·사용 방법 확인할 결과
승인자 검색·상세 검색 이름·계정으로 검색하거나 상세 검색에서 여러 명 선택 동명이인은 계정을 확인합니다.
단계 추가·순서 앞 단계가 완료된 뒤 다음 단계가 열림 서로 다른 검토 차례는 별도 단계입니다.
필요한 승인 수 해당 단계가 통과할 인원 수 단계 인원보다 클 수 없습니다.
단계 이름 법무 검토처럼 검토 목적 입력 진행 상태에서 단계 이름을 식별할 수 있습니다.
마감일 날짜·시각 입력. 비우면 마감 없음 정책·결재선 기본값을 그대로 쓸지 확인합니다.
참조 사용자·그룹 선택 알림·열람 대상이며 결정 권한이 생기지 않습니다.
요청 메모 선택, 최대 500자 승인자가 무엇을 검토해야 하는지 적습니다.
문서 맨 위에 결재란 추가 페이지에 결재란이 없으면 자동 삽입 삽입되면 오른 페이지 버전이 승인 대상입니다.

제출 뒤 확인

진행 중 요청은 한 대상에 하나만 생깁니다. 결재란 삽입에 실패해도 요청은 진행될 수 있으므로 요청을 중복 제출하지 않습니다. 결재란이 필요하면 직접 삽입 방법을 따르세요.

문제 해결

증상 확인 순서
승인자가 검색되지 않음 검색어·계정 상태 → 승인자 명부 → 그룹 설정
페이지를 볼 수 없는 승인자라는 오류 해당 사용자로 문서 접근 가능 여부 → 스페이스·페이지 제한
결재선이 없음 결재선 사용 여부 → 결재선의 적용 스페이스
이미 진행 중이라는 안내 기존 요청의 상태·마감 → 회수 또는 새 버전으로 다시 상신

승인 요청이 만들어져도 아직 문서가 승인된 것은 아닙니다. 결과는 승인 업무함과 문서의 결재란에서 확인합니다.
