전역 정책과 상태 표시명

사이트의 요청 기본값, 알림과 결정 확인 규칙을 정합니다. 마감 같은 요청 기본값을 스페이스별로 정하려면 스페이스 정책을 사용합니다. 현재 PIN·위임·서명 동작은 전역 정책을 기준으로 합니다.

경로: 설정 → 전역 정책.

정책 바꾸기

  1. 승인 상태 흐름에서 상태를 선택합니다. 오른쪽에는 선택한 상태의 의미와 표시명, 관련 정책이 나타납니다.
  2. **진행 중(PENDING)**에서 기본 마감·마감 임박 기준과 앱 내 알림·Confluence 알림·독촉 주기를 설정합니다. **반려(REJECTED)**에서 반려 사유 필수 여부를 설정합니다.
  3. 화면 아래의 결재 진행에서 PIN·서명 표시·위임·결재란 자동 추가를, 접근과 권한에서 등록 사용자 제한·승인자 페이지 접근 확인을 설정합니다. 예를 들어 PIN을 필수로 바꾸기 전에 사용자가 PIN을 등록할 수 있도록 안내합니다.
  4. 모든 변경을 확인하고 화면 아래의 정책 저장을 누릅니다. 저장 안내를 확인한 뒤 다시 열어 값이 유지되는지 확인합니다.
  5. 새 요청을 열어 기본 마감과 결재란 옵션을 확인합니다. 기존 요청의 마감이나 결재선까지 바뀌었다고 가정하지 않습니다.

상태 노드를 선택하거나 위치를 움직이는 것만으로 정책이 저장되지는 않습니다. 변경한 입력값과 토글은 정책 저장으로 함께 저장합니다.

요청과 결정

항목 기본값 사용과 영향
기본 마감일수 7일 새 요청 폼의 기본값. 0이면 마감 없이 시작하며 요청자가 건별로 바꿀 수 있습니다.
반려 사유 필수 켬 반려 확정에 사유 입력이 필요합니다.
요청 시 승인자의 페이지 접근 권한 확인 켬 요청 생성 시 접근 불가능한 승인자가 있으면 거절합니다.
결재란 자동 추가 켬 페이지 요청의 자동 삽입 옵션 기본값입니다.
서명·도장 표시 켬 결정과 결재란의 표시 방식을 정합니다.
서명 PIN 요구 끔 켜면 결정 전에 사용자가 PIN을 등록해야 합니다.
결재 위임 허용 끔 꺼져 있으면 등록된 위임도 동작하지 않습니다.

알림과 접근

항목 기본값 사용과 영향
앱 내 알림 켬 업무함 알림 생성 여부입니다.
Confluence 알림 켬 대상 페이지에 @멘션 댓글을 남깁니다.
마감 임박 기준 24시간 하루 한 번 점검하므로 더 짧게 정해도 최대 하루 전에 알릴 수 있습니다.
독촉 끔, 첫 3일·반복 3일 지금 차례인 승인자에게 앱 내 알림으로 알립니다.
등록된 사용자만 앱 사용 끔 명부·관리자 등록을 완료한 뒤 켭니다. 사이트 전체에 적용됩니다.

상태 표시명

흐름도에서 상태를 선택한 뒤 오른쪽 상태 코드 표시명 입력칸에 조직 용어를 입력합니다. 저장 전에는 흐름도와 오른쪽 제목에 새 이름이 미리 보입니다. 비워 두면 사용자 언어별 기본 이름을 사용하고, 입력한 조직 이름은 자동 번역되지 않습니다. 표시명은 상태당 80자까지 입력할 수 있습니다.

승인 완료(APPROVED)·만료(EXPIRED)·**회수(CANCELLED)**는 종료 상태이므로 이 화면에서는 표시명만 편집할 수 있습니다. 이름을 바꿔도 승인·반려·회수의 처리 규칙은 바뀌지 않습니다. 검토 단계 이름은 결재선에서 정합니다.

저장 결과는 변경 이력에서 확인할 수 있습니다. 특정 스페이스만 값이 다르면 전역 저장을 반복하기 전에 해당 스페이스의 재정의 값을 확인하세요.
