# 한국어 가이드

[한국어 가이드](cloudjira--00-index.md) · [English](../en/cloudjira--00-index.md)

Moves Approval은 Confluence Cloud 페이지와 페이지 안의 특정 영역에 **단계별 승인**을 요청하고, 승인·반려·만료·회수의 전 과정을 기록하는 앱입니다. 결재 상태는 문서 안의 **결재란**(단계·결재자·도장)으로 보여 주고, 끝난 결재는 **결재 증명서 PDF**로 내려받을 수 있습니다.

## 5분 만에 시작하기

1. **사이트 관리자** — Atlassian Marketplace에서 Moves Approval을 설치합니다. → [설치와 첫 설정](cloudjira--02-installation.md)
2. **관리자** — Confluence 설정의 **Moves Approval** 화면에서 전역 정책과 적용 스페이스를 확인합니다. → [관리자 가이드](cloudjira--06-admin-guide.md)
3. **요청자** — 페이지 제목 아래의 **승인 요청** 항목을 눌러 승인자를 순서대로 고르고 요청합니다. 기본으로 문서 맨 위에 결재란이 함께 들어갑니다. → [요청자 가이드](cloudjira--03-requester-guide.md)
4. **승인자** — 상단 **앱** 메뉴의 **Moves Approval**(승인 업무함) → **내 차례** 탭에서 승인 또는 반려합니다. → [승인자 가이드](cloudjira--04-approver-guide.md)
