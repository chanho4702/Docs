# 요청자 가이드

[한국어 가이드](cloudjira--00-index.md) · [English](../en/cloudjira--03-requester-guide.md)

> 대상: 자기 문서를 승인받아야 하는 사람(페이지 편집자)

## 요청하려면 필요한 것

- 대상 페이지의 **편집 권한**
- 페이지가 **적용 스페이스**에 있을 것(관리자가 일부 스페이스만 켠 경우)
- 관리자가 "등록된 사용자만 앱 사용"을 켰다면, 승인자 명부나 설정 관리자에 등록되어 있을 것
- 승인자 모두가 대상 페이지를 **볼 수 있을 것**(관리자 정책 기본값)

## 페이지 승인 요청하기

1. 승인받을 페이지를 **게시된 상태**로 엽니다.
2. 제목 아래의 **승인 요청** 항목을 누릅니다. `•••` 메뉴의 **승인 요청**으로도 열 수 있습니다.
3. **페이지 승인 요청** 창에서 결재선을 정합니다. 두 가지 방법이 있습니다.
   - **승인자 직접 선택** — 이름 또는 계정으로 검색해 승인자를 추가합니다. 많은 사람을 한꺼번에 고르려면 **상세 검색**을 씁니다. **승인자 검색 범위**를 **그룹**으로 바꾸면 승인 그룹을 한 단계로 넣을 수 있습니다.
   - **결재선 사용** — 관리자가 등록한 결재선을 고르면 단계와 승인자가 자동으로 채워집니다.
4. 단계를 다듬습니다(직접 선택한 경우).
   - **단계 추가**로 단계를 늘리고, **위로**/**아래로**로 순서를 바꿉니다.
   - **단계 이름**(선택)을 쓰면 진행 중 상태가 "법무 검토 중"처럼 보입니다.
   - **단계 통과에 필요한 승인 수**로 "3명 중 2명 승인" 같은 조건을 정합니다.
   - 그룹은 한 단계를 혼자 차지합니다. 같은 단계에 다른 사용자나 그룹을 함께 넣을 수 없습니다.
5. 선택 항목을 채웁니다.
   - **마감일** — 정책 기본값(예: 요청 후 7일)이 미리 채워집니다. 비우면 마감 없이 진행합니다. 시각(시:분)까지 지정할 수 있습니다.
   - **참조** — 결정 권한 없이 열람과 알림만 받을 사용자나 그룹. 그룹은 저장할 때 구성원으로 펼쳐집니다.
   - **요청 메모** — 승인자에게 전할 내용(최대 500자).
   - **문서 맨 위에 결재란 추가** — 요청과 함께 결재란 매크로를 넣습니다. 관리자 정책에 따라 미리 체크되어 있으며(기본 켬), 이번 요청에서만 끌 수 있습니다. 아래 [결재란 자동 추가](#결재란-자동-추가)를 보세요.
6. **승인 요청**을 누릅니다.

요청이 만들어지면 결재선의 승인자와 참조자에게 앱 내 알림이 가고(Confluence 알림이 켜져 있으면 1단계 승인자는 페이지 댓글로 @멘션됩니다), 페이지 제목 아래가 `⏳ 승인 대기 · 1/N단계 진행 중`으로 바뀝니다.

### 결재란 자동 추가

**문서 맨 위에 결재란 추가**를 체크한 채 요청하면 문서 맨 위에 **Moves 결재란** 매크로가 들어가, 문서를 여는 사람 누구나 단계·결재자·도장을 바로 봅니다.

- **페이지 버전이 하나 오릅니다.** 요청자 본인의 권한으로 수정하므로 페이지 기록에 요청자 이름으로, 버전 메시지 "Moves Approval"과 함께 남습니다. 결재는 이 오른 버전을 기준으로 걸리므로 곧바로 "요청 이후 페이지가 수정되었습니다"가 뜨지 않습니다.
- 문서에 이미 결재란이 있으면 다시 넣지 않습니다(버전도 오르지 않습니다).
- 결재란을 넣지 못해도(편집 권한이 없어졌거나, 그 사이 다른 사람이 페이지를 저장한 경우 등) **요청은 결재란 없이 그대로 진행됩니다.** 필요하면 아래처럼 직접 넣으세요.
- 영역 승인 요청에는 이 항목이 없습니다. 영역 승인 상자에는 결재란이 함께 붙습니다.

### 결재란 직접 넣기·템플릿

결재란은 언제든 직접 넣을 수 있습니다.

1. 페이지를 편집하고 `/` 명령이나 **+** 메뉴에서 **Moves 결재란**을 삽입한 뒤 게시합니다. 위치는 자유입니다.
2. 아직 요청이 없으면 결재란에 "아직 결재 요청이 없습니다."와 **승인 요청** 버튼(페이지 편집 권한이 있을 때)이 보입니다. 여기서 바로 요청할 수 있습니다.
3. 결재가 필요한 문서 양식이라면 **페이지 템플릿에 결재란을 미리 넣어 두세요.** 템플릿으로 만든 문서에는 이미 결재란이 있으므로, 요청할 때 결재란을 새로 넣지 않고 버전도 오르지 않습니다.

결재란 읽는 법은 [참조자·열람자 가이드 — 문서의 결재란 읽기](cloudjira--05-cc-and-viewer-guide.md#문서의-결재란-읽기)에 있습니다.

## 영역(일부 내용) 승인 요청하기

문서의 일부만 승인받아야 할 때는 **Moves Approval Region** 매크로를 씁니다.

1. 페이지를 편집하고 `/` 명령이나 **+** 메뉴에서 **Moves Approval Region**을 삽입합니다.
2. 승인받을 내용을 매크로 **안에** 넣거나 옮깁니다.
3. **페이지를 게시합니다.** 처음 삽입한 영역에는 "이 영역은 한 번 편집·저장해야 결재를 걸 수 있습니다"가 보일 수 있습니다. 매크로를 한 번 편집해 저장하면 영역 식별자가 기록됩니다.
4. 게시된 페이지에서 해당 영역의 **영역 승인 요청**을 열고, 페이지 승인과 같은 방법으로 결재선을 정해 요청합니다.

알아 둘 점:

- 영역마다 별도의 요청과 상태를 가집니다. 한 페이지에 여러 영역을 둘 수 있습니다.
- 영역 내용이 바뀌면 영역에 **내용 변경됨** 표시가 나타나지만 요청은 그대로 진행됩니다.
- 매크로를 **삭제**하면 그 영역의 진행 중 요청은 자동으로 **회수**됩니다.
- 매크로를 복사해 붙이면 식별자가 겹칠 수 있습니다. "같은 페이지에 중복된 영역 식별자가 있어 결재를 사용할 수 없습니다"가 보이면 뒤쪽 매크로를 지우고 새로 삽입하세요.
- 승인 창은 영역의 글을 미리 보여 줍니다. 이미지·첨부·다른 매크로는 미리보기에서 생략되므로 페이지에서 직접 확인하세요.
- 요청하면 영역 승인 상자 아래 칸에 그 영역의 결재란이 붙습니다. **결재란 접기**/**결재란 보기**로 접고 펼칩니다(기본 펼침).

## 진행 상황 확인하기

- **페이지에서** — 문서에 결재란이 있으면 결정이 나는 대로 도장이 찍힙니다. 제목 아래 항목이나 결재란의 **결재 상세 열기**를 누르면 **승인 진행** 스텝퍼, **승인 순서와 결정** 표(누가 언제 결정했는지, 서명 도장), **감사 타임라인**이 보입니다.
- **업무함에서** — 승인 업무함의 **내 요청** 탭에 내가 만든 모든 요청이 있습니다. 문서 이름을 누르면 그 문서로 이동하고(Ctrl/Cmd/Shift 클릭이나 가운데 클릭은 새 탭), 행의 다른 곳을 누르면 승인 창이 열립니다.
- **마감** — 마감 3일 전부터 승인 창과 업무함의 마감 열에 `D-3`·`오늘 마감` 같은 배지가 붙고, 마감이 지나면 `기한 초과`로 바뀝니다.
- 앱 내 알림으로 최종 승인, 반려, 만료 소식을 받습니다.

## 요청 회수하기

진행 중인 요청을 취소하려면 승인 창에서 **요청 회수**를 누르고, 필요하면 **회수 사유**(최대 200자)를 남깁니다.

- 요청자 본인과 Confluence 관리자만 회수할 수 있습니다.
- 회수하면 지금까지 모인 결정이 모두 무효가 되며 **되돌릴 수 없습니다.**

## 요청 이후 페이지를 고쳤다면

편집은 요청을 멈추지 않습니다. 대신 승인 창에 **요청 이후 페이지가 수정되었습니다**(예: v5 기준 요청, 현재 v7)와 **v5 → v7 변경 보기** 링크가 나타납니다.

- 고친 내용까지 승인받아야 하면 **새 버전으로 다시 상신**을 누릅니다. 이전 요청은 종료되고, 현재 버전으로 새 요청이 시작됩니다. 결재선은 그대로 가져오지만 **마감일·참조·요청 메모는 새로 확인**하세요.
- 새 버전으로 다시 상신하려면 현재 대상 페이지의 편집 권한이 필요합니다. 원 요청자라도 편집 권한을 잃었다면 페이지 관리자에게 권한을 확인하세요.
- 이전 요청에서 받은 결정과 이력은 **버전별 승인 이력**에 그대로 남습니다.

## 승인 완료 후 페이지를 고쳤다면

승인은 승인한 **버전**에 대한 기록입니다. 승인 뒤에 페이지를 고치면 승인 창에 "v5 기준 승인 · 현재 버전 미승인"이 표시됩니다. 현재 버전도 승인받아야 하면 새 요청을 만드세요. 이전 결재선을 재사용하도록 미리 채워집니다.

## 반려·만료되었다면

- **반려됨** — 승인 창과 알림에서 반려 사유를 확인하고, 문서를 고친 뒤 새 요청을 만드세요.
- **기한 초과** — 마감이 지났지만 아직 만료 처리되기 전입니다. 앱은 하루 한 번 마감이 지난 요청을 만료시키므로 최대 하루 동안 이렇게 보입니다(제목 아래 항목은 `⌛ 기한 초과`). 이때부터 승인자는 더 이상 승인·반려할 수 없습니다.
- **만료됨** — 마감 기한이 지나 종료되었습니다. 여전히 필요하면 새 요청을 만드세요.
- **마감이 지난 문서에 다시 요청하기** — 다시 요청하면 마감이 지난 이전 요청은 자동으로 만료되고 새 요청이 걸립니다. 마감이 지나면 만료 처리 전이라도 승인 창에 **승인 요청** 버튼이 나타납니다. 페이지를 고쳤다면 **새 버전으로 다시 상신**을 써도 됩니다.

## 자주 만나는 메시지

| 메시지 | 해결 |
| --- | --- |
| 이미 진행 중인 승인 요청이 있습니다 | 한 대상에는 요청이 하나만 열립니다. 기존 요청을 확인하거나 회수한 뒤 다시 요청하세요. |
| 이 페이지를 볼 수 없는 사용자가 결재선에 있습니다 | 해당 승인자를 빼거나, 그 사람에게 페이지·스페이스 보기 권한을 준 뒤 다시 요청하세요. |
| 등록된 승인자만 결재선에 넣을 수 있습니다 | 관리자가 승인자 명부를 운영 중입니다. 명부에 있는 사람을 고르거나 관리자에게 등록을 요청하세요. |
| 이 스페이스에서는 승인을 사용할 수 없습니다 | 관리자에게 적용 스페이스 추가를 요청하세요. |
| 결재선 구성이 올바르지 않습니다 | 비어 있는 단계가 없는지, 필요한 승인 수가 단계 인원보다 많지 않은지 확인하세요. |

더 많은 문제는 [FAQ와 문제 해결](cloudjira--07-faq-troubleshooting.md)을 보세요.
