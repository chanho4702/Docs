English Guide

English Guide · 한국어

Moves Approval lets you request step-by-step approval for Confluence Cloud pages, or for specific areas inside a page, and records every approval, rejection, expiry, and withdrawal. Approval status appears in the page itself as a stamp box (steps, approvers, and stamps), and finished approvals can be downloaded as an approval certificate PDF.

Get started in five minutes

  1. Site administrator — Install Moves Approval from the Atlassian Marketplace. → Installation and first-time setup
  2. Administrator — Open Moves Approval in Confluence settings and review the global policy and enabled spaces. → Administrator guide
  3. Requester — Select Request approval below a page title, choose approvers in order, and submit. By default, a stamp box is added to the top of the page as well. → Requester guide
  4. Approver — Open Apps → Moves Approval (the approval inbox) → My turn, then approve or reject. → Approver guide
