## 이번 원고 보완

- 각 페이지에 언어별 목차·대응 언어·관련 문서 링크를 연결했습니다.
- 홈을 제품 소개 → 언어별 가이드 → 첫 승인 → 심사 → 보안·지원 순서로 다시 작성했습니다.
- 종료된 요청은 회수할 수 없다는 점, 재상신에 현재 편집 권한이 필요하다는 점을 교정했습니다.
- 업무함 Excel이 현재 탭·필터의 최대 5,000건을 조회하며 감사 이력 전체 백업은 아니라는 점을 명시했습니다.
- 앱에 관리자 PIN 초기화 기능이 없으며 지원 초기화를 보장할 수 없다는 점을 교정했습니다.
- 이미지 위치는 모두 실제 캡처가 필요한 상태로 표시했습니다. 이미지 설명을 실제 첨부로 집계하지 않습니다.

## 게시 순서와 확인

1. 로그인된 MW·MA를 읽고 사용자 추가 내용·첨부가 있는지 확인합니다. 현재 본문을 보존한 뒤 업데이트할 범위를 정합니다.
2. 기존 ID를 유지하여 언어별 상세 페이지를 해당 언어 가이드 아래로 이동합니다. 제목·부모·본문을 함께 확인합니다.
3. 실제 제품 화면을 이미지 계획에 맞춰 캡처하고 첨부합니다. 캡처할 수 없는 항목은 위치 표시 상태를 유지합니다.
4. 상세 문서 → 언어별 목차 → 홈 순서로 게시합니다. 기존 이미지가 있는 페이지를 body HTML로 통째로 덮어쓰지 않습니다.
5. 한국어 중복 소개(204505109)는 내용을 비교한 후 대표 소개 문서로 연결합니다. 기존 초안 `p`(204537917)와 제목 없음 초안은 이번 작업에서 만든 실패 초안인지 확인한 후 정리합니다.
6. 게시된 페이지를 다시 열어 제목, 부모 위치, 본문, 한·영 연결, 이미지 표시를 확인합니다. 익명 접근 가능 여부도 별도로 확인합니다.
7. 실제 게시를 확인한 항목만 page-map.json과 image-plan.json의 상태를 갱신합니다. Marketplace 제출·심사 통과·법적 정책 확정은 문서 게시와 구분합니다.

## 원고 재생성

저장소 루트에서 `python docs/guide/prepare-confluence.py`, `node docs/guide/render-confluence.cjs` 순서로 실행합니다. renderer는 현재 설치된 markdown-it을 사용합니다. 원본은 `docs/guide/ko`와 `docs/guide/en`입니다. 재생성은 이 폴더의 원고를 덮어쓰므로 실제 첨부·게시 후의 편집을 먼저 보존해야 합니다. 이 도구는 서버를 변경하지 않습니다.

게시용 HTML의 문서 링크는 유효한 기존 페이지 URL로 변환합니다. Confluence가 생성하는 제목 앵커는 서버 검증 전이므로 문서 내 세부절 링크도 대상 페이지 본문으로 연결합니다. 미리보기는 세부절 앵커를 유지합니다.
