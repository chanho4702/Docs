# Moves Approval

Confluence Cloud 문서와 문서 안의 특정 영역에 단계별 승인을 요청하고, 결정과 버전별 이력을 확인하세요.

Request step-by-step approval for Confluence Cloud pages or areas, and track decisions and the versions they apply to.

## First approval · 첫 승인

1. 관리자가 앱을 설치하고 정책과 적용 스페이스를 확인합니다. / An administrator installs the app and reviews policy and enabled spaces.
2. 요청자가 게시된 문서에서 승인자·단계·마감을 정합니다. / A requester chooses approvers, steps, and a deadline on a published page.
3. 승인자가 업무함의 내 차례에서 내용을 확인하고 결정합니다. / Approvers review and decide on requests under My turn.
4. 문서에서 결재란과 이력을 확인하고 종료된 요청의 증명서를 내려받습니다. / Read the stamp box and history, and download a certificate for a finished request.
