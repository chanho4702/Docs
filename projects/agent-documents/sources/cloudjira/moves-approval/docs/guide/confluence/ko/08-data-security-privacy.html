대상: 사이트 관리자, 보안·개인정보 검토 담당자

요약

  • Moves Approval은 Atlassian Forge 앱으로, Atlassian 인프라 안에서만 실행됩니다.
  • 앱 데이터는 Atlassian이 호스팅하는 Forge 저장소(Forge SQL·Forge Key-Value Store)에만 저장됩니다. 외부 서버로 데이터를 보내지 않습니다.
  • 사용자를 대신해 Confluence에 접근할 때는 그 사용자의 권한으로 호출합니다. 사용자는 자신이 볼 수 없는 페이지의 정보를 앱을 통해 볼 수 없습니다.
  • 앱은 페이지 본문을 저장하지 않습니다. 승인 판단에 필요한 버전 번호와 영역 내용의 해시값만 저장합니다. 결재 증명서의 문서 지문도 그때그때 계산할 뿐 본문을 남기지 않습니다.
  • 앱이 페이지 본문을 고치는 경우는 요청자가 선택한 결재란 자동 추가 하나뿐이며, 요청자의 권한으로만 고칩니다.

결재 증명서 PDF는 요청할 때마다 브라우저에서 만들어 내려받으며, 앱이 사본을 보관하지 않습니다.

  • 사용자는 결재 기록을 수정할 수 없습니다. 결재 기록은 위의 보관 기간·정리 정책에 따라서만 지워집니다.

앱을 제거한 뒤의 데이터 처리는 Atlassian Forge 플랫폼의 데이터 보관 정책을 따릅니다.

내보낸 파일

엑셀로 내보내기로 받은 .xlsx 파일(시트: 결재 요청 / 결재선 / 이력)에는 문서 제목, 요청 메모, 반려·회수 사유, 그리고 내보낸 시점에 Confluence에서 읽은 사용자 이름이 들어 있습니다. 파일은 관리자의 컴퓨터로 내려받아지며 그 뒤의 보관·접근 통제·폐기는 고객의 책임입니다. 조직의 기록 보존 정책에 맞는 곳에 보관하세요.

저장 공간 한도

앱 데이터는 Forge SQL의 설치당 저장 한도(1 GiB 기준) 안에 저장됩니다. 한도를 넘으면 새 결재를 저장할 수 없습니다. 설정 → 데이터 관리 → 저장 공간에서 사용량을 확인할 수 있으며, 80% 이상이면 주의, 90% 이상이면 위험으로 표시됩니다. 테이블별 크기·행 수는 데이터베이스 통계 기반 추정치입니다.

Confluence에 쓰는 데이터

앱이 Confluence에 쓰는 것은 아래 두 가지뿐입니다.

무엇 언제 누구의 권한으로
결재란 매크로를 페이지 맨 위에 추가 페이지 결재를 요청할 때 요청자가 문서 맨 위에 결재란 추가를 선택한 경우(기본값은 정책 승인 요청 시 문서 맨 위에 결재란 자동 추가, 기본 켬) 요청자 — 앱 권한으로 쓰지 않습니다
관련자를 @멘션하는 댓글 Confluence 알림으로도 보내기가 켜진 경우(기본 켬) 해당 작업을 실행한 사용자(asUser)
  • 결재란 자동 추가는 앱이 페이지 본문을 고치는 유일한 경우입니다. 요청자 권한으로 고치므로 페이지 버전이 하나 오르고 페이지 이력에 요청자가 "Moves Approval" 메시지로 남습니다. 문서에 결재란이 이미 있으면 넣지 않고, 요청자에게 편집 권한이 없거나 그 사이 다른 저장이 있으면 넣지 않은 채 요청만 진행합니다. 결재란은 결재 상태를 표시하는 매크로일 뿐 결재 데이터를 본문에 적지 않습니다.
  • 댓글은 Confluence 콘텐츠이므로 페이지를 볼 수 있는 사람 모두에게 보이고, 앱을 제거해도 남습니다. 결재란 매크로도 페이지 본문에 남지만, 앱을 제거하면 더 이상 동작하지 않습니다.

결재 증명서

  • 결재 증명서 PDF는 끝난 결재에 대해서만, 그 페이지를 볼 수 있는 사용자에게만 발급됩니다. 요청이 그 페이지의 것인지 서버에서 다시 확인합니다.
  • 문서 지문을 계산하려고 결재 대상 버전의 본문을 증명서를 여는 사용자의 권한으로 읽고, SHA-256 값만 계산해 돌려줍니다. 본문은 저장하지 않습니다. 그 버전을 읽을 수 없으면 지문을 생략합니다.
  • 증명서에는 요청자·결재자·처리자 이름, 요청 메모, 반려·회수 사유가 들어갑니다. 내려받은 PDF의 보관과 공유는 고객의 책임입니다.

접근 통제

  • 모든 요청은 서버에서 권한을 다시 확인합니다. 화면에 버튼이 보이는지와 관계없이, 앱의 모든 기능은 서버의 권한 표에 선언된 조건(본인 데이터, 페이지 보기·편집 권한, 관리자 권한)을 통과해야 실행됩니다. 선언되지 않은 기능은 실행되지 않습니다.
  • 목록은 건별로 다시 걸러냅니다. 승인 업무함은 결과를 돌려주기 전에 사용자가 실제로 볼 수 있는 페이지만 남깁니다.
  • 페이지 권한을 우회하는 읽기는 사용자에게 돌려주지 않습니다. 마감 만료·페이지 수정 감지처럼 사용자 없이 도는 작업만 앱 권한으로 페이지를 읽으며, 그 결과는 버전 비교와 해시 계산에만 씁니다.
  • 앱 권한으로 페이지 본문을 고치지 않습니다. 결재란 자동 추가는 요청자 권한으로만 실행됩니다.
  • 동시 결정에 안전합니다. 같은 순간 여러 결정이 들어와도 한 대상에는 진행 중 요청이 하나만 존재하며, 다른 사람의 결정을 덮어쓸 수 없습니다.
  • 마감 이후 결정은 서버가 거절합니다. 정기 정리가 돌기 전이라도 마감이 지난 요청에 대한 승인·반려는 기록되지 않습니다.
  • 데이터 관리(저장 공간·결재 기록 보관·삭제)는 앱 관리자만 쓸 수 있습니다.
  • 서명 PIN은 5회 실패 시 15분 동안 잠깁니다.
  • 라이선스가 비활성이면 설정 화면을 제외한 모든 기능이 차단됩니다.

개인정보 주체 요청

사용자는 내 서명에서 서명과 PIN을, 내 위임에서 위임을 직접 삭제할 수 있습니다. 승인 결정 기록은 조직의 감사 기록이므로 사용자가 수정하거나 삭제할 수 없으며, 보관 기간이 지난 기록을 관리자가 내보낸 뒤 삭제할 때만 지워집니다. 앱은 이름·이메일을 자체 보관하지 않으므로, Atlassian 계정이 삭제되면 화면에는 Confluence가 그 계정에 대해 돌려주는 정보가 그대로 표시됩니다. 다만 이미 내보낸 엑셀 파일이나 내려받은 증명서 PDF에 들어간 이름은 고객이 관리하는 사본이므로 앱이 바꿀 수 없습니다. 그 밖의 요청은 사이트 관리자를 통해 지원 채널로 문의해 주세요.
