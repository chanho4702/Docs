가이드 홈 · English

승인은 특정 버전과 요청의 기록입니다. 문서를 고쳤을 때 기존 요청을 계속할지, 새 버전으로 다시 검토할지 결정합니다.

상황에 맞는 동작 선택

상황 기존 요청 해야 할 일
진행 중 문서 수정 편집만으로 종료되지 않음 변경을 확인하고 새 내용의 승인이 필요하면 다시 상신합니다.
승인 완료 후 수정 이전 버전의 승인 기록 유지 현재 버전은 새 요청으로 승인받습니다.
잘못 요청했거나 더 이상 필요 없음 진행 중이면 회수 가능 요청자 또는 Confluence 관리자가 회수합니다.
반려·만료·회수로 종료 기존 요청을 다시 열 수 없음 문서와 결재선을 확인하고 새 요청을 만듭니다.
마감 경과, 아직 기한 초과 표시 결정은 이미 불가 새 요청 시 지난 요청은 만료 처리됩니다.

새 버전으로 다시 상신하기

  1. 승인 상세에서 요청 당시 버전과 현재 버전을 비교합니다. 변경 보기로 달라진 내용을 확인합니다.
  2. 새 버전으로 다시 상신을 누릅니다. 현재 페이지 편집 권한이 필요하며 원 요청자에게도 같은 조건이 적용됩니다.
  3. 가져온 결재선을 검토하고 마감·참조·요청 메모를 다시 확인합니다.
  4. 제출 뒤 새 요청의 대상 버전과 첫 단계를 확인합니다. 이전 요청은 종료되며 기존 결정은 새 요청의 결정으로 이어지지 않습니다.

화면 위치 · MA-10 — 요청 버전과 현재 버전 안내, 변경 보기와 새 버전으로 다시 상신 버튼.

요청 회수하기

진행 중 요청의 상세에서 요청 회수를 누르고 선택적으로 200자 이하 사유를 입력한 뒤 확정합니다. 회수 후에는 복원할 수 없습니다. 설정 관리자라는 이유만으로 다른 사람의 요청을 회수할 수 있는 것은 아닙니다.

이력 확인

버전별 승인 이력을 펼쳐 이전 요청의 감사 타임라인에서 요청·결정·회수·만료를 확인합니다. 현재 문서와 이전에 승인한 문서가 같은 버전인지 함께 읽으세요. 이전 이력 확장은 상세의 현재 요청이나 PDF 대상을 전환하지 않습니다. 결재 증명서는 현재 상세에 표시된 요청이 종료 상태일 때 발급하며, 요청 ID와 버전을 확인한 뒤 보관합니다.
