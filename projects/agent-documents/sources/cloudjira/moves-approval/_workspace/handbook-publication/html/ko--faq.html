문제가 생기면 같은 동작을 반복하기 전에 대상 문서·요청·계정을 확인합니다. 요청 생성이나 일괄 승인 중 오류가 났다면 실제 반영된 상태를 먼저 확인하세요.

화면과 요청

증상 확인 순서 다음 안내
앱 또는 설정 메뉴가 없음 설치된 사이트 → 계정 → 앱 접근 정책·관리자 등록 설치, 권한
문서에서 요청할 수 없음 게시 여부 → 편집 권한 → 적용 스페이스 → 기존 진행 중 요청 페이지 승인
승인자·결재선 검색이 비어 있음 검색어 → 명부·그룹 → 결재선 사용 여부·적용 스페이스 결재선
요청을 제출했는데 결재란이 없음 요청 상세가 생성됐는지 → 페이지 버전·동시 편집 → 수동 삽입 결재란
영역 식별자 중복 복사한 영역 매크로 여부 → 중복 제거 후 새 삽입 영역 승인

결정과 버전

증상 확인 순서 다음 행동
내 이름이 있는데 승인 버튼이 없음 현재 단계 → 본인·위임 관계 → 마감 → 종료 여부 앞 단계가 끝날 때까지 기다리거나 요청자에게 확인합니다.
다른 사용자가 먼저 변경했다는 오류 최신 상태·결정 기록 이미 처리된 요청에 재시도하지 않습니다.
마감은 지났는데 만료로 안 바뀜 기한 초과 표시 정기 정리는 하루 한 번이며 결정은 이미 차단됩니다.
승인 뒤 문서를 수정함 승인 대상 버전과 현재 버전 현재 버전은 새 요청으로 승인받습니다.
잘못 승인·반려함 요청이 진행 중인지 종료됐는지 진행 중이면 회수 후 새 요청, 종료됐으면 새 요청을 만듭니다.
PIN 잠김·분실 실패 횟수·15분 잠금 앱의 관리자 초기화 기능은 없습니다. 지원에 처리 방법을 문의합니다.

알림과 파일

알림이 없으면 채널·수신 역할·정책을 확인합니다. 댓글 생성 실패만으로 결정이 실패한 것은 아닙니다. PDF 버튼은 종료 요청에만 나타납니다. 지문이 없는 PDF는 대상 버전의 본문을 읽을 수 있었는지 확인하세요.

Excel 행 수가 화면보다 많을 수 있는 이유는 화면에 아직 불러오지 않은 항목도 내보내기 대상이기 때문입니다. 업무함은 현재 탭·필터의 최대 5,000건을 내보냅니다. 보관 기록 삭제 전 내보내기와 혼동하지 마세요.
