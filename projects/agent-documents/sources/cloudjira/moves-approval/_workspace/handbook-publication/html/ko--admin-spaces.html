가이드 홈 · English

새 승인 요청을 허용할 스페이스와 예외 정책을 정합니다. 예를 들어 법무 스페이스만 마감을 3일로 하고 나머지는 전역 기본값을 따르게 할 수 있습니다.

경로: 설정 → 적용 스페이스.

적용 범위 정하기

  1. 처음 상태에서는 모든 스페이스에서 사용할 수 있다는 안내를 확인합니다.
  2. 이름 또는 key로 검색합니다. 목록이 더 있으면 더 보기로 확인합니다. 처음 하나를 켜는 순간부터 나머지 스페이스의 새 요청이 제한되므로, 필요한 적용 범위를 먼저 정합니다.
  3. 필요한 스페이스의 사용 토글을 하나씩 바꿉니다. 각 변경은 즉시 저장되므로 저장 결과와 오류 안내를 확인합니다.
  4. 제외하려는 스페이스에 진행 중 요청이 있으면 경고를 읽고 스페이스 제외로 확정합니다.

화면 위치 · MA-16 — 스페이스의 사용 여부와 정책 편집, 전역 상속·개별값이 보이는 정책 창.

개별 정책 설정하기

스페이스 행의 정책 편집을 엽니다. 다른 값을 쓸 항목만 켜고 값을 입력해 저장합니다. 끈 항목은 전역 정책을 따릅니다. 예를 들어 마감만 3일로 바꾸면 재정의하지 않은 요청 기본값은 전역 값을 따릅니다.

현재 버전의 PIN 필수 여부·결재 위임 허용·서명 표시는 전역 정책으로 동작합니다. 스페이스 정책 화면에서 이 항목을 바꾸는 것으로 공간별 제한을 설정하지 마세요.

항목 범위·동작 결과 확인
사용 해제 해당 공간의 새 요청·영역 사용 제한 진행 중 요청은 자동 종료되지 않습니다.
개별 정책 끄기 해당 항목을 전역 상속으로 복귀 표시된 전역 값을 확인합니다.
접근 제한·상태 표시명 전역 전용 스페이스별로 바꿀 수 없습니다.

저장 후 해당 스페이스의 테스트 문서에서 새 요청 폼을 열어 기본값을 확인합니다. 스페이스가 제외되어도 진행 중 요청은 페이지 권한을 충족하는 사용자가 업무함에서 처리할 수 있습니다.
