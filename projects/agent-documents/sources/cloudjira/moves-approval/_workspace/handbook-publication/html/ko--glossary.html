가이드 홈 · English

같은 문서에서도 페이지 전체 승인, 영역 승인, 이전 버전의 요청은 각각 다릅니다. 화면을 읽을 때 먼저 대상과 요청 버전을 확인하세요.

용어

용어 의미 헷갈리기 쉬운 점
요청 특정 대상과 버전에 대한 한 번의 승인 절차 종료 후 새 요청은 별도 기록입니다.
단계 순서대로 열리는 검토 차례 한 단계 안에 여러 사람이 있을 수 있습니다.
결재선 단계와 승인자, 단계별 통과 조건 저장된 결재선은 새 요청에 복사됩니다.
승인 그룹 한 단계를 구성하는 사람 묶음 Confluence 그룹 또는 앱 직접 구성 그룹입니다.
참조 상태·알림을 받는 역할 결정 권한을 뜻하지 않습니다.
위임 기간 동안 다른 사람의 결정을 대신함 페이지 보기 권한까지 부여하지 않습니다.
결재란 문서에 표시하는 단계·도장·날짜 삽입만으로 문서를 승인하지 않습니다.
대상 버전 해당 요청이 검토하는 문서 버전 현재 화면의 최신 버전과 다를 수 있습니다.

상태와 다음 행동

상태 의미 다음 행동
승인 대기 진행 중인 단계가 있음 현재 차례의 승인자가 검토합니다.
승인 완료 모든 단계의 통과 조건 충족 승인 대상 버전을 확인합니다.
반려됨 승인자가 반려해 종료 사유를 반영하고 새 요청을 만듭니다.
기한 초과 마감 경과, 정기 만료 정리가 아직 전일 수 있음 결정할 수 없으며 필요하면 새 요청을 만듭니다.
만료됨 마감 경과로 종료 새 마감·결재선으로 다시 요청합니다.
회수됨 진행 중 요청을 취소 필요하면 새 요청을 만듭니다.

관리자가 표시명을 바꿔도 처리 규칙은 그대로입니다. 상태 이름만으로 현재 버전의 승인을 판단하지 말고 버전 안내와 함께 확인합니다.
