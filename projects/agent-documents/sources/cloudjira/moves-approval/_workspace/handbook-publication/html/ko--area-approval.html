가이드 홈 · English

페이지의 계약 조항, 검토 대상 표처럼 일부 내용만 별도로 승인받습니다. 페이지 전체 승인과 영역 승인은 각각 다른 요청입니다.

준비와 위치

페이지 편집 권한으로 Moves Approval Region 매크로를 추가합니다. 승인받을 글을 매크로 안에 넣고 게시한 뒤, 해당 영역의 영역 승인 요청으로 요청합니다.

영역을 만들고 요청하기

  1. 페이지 편집기에서 / 또는 삽입 메뉴로 Moves Approval Region을 추가합니다.
  2. 승인할 내용을 매크로 안으로 옮깁니다. 매크로 바깥 내용까지 승인하는 요청으로 설명하지 않습니다.
  3. 페이지를 게시합니다. 영역을 한 번 편집·저장하라는 안내가 보이면 매크로를 편집해 저장한 뒤 다시 게시합니다.
  4. 해당 영역의 영역 승인 요청을 열고 단계·승인자·마감을 정합니다.
  5. 생성 후 그 영역의 상태와 결재란을 확인합니다. 같은 페이지의 다른 영역이나 페이지 전체 상태와 비교해 대상을 확인하세요.

화면 위치 · MA-04 — 영역 안의 내용, 영역 승인 버튼과 아래 결재란. 바깥 본문 일부를 포함해 승인 범위를 보여 줍니다.

화면과 변경의 의미

항목 의미·사용 방법 결과 확인
영역 본문 미리보기 승인 상세에서 검토할 글 확인 이미지·첨부·다른 매크로는 원래 페이지에서도 확인합니다.
결재란 보기·접기 영역 아래의 결재 진행 표시를 펼치거나 접기 페이지 전체 결재란과 구분합니다.
내용 변경됨 승인 기준 이후 영역 내용이 달라짐 변경만으로 요청이 종료되지는 않습니다.
영역 삭제 매크로가 페이지에서 제거됨 해당 영역의 진행 중 요청이 자동 회수됩니다.

완료 확인과 문제 해결

영역별로 요청·상태가 따로 표시되면 준비가 끝났습니다. 여러 영역이 필요하면 각각 새 매크로로 만드세요. 복사한 매크로 때문에 중복된 영역 식별자 안내가 나타나면 중복 매크로를 제거하고 새로 삽입합니다.

요청 버튼이 없으면 게시 여부 → 영역 초기 저장 여부 → 페이지 편집 권한 → 적용 스페이스 순으로 확인합니다. 문서 수정 후 새 내용의 승인이 필요하면 수정·재상신을 확인하세요.
