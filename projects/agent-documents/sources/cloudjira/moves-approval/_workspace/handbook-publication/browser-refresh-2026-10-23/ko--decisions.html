가이드 홈 · English

승인자는 자신의 차례에 대상 문서와 요청 버전을 확인하고 결정합니다. 한 단계에서 필요한 승인 수를 채우면 다음 단계가 열리고, 반려하면 요청 전체가 종료됩니다.

준비: 페이지 보기 권한, 현재 단계의 승인자 또는 유효한 대리인 자격. PIN 필수 사이트에서는 PIN 등록을 먼저 마칩니다.

문서 검토 후 결정하기

  1. 승인 업무함 → 내 차례에서 요청을 엽니다.
  2. 요청 메모, 승인 대상 버전, 현재 단계와 앞선 결정을 읽습니다.
  3. 문서가 수정됐다는 안내가 있으면 변경 보기로 차이를 확인합니다. 영역 승인은 미리보기뿐 아니라 원래 페이지의 이미지·첨부도 확인합니다.
  4. 동의하면 승인을 누릅니다. 수정이 필요하면 반려를 누르고 사유를 적어 확정합니다. 반려 사유는 기본 정책에서 필수입니다.
  5. 필요한 경우 PIN을 입력하고, 결정이 기록됐는지 상세 화면을 다시 확인합니다.

MA-06 · 넓어진 상세 창에서 대상 버전, 단계별 상태, 감사 이력과 결정 버튼을 함께 확인합니다.

결정의 결과

동작 바뀌는 것 확인할 결과
승인 내 결정 기록 단계의 필요한 수가 충족되면 다음 단계가 열립니다.
최종 단계 통과 요청 전체 상태 승인 완료가 됩니다.
반려 요청 전체 상태 다른 사람을 기다리지 않고 즉시 종료됩니다.
취소·뒤로 아직 확정하지 않은 창 이미 확정한 결정을 취소하는 기능이 아닙니다.

반려 사유는 요청 기록에 남으며, Confluence 알림이 켜져 있으면 페이지 댓글을 통해 다른 열람자에게 보일 수 있습니다.

여러 요청 한꺼번에 승인하기

내 차례에서 각 문서의 내용·버전을 먼저 확인하고 체크박스로 고릅니다. 선택 N건 승인으로 최대 50건을 처리합니다. PIN은 묶음당 한 번 입력합니다.

결과의 승인 N건 · 실패 M건을 확인하세요. 실패한 요청은 최신 상태·권한·마감을 다시 확인합니다. 마감이 지난 요청은 선택할 수 없고, 반려는 건별로 처리합니다.

MA-07 · 일괄 승인 전 선택 상태. 실행 뒤에는 요청별 성공·실패 결과를 확인합니다.

결정할 수 없거나 잘못 결정했을 때

앞 단계 대기, 이미 끝난 요청, 마감 경과, 페이지 권한 변경을 순서대로 확인합니다. 확정한 결정은 되돌릴 수 없습니다. 진행 중이면 요청자가 회수 후 새 요청을 만들 수 있고, 이미 종료됐다면 새 요청으로 다시 검토합니다. 수정·회수·재상신을 참고하세요.
