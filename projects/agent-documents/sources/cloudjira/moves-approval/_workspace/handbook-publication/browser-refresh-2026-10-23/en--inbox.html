MA-05 · Staging approval inbox. The list is restricted to requests whose pages the user can view.

Find a request

  1. Choose the appropriate tab: My turn for action, or My requests for pages you submitted.
  2. Narrow the list by page title, space, requester, and date. Use the due-soon condition for urgent deadlines.
  3. Select the page name to open the Confluence page. Select elsewhere on the row to open approval details.
  4. Use Show more for additional rows. If a request is missing, clear filters and check access to the source page.

Check the list and export

The Excel file is a request list, not a full backup of individual decisions and audit history. Use certificates for finished-request evidence and data management for retention exports.

Only pages you can view appear. If tab counts and visible rows differ, check filters and page permission. Being named on a line does not allow a decision before your step opens.
