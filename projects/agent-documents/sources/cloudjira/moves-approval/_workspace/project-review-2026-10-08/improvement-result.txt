Moves Approval 1차 개선 결과 — 2026-10-08

반영 범위
- R03: 업무함 투영 UPDATE에 req_rev 단조 증가 조건을 추가했다. 이미 결정한 승인자를 my_turn으로 되돌리지 않는다.
- R04: 보관 데이터의 승인자·감사 이력 조회에서 문자열 UUID를 BINARY UUID로 변환한다.
- R05: 페이지 열람 권한으로 내보내기를 필터링하고, 서버가 기록한 exportId별 요청 ID로만 삭제한다.
  세션은 내보낸 사용자에 귀속된다. 마지막 페이지 수신·구성 데이터 존재·건수 확인 후 확정하며,
  삭제 시 페이지 권한과 현재 보관 정책을 다시 검사한다. 이전 cutoff 전용 기록은 삭제 근거로 인정하지 않는다.
- R06: 기본값 조회가 주입된 pageLoader를 사용한다. 페이지 조회 실패를 전체 스페이스 조회로 우회하지 않는다.
- R07: 모달 조회·표시·결정을 동일 requestId로 묶고, 요청의 pageId 일치를 서버에서 검사한다.
  영역 요청은 저장된 regionId로 조회하며 재상신도 영역 resolver로 보낸다.
- R09: 스페이스 범위가 설정된 경우 활성 스페이스만 신규 생성한다. 미설정은 기존 전체 허용 정책을 유지한다.
- R10: 영역 생성에 공통 prepareRequest를 적용해 그룹 확장·승인자 자격·정책 스페이스·마감·메시지·CC를 검증한다.
  페이지 생성 resolver로 검증되지 않은 regionId를 보내는 우회는 거절한다.
- R11 일부: 권한 필터링으로 4회 스캔 예산을 소진해도 커서를 유지하여 다음 페이지를 탐색할 수 있게 했다.
