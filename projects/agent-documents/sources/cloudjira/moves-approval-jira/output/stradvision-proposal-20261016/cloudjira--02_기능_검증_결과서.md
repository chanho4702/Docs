## 6. 증거 작성 방법

사용자 수행 항목은 D01~D07입니다. 개발 측은 A01~A07을 구현 후 수행합니다. 실제 결과·판정·증거·실행일은 미리 채우지 않았습니다.

시험마다 앱 버전·실행 환경·사용자 역할·대상 기록·수행 시각을 남깁니다. 화면, Jira 원본, 승인 결과, Workforce 집계를 같은 대상 식별자로 연결하고, 개인정보·API 비밀값은 첨부에서 제외합니다. 실패와 보류도 그대로 기록하며 재시험은 이전 결과와 구분합니다.

도식 파일의 형식 검사는 기능 시험과 별개입니다. 이번 문서 산출 시에는 8개 draw.io 페이지의 도형·연결 참조 및 첨부 링크를 검사했으며, 이는 제품 API 기능의 성공 증거에 포함하지 않습니다.
