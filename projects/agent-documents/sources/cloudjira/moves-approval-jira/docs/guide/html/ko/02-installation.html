설치와 첫 설정

Jira Cloud 사이트 관리자, 시험 프로젝트, 요청자와 승인자 계정을 준비하세요. 공개 출시 전에는 공급자가 제공한 시험 설치 경로를 사용합니다.

  1. Marketplace 출시 후 Moves Approval for Jira의 공급자와 권한을 확인하고 설치합니다.
  2. Jira 앱 → Moves Approval을 열고 관리자 설정으로 이동합니다.
  3. 적용 프로젝트를 지정합니다. 명시적으로 범위를 설정하기 전에는 전체 프로젝트 허용이 기본이므로 시험 범위를 먼저 정하세요.
  4. 단독 모드에서는 팀·팀장과 필요한 승인자 명부를 등록합니다. 연동 모드라면 Workforce 연결을 먼저 완료합니다.
  5. 워크로그 자동 요청 여부와 월 마감 유예일을 정합니다. 자동 마감 일수 0은 자동 마감 꺼짐입니다.
  6. Jira 설정 → 작업 항목 → 작업 항목 기능 → 시간 추적에서 제공자로 Moves Approval을 선택하고 이슈의 Log work / Work log 진입을 확인합니다.
  7. 시험 워크로그 한 건을 저장하고 승인 요청·결정·이력을 요청자와 승인자 계정으로 확인합니다.
  8. 현재 제공 범위를 확인합니다. 상태 변경 승인·기간 타임시트는 현재 설치 절차에 포함하지 않습니다.

사이트의 활성 시간 추적 제공자는 하나입니다. 다른 제공자를 사용 중이면 전환 영향을 먼저 확인하세요. 설치 버전·프로젝트 유형에 따른 동작도 시험해야 합니다.

업데이트와 제거

권한이나 모듈이 바뀐 버전은 관리자의 설치 업그레이드가 필요할 수 있습니다. 제거 전에는 필요한 기록을 내보내고, 워크로그 통제 해제 결과를 확인한 뒤 시간 추적 제공자와 워크플로 validator 의존성을 정리하세요. 제거 직전 자동 해제는 보조 절차이며 모든 기록의 복구 완료를 보장하지 않습니다.

앱 제거가 Jira 워크로그 삭제를 뜻하지는 않습니다. 앱 데이터의 제거 후 보관·복구는 해당 Forge 정책과 공급자 정책을 확인하세요.
