제품 소개

Moves Approval for Jira는 Jira Cloud에 저장한 워크로그를 건별로 승인하고, 결정·변경 이력과 기간 마감을 관리하는 앱입니다.

작성자는 이슈의 Work log에서 기록과 요청 결과를 확인하고, 지정 승인자는 업무함에서 승인·반려합니다. 관리자는 기본 승인 규칙, 적용 프로젝트, 팀, 워크로그 통제와 이력 보관을 설정합니다.

현재 사용자 흐름

기록 저장 → 승인 요청 → 승인·반려 → 상태·이력 확인

저장과 승인 접수는 별도 결과입니다. 저장 후 요청만 실패했다면 같은 시간을 다시 기록하지 말고 원래 기록에서 요청만 재시도합니다. 승인된 기록은 앱에서 수정·삭제할 수 없습니다. 소명이 가능한 경우에도 기존 잠금과 확정 시간은 유지됩니다.

단독과 연동

단독 모드에서는 Approval의 팀·정책을 사용합니다. Moves Workforce와 연결하면 연결된 이슈와 조직 정보를 사용합니다. 연동 모드의 워크로그 승인은 Workforce 연결 대상 이슈에 한정됩니다. 두 앱 설치만으로 연결되지 않으며 관리자가 코드 연결을 완료해야 합니다.

제공 범위

현재 업무함 메뉴는 내 차례·진행 중·내 요청·내 이력·참조·알림·내 서명·내 위임입니다. 관리자에게는 승인 관리·기록·설정이 추가됩니다.

기간 타임시트 제출과 직접 인증은 현재 신규 메뉴에 노출되지 않습니다. 일반 이슈·필드 변경 신규 승인도 제공하지 않습니다. 상태 변경 승인은 서버 구현과 manifest 진입점은 있으나 현재 설정·프로젝트 화면 연결이 완성되지 않아 이 문서에서는 출시 기능으로 안내하지 않습니다.
