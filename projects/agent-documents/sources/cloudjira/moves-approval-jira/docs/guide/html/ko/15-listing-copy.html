Moves Approval for Jira — 등록용 문구

Tagline

Jira Cloud의 워크로그 승인·결정 이력·기간 마감을 한곳에서 관리하세요.

Summary

업무함에서 Jira 워크로그를 건별로 승인하고 결정 이력과 기간 마감을 관리하세요. 단독 팀 설정 또는 선택적인 Moves Workforce 연결을 지원합니다.

More details

Jira Cloud에서 작업 기록의 검토와 승인을 관리하세요. 작성자는 기록을 저장하고 승인 요청 결과를 확인하며, 지정 승인자는 업무함에서 건별로 검토합니다. 승인 결정과 관찰된 워크로그 변경 이력을 구분하고 자동 요청·기간 마감·허용된 기록 내보내기를 운영할 수 있습니다. 승인된 기록은 앱에서 수정·삭제가 제한됩니다. 관리자는 추가 워크로그 통제를 구성하고 실제 보호 범위를 검증한 뒤 적용합니다. 단독 사용하거나 Moves Workforce와 연결해 조직·연결 이슈 정보를 사용할 수 있습니다. 영어·한국어 번역을 포함합니다. 현재 신규 사용 안내는 워크로그 건별 승인 중심이며 기간 타임시트 제출과 상태 변경 승인은 출시 제공 기능으로 안내하지 않습니다.

Highlight 1: 업무함에서 워크로그 승인과 이력 확인

본인 요청과 처리 이력을 추적하세요. 이슈·기록 시간·승인 상태를 확인하고 가능한 요청은 일괄 처리합니다.

승인 완료와 회수된 요청 회차, 작업 일시·소요 시간을 구분하는 실제 개발 환경의 내 이력 화면입니다.

Highlight 2: 자동 요청과 월 마감 규칙 설정

자동·수동 요청과 월 마감 유예일을 정하세요. 승인된 기록은 앱 수정이 제한되며 소명 중에도 잠금이 유지됩니다.

실제 개발 환경의 기본 승인 규칙 화면입니다. 자동 마감 0일의 의미와 보호 범위를 함께 안내합니다.

Highlight 3: 필요할 때 Moves Workforce 연결

호환되는 두 앱을 연결 코드로 연결하세요. Workforce의 팀·연결 이슈와 Approval의 승인·통제를 함께 사용합니다.

실제 개발 환경의 연결 상태와 통신 진단 화면입니다. 연결 코드와 개인키는 표시하지 않았습니다.
