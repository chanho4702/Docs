# Periods, teams and timesheet availability

**My timesheet, Team timesheet and direct certification are not exposed in the current user navigation.** Their presence in older code or documentation does not make period submission part of the current onboarding flow. The current approval unit is [one worklog](cloudjira--03-requester-guide.md).

Administrators manage policy, period closing and teams in the period/team settings. Closing affects whether individual records can be edited or submitted. **Automatic closing set to 0 means off.**

Configure standalone teams in Approval and Workforce teams in the connected app. A team-lead role does not replace Jira issue visibility. See the [approver guide](cloudjira--04-approver-guide.md) for reviewing assigned worklogs in the inbox.
