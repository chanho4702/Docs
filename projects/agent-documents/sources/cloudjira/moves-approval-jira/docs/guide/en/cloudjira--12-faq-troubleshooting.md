# FAQ and troubleshooting

| Symptom | Check |
| --- | --- |
| Saved worklog has no pending request | Automatic/manual policy, candidate selection and request result; do not record the same time again |
| No approver candidates | Team hierarchy, directory, active accounts and issue visibility |
| Approved record cannot be edited | Expected lock; check any offered reconsideration action |
| Last month is still open | 0 disables automatic closing; check actual closing state |
| Work log missing or duplicated | Site time tracking provider and installation upgrade |
| Jira or another app shows a different total | Visibility controls, permissions and current/certified/submitted time |
| Workforce says connection required | Completed pairing as well as the feature switch |
| Workforce access denied | Peer-app permissions, actor and issue permissions |
| Missing change history | Collection scope, description settings, visibility and event/daily reconciliation delay |

## Contacting support

Include the app version and environment, time and time zone, request ID, issue key, worklog ID, reproduction steps, error code and expected versus actual outcome. Redact sensitive descriptions, rejection reasons and personal information. Never send PINs, private keys, pairing codes or authentication tokens.

After public release, use the vendor support channel linked from Marketplace. Before release, contact the person who supplied this guide. Response times and round-the-clock support depend on the finalized support policy.
