# 일반 이슈·필드 변경 승인 제공 범위

현재 제품 흐름에서는 **일반 이슈 결재와 필드 변경 승인의 신규 요청을 제공하지 않습니다.** 이전 문서에 나온 필드 변경 요청·자동 적용 절차를 현재 설치 안내로 사용하지 마세요.

상태 변경 승인은 [현재 제공 상태](cloudjira--07-transition-approval.md)를 확인하세요. 작업 기록을 승인받으려면 [작성자 가이드](cloudjira--03-requester-guide.md)를 사용합니다.

과거 요청 이력이 남아 있는 설치에서는 기존 기록이 표시될 수 있습니다. 기록이 보인다는 사실이 신규 기능 제공을 뜻하지는 않습니다.
