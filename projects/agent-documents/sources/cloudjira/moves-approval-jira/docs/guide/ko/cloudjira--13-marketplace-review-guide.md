# Marketplace 심사 재현 안내

이 안내는 재현 절차이며 실계정 통과 보고서가 아닙니다. 출시 후보 버전·설치 링크·시험 사이트와 계정은 심사 담당자에게 별도로 제공합니다.

## 준비

company-managed 시험 프로젝트, 요청자 A, 승인자/팀장 B, 관리자 C, 이슈 열람 권한이 없는 D를 준비합니다. 시간 추적 제공자, 팀, 적용 프로젝트를 구성합니다. 상태 변경·기간 타임시트 시나리오는 현재 UI 미연결로 제출 대상에서 제외합니다.

| ID | 절차 | 기대 결과 |
| --- | --- | --- |
| R01 | A가 정상 경로에서 기록 저장·요청, B 승인 | 저장과 접수 상태 구분, 건별 승인·결정 이력 |
| R02 | 별도 기록을 반려 후 A가 사유 확인 | 반려 이력 보존, 현재 정책에 맞는 재요청 |
| R03 | 저장 성공·요청 실패 조건 확인 | 원래 worklogId로 요청 재시도, 중복 기록 없음 |
| R04 | 승인된 기록을 앱에서 수정·삭제 시도 | 잠금 안내, 원본 불변 |
| R05 | 미승인 시험 월 마감, 자동 마감 0 설정 비교 | 실제 마감만 적용, 0은 자동 마감 OFF |
| R06 | 소명 대상에 사유 입력 | 재검토 요청, 기존 잠금·확정 시간 유지 |
| R07 | D의 목록·상세·내보내기, 다른 팀 조회 | 제한 자료 미제공 |
| R12 | 승인·변경 이력 및 파일 내보내기 | 조회자 범위 유지, 파일 내용 일치 |
| R13 | 선택: Workforce 코드 연결·작성·승인·장애 | 원장 분담, 장애를 허용으로 취급하지 않음 |
| R14 | 통제 해제·제공자 변경·제거 준비 | 남은 통제 확인, 복구 누락 없음 |

각 결과에 버전·환경·시각·계정 역할·기록 ID·실제 화면을 연결하세요. 단위 테스트나 화면 캡처만으로 권한 거부·전환 실행 검증을 통과 처리하지 않습니다. 개인정보·자격 증명은 공개 증빙에서 제외합니다.
