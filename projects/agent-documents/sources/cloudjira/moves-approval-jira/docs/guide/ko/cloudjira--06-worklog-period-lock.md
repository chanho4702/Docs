# 워크로그 보호와 기간 마감

승인된 워크로그는 앱에서 수정·삭제할 수 없습니다. 미승인 기록도 기간 마감·입력 가능 기간·통제 작업 상태에 따라 제한될 수 있습니다. **자동 마감 0일은 꺼짐**이며, 월이 지났다는 이유만으로 자동 마감되는 것은 아닙니다.

## 제공자와 보호 방식

Moves Approval을 Jira 시간 추적 제공자로 선택하면 앱의 **Log work / Work log**를 사용합니다. 제공자 선택만으로 REST·자동화·다른 앱의 모든 쓰기를 사전 차단하지는 않습니다.

관리자는 환경에 맞는 워크로그 통제를 별도로 설정하고 진단해야 합니다. 공개 범위를 제한하는 보호 방식은 Jira 기본 화면이나 다른 앱에서 해당 기록이 보이지 않거나 합계가 다르게 보일 수 있습니다. 앱은 본인 또는 허용된 팀장 조회 범위에서 필요한 기록을 보충하지만 다른 사람의 숨김 설명을 공개하지 않습니다.

외부 변경이 관찰되면 변경 표시·통제 이력·집계 제외 등이 적용될 수 있습니다. 확정 시간과 현재 원본의 시간이 다르다고 이전 승인을 새 시간에 자동으로 적용하지 않습니다. 이벤트와 일일 보정은 즉각적인 전수 감지를 보장하지 않습니다.

## 마감과 소명

관리자는 기간 마감 상태를 확인하고 허용된 화면에서 마감·재개를 관리합니다. 기간을 다시 열어도 승인된 기록의 잠금이 자동 해제되지는 않습니다. 마감 전에 접수된 대기 요청은 원본을 재검증한 뒤 처리할 수 있습니다.

상세에 제공되는 소명 요청에는 사유가 필요합니다. 소명 접수만으로 기록을 수정할 수 있게 되지는 않습니다.

## 제거 전

관리자 통제 화면에서 RELEASE를 입력해 해제를 시작하세요. 시작 성공은 완료가 아닙니다. 상태를 새로 조회해 잔여 통제 기록이 0인지 확인한 뒤 제거하세요. 그 후 시간 추적 제공자를 전환하고 앱을 제거합니다. 앱 제거만으로 숨김 기록이 모두 복구된다고 가정하지 마세요.
