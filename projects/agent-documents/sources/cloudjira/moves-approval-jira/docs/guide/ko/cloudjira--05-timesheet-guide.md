# 기간·팀 설정과 타임시트 제공 범위

현재 사용자 메뉴에는 **내 타임시트·팀 타임시트·직접 인증**이 노출되지 않습니다. 기존 코드나 예전 문서에 해당 이름이 있어도 신규 사용자에게 기간 제출 절차를 안내하지 않습니다. 현재 승인 단위는 [워크로그 한 건](cloudjira--03-requester-guide.md)입니다.

관리자는 **설정 → 승인 기간 · 팀**에서 정책·기간 마감·팀을 관리합니다. 기간 마감은 개별 기록의 수정·요청 가능 여부에 영향을 줍니다. **자동 마감 일수 0은 꺼짐**입니다.

단독 팀은 Approval에서 구성하고 Workforce 연동 팀은 상대 앱에서 관리합니다. 팀장 역할이 Jira 이슈 열람 권한을 대신하지 않습니다. 승인자가 업무함에서 내 차례인 워크로그를 처리하는 방법은 [승인자 가이드](cloudjira--04-approver-guide.md)를 참고하세요.
