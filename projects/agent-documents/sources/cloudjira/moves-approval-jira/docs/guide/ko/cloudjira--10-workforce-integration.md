# Moves Workforce 연결

Workforce는 선택 연동입니다. 두 앱을 설치한 뒤 관리자 설정에서 명시적으로 연결합니다. 단독 모드에서는 Approval의 자체 팀·정책을 사용합니다.

## 연결

1. 양쪽 앱의 호환 버전을 설치하고 관리자 계정으로 연동 설정을 엽니다.
2. 연동 사용을 켜고 한쪽 앱에서 **연결 코드 만들기**를 선택합니다.
3. 만료 전 코드를 다른 앱의 **연결 코드 붙여넣기**에 입력하고 화면 안내대로 연결합니다.
4. 양쪽에서 연결 상태를 확인하고 팀·연결 이슈를 조회합니다.
5. 시험 워크로그 한 건의 작성·승인·상대 앱 결과를 확인합니다.

연결 코드에는 비밀 정보가 포함됩니다. 공개 문서·캡처·지원 티켓에 넣지 마세요. 수동 개인키 배포, entity property 게시, 3LO 토큰 입력은 현재 연결 절차가 아닙니다.

## 어디서 바꾸나요?

| 정보 | 관리 위치 |
| --- | --- |
| Workforce 팀·팀장·연결 이슈 | Workforce |
| Workforce가 관리하는 이슈별 작성·요청 설정 | Workforce |
| 승인 결정·확정 근거·통제 판정 | Approval |
| 연결 상태·해제·연결 진단 | 각 앱의 연동 설정 |

Workforce 앱 내부의 정상 작성 경로는 저장 전에 Approval의 판정을 확인합니다. 승인 앱으로 이동하라는 안내가 나오면 해당 경로에서 계속합니다. 연결 장애 때 검증하지 못한 요청을 허용된 것으로 가정하지 않습니다.

승인 상태가 다르게 보이면 연결 상태·현재 권한·캐시 갱신·상대 버전을 확인하세요. 예전 프로퍼티 재게시 절차를 실행할 필요는 없습니다. 연결 해제와 워크로그 통제 해제는 다른 작업입니다.
