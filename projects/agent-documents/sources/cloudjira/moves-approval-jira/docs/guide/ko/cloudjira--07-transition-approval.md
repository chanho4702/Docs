# 상태 변경 승인 제공 상태

현재 코드에는 상태 변경 승인 서비스·자동 적용·워크플로 validator와 **Request status change approval** manifest 항목이 있습니다. 서버 기능 기본값은 꺼짐입니다.

그러나 현재 **기본 승인 규칙** 화면에는 자동 요청·자동 마감 설정만 있고 상태 변경 기능을 켜는 UI는 없습니다. 프로젝트 설정 엔트리도 워크로그 이슈 예외 화면만 렌더링합니다. 따라서 **현재 일반 관리자가 화면만으로 설정을 완료할 수 있는 출시 기능으로 안내하지 않습니다.**

공급자가 화면 연결·설치 업그레이드·실계정 검증을 완료한 버전에서 지원 범위를 다시 확인하세요. 내부 저장값을 직접 바꾸거나 숨은 resolver를 호출하는 방법을 설치 절차로 사용하지 않습니다.

서버 구현에서 승인 완료와 Jira 적용 성공은 별도 상태입니다. 요청자 권한으로 적용하며, 결과 불명(UNKNOWN)에는 재전송하지 않는 경계가 있습니다. 이 구현 설명만으로 현재 배포 환경의 전환 성공이 검증된 것은 아닙니다.
