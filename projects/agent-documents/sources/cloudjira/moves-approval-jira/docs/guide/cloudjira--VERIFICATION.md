`VALIDATION.json`에는 등록 문구별 글자 수와 근거 코드 SHA-256이 기록되어 있다. 코드 작업 트리가 바뀌면 근거를 재검토해야 한다. HTML은 원본 정본이 아니며 `node scripts/package-marketplace-docs.cjs`로 다시 만든다.

영문 UI 촬영은 계정 언어 변경 확인 대기 상태다. 현재 영문 문서의 캡처는 한국어 UI임을 명시했다. production 실계정 검증이나 Marketplace 제출을 완료했다고 주장하지 않는다.
