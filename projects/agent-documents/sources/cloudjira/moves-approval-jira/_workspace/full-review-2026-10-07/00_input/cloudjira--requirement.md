# 전체 검수와 개선

요청: 전체 검수 후 문제와 애매한 설계를 짚고, 확인된 결함을 개선한다.

검수 대상은 현재 작업 트리다. 기존 수정·신규 파일을 보존하며 커밋·푸시·배포는 수행하지 않는다.

중점: resolver 등록과 권한 범위, 승인 상태와 실제 Jira 적용의 경계, SQL UUID·CAS·준비 상태, 스윕과 알림, 보관 삭제와 내보내기, PIN과 라이선스, 프론트 응답 계약과 페이지 이동.

완료 기준: 확정 결함의 수정 및 회귀 검증, 코드 근거와 재현 조건을 포함한 잔존 설계 보고, 백엔드·UI 테스트, UI 빌드와 Forge lint 결과 기록. 실제 Forge SQL·Jira 실행에 의존하는 사항은 로컬 검증과 구분한다.
