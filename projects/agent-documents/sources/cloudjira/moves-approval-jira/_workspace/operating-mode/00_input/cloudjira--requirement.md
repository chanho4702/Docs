# 요구 — 운영 모드(단독 / 워크포스 연동) 표시 분리 (operating-mode)

작성: 2026-10-12 (리더). 사용자 제안: "워크포스 연동 모드랑 일반 모드 분리하는 게 좋을 것 같다". 리더 의견(사용자 "ㄱㄱ"로 확정):
엔진을 둘로 나누지 않는다 — 백엔드는 이미 `workforceLinkEnabled` 하나로 "연동 꺼짐 = 단독" 으로 동작한다
(TeamScope org=null, ControlLinkJudge NOT_LINKED, WorklogTab 채널). 나눌 것은 **화면**이다.

## 요구
1. 모드 = `workforceLinkEnabled` 가 **true 로 저장돼 있을 때만** 연동, 그 외(미저장·false)는 단독. **새 설정값을 만들지 않는다.**
   **서버 기본값을 꺼짐(false)으로 바꾼다** — 사용자 결정 2026-10-12: "설치는 둘 다 했어도 연동 안 할 수도 있다". 연동은 관리자의 명시적 선택이다.
2. 모드 선택 스위치는 **워크포스 연동 페이지에 그대로** 둔다(끄고 켤 때 전량 재게시·통제 해제 후과 설명이 있는 자리).
3. 단독 모드에서는 **연동 전용 UI 를 접는다**(숨기지 않고 한 줄 안내 + 펼치기). 저장된 값은 지우지 않는다 — 백엔드가 이미 연동 꺼짐이면 무시한다.
4. 모드가 어디서든 보이게 한다 — 설정 메뉴의 "워크포스 연동" 항목에 배지(연동 중 / 단독).
5. 모드를 모르는 상태(정책 로딩·실패·권한 없음)에서는 **전부 보인다**(표시 fail-open). 숨겼는데 동작 중인 상태는 만들지 않는다.
6. 모드 자동 감지 없음(불변식 9).

## 완료 기준
- 백엔드는 기본값 변경 + 판정 단일화(설계서 §8)만. manifest·엔트리·스키마 무변경. 백엔드·프론트 jest·빌드·`npm run merge` 통과.
- 단독 모드에서 접히는 요소 목록(설계서 §2)이 전부 반영되고, 연동 모드에서는 지금과 동일.

## 범위 밖
- 단독 모드에서 연동 전용 정책 값 자동 초기화.
- 팀 명부의 Jira 그룹 가져오기(`sourceGroupName`)는 워크포스가 아니라 Jira 그룹이다 — 건드리지 않는다.
