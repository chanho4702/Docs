## 3. 디자인 시스템

- 16:9 와이드(13.33×7.5in). 브랜드 틸 스케일(PRIMARY `#21ADAD`, 다크 `#103F3A`, 진한 강조 `#14756E`, 연한 `#E9F7F4`/`#C9ECE6`, 밝은 포인트 `#6FD3C6`). 주색 60~70%, 파란 기본값 금지
- 샌드위치: 표지·섹션·마무리 = 다크 `#103F3A` 풀블리드, 본문 = 흰색/연회색 `#F4F8F7`
- 반복 모티프: 좌상단 **챕터 칩**(틸 사각형 + 번호) + 틸 원형 아이콘. 제목 밑 장식선 없음
- 실제 화면은 **브라우저 프레임**(흰 카드 + 그림자 + 상단 점 3개) 안에 크게. 캡처 60% / 도식·표 30% / 분위기 10% 이하
- 폰트: Noto Sans KR(설치 확인) — 제목 28~32pt Bold, 본문 13~15pt, 캡션 10~11pt 회색. 산식은 Consolas
- 슬라이드당 핵심 메시지 1문장 + 불릿 ≤4. 텍스트만 있는 장 금지

## 4. 실 이미지 전략 — 캡처 자동 교체

- `captures/<키>.png` 파일이 있으면 빌드가 자동으로 프레임 안에 넣고, 없으면 **점선 placeholder**에 "📷 캡처 필요 · 파일명 · 화면 경로 · 강조 영역 · 권장 비율"을 적는다
- 캡처 목록은 `CAPTURE_LIST.md`(빌드가 생성). 파일을 넣고 `node build.js`만 다시 실행하면 된다
- 이미 확보된 캡처 3장: `progress.png`, `gantt.png`, `portfolio.png`
