# 요구사항: 접기/너비 조절 패널 레이아웃 — 공통 승격

> 2026-08-12. 사용자 요청 원문 요지: "프로젝트 배정 부분 레이아웃이 3개라 너무 좁음. 좌로 접기 기능이랑 핸들 드래그로 카드 너비 조절 기능 추가. 카드 접기랑 카드 접었을 때 옆 카드 너비 늘어나는 거 — 이거 공통 기능으로 승격해서 레이아웃 조절 편하게 하자"

## 대상·목표

1. **1차 적용 화면**: 자원관리(/resource) > 프로젝트 배정 탭 (`static/ui/src/pages/resource/assignment/ProjectAssignmentBoard.jsx`) — 패널 3개가 나란히 있어 각각이 너무 좁다.
2. **공통 컴포넌트로 승격**: 패널 접기/펼치기 + 드래그 너비 조절을 `components/layout/` 공용 지점으로 만들어 다른 다분할 화면(예: 작업관리 트리 좌/우, My Work 좌/우 등)에서도 재사용 가능하게 한다. 단 **이번에 실제 적용은 프로젝트 배정 화면만** — 다른 화면 확산은 별건.

## 기능 요구

1. **패널 접기(collapse)**: 패널을 좌측(또는 자기 방향)으로 접어 좁은 레일(아이콘/세로 제목 정도)로 축소. 다시 펼치기 가능. 접힘 상태가 명확히 보일 것.
2. **공간 재분배**: 패널을 접으면 남은 패널들이 그 공간을 자동으로 흡수(늘어남).
3. **드래그 너비 조절**: 패널 사이 경계 핸들을 드래그해 너비 비율 조절. 최소 폭 보호. 핸들은 **잡기 쉽게**(테이블 리사이즈에서 "잘 안 잡힌다" 피드백이 이미 나옴 — 히트 영역 충분히).
4. **상태 유지**: 접힘/너비 상태가 최소한 같은 세션의 탭 전환·리렌더에서 유지. localStorage 영속화는 설계 판단(과잉 금지 — 화면별 키 설계가 명확할 때만).

## 제약 (프로젝트 규약)

- 신규 외부 의존성 금지 수준으로 지양(번들 gzip 예산 950KB, 현재 ~895KB). react-resizable-panels 등 도입 대신 자체 구현 우선 — 테이블 리사이즈(ColumnResizeOverlay)에서 이미 pointer capture 패턴 보유.
- Atlaskit 토큰만 사용(다크 테마 자동), RFC-178 공용 UI 지점 원칙 — 신규 컴포넌트는 `components/layout/` 아래.
- 백엔드 변경 없음. i18n 신규 키는 kr/en + merge 규약.
- ProjectAssignmentBoard는 카드 지표 lazy hydrate·computeQueueFlags 등 데이터 로직이 있음 — **레이아웃만 감싸고 데이터 흐름은 불변**이어야 한다.
- 접기 UI는 Atlaskit 네이티브 관례(chevron 아이콘 버튼 등)를 따르고 스피너 금지.

## 검증 포인트

- 3패널 각각 접기/펼치기 동작, 접었을 때 옆 패널이 실제로 넓어짐
- 드래그로 너비 조절, 최소 폭 보호, 핸들 잡기 쉬움
- 탭 전환 후 돌아와도 상태 유지(설계된 범위 내)
- 데이터 동작 무회귀(카드 선택, 지표, 배정 실행 흐름)
- 기존 테스트 + CI 빌드 + 번들 예산 통과
