Purpose and access

Define job roles such as Data Engineer, DevOps Engineer, or QA Engineer. Role management read opens the screen; write permits adding, editing, deleting, and quick-add operations. Role choices are also available to People management readers for its forms.

Register roles

Add role creates one role from a name and description. Quick add selects several common job-role presets; already existing roles are marked and skipped. Edit or delete from the row actions. Name and description length and format are validated.

Where roles are used

Roles appear in person and project-member forms, dashboard role distribution, people filters, portfolio comparisons and costs, and My Work project cards.

Roles are separate from permissions

A job role does not grant access to screens or data. Configure that in Permission management. People without a role may not appear in role-distribution charts or role-specific filters.

Buttons, fields, and result checks

Job roles are reference choices for people/projects, distinct from permission-set roles.

Control or field Function, conditions, and data affected Result check and recovery
Add Role / name / description / Save Register an organizational job name/description. Duplicate names can be rejected. Check the saved list entry. Registration does not grant access permissions.
Quick Add / Select All / Add Select needed roles from industry presets and add them together. Existing items are skipped. Review added/skipped counts and whether names match organizational usage.
Edit / Delete Edit the name/description or delete an unused role. User references can prevent deletion. Review user/project references and resolve them before deleting.
