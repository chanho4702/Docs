가이드 홈 · English

인력 관리에서 서비스 사용자를 등록하고, 팀 관리에서 조직 소속과 팀장을 지정합니다. 프로젝트 참여 인력은 별도로 프로젝트에 배정합니다.

필요한 권한

사용자 등록·변경에는 인력 관리 쓰기, 팀 구조·소속·팀장 변경에는 팀 관리 쓰기가 필요합니다. 조회는 각 읽기 권한을 사용합니다. 급여·권한 세트 배정에는 추가 정책이 적용될 수 있습니다.

사용자 등록하기

  1. Settings → 인력 관리 → 인력 추가를 엽니다.
  2. Jira 사용자를 검색해 선택합니다.
  3. 역할·등급·권한을 지정하고 저장합니다.
  4. 팀을 지정한 뒤 실제 적용 권한을 확인합니다.

선택 가능한 Jira 사용자와 앱에 등록된 인력은 다릅니다. Jira에 존재해도 앱 인력으로 등록되지 않으면 일부 배정 후보에 나타나지 않습니다.

Excel로 여러 명 등록하기

  1. 화면에서 최신 템플릿을 내려받습니다.
  2. 양식을 채워 지원되는 xlsx 형식과 표시된 크기 제한에 맞춥니다.
  3. 업로드 후 진행률과 완료 결과를 확인합니다.
  4. 등록·중복·미존재·실패를 구분하고 실패 사유를 확인합니다.

업로드 버튼을 눌렀다고 완료된 것은 아닙니다. 미존재 계정은 Jira 계정 상태와 검색 가능 여부를 점검하고, 성공한 항목을 포함해 무조건 반복 업로드하지 않습니다.

팀 만들기와 팀장 지정

  1. Settings → 팀 관리에서 팀을 추가합니다.
  2. 이름과 상위 팀을 지정합니다. 상위 팀이 없으면 최상위 팀입니다.
  3. 등록된 인력 중 팀장을 선택합니다.
  4. 팀원을 배치하고, 팀 권한을 사용할 경우 권한 세트를 지정합니다.

팀장은 자신이 이끄는 팀에 소속돼야 합니다. 다른 팀 사람을 지정하면 소속이 바뀔 수 있으므로 저장 안내를 확인합니다. 현재 규칙에서는 한 사람이 여러 팀의 팀장을 겸하지 않습니다.

조직 변경 시 확인

  • 사용자는 하나의 팀에 소속됩니다. 다른 팀으로 배치하면 기존 소속이 바뀝니다.
  • 팀장을 팀 밖으로 옮기려면 먼저 팀장 지정을 바꾸거나 해제합니다.
  • 팀장 해제만으로 이전 팀원이 자동 탈퇴하는 것은 아닙니다.
  • 팀 삭제 전 하위 팀 이동, 팀 미지정 인원, 권한 상속 변화의 미리보기를 확인합니다.
  • 팀 변경 후 마이페이지와 권한 관리에서 실제 적용 결과를 확인합니다.

스킬 사전·등급·역할은 기준정보에서 관리합니다. 프로젝트 참여자를 변경하려면 프로젝트 인력을 사용합니다.

세부 안내

  • 인력 등록과 일괄 업로드
  • 팀 계층과 소속 관리
