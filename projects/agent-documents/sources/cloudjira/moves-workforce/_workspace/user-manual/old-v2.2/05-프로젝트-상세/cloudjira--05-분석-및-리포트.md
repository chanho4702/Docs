# 5.5 프로젝트 상세 — 분석 및 리포트

## 🔐 접근 권한

| 서브탭 | 필요 권한 |
|---|---|
| **작업 분석** | `REPORT` 읽기 |
| **인력 분석** | `REPORT` 읽기 |
| **팀** | `REPORT` 읽기 **+** `PROJECT` 읽기 (둘 다 필요 — 사람↔팀 축을 함께 읽습니다) |
| **진척률** | `REPORT` 읽기 |
| **비용** | `PROJECT_COST` 읽기 (없으면 **탭 자체가 보이지 않음**) |
| **작업 이력** | `PROJECT` **쓰기** (탭 노출 조건) |
| 엑셀 내보내기 | 해당 탭의 조회 권한과 동일 |

- 팀 탭은 권한이 없어도 탭이 보일 수 있으며, 선택하면 **권한 없음 안내 화면**이 표시됩니다.
- 비용 탭은 재무 민감정보라 기본(Member) 권한에는 **처음부터 노출되지 않습니다.**
- 팀 탭의 팀별 비용은 `PROJECT_COST`가 있을 때만 함께 표시됩니다.

## 5.5.1 작업 분석 — "계획 대비 얼마나 정확하게 일하고 있나"

이슈를 **계획 공수(MD)와 실투입 공수(MD)** 관점에서 비교합니다. 상단 필터(스페이스/담당자/상태 등)로 범위를 좁히고 **엑셀 내보내기**로 현재 결과를 저장할 수 있습니다.

| 컬럼 | 의미 |
|---|---|
| 상태 / 담당자 / 작업 인원 | 누가 몇 명이 매달려 있는지 |
| 시작일 / 기한 | 일정 |
| 계획 작업량(MD) | 계획 공수(Original Estimate) |
| 예상 완료일 | 남은 공수 추세로 추정한 종료일 |
| 실투입(MD) | 누적 워크로그 + **진행 바**와 **초과율 배지**(100% 초과 시) |
| 편차 | **완료 이슈만** 표시. 계획 대비 실제(+ 초과, − 절감) |

**색으로 위험을 읽습니다**
🟢 초록 = 계획 이내(≤100%) / 🟠 주황 = 초과(100~130%) / 🔴 빨강 = 심한 초과(130% 이상)

### 여기서 얻는 인사이트

- **추정 정확도**: 계획보다 공수를 훨씬 많이/적게 쓴 이슈 → 견적 역량 점검
- **공수 블랙홀**: 빨강 막대·큰 +편차 이슈는 비효율 또는 범위 누락(scope creep) 후보
- **완료 회고**: 편차 컬럼으로 끝난 이슈의 계획 정확도를 사후 검증
- **일정 리스크 예고**: 예상 완료일이 기한을 넘는 이슈를 미리 발견

### 상세 차트 (이슈 클릭)

선택 이슈의 **누적 공수 S-curve**입니다.

- 파란 실선 = 실제 누적 투입 / 회색 점선 = 시작~기한 균등 분배한 이상적 계획선
- 오늘·기한·예측 종료일 마커와 **편차 막대**(실제−계획)
- 실선이 점선보다 가파르면 계획보다 빨리 소진(초과 위험), 완만하면 지연 신호. 아래 워크로그 원본으로 "언제 누가 얼마나" 투입했는지 추적

## 5.5.2 인력 분석 — "누가 과부하이고 누가 여유인가"

프로젝트 멤버별 투입 공수(MD/MM)와 **가동률**을 기간 기준으로 분석합니다.

- **퀵 필터**: 오늘 / 이번 주 / 이번 달 / 지난 주 / 지난 달, 또는 날짜 직접 선택
- 상단 기준값: `1MD = N h · 1MM = M 근무일(= M×N h) · MM = MD ÷ M`

| 컬럼 | 의미 |
|---|---|
| 총 MM | 투입 공수를 인월로 환산(`총MD ÷ 1MM 근무일`) — 절대 투입량 |
| 실효 가용 MD | 기간 근무일에서 **연차·공휴일을 뺀** 실제 출근 가능 일수(가동률 분모). 차감이 있으면 주황색으로 내역 표시 |
| 총 MD / 총 시간 / 이슈 수 | 실제 투입 공수·시간과 관여한 이슈 수 |
| 가동률 | `총 MD ÷ 실효 가용 MD`. 진행 바 + % |

**가동률 색상**
⚪ 회색 <50%(저활용) / 🟢 초록 50~80% / 🔵 파랑 80~100%(적정) / 🔴 빨강 >100%(과부하)

### 여기서 얻는 인사이트

- **부하 균형**: 빨강(과부하)·회색(저활용)을 비교해 업무 재분배 판단
- **공정한 비교**: 연차를 분모에서 빼므로 휴가자가 "일 안 한 사람"으로 과소평가되지 않음
- **투입량 정산**: 총 MM으로 인월 기준 정산 근거 확보
- **집중도**: 이슈 수 대비 MD로 소수 이슈에 깊게/다수 이슈에 얕게 붙어 있는지 확인

### 상세 차트 (멤버 클릭)

**일별 / 주별 / 월별** 탭 전환. MD 막대 + 시간(h) 라인, 월별 탭에는 **1MM 기준선**(주황 점선)을 그려 풀가동 대비 위치를 표시합니다. 하단 워크로그 원본 테이블로 개인 투입 내역을 그대로 확인합니다.

> **가동률 = 실제 일한 양(MD) ÷ 일할 수 있었던 양(근무일 − 연차·공휴일)**. 1.0 = 100%(풀가동). 이 프로젝트 기준 가동률이라, 여러 프로젝트를 합산하는 전사 종합 가동률과는 분모가 달라 의미가 다릅니다.

인력 분석은 **인별 / 팀별** 보기를 전환할 수 있습니다. 팀별 가동률은 팀원 비율의 단순 평균이 아니라 `팀 합계 MD ÷ 팀 합계 가용 MD`이며, 하위 팀 포함 필터와 팀 미지정 필터를 제공합니다.

## 5.5.3 팀 분석 — "담당 조직과 실제 기여가 일치하는가"

프로젝트에 지정한 [담당 팀](cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md#521-담당-팀)과 선택 기간의 워크로그 실제 기여 팀을 나란히 봅니다.

| 구분 | 의미 |
|---|---|
| **담당·기여** | 계획과 실행이 일치 |
| **담당이지만 기여 없음** | 책임 팀으로 지정됐지만 선택 기간에 워크로그 기여가 없음 |
| **미담당 기여** | 담당 팀이 아닌 조직이 실제 작업에 참여 |

- 비용 권한이 있으면 **프로젝트 전체 기간 기준** 팀별 비용도 표시합니다(위 기간 필터와 무관하다는 안내가 함께 표시됩니다).
- 팀 분석은 **현재 소속 기준**입니다. 과거에 다른 팀이었던 인원의 실적도 지금 소속된 팀에 집계됩니다.

## 5.5.4 진척률 — "일정 대비 진짜로 얼마나 끝났나"

프로젝트의 **현재 시점 진척 스냅샷**입니다. 이 화면의 핵심 철학은 **성격이 다른 세 가지를 한 숫자로 합치지 않는다**는 것입니다. (흔한 함정: "공수를 80% 썼으니 80% 끝났다" → 틀린 판단)

| 층 | 질문 | 계산 |
|---|---|---|
| **완성 진척**(핵심) | 얼마나 **끝났나** | Σ(이슈 진행률 × 계획공수) ÷ Σ(계획공수). 완료=100%, 진행 중=실투입/계획(최대 100%), 할 일=0% |
| **공수 진척** | 얼마나 **일했나** | 실투입 워크로그 누적. 완성도가 아닌 효율·리스크 신호 |
| **일정 진척** | 시간이 얼마나 **흘렀나** | 경과 근무일 ÷ 전체 근무일(휴일·주말 제외) |

### 핵심 판단 규칙

- **① 완성 vs 일정 (주 신호)**: 완성이 일정보다 임계치(기본 5%p, [7.1에서 조정](../07-%EC%84%A4%EC%A0%95/cloudjira--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md)) 이상 낮으면 **지연**
- **② 공수 vs 완성 (보조)**: 공수를 많이 썼는데 완성이 낮으면 **비효율·리스크**

> 상단 종합 헤더의 **차이(완성률 − 일정률)** 가 이 화면의 단일 핵심 신호입니다. **음수면 지연, 양수면 선행.**

### 영역별로 읽는 법

| 영역 | 무엇을 보여주나 | 어떤 인사이트를 얻나 |
|---|---|---|
| **종합 헤더** | 완성/일정 진척률, 차이(%p), 지연 배지(정상/주의/지연), 확정 지연·예측 지연, 예상 완료일 | 일정대로인지 **한 줄 결론**. 종료 예정일 초과 여부 선제 파악 |
| **진척 비교 막대** | 일정·완성·공수를 같은 0~100% 축에 병치 + 계획/실적 기성/실투입(MD) | 완성 막대가 일정보다 짧으면 지연, 공수 막대만 길면 비효율. **실적 기성 < 실투입**이면 쓴 공수만큼 못 끝낸 것 |
| **진척 추이(S-curve)** | 계획 누적(점선) vs 실적 누적(실선) + 오늘·종료 예정·예상 완료 마커 | 실선이 점선 아래로 처지면 진행이 느림. **곡선 모양으로 막판 몰림 예측** |
| **상태별 분포** | 완료/진행 중/할 일을 **개수** 또는 **공수(MD)** 기준으로 | 공수 기준 권장. 대기 비중이 큰데 일정이 임박하면 범위 리스크 |
| **지연·위험 이슈** | 기한 초과 미완료·공수 편차 큰 이슈 테이블 | **당장 손봐야 할 이슈를 우선순위로 식별** |

### 지연 지표 두 가지

- **확정 지연** = 이미 완료된 이슈의 (실적일 − 기한) 평균 → **회고**
- **예측 지연** = 남은 공수 추세로 본 예상 종료일 − 종료 예정일 → **예보**

> 예측 지연은 **낙관 근사치**입니다. 이슈별 예상 종료일의 최댓값 기준이라 병렬 작업 한계를 무시 — 실제보다 빠르게 잡힐 수 있어 보수적으로 해석하세요.

### 대표 사용 시나리오

- **주간 스탠드업**: 종합 헤더의 차이(%p)·지연 배지로 30초 상태 보고
- **일정 위험 조기 경보**: S-curve 실선이 점선 아래로 벌어지기 시작하면 인력 보강/범위 조정 판단
- **비효율 감지**: 공수율은 높은데 완성률이 낮은 구간 → 추정 오류·재작업·블로커 조사

### 제약

- 진척률은 현재 시점 전체 스냅샷이라 **기간 필터가 없습니다**(기준 기간은 프로젝트 시작~종료, 일정은 시작~오늘).
- **계획 작업량(Original Estimate)이 입력된 이슈가 없으면 계산할 수 없습니다.**
- 상단의 접이식 **"이 화면 읽는 법"** 가이드에서 각 지표의 정의·계산식을 확인할 수 있습니다.
