# 8. 통합 대시보드 (전사)

## 🔐 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 메뉴·화면 진입 (`/dashboard`) | `REPORT` 읽기 (없으면 **사이드바에 메뉴가 없고**, URL로 들어가도 권한 안내 화면이 뜹니다) |
| 종합 개요 · 일정 · 범위 · 자원 서브탭 | `REPORT` 읽기 |
| **비용** 서브탭 | `REPORT` 읽기 **+** `PROJECT_COST` 읽기 |
| **지금 재집계** 실행 | `REPORT` 쓰기 |

- 표시되는 프로젝트는 권한 세트의 **조회 범위**(`ALL` / `MEMBER_ONLY` / `TEAM_ONLY`)로 필터됩니다. 범위가 좁으면 전사 대시보드라도 일부 프로젝트만 비교됩니다.
- 가동률 밴드(과소/과부하/심한 과부하) 경계값은 [7.1 일반 설정](07-%EC%84%A4%EC%A0%95/cloudjira--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md)을 따릅니다.

---

**언제 쓰나** — 프로젝트 하나가 아니라 **여러 프로젝트를 한 화면에서 비교**할 때. 경영 보고, 포트폴리오 점검, 위험 프로젝트 선별에 씁니다.

## 8.1 화면 공통

| 요소 | 설명 |
|---|---|
| **기준 시각** | 마지막 집계 시각. 이 화면은 **실시간이 아니라 배치 집계 결과**입니다 |
| **지금 재집계** | 즉시 집계를 실행합니다. 백그라운드로 **수 초~수십 초** 걸리며 완료되면 화면이 갱신됩니다 |
| **프로젝트 필터 바** | 비교할 프로젝트를 선택(전체 선택/해제)하면 **아래 모든 위젯이 함께 반응**합니다 |

> ⚠️ **숫자가 방금 한 작업과 다르다면** 기준 시각을 먼저 확인하세요. 워크로그를 막 입력했다면 재집계 전까지 반영되지 않습니다.

## 8.2 종합 개요 — 프로젝트별 T/S/R 신호

각 프로젝트의 **일정(Time) / 범위(Scope) / 자원(Resource)** 상태를 **신호등(정상 / 주의 / 위험)** 으로 요약합니다. 행을 클릭하면 상세로 드릴다운합니다.

| 축 | 판정 기준 |
|---|---|
| **일정 (Time)** | 완성 진척 − 일정 진척 (음수로 벌어질수록 위험) |
| **범위 (Scope)** | 대기(할 일) 이슈 비중 |
| **자원 (Resource)** | 프로젝트 평균 가동률 밴드 — 과소 0.7 미만 / 과부하 1.1 이상 / 심한 과부하 1.3 이상 ([7.1 설정값](07-%EC%84%A4%EC%A0%95/cloudjira--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md)) |

**읽는 법**

- 세 축이 모두 초록이면 정상 운영 중입니다.
- **일정 적색 + 자원 과부하**는 "사람을 갈아넣는데도 못 따라가는" 상태 — 범위 조정이나 증원을 검토합니다.
- **일정 적색 + 자원 과소**는 투입 부족 신호입니다.
- **범위 적색**은 착수도 못한 일이 많다는 뜻이라, 일정이 아직 초록이어도 후반에 몰릴 위험이 큽니다.

## 8.3 비교 서브탭

| 서브탭 | 주요 위젯 |
|---|---|
| **일정 (Time)** | 프로젝트 일정 간트(경과율), 공수 추이(월/주·누적), 계획 대비 실적 공수 |
| **범위 (Scope)** | 완성률 vs 일정률, 이슈 상태 분포(완료/진행/대기), 리스크 TOP, 문제 이슈 버블(TOP 50) |
| **자원 (Resource)** | 롤/레벨 분포 비교, 작업 분포(인력 대비 공수), 인력 가동률(전사 종합 / 프로젝트별) |
| **비용 (Cost)** | 프로젝트별 총 인건비, 급여 구간 히스토그램 |

- 각 위젯에는 **계산식/해석 안내(ⓘ)** 가 있어 지표의 의미를 그 자리에서 확인할 수 있습니다.
- 팀 축 비교는 이 화면이 아니라 [6.3 자원 관리 > 팀 분석](06-%EC%9E%90%EC%9B%90-%EA%B4%80%EB%A6%AC/cloudjira--03-%ED%8C%80-%EB%B6%84%EC%84%9D.md)에서 제공합니다.

## 8.4 가동률 두 종류를 헷갈리지 마세요

| 지표 | 분모 | 특징 |
|---|---|---|
| **가동률(종합)** | 한 사람이 참여한 **모든 프로젝트 기간을 겹치지 않게 합산** | 이중 계상 방지. **프로젝트 필터와 무관**하게 고정 |
| **프로젝트별 가동률** | 그 프로젝트 기간의 실효 가용 MD | [5.5 인력 분석](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--05-%EB%B6%84%EC%84%9D-%EB%B0%8F-%EB%A6%AC%ED%8F%AC%ED%8A%B8.md#552-인력-분석--누가-과부하이고-누가-여유인가)과 같은 기준 |

> 두 숫자가 다르다고 오류가 아닙니다. **분모가 다른 서로 다른 지표**입니다.

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 사이드바에 메뉴가 없습니다 | `REPORT` 읽기 권한이 없습니다 |
| 프로젝트가 일부만 보입니다 | 권한 세트의 조회 범위가 `MEMBER_ONLY` 또는 `TEAM_ONLY`입니다 |
| 비용 서브탭이 없습니다 | `PROJECT_COST` 읽기 권한이 없습니다 |
| 숫자가 오래됐습니다 | 배치 집계 결과입니다. 기준 시각을 확인하고 **지금 재집계**를 실행하세요(`REPORT` 쓰기 필요) |
| 재집계 버튼이 없습니다 | `REPORT` **쓰기** 권한이 없습니다 |
| 인건비가 0인 프로젝트가 있습니다 | 급여 미등록·기간 미설정 등입니다 — [5.2 인건비가 0원으로 나올 때](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md#인건비가-0원으로-나올-때) |
