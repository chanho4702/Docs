# 7.4 설정 — 역할 관리

## 🔐 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 (`/backoffice/role`) | `ROLE_MANAGEMENT` 읽기 |
| 역할 추가·수정·삭제·빠른 추가 | `ROLE_MANAGEMENT` 쓰기 |

- 역할 **목록**은 `USER_MANAGEMENT` 읽기로도 조회됩니다(인력 관리·프로젝트 인력 화면의 선택지에 필요). 편집은 `ROLE_MANAGEMENT` 쓰기만 가능합니다.

---

**언제 쓰나** — 인력의 **역할(직무)** 을 정의할 때. 예: Data Engineer, DevOps Engineer, QA Engineer.

## 등록 방법 두 가지

| 방법 | 설명 |
|---|---|
| **역할 추가** | 이름과 설명을 입력해 하나씩 등록 |
| **빠른 추가** | 일반적인 직무 프리셋에서 골라 **한 번에 여러 개** 등록. 이미 있는 항목은 "이미 존재"로 표시되고 건너뜁니다 |

행에서 수정·삭제할 수 있습니다.

- 역할은 **권한과 무관합니다.** 화면 접근 권한은 [7.8 권한 관리](cloudjira--08-%EA%B6%8C%ED%95%9C-%EA%B4%80%EB%A6%AC.md)에서 따로 정합니다.
