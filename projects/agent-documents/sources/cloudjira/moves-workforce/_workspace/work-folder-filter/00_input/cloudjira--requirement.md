# 요구사항 — 트리·간트 폴더 필터 + 트리 폴더 구분 UI 개선 (2026-09-30)

## 확정 (제품 소유자)
1. **폴더 필터**: 작업관리 트리·간트 뷰의 필터 줄에 「폴더」 선택(드롭다운)을 추가한다. 고른 폴더와 그 **하위 폴더 전체**의 작업만 보인다. 여러 개 선택 가능 여부는 기존 필터 관례를 따른다. 트리와 간트는 **선택을 공유**한다(기존 tree↔gantt 필터 공유 방식과 같게, `WORK_VIEWS.md` 참조). 「폴더 없음」(폴더에 넣지 않은 작업) 선택지도 둔다.
2. **트리 폴더 구분 개선** — A + B:
   - A. 폴더 행 강조: 배경색(Atlaskit 토큰, 다크 모드 대응), 굵은 이름, 폴더 아이콘, 하위 작업 수·진척률 요약(간트 폴더 롤업과 같은 값).
   - B. 들여쓰기 안내선: 깊이마다 세로 안내선.

## 지킬 것
- 프론트 전용. 간트 데이터(`useGanttData`의 `folders`·`folderIssues`)를 재사용, 새 조회 없음.
- 필터는 순수 함수로(폴더 id 집합 → 하위 폴더 포함 확장 → 작업 거르기), 테스트.
- 폴더 계층은 임의 깊이·순환 방지 규칙(`GANTT.md`)을 따른다.
- 쿼리 키 변경 없음(필터는 화면 상태). URL 쿼리에 싣는 기존 필터 관례가 있으면 따른다.
- 간트는 SVAR 기반 — 필터로 작업을 걸러 넘기는 기존 경로(`filterGanttTasks`)에 폴더 조건을 얹는다. 폴더 노드 자체의 표시는 거른 결과에 맞춰(비어 버린 폴더는 숨김).
- 스피너 금지, 공용 UI, 번역 kr/en + merge, 문서(`WORK_VIEWS.md`) 갱신.
