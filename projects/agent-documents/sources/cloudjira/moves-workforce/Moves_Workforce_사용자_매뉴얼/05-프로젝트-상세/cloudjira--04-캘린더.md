# 5.4 캘린더

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | 「프로젝트 관리」 읽기 |
| 워크로그 수정·삭제 | 각 워크로그의 **작성자 본인만** (앱 권한과 무관) |
| 프로젝트 이벤트 추가·수정 | 「프로젝트 관리」 쓰기 |

- 프로젝트 조회 범위(소속 프로젝트만 / 내 팀만) 밖 프로젝트에서는 열리지 않습니다.
- 여기서 보이는 워크로그는 각자 [My Work](../cloudjira--02-my-work.md)에서 기록한 것과 같은 데이터입니다.

---

**언제 쓰나** — 프로젝트 전체의 **워크로그·이슈 일정·이벤트를 달력**으로 볼 때. [개인 캘린더](../cloudjira--02-my-work.md#캘린더-뷰)의 프로젝트 단위 버전입니다.

![그림 5-12 프로젝트 캘린더 이슈 모드](../images/05-calendar-issue-mode.png)
*그림 5-12. 프로젝트 캘린더(주간, 이슈 모드) — ① 작업자·작업 필터 ② 워크로그/이슈 모드 토글 ③ 상태 색 이슈 막대 ④ 공휴일 라벨 ⑤ 기간 미설정 N건.*

## 화면 구성

- **작업자 선택 / 작업 선택** 필터로 특정 인원·작업만 볼 수 있습니다.
- **월간 / 주간** 보기와 기간 이동을 지원합니다. 월간은 촘촘하게, 주간은 시간·제목을 자세히 보여줍니다.
- 오른쪽 위 **표시 모드** 토글:

| 표시 모드 | 달력에 보이는 것 |
|---|---|
| **워크로그** (기본) | 이슈별 워크로그(시간 범위·담당자)와 **일별 합계** |
| **이슈** | 프로젝트에 편입된 이슈의 **시작일~기한 기간 막대**, 상태 색(할 일 / 진행 중 / 완료). [작업 관리 간트](cloudjira--03-%EC%9E%91%EC%97%85-%EA%B4%80%EB%A6%AC.md#537-간트-보기)와 같은 일정 데이터를 씁니다 |

- 두 모드 모두 **프로젝트 이벤트**(예: "워크숍")와 **공휴일 라벨**이 표시됩니다.
- 이슈 모드에서 시작일·기한이 없는 이슈는 **기간 미설정 N건** 버튼에 모아 보여주며, 일정은 간트에서 지정하라고 안내합니다.

## 알아두기

- 여기 보이는 워크로그는 [My Work](../cloudjira--02-my-work.md)에서 각자 기록한 것과 같은 데이터입니다. 캘린더에서 확인하고, 수정은 작성자 본인이 합니다.
- 특정 인원의 투입 추이를 수치로 보려면 [5.5 인력 분석](cloudjira--05-%EB%B6%84%EC%84%9D-%EB%B0%8F-%EB%A6%AC%ED%8F%AC%ED%8A%B8.md#552-인력-분석)이 더 적합합니다.
- 여러 날에 걸친 이슈 막대와 개인 일정이 같은 주에 있으면 겹치지 않도록 줄이 나뉘어 표시됩니다.

> **연차·휴가처럼 종료일이 있는 일정을 등록할 때**는 화면에 표시되는 마지막 날짜가 실제 종료일과 맞는지 확인하세요. 종료일 처리 방식 때문에 하루 차이가 나는 사례가 있었습니다.
