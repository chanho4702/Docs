# 5.2 인력 관리

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 인력 목록 조회 | 「프로젝트 관리」 읽기 |
| 인력 추가·삭제, 역할·등급 수정 | 「프로젝트 관리」 쓰기 또는 「자원관리」 쓰기 |
| 담당 팀 조회 | 「프로젝트 관리」 읽기 또는 「자원관리」 읽기 |
| 담당 팀 편집·팀 전체 추가 | 「프로젝트 관리」 쓰기 또는 「자원관리」 쓰기 |
| **급여 관리** 서브탭 | 「비용」 읽기 (없으면 **서브탭 자체가 보이지 않음**) |
| 급여 금액 수정 | 「비용」 쓰기 |
| **작업 배정** 서브탭 | 「프로젝트 관리」 읽기 또는 「자원관리」 읽기 |
| 배정 실행 | 「프로젝트 관리」 쓰기 또는 「자원관리」 쓰기 **+ Jira 담당자 지정 권한** |

- 개인 금액이 보이려면 「비용」 읽기 **와** 급여 정책 **인원별**이 **둘 다** 충족돼야 합니다. 등급 기반 정책에서는 권한이 있어도 개인 금액이 숨겨집니다.
- 팀 구성 자체(팀 생성·팀원 배치)는 「팀 관리」 권한이며 [7.3](../07-%EC%84%A4%EC%A0%95/cloudjira--03-%ED%8C%80-%EA%B4%80%EB%A6%AC.md)에서 합니다.

**언제 쓰나** — 이 프로젝트에 **누가 참여하는지**, **인건비를 얼마로 잡을지**, **누구에게 무엇을 맡길지** 정할 때.

세 개의 서브탭으로 구성됩니다: **인력 목록 / 급여 관리 / 작업 배정**

## 5.2.1 담당 팀

인력 목록 상단에서 **담당 팀 여러 개**와 **주 담당 팀 하나**를 지정할 수 있습니다.

> **담당 팀과 프로젝트 인력은 별개 축입니다.** 팀을 지정해도 인력이 자동으로 추가되지 않습니다. 인력으로 넣으려면 **팀 전체 추가** 또는 **팀원 골라 담기**를 실행해야 합니다.

- 팀 카드에는 `이미 투입된 인원 / 팀 직속 인원`이 표시됩니다.
- **팀 전체 추가**는 이미 투입된 인원을 건너뛰고 나머지만 등록합니다. 결과는 "N명 추가, M명 건너뜀"으로 안내됩니다. 이 프로젝트의 담당 팀이 아닌 팀은 추가할 수 없습니다.
- 담당 팀을 모두 해제하면 이 프로젝트의 팀 배정이 사라진다는 경고가 표시됩니다.

> 팀 구성 자체는 [7.3 팀 관리](../07-%EC%84%A4%EC%A0%95/cloudjira--03-%ED%8C%80-%EA%B4%80%EB%A6%AC.md)에서 합니다.

## 5.2.2 인력 목록

| 컬럼 | 설명 |
|---|---|
| 사용자 | 멤버 이름/아바타. 그 사람이 소속 팀의 팀장이면 **팀장** 배지가 붙습니다 |
| 역할 | 예: DevOps Engineer, Data Engineer ([7.4에서 정의](../07-%EC%84%A4%EC%A0%95/cloudjira--04-%EC%97%AD%ED%95%A0-%EA%B4%80%EB%A6%AC.md)) |
| 등급 | 예: Junior / Mid-level / Senior / Lead ([7.5에서 정의](../07-%EC%84%A4%EC%A0%95/cloudjira--05-%EB%93%B1%EA%B8%89-%EA%B4%80%EB%A6%AC.md)) |
| 급여 | 인원별 정책에서 쓰는 금액. 등급 기반 정책에서는 등급 급여 범위 표시 |
| 추가 작업 | 삭제 |

### 인력 추가하기

1. 우측 위 **+ 사용자 추가**를 누릅니다.
2. Jira 사용자를 **이름 또는 이메일로 검색**합니다.
3. 추가 후 **역할 / 등급 셀을 클릭**해 그 자리에서 지정합니다.

> 급여 수정은 「비용」 권한이 있는 사용자가 **급여 관리** 서브탭에서 수행합니다.

> **여기 등록해야 집계에 들어갑니다.** 이슈 담당자로만 지정된 사람은 인건비·가동률 집계에 포함되지 않습니다.

## 5.2.3 급여 관리

이 화면에서 정한 금액이 **비용 탭 · 대시보드 총 인건비 · 전사 대시보드 비용 축**의 원천이 됩니다.

![그림 5-5 급여 관리 서브탭](../images/05-salary-management.png)
*그림 5-5. 급여 관리(인원별 정책) — ① 인원별 투입 유형(프로젝트/연봉) ② 투입 급여·개인 연봉 ③ 계산된 인건비 ④ 정책 안내. 금액은 예시 데이터로 캡처.*

### 금액이 저장되는 세 곳

| 구분 | 입력 화면 | 의미 |
|---|---|---|
| **개인 연봉** | [설정 > 인력 관리](../07-%EC%84%A4%EC%A0%95/cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md) | 그 사람의 연봉. 프로젝트와 무관한 인사 정보 |
| **투입 급여** | 프로젝트 상세 > 인력 > **급여 관리** | **이 프로젝트에** 그 사람을 쓰는 데 잡는 금액 |
| **등급 급여 밴드** | [설정 > 등급 관리](../07-%EC%84%A4%EC%A0%95/cloudjira--05-%EB%93%B1%EA%B8%89-%EA%B4%80%EB%A6%AC.md) | 등급별 가격표(하한·상한·대표값). 개인이 아니라 직급에 값을 매김 |

세 곳이 나뉜 이유는 조직마다 인건비를 잡는 방식이 다르기 때문입니다. 사람별로 잡는 곳도 있고, 직급 테이블로 일괄 산정하는 곳도 있습니다.

### 계산 방식은 급여 정책이 결정합니다

전역 설정([설정 > 일반 설정 > 급여 정책](../07-%EC%84%A4%EC%A0%95/cloudjira--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md))에서 조직 전체가 쓸 방식을 하나 고릅니다.

#### ① 인원별(기본값)

사람별 금액을 그대로 씁니다. 프로젝트 인력마다 **투입 유형**을 다시 고릅니다.

| 투입 유형 | 계산 | 언제 쓰나 |
|---|---|---|
| **프로젝트** (기본) | 투입 급여를 **그대로** 인정 | "이 프로젝트에 3,000만원어치 투입" 같은 계약 단위 |
| **연봉** | 연봉을 **투입 기간만큼 잘라서** 인정 | 정규 인력을 기간 비례로 배분할 때 |

> 두 금액(투입 급여·개인 연봉)이 모두 저장돼 있어도 **선택한 투입 유형에 해당하는 금액만** 계산에 씁니다.

#### ② 등급 기반

개인 금액을 **아예 읽지 않고** 그 사람의 등급 대표값으로 계산합니다. 개인 연봉을 노출하지 않으면서 원가를 산출하고 싶을 때 사용하며, 이 정책에서는 개인 금액 편집이 잠깁니다.

> 저장된 개인 금액을 **지우지는 않습니다.** 정책을 되돌리면 원래 숫자가 그대로 살아납니다.

### 계산식

**연봉** 유형과 **등급 기반** 정책은 **같은 식**을 씁니다. 연봉을 어디서 가져오는지만 다릅니다.

```
투입 개월수 = 총 달력일수(종료일 포함) ÷ 30.4375
인건비      = (연봉 ÷ 12) × 투입 개월수
```

- 연봉 유형은 **개인 연봉**에서, 등급 기반은 **등급 대표값**에서 연봉을 가져옵니다.
- 프로젝트 유형은 환산 없이 투입 급여를 그대로 씁니다.
- **30.4375**는 365.25 ÷ 12로, 윤년까지 반영한 평균 월 길이입니다.

**근무일이 아니라 달력일을 쓰는 이유** — 공휴일과 연차에도 급여는 지급되기 때문입니다. 실제 지급 방식과 맞추기 위해 달력일 기준을 사용합니다.

| 프로젝트 기간 | 달력일 | 투입 개월수 |
|---|---|---|
| 1/1 ~ 12/31 | 365일 | 11.99 (≈ 12개월) |
| 15일간 | 15일 | 0.49 |
| 하루 (시작일 = 종료일) | 1일 | 0.03 |

### 인건비가 0원으로 나올 때

[비용 화면](cloudjira--05-%EB%B6%84%EC%84%9D-%EB%B0%8F-%EB%A6%AC%ED%8F%AC%ED%8A%B8.md#555-비용)의 **미산정 인원** 지표로 확인할 수 있습니다.

| 정책 | 0원이 되는 조건 |
|---|---|
| 인원별 | 투입 유형이 **연봉**인데 **개인 연봉이 등록되지 않음** |
| 등급 기반 | 등급 미지정 / 등급에 밴드 미설정 / 대표값이 0 |
| 공통 | **프로젝트 기간이 설정되지 않음** → 투입 개월수 0 → 결과 0 |

> 프로젝트 유형의 0원은 미산정으로 세지 않습니다. "무상 투입"이라는 정상적인 배정일 수 있기 때문입니다.

### 누가 볼 수 있나

급여 금액이 보이려면 **두 조건이 모두** 충족돼야 합니다.

1. 「비용」 **읽기 권한**이 있을 것
2. 급여 정책이 **인원별**일 것 (등급 기반에서는 개인 금액이 숨겨집니다)

권한이 없으면 금액이 **0원으로 표시되는 것이 아니라 항목 자체가 나타나지 않습니다.** 대시보드의 총 인건비 카드도 마찬가지입니다.

## 5.2.4 작업 배정

"이 사람에게 무엇을 맡길까"를 정하는 화면입니다. 좌우 패널은 접거나 폭을 조절할 수 있습니다.

- 프로젝트 인력 후보의 **스킬 적합도**와 **현재 부하**를 함께 보고 이슈 또는 프로젝트에 배정합니다.
- 배정할 이슈가 없으면 확인 후 **프로젝트 인력으로만 추가**할 수도 있습니다.

> 담당자·동료를 지정하는 세 가지 경로의 차이는 [5.3 담당자·동료 관리](cloudjira--03-%EC%9E%91%EC%97%85-%EA%B4%80%EB%A6%AC.md#지정하는-세-가지-경로)를 참고하세요.
> 전사 범위로 사람을 찾아 배정하려면 [6.4 프로젝트 배정](../06-%EC%9E%90%EC%9B%90-%EA%B4%80%EB%A6%AC/cloudjira--04-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EB%B0%B0%EC%A0%95.md)을 사용합니다.
