# 7.3 팀 관리

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | 「팀 관리」 읽기 |
| 팀 추가·수정·삭제 | 「팀 관리」 쓰기 |
| 계층 이동(드래그) | 「팀 관리」 쓰기 |
| 팀원 배치·소속 해제 | 「팀 관리」 쓰기 |
| 팀 권한 세트 지정 | 「팀 관리」 쓰기. **자기 권한을 넘는 세트는 걸 수 없습니다** |

- 팀 **목록**은 「인력 관리」 읽기로도 조회됩니다(인력 관리 화면의 팀 컬럼·필터에 필요). 편집은 「팀 관리」 쓰기만 가능합니다.
- 팀장 후보는 [7.2 인력 관리](cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md)에 등록된 인원으로 한정됩니다.
- 여기서 지정한 팀 권한 세트는 [7.8 권한 관리](cloudjira--08-%EA%B6%8C%ED%95%9C-%EA%B4%80%EB%A6%AC.md)에서 만든 세트 중에서 고릅니다.

---

**언제 쓰나** — 조직 계층과 팀 소속을 구성할 때. 좌측 **팀 트리**, 우측 **선택 팀 상세** 구성입니다.

![그림 7-5 팀 관리](../images/07-teams.png)
*그림 7-5. 팀 관리 — ① 팀 트리(검색·모두 펼치기/접기·팀 미지정 N명) ② 팀 추가 ③ 선택 팀 상세(팀장·권한 세트 상속 문장) ④ 팀원 목록(팀장 맨 앞)·팀원 배치·소속 해제.*

## 팀 만들기

1. **팀 추가**를 누릅니다.
2. 입력 항목:

| 항목 | 설명 |
|---|---|
| 팀명 | 중복 불가 |
| 상위 팀 | 비우면 **최상위 팀**으로 생성 |
| 팀장 | **서비스에 등록된 인원**([7.2](cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md)) 중에서만 지정 가능. **지정하면 소속이 이 팀으로 변경됩니다** |
| 팀 권한 세트 | **개인 권한이 지정되지 않은 팀원에게만** 적용 |
| 설명 | |

> 팀장으로 지정된 사람은 [마이페이지 > 내 팀](../cloudjira--03-%EB%A7%88%EC%9D%B4%ED%8E%98%EC%9D%B4%EC%A7%80.md#32-내-팀-팀장-전용)에서 팀원 현황을 볼 수 있게 되고, [자원 관리](../06-%EC%9E%90%EC%9B%90-%EA%B4%80%EB%A6%AC/cloudjira--README.md)의 조회 범위도 자신의 팀으로 열립니다.

## 팀장 규칙

| 규칙 | 화면에서 일어나는 일 |
|---|---|
| **팀장은 반드시 그 팀 소속** | 다른 팀 사람을 팀장으로 지정하면 저장과 함께 **소속이 이 팀으로 옮겨집니다.** 지정 폼에 "팀장으로 지정하면 소속이 이 팀으로 변경됩니다" 안내가 표시됩니다 |
| **한 사람은 한 팀만 이끕니다** | 이미 다른 팀의 팀장인 사람은 지정할 수 없습니다(겸임 불가). 먼저 그 팀의 팀장을 바꾸세요 |
| **팀장은 팀 밖으로 옮길 수 없습니다** | 팀원 배치·소속 해제·[7.2 인력 수정](cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md)에서 팀장을 다른 팀으로 옮기려 하면 "팀장은 이끄는 팀 밖으로 옮길 수 없습니다. 팀장 지정을 먼저 해제하세요"로 거부됩니다 |
| 팀장 해제·교체 | 이전 팀장의 소속은 그대로 둡니다(자동으로 빠지지 않습니다) |
| 팀장이 **인력 삭제**되면 | 그 팀의 팀장이 비워집니다 |

팀장은 팀원 목록 **맨 앞**에 **팀장** 배지와 함께 표시되고, [인력 관리](cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md)·[프로젝트 인력 목록](../05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md)에서도 같은 배지가 붙습니다.

## 계층 바꾸기

- 팀을 끌어 다른 팀 위에 놓으면 **상위 팀이 바뀝니다.**
- **"여기에 놓으면 최상위 팀이 됩니다"** 영역에 놓으면 최상위로 이동합니다.
- **모두 펼치기 / 모두 접기**, **팀 검색**을 제공합니다.

**차단되는 이동**

| 상황 | 안내 |
|---|---|
| 하위 팀 밑으로 이동 | "하위 팀 밑으로는 옮길 수 없습니다" (순환 방지) |
| 계층 깊이 한도 초과 | "계층 깊이 한도를 초과합니다" — 하위 팀까지 함께 이동하기 때문입니다 |
| 목록이 오래됨 | "지금은 팀을 옮길 수 없습니다. 목록을 새로고침한 뒤 다시 시도하세요" |

## 팀원 배치

- **팀원 배치** 버튼으로 여러 명을 한 번에 넣습니다. **한 번에 최대 500명.**
- **사용자는 하나의 팀에만 속합니다.** 다른 팀 소속자를 선택하면 **이 팀으로 이동**합니다. 단, 다른 팀의 **팀장**은 데려올 수 없습니다.
- **소속 해제 (N)** 으로 선택 인원을 팀 미지정 상태로 만듭니다. 팀장은 해제할 수 없습니다.
- 좌측 트리 하단에서 **팀 미지정 N명**을 확인할 수 있습니다.

## 팀 권한 상속

팀에 권한 세트를 지정하면, **개인 권한이 "팀 권한 상속"인 팀원**이 그 권한을 따릅니다. 상세 화면에 현재 상태가 문장으로 표시됩니다.

| 표시 | 의미 |
|---|---|
| 이 팀의 권한 세트: {이름} | 이 팀이 직접 권한을 가짐 |
| 상위 팀 '{팀}'의 권한 세트({이름})를 상속합니다 | 상위에서 물려받는 중 |
| **이 팀과 상위 팀 어디에도 권한 세트가 없습니다** | 이 팀에 배치되고 개인 권한이 '팀 권한 상속'인 사용자는 **모든 권한을 잃습니다** |

> 팀장을 새로 지정하면 그 사람도 이 팀으로 옮겨져 팀 세트를 상속받을 수 있으므로, 팀 권한 세트는 **지정자 자신의 권한을 넘지 않는 범위**에서만 걸 수 있습니다.

## 팀 삭제

- 하위 팀은 **상위 팀으로 이동**하고, 팀원은 **팀 미지정** 상태가 됩니다.
- 삭제 전 미리보기로 알려주는 것:
  - **권한을 잃는 인원 수** (팀 권한을 상속받던 사람)
  - **상속이 바뀌는 인원 수** (하위 팀 소속자)
- 프로젝트 배정 정리 결과도 함께 안내됩니다.

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| "순환 참조가 감지된 팀이 있습니다" 경고 | 상위 팀 설정이 서로를 가리키고 있습니다. 해당 팀의 상위 팀을 다시 지정하세요 |
| "상위 팀 연결이 유효하지 않아 최상위로 표시 중" | 상위 팀이 삭제됐거나 조회되지 않습니다. 상위 팀을 다시 지정하세요 |
| "팀 수가 조회 한도를 초과해 일부만 표시됩니다" | 관리자에게 문의하세요 |
| 팀장 후보 목록이 비어 있습니다 | [7.2 인력 관리](cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md)에서 인원을 먼저 등록해야 합니다 |
| 팀장으로 지정했더니 그 사람 소속이 바뀌었습니다 | 정상입니다. 팀장은 그 팀의 구성원이어야 합니다 |
| "팀장은 이끄는 팀 밖으로 옮길 수 없습니다" | 그 팀에서 팀장을 먼저 바꾸거나 비운 뒤 이동하세요 |
| 배치하려는 인원이 "이 팀 범위 밖"이라고 나옵니다 | 목록을 새로고침한 뒤 다시 시도하세요 |
