# 8. 통합 대시보드 (전사)

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 메뉴·화면 진입 | 「리포트」 읽기 (없으면 **사이드바에 메뉴가 없고**, 주소로 들어가도 권한 안내 화면이 뜹니다) |
| 종합 개요 · 일정 · 범위 · 자원 서브탭 | 「리포트」 읽기 |
| **비용** 서브탭 | 「리포트」 읽기 **+** 「비용」 읽기 |
| **지금 재집계** 실행 | 「리포트」 쓰기 |

- 표시되는 프로젝트는 권한 세트의 **조회 범위**(전체 / 소속 프로젝트만 / 내 팀만)로 필터됩니다. 범위가 좁으면 전사 대시보드라도 일부 프로젝트만 비교됩니다.
- 가동률 밴드(과소/과부하/심한 과부하) 경계값은 [7.1 일반 설정](07-%EC%84%A4%EC%A0%95/cloudjira--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md)을 따릅니다.

---

**언제 쓰나** — 프로젝트 하나가 아니라 **여러 프로젝트를 한 화면에서 비교**할 때. 경영 보고, 포트폴리오 점검, 위험 프로젝트 선별에 씁니다.

![그림 8-1 통합 대시보드 상단](./images/08-portfolio-overview.png)
*그림 8-1. 통합 대시보드 — ① 기준 시각과 지금 재집계 ② 프로젝트 필터 바(인원·투입 MM·인건비 요약) ③ 종합 개요 T/S/R 신호등 표 ④ 비교 서브탭(일정·범위·자원·비용).*

## 8.1 화면 공통

| 요소 | 설명 |
|---|---|
| **기준 시각** | 마지막 집계 시각. 이 화면은 **실시간이 아니라 배치 집계 결과**입니다 |
| **지금 재집계** | 즉시 집계를 실행합니다. 백그라운드로 **수 초~수십 초** 걸리며 완료되면 화면이 자동 갱신됩니다. 일부 프로젝트 집계가 실패하면 "직전 값 표시" 안내가 붙습니다 |
| **프로젝트 필터 바** | 비교할 프로젝트를 선택(전체 선택/해제)하면 **아래 모든 위젯이 함께 반응**합니다. 선택 프로젝트의 인원·투입 MM·인건비 합계가 요약됩니다 |

> **숫자가 방금 한 작업과 다르다면** 기준 시각을 먼저 확인하세요. 워크로그를 막 입력했다면 재집계 전까지 반영되지 않습니다.

## 8.2 종합 개요(T/S/R 신호)

각 프로젝트의 **일정(Time) / 범위(Scope) / 자원(Resource)** 상태를 **신호등(정상 / 주의 / 위험)** 으로 요약합니다. **신호등 ↔ 수치표** 보기를 전환할 수 있고, 행을 클릭하면 프로젝트 상세로 드릴다운합니다.

| 축 | 판정 기준 |
|---|---|
| **일정 (Time)** | 완성 진척 − 일정 진척 (음수로 벌어질수록 위험) |
| **범위 (Scope)** | 대기(할 일) 이슈 비중 |
| **자원 (Resource)** | 프로젝트 평균 가동률 밴드 — 과소 0.7 미만 / 과부하 1.1 이상 / 심한 과부하 1.3 이상 ([7.1 설정값](07-%EC%84%A4%EC%A0%95/cloudjira--01-%EC%9D%BC%EB%B0%98-%EC%84%A4%EC%A0%95.md)) |

**읽는 법**

- 세 축이 모두 초록이면 정상 운영 중입니다.
- **일정 적색 + 자원 과부하**는 투입을 늘려도 일정을 따라가지 못하는 상태 — 범위 조정이나 증원을 검토합니다.
- **일정 적색 + 자원 과소**는 투입 부족 신호입니다.
- **범위 적색**은 착수도 못한 일이 많다는 뜻이라, 일정이 아직 초록이어도 후반에 몰릴 위험이 큽니다.

## 8.3 비교 서브탭

| 서브탭 | 위젯 |
|---|---|
| **일정 (Time)** | 프로젝트 일정(간트·경과율) · 공수 추이 비교(월/주·누적) · 리스크 TOP 프로젝트 |
| **범위 (Scope)** | 이슈 상태 분포(완료/진행/대기) · 완성률 vs 일정률 · 계획 대비 실적 공수 · 문제 이슈 한눈에(버블 TOP 50) · **토폴로지**(8.4) · 이슈 완료율 vs 진척률 · 지연 이슈가 몰린 담당자 |
| **자원 (Resource)** | 롤/레벨 분포 비교 · 인력 가동률(전사 종합 / 프로젝트별) · 작업 분포(투입 인력 대비 공수) · 인력 집중도 · 가동률과 투입 공수(산점도) · 전사 배정 관계도 |
| **비용 (Cost)** | 전사 비용 요약 · 계획 대비 실집행 · 비용 초과 위험 순위 · 소진율 vs 진척률 · 전사 월별 소진 추이 · 역할/레벨별 비용 · 완료 시 예상 비용 · MD 단가 비교 |

- 각 위젯에는 **계산식/해석 안내(ⓘ)** 가 있어 지표의 의미를 그 자리에서 확인할 수 있습니다.
- 일부 위젯은 **상단 프로젝트 필터와 무관**하게 전사 기준으로 그립니다(전사 가동률 분포, 지연 이슈가 몰린 담당자, 전사 배정 관계도). 위젯의 안내 문구에 명시돼 있습니다.
- 비용 서브탭은 「비용」 권한이 없으면 "인건비 조회 권한이 없어 비용 정보를 표시하지 않습니다"로 가려집니다. 급여 정책을 바꾼 뒤에는 **재집계 전까지** 이전 집계의 인건비를 표시하지 않습니다.
- 팀 축 비교는 이 화면이 아니라 [6.3 자원 관리 > 팀 분석](06-%EC%9E%90%EC%9B%90-%EA%B4%80%EB%A6%AC/cloudjira--03-%ED%8C%80-%EB%B6%84%EC%84%9D.md)에서 제공합니다.

## 8.4 토폴로지

범위 서브탭 상단의 **Workforce(RMS) 프로젝트 · 상태 · 이슈 토폴로지**는 `Workforce 허브 → 앱 프로젝트 → (Jira 스페이스) → 작업 상태 → 이슈` 경로를 관계망으로 그립니다.

![그림 8-2 토폴로지 위젯](./images/08-portfolio-topology.png)
*그림 8-2. 토폴로지 — ① 계층 필터(프로젝트/스페이스/상태)와 작업 상태 필터 ② Workforce 허브 ③ 프로젝트 노드(크기 = 투입 MD) ④ 상태 노드를 눌러 펼친 이슈 노드 ⑤ 스페이스 이슈 패널.*

| 조작 | 결과 |
|---|---|
| **계층** 필터 | 프로젝트까지 / 스페이스까지 / 상태까지 중 어디까지 펼칠지 |
| **작업 상태** 필터 | 할 일 / 진행 중 / 완료 중 보고 싶은 상태만 |
| 상태 노드 클릭 | 그 상태의 이슈가 그래프에 펼쳐집니다(여러 노드 동시 가능). 다시 누르면 접힘 |
| **전체 이슈 펼치기 / 모두 접기** | 한 번에 펼치거나 접기 |
| 프로젝트 노드 클릭 | 프로젝트 상세로 이동 |
| 스페이스 노드 클릭 | 오른쪽에 **스페이스 이슈** 패널(최대 300건, 실적·계획 포함) |
| 이슈 노드 클릭 | Jira에서 엽니다 |

- 프로젝트 노드 크기는 투입 공수(MD), 스페이스 노드 크기는 이슈 수, 이슈 노드 크기는 실제 투입 공수입니다.
- 프로젝트가 많으면 **위험도 상위만** 먼저 표시하고 **전체 표시**로 펼칠 수 있습니다.
- "스페이스 계층은 다음 집계 후 표시됩니다"가 뜨면 아직 스페이스 정보가 집계되지 않은 것입니다. 재집계 후 다시 열어 보세요.

## 8.5 가동률 두 종류의 차이

| 지표 | 분모 | 특징 |
|---|---|---|
| **가동률(종합)** | 한 사람이 참여한 **모든 프로젝트 기간을 겹치지 않게 합산** | 이중 계상 방지. **프로젝트 필터와 무관**하게 고정 |
| **프로젝트별 가동률** | 그 프로젝트 기간의 실효 가용 MD | [5.5 인력 분석](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--05-%EB%B6%84%EC%84%9D-%EB%B0%8F-%EB%A6%AC%ED%8F%AC%ED%8A%B8.md#552-인력-분석)과 같은 기준 |

> 두 숫자가 다르다고 오류가 아닙니다. **분모가 다른 서로 다른 지표**입니다.

## 8.6 프로젝트 상세 화면과의 관계

| 질문 | 이 화면 (8장) | 프로젝트 상세 (5장) |
|---|---|---|
| 어느 프로젝트가 위험한가? | **종합 개요 신호등**으로 선별 | — |
| 왜 위험한가? | 비교 서브탭·토폴로지로 축을 좁힘 | [5.5 진척률](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--05-%EB%B6%84%EC%84%9D-%EB%B0%8F-%EB%A6%AC%ED%8F%AC%ED%8A%B8.md#554-진척률)에서 원인 이슈까지 추적 |
| 누구를 조정할까? | 자원 서브탭에서 부하 비교 | [5.2 인력 관리](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md) · [6.4 프로젝트 배정](06-%EC%9E%90%EC%9B%90-%EA%B4%80%EB%A6%AC/cloudjira--04-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EB%B0%B0%EC%A0%95.md) |

**권장 흐름**: 통합 대시보드에서 **위험 프로젝트를 고르고** → 프로젝트 상세 진척률에서 **원인을 찾고** → 자원 관리에서 **사람을 조정**합니다.

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 사이드바에 메뉴가 없습니다 | 「리포트」 읽기 권한이 없습니다 |
| 프로젝트가 일부만 보입니다 | 권한 세트의 조회 범위가 "소속 프로젝트만" 또는 "내 팀만"입니다 |
| 비용 서브탭이 가려져 있습니다 | 「비용」 읽기 권한이 없거나, 급여 정책 변경 후 아직 재집계하지 않았습니다 |
| 숫자가 오래됐습니다 | 배치 집계 결과입니다. 기준 시각을 확인하고 **지금 재집계**를 실행하세요(「리포트」 쓰기 필요) |
| 재집계 버튼이 없습니다 | 「리포트」 **쓰기** 권한이 없습니다 |
| 토폴로지에 스페이스 계층이 없습니다 | 다음 집계 후 표시됩니다. 지금 재집계를 실행하세요 |
| 인건비가 0인 프로젝트가 있습니다 | 급여 미등록·기간 미설정 등입니다 — [5.2 인건비가 0원으로 나올 때](05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/cloudjira--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md#인건비가-0원으로-나올-때) |
