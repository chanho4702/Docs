> **[이미지 삽입 위치 · 추가 캡처 필요]** 인력 분석 — ① 퀵 필터와 기준값(1MD·1MM) ② 상단 조망 차트(인원별 가동률 · 팀별 투입) ③ 인별/팀별 전환 ④ 멤버 표(실효 가용 MD·가동률 바) ⑤ 멤버 클릭 시 일/주/월 상세.


### 상단 조망 차트

| 차트 | 내용 |
|---|---|
| **인원별 가동률** | 가동률 상위 인력(**최대 20명**)을 막대로. 100% 기준선과 색 밴드로 과부하 여부를 바로 읽습니다 |
| **팀별 투입** | 선택 기간의 팀별 투입 공수 합계 |

### 멤버 표

프로젝트 멤버별 투입 공수(MD/MM)와 **가동률**을 기간 기준으로 분석합니다.

- **퀵 필터**: 오늘 / 이번 주 / 이번 달 / 지난 주 / 지난 달, 또는 날짜 직접 선택
- 상단 기준값: `1MD = N h · 1MM = M 근무일(= M×N h) · MM = MD ÷ M`

| 컬럼 | 의미 |
|---|---|
| 총 MM | 투입 공수를 인월로 환산(`총MD ÷ 1MM 근무일`) — 절대 투입량 |
| 실효 가용 MD | 기간 근무일에서 **연차·공휴일을 뺀** 실제 출근 가능 일수(가동률 분모). 차감이 있으면 주황색으로 내역 표시 |
| 총 MD / 총 시간 / 이슈 수 | 실제 투입 공수·시간과 관여한 이슈 수 |
| 가동률 | `총 MD ÷ 실효 가용 MD`. 진행 바 + % |

**가동률 색상**
회색 <50%(저활용) / 초록 50~80% / 파랑 80~100%(적정) / 빨강 >100%(과부하)

### 활용

- **부하 균형**: 빨강(과부하)·회색(저활용)을 비교해 업무 재분배 판단
- **공정한 비교**: 연차를 분모에서 빼므로 휴가자가 "일 안 한 사람"으로 과소평가되지 않음
- **투입량 정산**: 총 MM으로 인월 기준 정산 근거 확보
- **집중도**: 이슈 수 대비 MD로 소수 이슈에 깊게/다수 이슈에 얕게 붙어 있는지 확인

### 상세 차트 (멤버 클릭)

**일별 / 주별 / 월별** 탭 전환. MD 막대 + 시간(h) 라인, 월별 탭에는 **1MM 기준선**(주황 점선)을 그려 풀가동 대비 위치를 표시합니다. 하단 워크로그 원본 테이블(이슈 타입 아이콘 포함)로 개인 투입 내역을 그대로 확인합니다.

> **가동률 = 실제 일한 양(MD) ÷ 일할 수 있었던 양(근무일 − 연차·공휴일)**. 1.0 = 100%(풀가동). 이 프로젝트 기준 가동률이라, 여러 프로젝트를 합산하는 전사 종합 가동률과는 분모가 달라 의미가 다릅니다.

인력 분석은 **인별 / 팀별** 보기를 전환할 수 있습니다. 팀별 가동률은 팀원 비율의 단순 평균이 아니라 `팀 합계 MD ÷ 팀 합계 가용 MD`이며, 하위 팀 포함 필터와 팀 미지정 필터를 제공합니다.

## 버튼·입력 항목과 처리 결과 상세

인력 분석은 선택한 기간에서 프로젝트 인력의 투입과 실효 가용량을 비교합니다.

| 버튼·입력 항목 | 기능·사용 조건·변경 대상 | 결과 확인과 문제 대응 |
|---|---|---|
| 기간·빠른 선택 | 해당 기간의 시간·MD·MM·가용량을 조회합니다. 기본은 이번 달 1일~오늘입니다. | 날짜 순서와 실제 포함 날짜를 확인합니다. |
| 인력별·팀별·팀·하위 팀 | 같은 기간의 개인 또는 팀 합계를 표시합니다. 팀 가동률은 팀 투입 합÷팀 가용량 합이며 개인 비율 평균이 아닙니다. | 현재 소속 기준으로 팀을 나눕니다. 500명 초과 프로젝트에서는 팀 보기·필터가 제한될 수 있습니다. |
| 인력 선택·분석·일/주/월 | 선택 인력의 기록을 일·주·월 축으로 확인합니다. 월별 상세에는 적용된 1MM 기준이 포함됩니다. | 다른 사람의 기록을 본인 기록으로 오인하지 않도록 선택 이름·이슈·날짜를 확인합니다. |
| 가용 MD·휴일·휴가·가동률 | 가용량은 휴일·개인 일정을 반영한 분모입니다. 기록이 없는 구성원도 가용량 분모에 영향을 줄 수 있습니다. | 가용량 0 또는 미산정 안내를 실제 낮은 성과로 해석하지 않습니다. |
