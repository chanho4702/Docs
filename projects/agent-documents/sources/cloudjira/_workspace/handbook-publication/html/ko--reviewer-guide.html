앱과 문서

Moves Approval for Confluence는 Confluence Cloud 페이지 또는 특정 영역에 순차 승인을 요청하고 결정·버전별 이력을 기록합니다. 결재선·승인 그룹·참조·위임·서명 PIN·일괄 승인·결재란·PDF 증명서를 지원합니다.

사용 안내는 빠른 시작, 설치는 설치와 준비, 데이터 항목과 권한은 데이터·보안을 확인합니다. 이 앱의 문서를 Jira 또는 Confluence Data Center용 안내로 사용하지 않습니다.

실행과 기대 결과

각 종료 시나리오는 별도 요청으로 실행하고, 바꾼 정책은 다음 테스트 전에 원래 조건으로 복원합니다.

확인 실행 기대 결과
진입·설치 업무함, 페이지 승인 창, 관리자 설정 열기 화면이 로드되며 기본 페이지 편집도 정상 동작
순차 승인 A가 B → C 순서로 요청하고 각각 승인 C는 먼저 결정할 수 없고 최종 단계 뒤 승인 완료
반려·회수 별도 요청에서 B 반려, 다른 요청에서 A 회수 각 종료 상태·사유·처리 이력 기록
문서 수정 진행 중 편집 후 새 버전으로 다시 상신 편집만으로 종료되지 않으며 재상신 시 이전 요청 종료·새 요청 생성
영역 영역 요청 후 매크로 삭제 페이지 전체와 별도 상태, 영역 제거 시 자동 회수
권한 D가 목록과 상세 접근 시도 제한 문서 정보가 노출되지 않음
마감 준비한 기한 초과 요청에서 결정·새 요청 시도 결정 거절, 새 요청 시 지난 요청 만료
PIN·위임 PIN 필수와 유효한 위임으로 각각 결정 PIN 확인, 원 승인자와 실제 대리 처리자 기록
참조·알림 참조 지정 후 생성·결과와 댓글 확인 참조는 결정 불가, 댓글 권한 실패가 결정 기록을 되돌리지 않음
일괄 승인 현재 차례인 여러 요청 선택 후 처리 요청별 성공·실패 건수 확인
파일 종료 요청 PDF, 업무함 Excel 다운로드 대상 버전·요청 ID 확인, 목록 내보내기 범위 확인
기록 정리 기간 지난 기록 내보내기 후 삭제 확정한 내보내기 범위만 삭제, 진행 중 요청 제외
언어 한국어·영어 설정의 계정으로 확인 같은 기능과 대응 문서 이용 가능
라이선스 유료 출시 구성에서 비활성 상태 확인 새 요청·결정 차단, 설정 접근 가능

실행자는 제출 버전, 날짜·시간대, 계정 역할, 실제 결과와 화면 증빙을 기록합니다. 마감·보관 테스트를 위해 운영 데이터 날짜를 변경하지 않습니다.
