# Requester guide

## Navigate the inbox

Open **Apps → Moves Approval** in Jira to use the full-page inbox. The sidebar and main content scroll independently. Collapse the sidebar for more working space, or expand it to read menu names even on a narrow screen.

Use the left sidebar for your approval tasks, waiting items, requests, completed items, Cc, timesheets and notifications. Team timesheets appear for team leads. A collapsed sidebar or narrow screen uses icons; hover or focus an icon to read its menu name. Inbox views, filters and settings subsections are restored from the URL after going back or refreshing.

## Request a general issue approval

General approval requesters need issue edit permission. Approvers and Cc recipients must be able to view the issue.

1. Open the issue, then **Moves Approval** or **••• → Request approval**.
2. Select **General approval (review)**. To move to a governed status, choose [Transition approval](cloudjira--07-transition-approval.md).
3. Select a flow or build the approval line. Review its steps, approvers and completion rules.
4. Enter a deadline, any message and Cc recipients, then submit.
5. Track the request and current step in **My requests**. Participants need issue visibility as well as app access.

## If the issue changes

An edit during general approval displays **Edited since request**; the request continues. The requester can **Resubmit** to seek approval of the current content. The new request replaces the earlier one and keeps its decision history.

An edit after approval displays **Edited since approval**. The old approval does not approve the current content. Very long change histories may prevent listing every changed field.

## Cancel or request again

Cancel your pending request from its details. Decisions on rejected, expired or cancelled requests are not edited; start a new request when needed. Approval and rejection are unavailable after the decision deadline.

Submit periods through [My timesheet](cloudjira--05-timesheet-guide.md). Use [Field change approval](cloudjira--08-field-change-approval.md) for governed field changes.
