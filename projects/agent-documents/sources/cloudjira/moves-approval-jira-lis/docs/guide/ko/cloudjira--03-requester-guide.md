# 요청자 가이드

## 업무함 이동

Jira의 **앱 → Moves Approval**에서 전체 페이지 업무함을 엽니다. 왼쪽 메뉴와 본문은 각각 스크롤하며, 메뉴를 접으면 작업 영역을 넓게 사용할 수 있습니다. 좁은 화면에서도 펼치기 버튼으로 메뉴 이름을 볼 수 있습니다.

왼쪽 사이드바에서 내 차례·진행 중·내 요청·처리한 건·참조, 타임시트와 알림으로 이동합니다. 팀 타임시트는 팀장에게 표시됩니다. 사이드바를 접거나 좁은 화면을 사용하면 아이콘으로 이동하며, 아이콘에 마우스를 올리거나 키보드로 초점을 이동하면 메뉴 이름을 확인할 수 있습니다. 업무함의 메뉴·필터와 설정 하위 메뉴는 뒤로 가기와 새로고침 후에도 URL에서 복원됩니다.

## 이슈 일반 승인 요청

일반 승인 요청자는 이슈 편집 권한이 필요합니다. 승인자·참조자는 이슈를 볼 수 있어야 합니다.

1. 검토받을 이슈를 열고 **Moves Approval** 영역 또는 **••• → Request approval**을 엽니다.
2. **일반 승인(검토)**을 선택합니다. 상태 이동이 목적이면 [상태 전환 승인](cloudjira--07-transition-approval.md)을 선택하세요.
3. 결재선을 선택하거나 직접 구성합니다. 단계·승인자·완료 조건을 확인합니다.
4. 마감일, 필요한 요청 메시지와 참조자를 입력하고 제출합니다.
5. 업무함 **내 요청**에서 상태와 현재 단계를 확인합니다. 상대방에게 앱 사용 권한뿐 아니라 이슈 열람 권한도 필요합니다.

## 요청한 뒤 내용이 바뀌면

일반 승인 요청 중 이슈가 수정되면 **요청 이후 수정됨**을 표시하며 요청은 계속됩니다. 현재 내용으로 다시 승인받으려면 요청자가 **재상신**합니다. 이전 요청은 새 요청으로 대체되고 이전 결정 이력은 남습니다.

승인 완료 후 이슈가 수정되면 **승인 후 수정됨**으로 표시합니다. 이전 승인이 현재 내용을 승인했다는 뜻은 아닙니다. 변경 이력이 길면 모든 변경 필드를 표시하지 못할 수 있습니다.

## 회수·재요청

진행 중인 본인 요청은 상세 화면에서 회수할 수 있습니다. 반려·만료·회수된 요청의 결정은 수정하지 않으며 필요하면 새 요청을 만듭니다. 결재 마감이 지난 요청에는 승인·반려할 수 없습니다.

타임시트는 [내 타임시트](cloudjira--05-timesheet-guide.md)에서 기간을 제출합니다. 필드 값 변경은 [필드 변경 승인](cloudjira--08-field-change-approval.md)을 사용합니다.
