# Marketplace 심사자 재현 안내

본 안내는 Jira Cloud용 **Moves Approval for Jira**의 검증 절차입니다. Confluence 앱 설치는 필요하지 않습니다. Moves Workforce는 선택 연동으로 별도 검증하며 단독 사용을 먼저 확인합니다.

현재 문서는 코드 기준 준비본이며 아래 실환경 결과는 아직 기록되지 않았습니다. 심사 사이트·설치 링크·출시 버전·계정 권한은 제출 시 담당자가 별도 보안 채널로 제공합니다. 비밀번호는 공개 문서에 쓰지 않습니다.

## 준비

- company-managed 시험 프로젝트, 요청자 A, 승인자/팀장 B, Jira 관리자 C, 이슈 열람 불가 사용자 D를 준비합니다.
- 요청자·승인자는 시험 이슈 열람, 워크로그 작업 권한을 갖습니다. 필드 적용자는 편집 권한과 대상 필드가 있는 편집 화면을 사용합니다.
- 프로젝트 사용, 1단계 결재선, 타임시트 팀과 팀장, 전환·필드 규칙을 설정합니다.
- 전환 목적 상태의 모든 시험 경로에 validator를 추가하고 게시합니다. 기간 잠금 시험에는 시간 추적 제공자를 선택합니다.

## 심사에서 명확히 확인할 제한

워크로그 사전 승인과 기간 잠금은 모든 입력 경로를 막지 않습니다. 전환 강제에는 validator 설치가 필요합니다. 필드 직접 편집은 감지형입니다. team-managed 지원·Preview 모듈 동작·Workforce 상대 버전은 실환경 결과로 확정합니다.

공개 문서·지원·개인정보·EULA 링크와 Privacy & Security 응답은 [Atlassian 리스팅 안내](https://developer.atlassian.com/platform/marketplace/onboarding-hub/launch/create-your-marketplace-listing-and-link-your-forge-app/)와 대조합니다. 문서의 설명과 실제 앱 동작은 [심사 지침](https://developer.atlassian.com/platform/marketplace/app-approval-guidelines/)에 맞춰 일치시킵니다.

## 추가 심사 시나리오: 자동 적용과 사후 인증

신규 전환 요청을 A가 제출하고 B가 최종 승인한 뒤 승인 상태와 Jira 적용 상태를 각각 확인합니다. 요청자 offline 권한·Jira 이력 actor·validator REST 재진입·필수 화면 입력 차단·동시 적용 1회·UNKNOWN 재POST 0회·결과 대조 근거를 실환경에서 검증해야 합니다. 기존 LEGACY_MANUAL 요청이 자동 적용되지 않는지도 확인합니다. 현재 backend/UI 테스트는 live 증빙을 대체하지 않습니다.

Jira에 먼저 저장한 워크로그에서 작성자만 사후 인증 결재선을 선택하여 요청하고 VERIFIED를 확인합니다. 시간·설명·공개 범위 변경·삭제로 CHANGED_AFTER_VERIFICATION이 되는지, 원래 값 복원으로 자동 인증 복구되지 않는지 확인합니다. 사후 인증·WORKLOG_CREATE 고통제 승인 후 본인 등록·기간 타임시트 승인을 별도 시나리오로 검증합니다. native/REST/자동화 입력을 항상 사전 차단한다고 주장하지 않습니다. 실제 impersonation 동의·Forge SQL migration·5분 schedule·team-managed 지원은 아직 live 미실측입니다.

## 워크로그 정책 계층 안내

정책 계층 추가 검증: 사이트 기본값·Workforce 잠금·Jira 프로젝트·이슈 sparse override와 상속 복원, 비교 가능한 잠금 강화/완화 거부, 설명 보관 lock 변경 거부, 동일/낮은/같은 rev 다른 문서, 서명·대상·TTL 실패, STALE 유예와 EXPIRED 관련 쓰기 차단을 시험합니다. 작성/수정/삭제의 원래 작성일 window·WARN/BLOCK·시간 상한·기간 잠금·사전 승인 모델도 확인하세요. 보존은 사이트 전용이고 0=무기한인지 확인합니다. 실제 Workforce 송신·공개 키 provisioning·Forge v042–v045 SQL·Jira property·사용자 UX·latency는 live 증거가 별도로 필요합니다.
