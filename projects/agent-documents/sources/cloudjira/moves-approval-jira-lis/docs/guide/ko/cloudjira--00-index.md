# Moves Approval for Jira 사용 가이드

Moves Approval은 Jira Cloud에서 이슈 검토, 타임시트, 상태 전환, 필드 변경의 승인 업무를 관리합니다. Moves Workforce 없이도 사용할 수 있습니다.

이 문서는 2026-10-05 구현 기준의 게시 준비본입니다. 출시 대상 사이트 검증과 공개 게시가 완료되기 전에는 설치 가능 여부와 지원 범위를 담당자에게 확인하세요.
