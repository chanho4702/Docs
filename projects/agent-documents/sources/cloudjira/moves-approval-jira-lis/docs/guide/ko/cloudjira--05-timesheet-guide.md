# 타임시트·팀장 가이드

승인 단위는 **사용자 한 명 × 기간**입니다. 기본은 월이며 관리자가 ISO 주 단위로 바꿀 수 있습니다. 기간 경계는 설정된 시간대에 따릅니다.

## 내 타임시트 제출

1. **Moves Approval → 내 타임시트**에서 기간을 선택합니다.
2. 일별·이슈별 합계, 워크로그 건수와 제한선 경고를 확인합니다.
3. 표시된 팀장 결재 경로와 예외 승인 단계를 확인합니다.
4. 선택 메시지를 입력하고 **제출**합니다.
5. **제출본 보기**에서 제출 시점 내용을 확인합니다. 현재 작업 로그는 제출본과 다를 수 있습니다.

미래의 아직 시작하지 않은 기간은 제출할 수 없습니다. 빈 기간은 기본적으로 제출 가능하지만 관리자가 금지할 수 있습니다. 팀·팀장 정보가 없으면 관리자에게 등록을 요청하세요.

| 표시 상태 | 다음 행동 |
| --- | --- |
| 미제출 | 기록을 확인하고 제출 |
| 제출됨 | 결정 대기 또는 본인 제출 회수 |
| 승인됨 | 제출본이 승인되었음 |
| 반려됨 | 사유 확인·수정 후 다시 제출 |
| 승인 후 변경됨 | 현재 워크로그 확인 후 다시 제출 |

결재 중 워크로그가 바뀌면 변경 감지로 요청이 만료되어 재제출이 필요합니다. 승인 후 변경은 이전 승인 기록을 보존하면서 기간을 **승인 후 변경됨**으로 표시합니다. 변경 감지는 이벤트·정기 보정에 따라 지연될 수 있습니다.

## 팀장 검토

1. **팀 타임시트**에서 본인이 이끄는 팀과 기간을 고릅니다.
2. 팀원별 제출 상태·합계·위반·결재 단계를 확인합니다.
3. 제출본을 열어 검토하고, 내 차례인 건을 선택해 **선택 N건 승인**합니다.
4. 반려 시 사유를 남깁니다. 일괄 처리 결과에서 실패한 건은 다시 확인합니다.
5. 필요한 범위만 엑셀로 내보냅니다.

팀장 역할은 다른 팀의 조회 권한을 주지 않습니다. Jira에서 볼 수 없는 이슈의 정보는 제한되므로 누락된 정보를 임의로 추정하지 마세요.

## 제한선

일·주 최대 시간, 미래 날짜, 소급 입력을 검사합니다. 정책에 따라 경고만 표시하거나, 예외 승인 단계를 추가하거나, 제출을 거부합니다. Workforce 연동 위반도 추가될 수 있습니다. 제한선은 모든 Jira 입력 경로를 사전 차단하는 권한 장치가 아닙니다.
