### 사이드 이펙트 공통 주의
- **응답 계약이 바뀌는 항목**(truncated 플래그·페이징 추가·비동기 작업 ID): H4·E3·E15·F7·F11·H20 → 계약서(`contract_*.md`) 갱신과 FE 동시 반영.
- **숫자가 바뀌는 항목**(정정이지만 사용자에게는 "값이 달라짐"): X5 그룹 사용률 하락 · F7 배지 증가 · A3 증감률 · T-B 커버리지 표시 → 변경 이력·릴리스 노트에 명시.
- **권한 재현이 필요한 항목**(시스템 토큰으로 만든 공용 결과를 사용자별로 거르기): R4 전체 · E1 SQL 전환 → ZM-125의 전 호스트 AND·fail-closed 규칙 재사용, 권한 테스트 필수.
- **자빅스 호출 수 증가**(분할의 대가): R1 → ZM-133 운영 문서의 부하 상한 문구 갱신.
