# MovesEye — 제품 행사 지원 문답

> 작성 2026-09-03. 근거: `moveseye-docs/guides/자주-묻는-질문.md`(baseline 09-01), `moveseye-docs/product/제품-소개서.md`.
> 부스·데모 현장에서 구두로 답하는 용도라 한 답이 4줄을 넘지 않게 썼다. 상세 근거가 필요하면 FAQ 문서 해당 절을 본다.

---

## 1. MovesEye

Zabbix 하나만 연결하면 장애·메트릭·자산·비용·구성도·권한까지 한 화면에서 운영하는 설치형 통합 모니터링 제품입니다.

Zabbix는 지표를 모으고, 우리는 운영을 완성합니다.

---

### What?

**Q. MovesEye가 뭔가요?**
고객사 서버에 설치하는 통합 모니터링 제품입니다. 이미 운영 중인 Zabbix를 원천으로 삼아 장애 목록, 호스트·그룹 모니터링, 자산 대장과 감가상각, 네트워크·지리 맵, 부서별 권한, 주간·월간 리포트, AI 어시스턴트까지 한 화면에 얹습니다.
Zabbix는 그대로 두고 API로만 붙습니다. 추가로 필요한 것은 애플리케이션 서버, PostgreSQL, Redis뿐입니다.

**Q. 누구를 위한 제품인가요?**
Zabbix로 서버·네트워크를 감시하면서, 장애 화면 따로, 자산 엑셀 따로, 구성도 파워포인트 따로 관리하고 있는 운영 조직입니다.
전산실을 둔 기업·공공기관, 고객사 인프라를 대신 운영하는 MSP·SI 운영팀이 대표적입니다. 부서나 협력사별로 "볼 수 있는 장비"를 나눠야 하는 곳이면 바로 대상입니다.

**Q. Zabbix를 대체하나요?**
아니요. Zabbix Server·Agent·트리거·알림 규칙은 손대지 않습니다. 기존 감시 체계에 영향이 없고, 제품을 빼도 Zabbix는 그대로 돕니다.

---

### Zabbix와 뭐가 다른가

**Q. Zabbix에도 대시보드·맵·권한이 있는데 왜 필요하죠?**
Zabbix는 "수집과 감지"에 최적화된 도구라 운영자가 매일 묻는 질문에 화면이 없습니다.
"이 장비가 뭐고 얼마짜리냐", "우리 팀 장비만 보여 달라", "이번 달 그룹별 자원·알람 리포트를 엑셀로", "지금 알림이 왜 안 오냐"는 Zabbix 어디에도 한 화면으로 없습니다. 우리는 그 질문을 화면 단위로 만들어 놓았습니다.

**Q. 조회 전용 대시보드 아닌가요?**
아닙니다. 호스트 등록, 템플릿 연결, 아이템·트리거·액션·미디어·매크로·점검 기간까지 화면에서 관리하고, 여기서 바꾼 것은 즉시 Zabbix에 기록됩니다. 별도 사본이 아닙니다.
Zabbix 원 화면보다 쉽습니다. 예를 들어 트리거·아이템 관리는 "이 정의가 템플릿에서 왔는지, 몇 대에 전파됐는지"를 같이 보여 줍니다.

**Q. Zabbix 권한으로도 범위를 나눌 수 있지 않나요?**
Zabbix 권한은 Zabbix 안에서만 통합니다. 우리는 기능 권한(어떤 메뉴)과 데이터 범위(어떤 호스트 그룹)를 두 축으로 나누고, 서버에서 다시 검증합니다.
협력사에 특정 그룹만 열거나 부서별 담당 장비만 보이게 하는 구성을 화면 숨김이 아니라 서버 검증으로 막습니다.

**Q. 우리 Zabbix가 제대로 구성돼 있는지 어떻게 아나요?**
"구성 현황"에서 정의된 템플릿 중 실제 쓰이는 것, 아이템·트리거·미디어 사용 현황을 봅니다. "모니터링 커버리지"는 호스트별로 에이전트·템플릿·핵심 아이템이 갖춰졌는지 진단합니다.
Zabbix를 오래 쓴 조직일수록 안 쓰는 템플릿과 빠진 호스트가 여기서 드러납니다.

### Grafana와 뭐가 다른가

**Q. Grafana를 이미 쓰는데 뭐가 다른가요?**
크게 네 가지입니다.

- 완성도: Grafana는 패널마다 쿼리를 직접 짜는 범용 시각화 도구입니다. 우리는 운영 화면이 이미 완성된 제품이라 쿼리 언어를 몰라도 씁니다.
- 관리: Grafana는 보기만 합니다. 우리는 호스트·템플릿·트리거·알림을 화면에서 관리하고 Zabbix에 기록합니다.
- 자산·비용·맵: Grafana에 없는 영역입니다. 모니터링 대상이 곧 자산 대장이고, 감가상각과 클라우드 비용까지 같은 화면에 있습니다.
- 권한: Grafana는 대시보드 단위 권한입니다. 우리는 호스트 그룹 단위 데이터 범위를 서버에서 검증합니다.

**Q. 그래도 Grafana가 더 낫지 않나요?**
시각화 자유도와 플러그인 생태계는 Grafana가 앞섭니다. 패널을 마음대로 조립해야 하면 Grafana가 맞습니다.
대신 대상 관리, 자산·비용, 살아 있는 구성도, 부서별 데이터 범위는 Grafana가 구조적으로 못 하는 부분입니다. 정직하게 말하면 자유로운 시각화는 Grafana, 매일 보는 운영 화면과 자산·권한은 우리입니다. 함께 쓰는 구성도 됩니다.

**Q. 홈 화면은 커스터마이즈가 안 되나요?**
됩니다. 홈은 사용자별 위젯 대시보드입니다. 위젯 14종을 추가·배치·크기 조정하고, 위젯의 이상 수치를 누르면 해당 화면으로 바로 내려갑니다.

### 뭐가 좋은가

**Q. 도입하면 당장 뭐가 달라지나요?**
장애를 찾는 콘솔이 하나가 됩니다. 문제 목록에서 심각도·호스트로 좁히고 그룹 → 호스트 → 메트릭으로 내려가며, 인지 처리로 누가 보고 있는지를 팀이 공유합니다.
자산 엑셀이 사라집니다. 수집 중인 호스트가 자동으로 자산에 올라오고, 비품·회선처럼 수집 대상이 아닌 것도 함께 등록합니다. 취득가·취득일만 넣으면 감가상각이 자동 계산됩니다.
구성도가 낡지 않습니다. 네트워크 맵의 노드에 실제 호스트를 연결하면 현재 상태가 반영된 구성도가 됩니다. 지리 맵은 사업장·데이터센터 단위로 지도 위에 장비를 놓습니다.

**Q. 리포트는요?**
호스트 그룹 상세의 리포트 탭에서 주간·월간 자원·알람 리포트를 보고 엑셀로 내려받습니다. 배치가 스냅샷을 만들어 두고, 없는 구간은 조회 시 자동으로 채웁니다. 자산 비용 화면도 엑셀 내보내기를 제공합니다.

**Q. 알림이 안 올 때는요?**
알림 관리 화면 또는 AI 어시스턴트의 알림 진단이 배달 경로 3단(액션 활성 → 오퍼레이션 미디어 지정 → 사용자 미디어 활성)을 순서대로 확인해 줍니다. Zabbix에서 가장 자주 헤매는 지점입니다.

**Q. AI 어시스턴트는 뭘 하나요?**
화면 어디서든 플로팅 챗을 열어 "지금 CPU 높은 호스트 알려 줘", "이번 주 알람 엑셀로 정리해 줘", "web-01에 태그 붙여 줘"처럼 말하면 제품 API를 대신 호출합니다.
읽기는 즉시 실행되고, 쓰기·삭제는 확인 카드를 띄워 승인을 받아야 실행됩니다. 사용자가 화면에서 못 하는 일은 AI로도 못 합니다. LLM은 Anthropic·OpenAI 호환·Azure·Ollama 중 고르며, 폐쇄망이면 사내 Ollama를 씁니다.

**Q. 클라우드도 되나요?**
AWS가 됩니다. Access Key를 등록하면 전 리전의 EC2·VPC 상태가 붙습니다. 기본 상태에서는 무료 API만 써서 AWS 과금이 0이고, CloudWatch 지표와 Cost Explorer 실청구액은 관리자가 명시적으로 켠 경우에만 호출합니다. 월 예산 가드가 있습니다.
Zabbix 에이전트가 설치된 인스턴스는 에이전트 값을 우선 쓰고 없을 때만 CloudWatch로 폴백합니다. Azure·GCP는 예정입니다.

**Q. 팀 관리(운영 협업)에 도움이 되나요?**
됩니다. 장애 인지 처리, 자산 변경 이력, 감사 로그가 사용자 계정에 남아 누가 무엇을 했는지 추적됩니다. 퇴사자는 삭제가 아니라 비활성화가 기본이라 이력이 끊기지 않습니다.

### 도입·보안

**Q. 데이터는 어디에 저장되나요?**
전부 고객사 인프라입니다. 온프레미스 설치형이라 외부로 나가지 않습니다.
예외는 세 가지입니다. 지리 맵의 지도 타일, AWS 연동, 그리고 AI 어시스턴트에 외부 LLM을 연결한 경우입니다. 마지막은 Ollama 등 로컬 프로바이더로 대체하면 폐쇄망에서도 됩니다. AWS 자격증명과 LLM 키는 DB에 AES-256-GCM으로 암호화 저장됩니다.

**Q. 폐쇄망에서 쓸 수 있나요?**
제품 자체는 외부 통신 없이 동작합니다. Zabbix 에이전트 설치 가이드도 폐쇄망용 반입 절차를 따로 제공합니다.

**Q. 설치하고 뭘 채워야 하나요?**
Zabbix 연동 계정, 자산 최초 동기화, 장비 분류, 역할과 데이터 범위 네 가지입니다. DB 스키마는 기동 시 자동 생성되고, 배치 주기는 재기동 없이 화면에서 바꿉니다.
가장 중요한 것은 권한 설계입니다. 시스템 관리자·운영자·자산 담당자·조회 전용 서너 개 역할로 시작하고 불편한 지점만 나중에 나누기를 권합니다.

**Q. 몇 대까지 되나요?**
제품 자체에 대수 제한은 없습니다. 라이선스도 호스트 대수로 과금하지 않습니다. 성능은 연결된 Zabbix 규모와 서버 사양에 따르므로 규모를 알려 주시면 검토합니다.

**Q. SSO·LDAP·2차 인증은요?**
현재는 제품 자체 계정(ID/비밀번호)만 지원합니다. LDAP·SSO·OTP는 요구사항 접수 단계입니다. 세션은 계정당 1개, 액세스 토큰 30분·리프레시 8시간이 기본입니다.

**Q. Prometheus나 다른 소스도 붙나요?**
지금 실제 동작하는 어댑터는 Zabbix 하나입니다. 다중 소스를 위한 내부 구조(소스 중립 계약, 능력 기반 메뉴)는 완성됐고, 애플리케이션이 Zabbix를 직접 참조하면 빌드가 실패하도록 강제해 두었습니다. Prometheus 어댑터가 다음 단계이며 일정은 협의가 필요합니다. 붙어도 화면은 그대로입니다.

**Q. 에디션과 라이선스는요?**
STANDARD는 통합 모니터링·이벤트·자산·비용·맵·클라우드·대상 관리·리포트·권한을 전부 포함합니다. PREMIUM은 여기에 GPU 모니터링·DB 모니터링·APM을 더합니다. STANDARD에 특정 기능만 추가하는 구성도 됩니다.
기간제와 영구 모두 지원하고 유효 기간은 등록일부터 계산됩니다. 만료돼도 즉시 잠그지 않습니다. 약 30일은 읽기 전용으로 실시간 모니터링이 유지되고, 그 뒤에는 쌓인 데이터 조회만 됩니다.

**Q. 무료로 써볼 수 있나요?**
설치 후 7일 안에 라이선스 키를 등록하는 구조라, 평가는 평가용 키를 발급해 드리는 방식으로 진행합니다. 기존 Zabbix에 읽기 계정 하나만 주시면 당일 연동해서 실제 데이터로 보실 수 있습니다.

## 현장 주의 문구

- "Prometheus·Datadog·Elasticsearch가 데이터 소스 화면에 보인다"는 질문에는 **화면 골격만 있고 어댑터는 없다**고 답한다. 과장하면 도입 후 첫 미팅에서 신뢰를 잃는다.
- APM·DB·GPU는 PREMIUM이며 APM 외에는 **예정**이다. APM은 1단계(개요·서비스·수집기·알람 규칙)가 제공되고 트레이스는 반영 중, 합성 감시는 예정이다.
- 자산 비용(감가상각)은 **[개발 중]** 표기가 붙어 있다. 데모는 되지만 확정 기능처럼 약속하지 않는다.
- 요금은 현장에서 말하지 않고 별도 견적으로 안내한다.
