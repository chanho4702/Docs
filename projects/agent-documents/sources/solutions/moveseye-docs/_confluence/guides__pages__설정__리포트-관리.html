리포트 관리

사이드바 설정 > 리포트 관리 경로 /setting/report-management

무엇을 하는 화면인가

배치가 생성한 주간·월간 리포트를 관리하고 보존 기간 정책을 정하는 화면이다.

화면 구성

영역내용
저장된 리포트생성된 리포트 목록, 선택 삭제
보존 설정자동 삭제 기준 기간

사용 흐름

  1. 저장된 리포트 목록에서 생성 상태를 확인한다.
  2. 보존 기간을 조직 정책에 맞게 설정한다.
  3. 불필요한 리포트는 선택 삭제한다.

주의할 점

보존 기간을 정하지 않으면 무한 누적된다

리포트는 주간·월간으로 계속 쌓인다. 보존 정책이 없으면 디스크가 계속 찬다. 도입 초기에 반드시 설정한다.

자동 삭제는 배치가 수행한다

report_cleanup 배치가 보존 기간이 지난 리포트를 지운다. 이 배치가 꺼져 있으면 정책을 설정해도 삭제되지 않는다. 스케줄러에서 활성 상태를 확인한다.

참고: 정리 계열 배치는 라이선스가 만료돼도 계속 동작한다. 멈추면 디스크가 무한정 차기 때문이다.

리포트가 생성되지 않을 때

목록이 비어 있다면 생성 배치(report_weekly, report_monthly)를 확인한다.

  • 배치가 활성화돼 있는가
  • 마지막 실행이 성공했는가
  • 부분 실패가 아닌가 — 실행 이력의 요약(ok=38 fail=2)을 읽는다

보존 기간 단축의 영향

보존 기간을 줄이면 다음 정리 배치 실행 시 기존 리포트가 삭제된다. 과거 자료가 필요하다면 먼저 내려받는다.
