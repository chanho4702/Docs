무엇을 하는 화면인가

IT 자산의 취득 비용과 감가상각을 관리하는 화면이다. 엑셀로 관리하던 자산 대장의 비용 부분을 제품 안으로 가져온다.

사용 흐름

  1. HW 비용 탭에서 미입력 자산을 확인한다.
  2. 소량이면 인라인으로 직접 입력한다.
  3. 대량이면 CSV 템플릿을 내려받아 채운 뒤 업로드한다.
  4. 개별 자산의 상각 상세에서 계산 결과를 검증한다.

주의할 점

CSV 업로드는 비동기다

🔴 업로드 성공 메시지는 "접수됨"이지 "처리 완료"가 아니다. 작업 상태를 따로 확인해야 한다. 업로드 직후 목록에 반영이 안 됐다고 다시 올리지 않는다 — 동시에 여러 작업이 돌지 않도록 제한이 걸려 있다.

파일 크기 상한은 10MB다.

소급 재계산

파라미터(상각방법·내용연수 등)를 바꾸면 현재 파라미터 기준으로 과거까지 다시 계산된다. 과거 시점의 값을 스냅샷으로 보존하지 않는 설계다. 결산이 끝난 기간의 수치도 함께 바뀌므로, 변경 전에 영향 범위를 확인한다.

기기분류의 상각 기본값을 바꿀 때도 마찬가지다 — 그 분류를 쓰는 모든 자산에 소급 적용되며, 저장 전에 영향받는 자산 수를 확인하는 안내가 뜬다.

계산 기준

한국 세무 기준을 따른다 — 월할 계산, 기본 잔존가액 0. 정액법과 정률법을 지원한다.

상각이 계산되지 않을 때

"상각을 계산할 수 없습니다"가 뜨면 필수 입력(구매 비용, 취득일)이 빠진 것이다. 데이터 품질 안내를 확인한다.
