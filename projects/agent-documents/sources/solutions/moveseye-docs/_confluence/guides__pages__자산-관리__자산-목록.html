무엇을 하는 화면인가

모니터링 대상을 자산 관점에서 관리하는 화면이다. 감시 중인 장비가 곧 자산이며, 여기에 소유자·위치·라이프사이클 같은 업무 정보를 덧붙인다.

주요 동작

  • 검색
  • 동기화 — 데이터소스에서 자산을 가져온다
  • 자산 생성 — 수집 대상이 아닌 자산을 직접 등록
  • 제외 / 복원

상세

자산 레코드, HW 정보, 연결 Host, 위치, 소유자, 커스텀 속성, 비고, 이력 탭으로 구성된다.

세 가지 상태값의 차이

화면에 함께 나오지만 성격이 완전히 다르다. 이것을 구분하지 못하면 "왜 못 바꾸지?"에서 막힌다.

값누가 정하나편집
커버리지동기화가 자동 판정 (호스트가 활성이면 '모니터링됨')❌ 직접 변경 불가
라이프사이클사용자가 지정 (기본 '사용중')✅ 자산 상세에서
배포데이터소스 인벤토리의 deployment_status (없으면 '배포됨')원천에서

제외(Exclude)의 의미

삭제가 아니다.

  • 목록에서 감춰지고 동기화 대상에서 빠진다
  • 데이터는 지워지지 않으며 언제든 복원할 수 있다
  • 원천 시스템(Zabbix)에는 영향이 없다

퇴역 장비를 정리할 때 삭제 대신 제외를 쓴다. 이력이 보존된다.

사용 흐름

  1. 처음이라면 동기화를 먼저 실행한다.
  2. 필터로 대상을 좁힌다.
  3. 자산 상세에서 소유자·위치·라이프사이클 같은 업무 정보를 채운다.
  4. 퇴역 장비는 제외 처리한다.

주의할 점

  • 🔴 원천 필드를 고쳐도 다음 동기화가 덮어쓴다. 영구히 유지할 값은 MovesEye가 소유하는 보강 필드에 넣는다.
  • 지리 맵을 쓸 계획이면 동기화를 반드시 먼저 한 번 돌린다. 안 하면 지리 맵의 호스트 후보가 0건으로 나온다.
  • 제외한 자산을 다시 찾으려면 필터를 '제외 포함' 으로 바꾼다.
  • 일부 동작은 권한이 필요하다. "권한이 없습니다" 안내가 뜨면 관리자에게 문의한다.
