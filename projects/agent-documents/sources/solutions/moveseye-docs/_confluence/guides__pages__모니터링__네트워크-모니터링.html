무엇을 하는 화면인가

스위치·라우터 등 네트워크 장비를 목록으로 보고, 장비별 트래픽과 응답 상태를 확인하는 화면이다. 서버 모니터링과 구조는 같지만 대상 장비군과 주요 지표가 다르다.

화면 구성

목록

  • 호스트 그룹 필터와 조회 기간
  • 장비별 상태와 주요 지표

상세

지표의미
인터페이스 트래픽포트별 in/out
응답 시간장비 반응 지연
패킷 손실유실 비율
CPU·메모리장비 자체 부하(제공되는 장비에 한함)

사용 흐름

  1. 호스트 그룹으로 대상 장비를 좁힌다.
  2. 응답 시간과 패킷 손실이 튀는 장비를 찾는다.
  3. 상세에서 어느 인터페이스가 문제인지 좁힌다.
  4. 트래픽 추이로 포화 여부를 판단한다.

주의할 점

  • 트래픽은 bps 원값이다. 바이트 단위 감각으로 읽으면 안 된다.
  • 장비가 Proxy를 통해 수집되는 경우, 값이 안 보이면 장비가 아니라 Proxy 문제일 수 있다. 호스트 관리 화면에서 수집 경로(monitored by)를 확인한다.
  • 네트워크 장비는 서버보다 수집 항목이 적은 경우가 많다. 특정 지표가 없는 것이 비정상은 아니다.
  • 인터페이스가 많은 장비는 목록이 길다. 실제로 쓰는 포트만 보려면 상세에서 필터링한다.
