번호 규칙

ADR-0001-short-title.md처럼 순차 번호를 사용한다. 문서 생명주기는 status, 결정 상태는 decision_status로 분리한다. 결정 상태는 proposed, accepted, superseded, rejected 중 하나다. 대체된 ADR은 삭제하지 않고 superseded_by를 연결한다.
