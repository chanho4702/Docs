사용 흐름 — 새 호스트 등록

  1. 호스트 탭에서 생성.
  2. 이름과 호스트 그룹을 지정한다 — 그룹은 권한 경계이므로 신중히 고른다.
  3. 인터페이스를 등록한다(IP/DNS, 포트, agent/SNMP 등).
  4. 템플릿을 연결한다. 아이템과 트리거는 대개 템플릿에서 상속받는 것이 관리하기 쉽다.
  5. 필요하면 분류·태그를 지정한다.

주의할 점

배열 필드 전체 교체

🔴 가장 위험한 함정이다. Zabbix의 update는 부분 수정이 아니라 보낸 배열로 통째 교체한다. 태그 하나를 추가하려고 그것만 보내면 나머지 태그가 전부 사라진다.

제품 화면은 현재 값을 읽어 폼에 채우고 전체를 다시 보내는 방식으로 이를 막고 있다. 그러므로:

  • 폼에 이미 채워진 값을 임의로 지우지 않는다
  • 다건 일괄 변경 전에 대상 호스트의 현재 태그·템플릿 연결을 먼저 확인한다

템플릿 링크도 같은 방식이다.

그룹 변경의 파급

호스트 그룹을 바꾸면 그 그룹을 볼 수 있는 사용자가 바뀐다. 권한 경계이기 때문이다. 담당자가 갑자기 장비를 못 보게 되는 일이 여기서 생긴다.

수집 경로

장비가 Proxy를 통해 수집되는 경우 정보/인터페이스 탭에서 확인할 수 있다. 값이 안 들어올 때 장비가 아니라 Proxy 문제일 수 있다.
