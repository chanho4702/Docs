호스트 그룹

사이드바 모니터링 > 호스트 그룹 경로 /monitoring/host-group → 상세 /monitoring/host-group/:id

무엇을 하는 화면인가

담당 시스템 묶음(그룹) 단위로 상태를 비교하고, 이상이 있는 그룹에서 개별 호스트로 내려가는 화면이다. 운영자가 가장 자주 쓰는 진입점이다.

호스트 그룹은 단순한 분류가 아니라 권한의 경계이기도 하다. 내게 권한이 없는 그룹은 목록에도, 집계 수치에도 나타나지 않는다.

화면 구성

목록

그룹별 상태 요약을 표로 본다. 문제 수와 정상 비율을 그룹끼리 비교하는 것이 목적이다.

상세 (그룹 선택 시)

다섯 개 탭으로 구성된다.

탭내용언제 보나
리소스 추이CPU·메모리·디스크·트래픽의 시계열부하 변화 시점을 찾을 때
알람 추이기간별 알람 발생 흐름장애가 잦아지는 추세인지 볼 때
호스트 목록그룹에 속한 호스트와 현재 상태개별 호스트로 내려갈 때
호스트 분류기기 분류별 구성그룹의 장비 구성을 파악할 때
리포트주간·월간 집계 리포트정기 보고 자료가 필요할 때

사용 흐름

권장 탐색 순서다.

  1. 문제 수와 정상 비율을 확인한다.
  2. 리소스 추이에서 avg/max를 전환해 본다. 평균은 정상인데 최대가 튀는 경우가 흔하다.
  3. 급격한 변화가 언제 시작됐는지 시점을 찾는다.
  4. 알람 추이와 시점이 겹치는지 대조한다.
  5. 호스트 목록에서 해당 호스트로 내려간다.

주의할 점

  • avg만 보고 판단하지 않는다. 평균은 짧은 스파이크를 숨긴다. max로 전환해 순간 부하를 확인한다.
  • 차트가 비어 있다고 장애가 아니다. 해당 아이템이 그 그룹의 호스트에 없을 수 있다.
  • 리포트 탭의 데이터는 배치가 생성한다. 최근 기간이 비어 있으면 리포트 배치 실행 이력을 확인한다(스케줄러).
  • 그룹 목록이 비었다면 권한 문제다. 관리자에게 호스트 그룹 데이터 범위를 요청한다.
