# Moves Workforce 한영 부속 문서 마무리

- 고객이 핵심 21쌍만으로 전체 가이드가 1:1이 아니라고 지적했다. 전체 공간을 공개 조회해 기존 영어 영역의 한국어 부속 21개와 영어 대응이 없는 부록 2개를 확인했다.
- 부속 23쌍을 정리해 핵심 포함 한·영 44쌍, 88페이지를 실제 게시했다. 기존 주소를 재사용하고 영어 부록 2개만 추가했다. 각 문서의 언어 전환과 두 목차의 상세 안내를 연결했다.
- 공간 홈과 예전 통합 User Guide도 최신 가이드·심사 안내·정책으로 연결했다. 핵심 42/42, 부속 46/46, 진입 안내 2/2 공개 검증 통과. 대응 검사는 KO44·EN44·44쌍, 실패0이다.
- 영어 제목만 바뀌고 오래된 한국어 본문이 남는 경우가 있었다. 제목·H2 존재뿐 아니라 영어 본문의 한국어 잔존을 검사해 2개 분석 페이지를 찾아 완전히 교체했다. 용어집의 의도된 한국어 대조 열만 원본 값으로 제한해 허용한다.
- contenteditable의 빈 안내는 실제 본문처럼 innerText에 보일 수 있다. 실제 Page editing area의 aria-label로 Rovo 입력과 중복ID를 분리하고, fill 후 남은 본문은 Control+A 두 번과 Backspace로 제거한다. 빈 상태를 확인하고 붙여넣은 본문을 검사한다.
- 새 페이지에 HTML을 붙이면 Rovo가 자동 제목을 생성할 수 있었다. 게시 이후 실제 제목을 공개 조회해 확인해야 한다. 신규 페이지는 Publish... 이후 위치 대화상자의 Publish가 필요하다.
- 저장 HTML의 &middot;와 Unicode 중점은 동등하게 비교한다. 원본의 깨진 색상 문자도 정리했다. 실제 본문이 예상 본문보다 크게 늘어났는지 비교하면 오래된 블록 잔존을 찾는 데 도움이 된다.
- 고객이 로컬 파일 드래그 업로드도 요청했다. 현재 공식 runtime은 브라우저 내부 drag만 지원하고 OS 파일 탐색기 drag 기능은 없다. 파일 선택은 확장의 파일 URL 접근 설정으로 막혀 있었다. 실제 첨부를 주장하지 않고 사용자가 허용한 위치 표시를 총75곳에 유지했다.
- 문서 본문·번역·목차·언어 이동 완료와 실제 이미지 첨부·역할별 앱 검증은 별도로 보고한다. 물리적 사용자·관리자 폴더가 달라도 주제 대응과 상호 이동을 검증해야 한다.
