# Moves Workforce 핵심 기능 10가지

> 컨플루언스 페이지용 원고. 페이지 구조는 **머리말 → 기능 10개(텍스트 왼쪽 · 캡처 오른쪽 2열 레이아웃) → 도입 안내** 입니다.
> 캡처 파일명은 사용자 매뉴얼 캡처 계획(`Moves_Workforce_사용자_매뉴얼/images/README.md`)과 같은 이름을 쓰되, 이 페이지용은 **번호 표식 없이** 깨끗하게 찍습니다. 파일명 끝에 `-clean`을 붙여 매뉴얼용과 구분합니다.

---

## 머리말

**Jira 안에서 사람과 시간, 비용을 한 번에 관리합니다.**

Moves Workforce는 Jira에 설치하는 인력·프로젝트 관리 앱입니다. 실무자가 남긴 작업 시간이 공수, 가동률, 인건비, 진척률로 이어지고, PM과 경영진은 프로젝트 하나부터 전사까지 같은 숫자로 봅니다. 별도 서버 없이 Atlassian 인프라 안에서만 동작합니다.

| 캡처 | `00-hero-dashboard-clean.png` |
|---|---|
| 화면 | 프로젝트 상세 > 대시보드, "전부 추가" 배치, 스크롤 상단 |
| 상태 | 데모 프로젝트, 위젯에 값이 채워진 상태, 라이트 테마, 폭 1440 |
| 용도 | 페이지 맨 위 전체 폭 이미지. 제품 첫인상용이라 카드·차트가 고르게 보이는 프로젝트 선택 |

## 1. 워크로그 기록

**기록은 한 번, 계산은 앱이.**

My Work 캘린더에서 날짜를 누르거나, Jira 이슈 화면의 Moves Workforce 패널에서 바로 시간을 남깁니다. 여러 날치는 기간 입력으로 한 번에 만듭니다. 여기서 쌓인 시간이 아래 모든 숫자의 원천입니다.

| 캡처 | `02-mywork-overview-clean.png` |
|---|---|
| 화면 | My Work, 캘린더 뷰(주간), 워크로그 모드 |
| 상태 | 최근 2주에 워크로그가 고르게 있고 업무일지 추가 창을 하나 열어 둔 상태(시작·종료 시간 입력, 계산된 시간 표시) |
| 강조 | 열린 입력 창이 화면 중앙에 오게. 요약 카드 5개가 위에 보이게 |
| 보조 | `10-issue-panel-both-clean.png` — Jira 이슈 화면 오른쪽 패널. 작게 넣거나 생략 |

## 2. 작업 관리

**목록, 트리, 간트, 맵. 같은 작업을 네 가지로 봅니다.**

Jira의 3단계 계층을 넘는 WBS를 만들고, 폴더로 묶고, 간트에서 드래그로 일정과 선후행을 잡습니다. 목록에서 여러 작업을 골라 일정과 계획 작업량을 한 번에 넣을 수 있습니다.

| 캡처 | `05-work-gantt-clean.png` |
|---|---|
| 화면 | 프로젝트 상세 > 작업 관리 > 간트, 주 단위 |
| 상태 | 폴더 2개, 요약 막대, 마일스톤, 선후행 연결선이 한 화면에 보이는 구간. 조회 전용 배지가 없는 쓰기 권한 계정 |
| 강조 | 왼쪽 표와 타임라인이 반반. 오늘 기준선이 화면 안에 |
| 보조 | `05-work-map-clean.png` — 맵 보기, 미니맵 켜고 드로어는 닫은 상태. 2열 아래에 작게 |

---

## 3. 자동 편입

**이슈는 알아서 들어옵니다.**

Jira 프로젝트를 구독해 두면 이슈 타입과 조건에 맞는 이슈가 프로젝트에 자동으로 등록됩니다. 기본 계획 작업량까지 정해 두면 새 이슈가 진척률 계산에 바로 포함됩니다.

| 캡처 | `05-work-subscription-clean.png` |
|---|---|
| 화면 | 작업 추가 창 > 구독 설정 탭 |
| 상태 | 스페이스 선택, 이슈 타입 2개 선택, 미리보기에 "편입 대상 N건" 표시, 아래에 구독 중인 소스 1개(정상 상태) |
| 강조 | 미리보기 숫자와 구독 목록의 "누적 N건 편입"이 보이게 |

---

## 4. 진척률 분석

**공수를 다 썼다고 끝난 게 아닙니다.**

완성·공수·일정 세 가지를 따로 보여줍니다. 완성이 일정보다 뒤처지면 지연, 공수만 앞서면 비효율로 읽습니다. 예상 완료일과 지연·위험 이슈까지 한 화면에서 짚습니다.

| 캡처 | `05-analysis-progress-clean.png` |
|---|---|
| 화면 | 프로젝트 상세 > 분석 및 리포트 > 진척률 |
| 상태 | 지연 배지가 "주의"인 프로젝트. 종합 헤더, 진척 비교 막대, S-curve가 첫 화면에 들어오게 |
| 강조 | 세 막대의 길이 차이가 눈에 띄는 프로젝트 선택. 지연·위험 이슈 표는 잘려도 됨 |

---

## 5. 작업·인력 분석

**누가 과부하이고, 어떤 작업이 새고 있는지.**

작업 분석은 계획 대비 실투입과 담당자별 산정 정확도를, 인력 분석은 인원별 가동률과 팀별 투입을 보여줍니다. 가동률은 공휴일과 연차를 빼고 계산해 휴가 간 사람이 불리하지 않습니다.

| 캡처 | `05-analysis-resource-clean.png` |
|---|---|
| 화면 | 분석 및 리포트 > 인력 분석, 이번 달 |
| 상태 | 상단 인원별 가동률 차트에 과부하(빨강)와 적정(파랑)이 섞여 있고, 표에 실효 가용 MD 차감(주황)이 한 명 이상 |
| 강조 | 상단 차트와 표 상위 5행. 상세 패널은 닫은 상태 |

---

## 6. 인건비 산출

**연봉을 넣으면 프로젝트 비용이 나옵니다.**

연봉 또는 등급 급여 밴드를 기준으로 프로젝트 기간에 맞춰 인건비를 계산합니다. 개인 급여를 보여줄지, 등급 대표값으로만 계산할지는 정책으로 정합니다. 비용 권한이 없으면 금액 항목이 화면에서 아예 사라집니다.

| 캡처 | `05-analysis-cost-clean.png` |
|---|---|
| 화면 | 분석 및 리포트 > 비용 |
| 상태 | 예시 급여 데이터(실제 인명·금액 금지). 총 인건비, 인력별 인건비, 이슈별 비용 차트 |
| 강조 | 요약 숫자와 이슈별 차트. 개인 연봉 열이 보이면 마스킹 대신 등급 기반 정책으로 바꿔 캡처 |

---

## 7. 프로젝트 대시보드

**보고 싶은 위젯만 골라 프로젝트마다 다르게.**

상태 분포, 계획 대비 실적, 진척 추이, 비용 소진, 지연·임박 이슈, 관계 토폴로지 등 15종 위젯을 드래그로 배치합니다. 담당자·상태·기한 조건을 직접 정하는 커스텀 필터 위젯도 있습니다.

| 캡처 | `05-dashboard-add-chart-clean.png` |
|---|---|
| 화면 | 대시보드 편집 모드에서 차트 추가 창 > 추천 탭 |
| 상태 | 템플릿 6개가 모두 보이게. 뒤 배경에 위젯 그리드가 흐리게 보여도 됨 |
| 강조 | 창 자체. 머리말 히어로가 대시보드 전체이므로 여기서는 "고르는 장면"을 보여줌 |

---

## 8. 통합 대시보드

**경영진은 신호등만 보면 됩니다.**

전사 프로젝트를 일정·범위·자원·비용 축으로 나란히 놓고 정상·주의·위험 신호로 요약합니다. 빨간 프로젝트를 누르면 그 프로젝트의 진척률과 원인 이슈로 내려갑니다.

| 캡처 | `08-portfolio-overview-clean.png` |
|---|---|
| 화면 | 통합 대시보드 상단 |
| 상태 | 프로젝트 5개 이상, 신호등 표에 빨강·노랑·초록이 섞여 있게. 필터 바에 인원·투입 MM·인건비 요약 표시 |
| 강조 | 신호등 표가 화면 중앙. 서브탭은 보이되 내용은 잘려도 됨 |

---

## 9. 자원 관리

**누구를 넣을지 감으로 정하지 않습니다.**

인력 현황에서 전사 인력의 부하와 스킬을 보고, 조직도에서 팀 구성을 확인하고, 프로젝트 배정에서 필요 스킬 대비 적합도와 현재 부하를 함께 보며 사람을 넣습니다.

| 캡처 | `06-resource-assignment-clean.png` |
|---|---|
| 화면 | 자원 관리 > 프로젝트 배정, 프로젝트 하나 선택 |
| 상태 | 오른쪽 전사 인력 목록에 적합도 %와 부하 신호가 다양하게 보이게. 왼쪽 카드에 D-day 배지 |
| 강조 | 세 패널이 모두 보이는 전체 폭. 패널은 접지 않음 |
| 보조 | `06-resource-people-clean.png` — 인력 현황 표, 드로어 닫은 상태. 생략 가능 |

---

## 10. 권한·기준 설정

**역할에 맞는 화면만, 조직 기준대로.**

읽기·쓰기 권한과 프로젝트 조회 범위(전체·소속·내 팀)를 세트로 묶어 사용자나 팀에 배정합니다. 근무시간, 휴일, 역할, 등급, 스킬, 프로젝트 상태를 조직 기준에 맞춰 두면 모든 계산이 그 기준을 따릅니다.

| 캡처 | `07-permission-set-clean.png` |
|---|---|
| 화면 | Settings > 권한 관리, 커스텀 세트(예: PM) 편집 |
| 상태 | 워크포스 영역 항목 7개가 모두 보이고 읽기·쓰기 체크가 섞여 있게. 프로젝트 데이터 범위 선택 영역이 아래에 |
| 강조 | 체크 표. 설정 영역 항목은 잘려도 됨 |

## 도입 안내

Atlassian Marketplace에서 설치하면 바로 쓸 수 있습니다. 설치 후 근무시간·급여 정책·역할·등급·권한 네 가지를 채우면 첫 프로젝트를 만들 수 있고, 데이터는 Atlassian 인프라 밖으로 나가지 않습니다.

- 사용 방법: 사용자 가이드
- 설치·초기 설정: 관리자 가이드
- 자주 묻는 질문: FAQ
