# 요구사항 — 마이페이지(/my-page) 전면 개선

사용자 원문(2026-07-22):

> 지금 마이페이지 전체적으로 개선해야할거같아 디자인도 별로고 화면 배치나 내용도 별로야
> 나에게 할당된 프로젝트랑 나에게 할당된 작업 좌우로 일단 나눠주고 mywork처럼 선택하면 해당 내용 볼수있게
> 아래 클릭한 프로젝트에 따라 내가 작성한 워크로그도 나오게해주고
> 그리고 결정적으로 내 권한이 어떤건지 알수가 없어
> 차트도 적절히 넣어서 나만의 대시보드 처럼 만들어줘
> 핵심은 나한테 어떤 작업이 할당 됐고 얼마나 기여하고있으며 내가 한일을 볼 수있어야해
> 데이터가 많을 수 있으니 항상 필터 두는거 잊지말고

## 요구 분해

| # | 요구 | 판정 |
|---|------|------|
| R1 | 좌: 나에게 할당된 프로젝트 / 우: 나에게 할당된 작업 — 좌우 2분할 | 레이아웃 |
| R2 | myWork처럼 프로젝트 선택 → 선택 스코프가 우측/하단에 연동 | 상태 연동 |
| R3 | 선택한 프로젝트 기준으로 내가 작성한 워크로그 노출 | 데이터 스코프 |
| R4 | 내 권한이 무엇인지 화면에서 확인 가능 | 신규 섹션 |
| R5 | 차트를 넣어 "나만의 대시보드"화 | 시각화 |
| R6 | 핵심 3축: (a) 나에게 할당된 작업 (b) 내 기여도 (c) 내가 한 일 | 정보구조 |
| R7 | 데이터가 많을 수 있으니 모든 목록에 필터 | 전 섹션 필수 |

## 제약/전제

- **백엔드 신규 개발 없음**: 기존 SELF resolver 재사용
  (`getMyProjectList`, `getMyIssueList`, `getMyCalendarWorklog`, `getMySkills`/`setMySkills`)
  + PUBLIC (`userPermissionCheck`, `getPermissionCatalog`, `getSettingData`, `getPublicHolidayList`)
- 이슈 응답 fields = `duedate,summary,worklog,project,assignee,issuetype,status` + `properties.movesRms`
  → **priority/timetracking 없음** → 우선순위·잔여추정 기반 지표는 불가. 기여도는 **워크로그 시간** 기준.
- 팀 전체 워크로그는 SELF 스코프에서 조회 불가 → "팀 대비 기여율"은 산출 불가.
  기여도는 **내 투입시간 / 처리율 / 작업량** 으로 표현한다(과장 금지).
