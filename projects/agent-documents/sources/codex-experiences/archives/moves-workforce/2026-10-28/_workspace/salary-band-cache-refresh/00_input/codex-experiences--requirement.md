# 급여 밴드 변경 시 인력 관리 급여 범위 즉시 갱신

## 사용자 요청

급여 밴드 설정을 저장하면 인력 관리 화면에 표시되는 급여 범위가 새로고침 없이 즉시 최신 값으로 갱신되어야 한다. 현재는 브라우저를 새로고침해야 반영된다.

## 관찰된 증상

- 급여 밴드 저장 요청 자체는 성공한다.
- 이미 조회되어 TanStack Query cache에 남아 있는 인력 관리 데이터가 무효화되지 않는 것으로 추정된다.
- 급여 밴드 저장 mutation의 성공 처리와 인력 관리 조회 query key 사이의 연결을 확인해야 한다.

## 목표

1. 급여 밴드 생성·수정·삭제 성공 후 인력 관리 급여 범위를 제공하는 모든 관련 query를 정확한 query key factory로 무효화한다.
2. 브라우저 전체 새로고침 없이 활성 인력 관리 화면이 재조회되어 최신 급여 범위를 표시한다.
3. 잘못된 문자열 query key나 지나치게 넓은 전체 cache invalidation은 사용하지 않는다.
4. 회귀 테스트로 저장 성공 시 필요한 query key가 무효화되는지 검증한다.

## 영향 범위 가정

- 프론트엔드 TanStack Query cache invalidation 및 query key factory
- 필요 시 관련 프론트엔드 테스트
- 백엔드 API/DB/manifest/i18n 변경 없음
