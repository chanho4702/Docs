# 요구사항 — 프로젝트 「협업 모드」 (2026-09-30)

## 배경
화면이 Jira 이슈를 **보는 사람 자격(asUser)** 으로 조회한다. 그래서 우리 프로젝트에 연결된 이슈라도, 그 이슈가 속한 Jira 프로젝트를 볼 권한이 없는 참여 인원에게는 보이지 않는다(다른 부서 스페이스의 이슈 등).

## 요구 (제품 소유자, 2026-09-30)
프로젝트 설정에 **「협업 모드」** 를 두고, 켜면 그 프로젝트에 **연결된 이슈**를 **앱 자격(asApp)** 으로 조회해 **프로젝트 참여 인원이 내용을 전부 볼 수 있게** 한다.

확정 사항:
| 항목 | 결정 |
|---|---|
| 적용 화면 | **작업관리 탭**(목록 · 트리 · 간트 · 이슈 맵) + **캘린더 탭** + **프로젝트 대시보드 탭** |
| 켜는 사람 | 프로젝트 **쓰기 권한자**(`PROJECT write`) — 프로젝트 정보 수정과 같은 권한 |
| 워크로그 | **포함** — MD·진척도 집계에 쓰이는 워크로그(다른 사람의 시간 기록)도 앱 자격으로 읽는다 |
| 쓰기 동작 | 지금처럼 **본인 자격**(이슈 편집·워크로그 기록·상태 변경·연결 변경). 권한이 없으면 그대로 실패한다 |

## 반드시 지킬 경계 (Jira 권한을 앱이 의도적으로 넘어서는 기능이므로)
1. **대상 이슈 한정**: 그 프로젝트에 연결된 이슈(`moves_RMS_projectId = <id>`)만. JQL 은 **서버가 조립**하고 프로젝트 술어를 항상 AND 로 붙인다. 클라이언트가 보낸 JQL 문자열을 그대로 실행하지 않는다(구조화된 필터 인자만 받는다).
2. **대상 사용자 한정**: 그 프로젝트 **참여 인원**만. 서버가 `principal` 로 참여 여부(project_users)와 프로젝트 데이터 범위(`ProjectScope`)를 확인한다. 참여자가 아니면 거부.
3. **켜져 있을 때만**: 협업 모드가 꺼진 프로젝트에서 앱 자격 resolver 를 부르면 거부(fail-close). 설정값은 서버가 읽는다(클라이언트가 보낸 값을 믿지 않는다).
4. **응답 최소화**: 화면이 쓰는 필드만 내려준다(전체 이슈 객체 전달 금지).
5. **표시**: 협업 모드로 조회된 화면임을 사용자가 알 수 있게 표시한다(배지·안내). Jira 링크를 눌러 이동하면 못 보는 이슈일 수 있다.
6. **감사 가능성**: 협업 모드를 켜고 끈 사람·시각을 기록한다(프로젝트 레코드 컬럼 정도면 충분).
7. **아키텍처 문서의 asApp 허용 경로 목록**(`Moves_Workforce_아키텍처_설계서.md` §4.4)에 ⑥으로 추가한다. 마켓 심사 사유: "프로젝트 설정으로 쓰기 권한자가 켜는 열람 기능, 대상은 연결 이슈·참여 인원으로 한정".

## 구조 방향 (설계에서 확정)
- 앱 자격 호출은 브라우저에서 못 한다 → 적용 화면의 이슈·워크로그 조회를 **서버 resolver 경유**로 바꾸는 경로가 필요하다. 협업 모드가 꺼진 프로젝트는 **지금 경로(브라우저 직접, 본인 자격)를 그대로** 쓴다. 즉 화면은 프로젝트의 협업 모드 여부에 따라 두 경로 중 하나를 고른다.
- 설정 저장: 프로젝트 레코드(Forge SQL `project` 테이블)에 컬럼 추가 + 마이그레이션(`src/rdb/schema/ddl` 등록 규약). 프로젝트 정보 수정 모달(`ProjectModal`)에 토글.
- 기존 asApp 예외 경로·`RequestJiaJson`의 `as` 인자·`WorklogApi`·`IssueApi` 를 재사용한다. 워크로그 N+1 최적화 교훈: 공통 경로를 고치지 말고 **기능별 전용 페처**로 분리한다(메모리 `feedback_worklog_fetch_isolation`).

## 하지 않는 것
- 분석 리포트 탭·워크로그(내 작업) 화면·문서 탭·자원관리·전사 대시보드에는 적용하지 않는다(1차 범위 밖).
- 이슈 본문(description)·댓글·첨부는 지금도 화면에 없으면 추가하지 않는다.
- 쓰기 동작을 앱 자격으로 바꾸지 않는다.

## 영향 범위
백엔드(resolver 신설 · JQL 조립 · 참여자 검사 · 마이그레이션 · PermissionMap), 프론트(적용 화면의 조회 경로 분기 · 설정 토글 · 표시), 문서(아키텍처 설계서 §4.4), 테스트.
