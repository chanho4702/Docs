  • 스킬명은 중복될 수 없습니다. 목록이 100건을 넘어도 전체가 표시되고 중복 판정도 전체 기준입니다.

적합도는 필요 스킬과 보유 스킬을 맞대어 계산합니다. 둘 중 하나라도 비어 있으면 의미 있는 값이 나오지 않습니다.

2. 프로젝트에 필요 스킬을 지정한다        → 4.1 프로젝트 추가/수정 창 또는 6.4의 요구 스킬 편집
3. 인력에 보유 스킬을 지정한다            → 6.1 인력 현황 / 마이페이지 / 팀장의 내 팀
4. 6.4에서 적합도 순으로 후보를 본다

버튼·입력 항목과 처리 결과 상세

스킬 관리에서는 보유·필요 스킬 선택에 쓰는 사전을 관리합니다. 특정 사용자의 보유 스킬 편집과 다릅니다.

버튼·입력 항목 기능·사용 조건·변경 대상 결과 확인과 문제 대응
스킬 추가·이름·분류·설명 이름은 필수이며 기존 이름과 중복될 수 없습니다. 분류는 기존 값을 선택하거나 입력해 정리합니다. 등록 후 사용자·프로젝트 스킬 선택지에서 확인합니다. 사전 등록만으로 사용자에게 보유 스킬을 부여하지 않습니다.
프리셋 추가·전체 선택 분류별 예시 스킬을 골라 등록합니다. 이미 있는 이름은 추가에서 건너뜁니다. 중복 표현과 실제 조직 필요성을 확인하고 추가·건너뜀 결과를 검토합니다.
수정·삭제 이름·분류·설명을 수정하거나 사용되지 않는 사전 항목을 제거합니다. 사용 중인 스킬은 삭제가 거부됩니다. 사용자 보유·프로젝트 필요 스킬 참조를 확인하고 먼저 정리합니다.
