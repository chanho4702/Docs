## 내레이션 원고 (TTS에 그대로 넣는 용)

이번 달 투입 MM, 인건비, 진척률. 아직도 엑셀로 맞추고 계신가요?
이슈는 Jira에, 인력 배치는 엑셀에, 비용은 별도 시트에. 보고할 때마다 숫자를 다시 맞춥니다.
Moves Workforce는 이 숫자를 Jira 안에서, 규칙으로 만듭니다.
실무자는 평소처럼 워크로그만 남기면 됩니다.
PM은 목록, 트리, 간트로 작업 구조와 일정을 관리하고,
공휴일과 연차를 반영한 MD·MM, 가동률, 실제 완성 기준의 진척률이 자동으로 계산됩니다.
급여 정책에 따른 인건비까지, 권한 있는 사람에게만 보여 줍니다.
경영진은 전사 프로젝트의 일정·범위·인력 상태를 한 화면에서 확인합니다.
Jira의 업무 기록을 판단 근거로. Moves Workforce.

## 영상 파일로 만드는 순서

1. Claude Desktop이 만든 HTML을 브라우저 전체 화면(F11)으로 연다
2. 녹화: Windows `Win+Alt+R`(Xbox Game Bar) 또는 OBS로 55초 녹화
3. 내레이션: 직접 녹음하거나 TTS(Clipchamp 내장 TTS — 한국어 음성 있음)로 위 원고 생성
4. Clipchamp(Windows 기본 탑재)에서 녹화본 + 음성 + 배경음악 합치고 장면 타이밍 미세 조정 → 1080p 내보내기
