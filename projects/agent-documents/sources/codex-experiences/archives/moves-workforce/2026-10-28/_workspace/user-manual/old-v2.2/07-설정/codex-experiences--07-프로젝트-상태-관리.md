# 7.7 설정 — 프로젝트 상태 관리

## 🔐 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 (`/backoffice/project-status`) | `PROJECT_STATUS_MANAGEMENT` 읽기 |
| 상태 추가·수정·삭제 | `PROJECT_STATUS_MANAGEMENT` 쓰기 |
| 상태 연결(흐름) 편집 | `PROJECT_STATUS_MANAGEMENT` 쓰기 |
| 칸반 화면에서 컬럼 추가·이름 변경·삭제 | `KANBAN` 쓰기 |

- 같은 상태를 두 곳에서 만질 수 있습니다. **설정 화면은 `PROJECT_STATUS_MANAGEMENT`**, **칸반 화면은 `KANBAN`** 권한을 씁니다.

---

**언제 쓰나** — 프로젝트의 **상태(칸반 컬럼)** 와 **상태 전이 흐름**을 정의할 때.

기본 시드 상태는 `To Do` → `IN PROGRESS` → `DONE` 입니다.

## 상태 추가·수정

1. **상태 추가**를 누릅니다.
2. **상태 이름**(예: 진행중)과 **색상**을 지정합니다.
3. 행에서 수정·삭제할 수 있습니다.

> 여기서 정의한 상태가 [프로젝트 목록](../codex-experiences--04-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EA%B4%80%EB%A6%AC.md#41-프로젝트-목록)의 상태 선택지와 [칸반 보드](../codex-experiences--04-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EA%B4%80%EB%A6%AC.md#42-칸반-보드)의 **컬럼**이 됩니다. 칸반 화면에서도 컬럼 추가·이름 변경·삭제를 할 수 있습니다.

## 상태 흐름 편집

**상태 연결 편집**을 누르면 상태 간 이동 흐름을 시각적으로 정의합니다.

**규칙**

- 각 상태는 **다음 상태 하나, 이전 상태 하나**만 가질 수 있습니다(1:1 연결).
- **순환 연결은 허용되지 않습니다.**
- 연결되지 않은 상태는 "연결되지 않은 상태입니다"로 표시됩니다.

## 삭제 제약

| 제약 | 이유 |
|---|---|
| 최소 1개의 상태가 필요합니다 | 상태가 하나도 없으면 프로젝트를 만들 수 없습니다 |
| 이전 상태가 없으면 삭제할 수 없습니다 | 삭제 시 그 상태의 프로젝트를 옮길 곳이 필요합니다 |

> 삭제하면 그 상태에 있던 **프로젝트는 이전 상태로 변경**됩니다(프로젝트가 삭제되지 않습니다).
