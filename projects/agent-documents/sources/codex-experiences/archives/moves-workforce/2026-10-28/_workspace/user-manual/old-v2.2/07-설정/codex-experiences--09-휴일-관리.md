# 7.9 설정 — 휴일 관리

## 🔐 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 메뉴 노출 (사이드바) | `PERMISSION_MANAGEMENT` 읽기 |
| 휴일 추가·수정·삭제 | `PUBLIC_HOLIDAY_MANAGEMENT` 쓰기 |
| 휴일 목록 자체 | 전역 공개 — 근무일 계산에 쓰이므로 모든 화면에서 읽힙니다 |

> ⚠️ **알려진 불일치:** 메뉴 노출과 편집 판정이 서로 다른 키를 씁니다. `PUBLIC_HOLIDAY_MANAGEMENT`만 가진 사용자는 **사이드바에 메뉴가 보이지 않아** `/backoffice/public-holiday` URL로 직접 접근해야 합니다.

---

**언제 쓰나** — 근무일·가용 MD 계산의 기준이 되는 **공휴일**을 등록할 때.

## 목록 컬럼

| 컬럼 | 설명 |
|---|---|
| 이름 | 예: 설날 |
| 날짜 | 휴일 날짜 |
| 가용률 | 그날의 근무 가능 비율 |
| 작업 | 수정·삭제 |

**휴일 추가**로 이름·날짜·가용률을 입력해 등록합니다.

## 가용률 이해하기

| 값 | 의미 | 차감 |
|---|---|---|
| 0 | 완전 휴무 | **1 MD 차감** |
| 0.5 | 반일 근무 | **0.5 MD 차감** |
| 1 | 정상 근무 | 차감 없음 |

## 계산 규칙

- **주말(토·일)에 등록된 공휴일은 가용 MD 차감에서 제외됩니다.** 기준 작업일(월 기준 MD)이 이미 주말을 빼고 있기 때문입니다.
- **개인 휴가는 별도로 반영**됩니다 — 연차 1일당 1 MD, 반차 0.5 MD 차감, '기타'(가용률 1)는 차감 없음.

## 월별 1MM 기준

상단에 공휴일과 평일을 기준으로 **자동 계산된 월별 1MM(근무일/시간)** 이 표시됩니다. 휴일을 등록·수정하면 **즉시 반영**됩니다.
