가이드 홈 · English

여러 프로젝트의 일정·범위·자원·비용을 비교해 점검할 프로젝트를 고릅니다. 통합 대시보드는 실시간 입력 화면이 아니라 집계된 현황입니다.

필요한 권한

리포트 읽기로 조회하고, 리포트 쓰기로 재집계합니다. 비용 정보에는 비용 읽기도 필요합니다. 프로젝트는 본인의 조회 범위 안에서 표시됩니다.

권장 점검 순서

  1. 기준 시각과 집계 상태를 확인합니다.

  2. 비교할 프로젝트를 선택합니다.

  3. 종합 개요의 일정·범위·자원 신호로 점검 대상을 고릅니다.

  4. 해당 비교 탭에서 원인을 좁힙니다.

  5. 프로젝트 상세의 진척·작업·인력 분석에서 실제 이슈를 확인합니다.

비용

신호등은 조사할 대상을 고르는 요약입니다. 초록이라고 모든 문제가 없다는 뜻은 아니며, 적색이라고 원인이 확정된 것도 아닙니다.

집계와 필터 유의점

  • 워크로그나 인력 변경 직후에는 이전 집계가 보일 수 있습니다. 권한이 있다면 재집계하고 완료 여부를 확인합니다.

  • 일부 프로젝트 집계가 실패해 직전 값을 표시하면 해당 프로젝트를 최신으로 보고하지 않습니다.

  • 일부 전사 위젯은 상단 프로젝트 필터와 다른 범위를 사용합니다. 위젯의 설명을 확인합니다.

  • 급여 정책 변경 후에는 새 정책으로 집계되기 전 비용 표시가 제한될 수 있습니다.

  • 전사 종합 가동률과 프로젝트별 가동률은 기간의 중복 처리와 분모가 달라질 수 있습니다.

토폴로지가 제공되면 프로젝트·스페이스·상태·이슈의 연결을 펼쳐 원인 이슈로 이동할 수 있습니다. 표시 상한이나 일부 표시 안내가 있으면 전체 데이터로 해석하지 않습니다.

공통 조작과 집계

포트폴리오는 집계 시점의 여러 프로젝트를 비교합니다. 새 워크로그가 저장되어도 마지막 집계 기준 값일 수 있습니다.

지금 집계·집계 시각·부분 실패

권한이 있으면 새 집계를 요청하고 완료 후 갱신합니다. 일부 프로젝트 실패 시 이전 값이 남을 수 있습니다.

접수·실행 중·완료를 구분하고 As of와 실패 안내를 확인합니다. 혼합 시점 값을 모두 최신이라고 읽지 않습니다.

프로젝트 선택·모두·해제

비교할 프로젝트를 선택합니다. 해제는 저장 데이터를 지우지 않습니다. 일부 조직 전체 지표는 프로젝트 선택과 무관합니다.

각 위젯의 전체·선택 프로젝트 기준을 확인합니다. 선택 0개면 선택 안내가 나올 수 있습니다.

Time·Scope·Resource·Cost

일정·범위·인력·비용 분석 축을 전환합니다. Cost는 비용 접근에 따라 표시됩니다.

비용 축이 없으면 일반 조회 권한과 비용 권한을 구분해 확인합니다.

Signals·표·차트·확대·행 상세

표현을 바꾸거나 프로젝트별 상세로 들어갑니다. 현재 신호와 계산 설명을 함께 확인합니다.

닫기·보기 전환은 데이터 변경이 아닙니다. 확대 화면에서도 동일 필터와 집계 시각을 확인합니다.

종합 개요

종합 개요 — 프로젝트별 T/S/R 신호

보여주는 내용: 각 프로젝트의 일정·범위·자원 상태를 신호등으로 요약 (행 클릭 → 상세)

계산 기준

T는 완료 진척 대비 일정 경과, S는 미착수 작업 비율, R은 프로젝트 평균 가동률을 진단합니다. 가동률·미착수 비율의 색상 경계는 현재 사이트 설정과 집계값을 따릅니다.

해석 방법

자원(R) 신호는 프로젝트 내 평균 부하 기준이라 전사 가동률 분포(필터 무관)와 의미가 다릅니다. 일정(T)·비용(CPI)의 완성률은 진행중 이슈를 공수 소진율로 근사하므로 실제 산출물 완성도와 다를 수 있습니다. 세 신호 중 적색이 많을수록 종합 리스크가 높습니다.

필터·권한·주의사항: 상단에서 선택한 프로젝트와 본인의 조회 권한 범위를 따릅니다. 선택 변경 후 집계 기준 시각을 함께 확인합니다.

Time — 일정

프로젝트 일정

보여주는 내용: 프로젝트별 시작~종료 기간 위에 일정 경과율(파란 막대)과 완성률(초록 막대)을 한 행에서 비교

계산 기준

위 막대=일정 경과(시작일오늘, 캘린더 기준, 채움 경계=오늘 점선과 일치). 아래 막대=완성률(초록, 시작일 기준 진척). 두 막대 모두 시작종료 전체 길이를 기준으로 채워진다.

해석 방법

초록(완성률) 끝이 파랑(경과)·오늘 선보다 왼쪽이면 일정 대비 진척이 뒤처진 지연 신호. 오른쪽이면 일정보다 앞섬. 이제 차트에서 직접 비교된다.

필터·권한·주의사항: 상단에서 선택한 프로젝트와 본인의 조회 권한 범위를 따릅니다. 선택 변경 후 집계 기준 시각을 함께 확인합니다.

공수 추이 비교

보여주는 내용: 선택 프로젝트별 투입 MD 라인 비교 (월/주 단위 전환)

계산 기준

프로젝트별 투입 공수(MD)를 라인으로 표시. 월간/주간 단위 전환, 누적 모드는 값을 앞에서부터 합산.

해석 방법

기간별은 투입 리듬, 누적은 진행 S-curve. 주간은 더 촘촘한 추이를 본다.

필터·권한·주의사항: 선택 프로젝트 기준입니다. 월·주와 기간별·누적을 전환합니다. 누적 곡선을 산출물 완료 비율로 해석하지 않습니다.

리스크 TOP 프로젝트

보여주는 내용: 완성-일정 차이(지연 %p) 큰 순

계산 기준

리스크 = max(0, 일정율-완성율)×100(%p). 값이 클수록 일정 대비 진척 지연.

해석 방법

상위 막대가 가장 위험한 프로젝트. 색(빨강/노랑/초록)으로 심각도를 구분.

필터·권한·주의사항: 상단에서 선택한 프로젝트와 본인의 조회 권한 범위를 따릅니다. 선택 변경 후 집계 기준 시각을 함께 확인합니다.

Scope — 범위

Workforce(RMS) 프로젝트 · 상태 · 이슈 토폴로지

보여주는 내용: 각 Workforce(RMS) 프로젝트가 작업 상태와 전개된 이슈로 이어지는 경로를 봅니다.

계산 기준

Workforce 허브가 화면에 표시된 프로젝트를 연결합니다. 프로젝트별 작업 상태 건수는 최근 집계 결과에서 가져오며, 상태를 누르면 해당 이슈가 펼쳐집니다.

해석 방법

Workforce에서 RMS 프로젝트와 상태까지 이어지는 선을 따라 작업 집중도를 봅니다.

필터·권한·주의사항: 상단 선택 프로젝트 기준입니다. 상태 노드를 선택해 이슈를 펼칩니다. 펼친 목록은 집계 상태와 조회 시점이 다를 수 있으며 Jira 접근·일부 표시 안내를 확인합니다.

이슈 상태 분포

보여주는 내용: 프로젝트별 완료 / 진행 / 대기 이슈 구성

계산 기준

issue counts 의 done/inProgress/todo 카운트를 프로젝트별 누적막대로 표시(비율 모드는 프로젝트 합으로 정규화).

해석 방법

대기 비중이 큰데 일정이 임박하면 범위 리스크. 완료 비중이 높을수록 범위 소화가 진척된 상태.

필터·권한·주의사항: 상단에서 선택한 프로젝트와 본인의 조회 권한 범위를 따릅니다. 선택 변경 후 집계 기준 시각을 함께 확인합니다.

완성률 vs 일정률

보여주는 내용: 프로젝트별 범위 소화(완성) 대비 시간 경과(일정)

계산 기준

프로젝트별 completion(완성률)와 elapsed schedule(일정률)를 그룹막대로 병치.

해석 방법

완성막대가 일정막대보다 낮으면 일정 대비 지연, 높으면 선행. 범위 진척 속도를 비교.

필터·권한·주의사항: 상단에서 선택한 프로젝트와 본인의 조회 권한 범위를 따릅니다. 선택 변경 후 집계 기준 시각을 함께 확인합니다.

이슈 완료율 vs 진척률

보여주는 내용: 끝난 이슈 수로 본 완료율과 공수로 본 진척률을 나란히 놓고 차이를 봅니다

계산 기준

이슈 완료율 = 완료 이슈 수 ÷ 전체 이슈 수. 진척률은 계획 공수를 기준으로 얼마나 됐는지를 본 값으로 진척도 탭과 같습니다. 이슈가 없는 프로젝트는 뺍니다.

해석 방법

두 값이 벌어질수록 "몇 개 끝났나"와 "얼마나 됐나"가 다르게 읽히는 프로젝트입니다. 완료 건수만 보고 안심하면 안 되는 곳을 찾을 때 씁니다.

필터·권한·주의사항: 상단에서 선택한 프로젝트와 본인의 조회 권한 범위를 따릅니다. 선택 변경 후 집계 기준 시각을 함께 확인합니다.

지연 이슈가 몰린 담당자

보여주는 내용: 문제 이슈를 많이 안고 있는 담당자 10명

계산 기준

전 프로젝트의 문제 이슈 상위 50건에서 담당자별 건수를 세어 상위 10명을 표시합니다. 상단 프로젝트 필터는 적용되지 않습니다.

해석 방법

미배정 그룹이 크면 담당자 지정 여부와 실제 지연 원인을 함께 확인합니다. 담당자별 문제 건수를 개인 성과 평가로 단정하지 않습니다.

필터·권한·주의사항: 상단 선택과 무관한 전역 문제 이슈 TOP50을 담당자별로 집계한 TOP10입니다. 모든 지연 작업이나 전체 담당자 목록을 집계한 표는 아닙니다.

계획 대비 실적 공수

보여주는 내용: 프로젝트별 계획 공수(MD) 대비 실 투입 공수(MD) 비교

계산 기준

planned MD(계획) 대비 actual MD(실적) 막대 병치. 투입률 = 실적 / 계획.

해석 방법

실적이 계획을 넘으면 공수 초과, 한참 못 미치면 범위 미소화 또는 지연.

필터·권한·주의사항: 상단에서 선택한 프로젝트와 본인의 조회 권한 범위를 따릅니다. 선택 변경 후 집계 기준 시각을 함께 확인합니다.

문제 이슈 한눈에 (TOP 50)

보여주는 내용: x=지연일수, y=공수편차, 버블=심각도

계산 기준

심각도 = 지연일수×1 + max(공수편차,0)×2 — 일정 지연보다 초과 공수에 2배 가중(계획보다 덜 쓴 공수는 0 처리). 전 프로젝트 상위 50건을 버블로 표시.

해석 방법

우상단(지연·초과 큼)일수록 위험. 버블 크기는 심각도이며 공수 초과가 클수록 더 크게 부각. 우선 대응 대상을 식별.

필터·권한·주의사항: 포트폴리오 전역 집계의 문제 이슈 상위 50건이며, 상단 프로젝트 선택과 프로젝트 범위 필터가 적용되지 않습니다. 표시 상한을 전체 문제 건수로 읽지 않습니다.

Resource — 자원

전사 배정 관계도

보여주는 내용: 어느 팀의 누가 어떤 프로젝트에 배정돼 있는지 한눈에 봅니다

계산 기준

자원관리의 프로젝트 배정 탭과 같은 데이터입니다. 배정 기준이라 실제 투입 공수와는 다릅니다.

해석 방법

한 사람에게서 여러 프로젝트로 선이 나가면 여러 곳에 배정된 사람입니다. 이 카드는 상단 프로젝트 필터와 상관없이 전사 배정을 보여줍니다.

필터·권한·주의사항: 상단 프로젝트 선택이 적용되지 않으며 관계도 자체 필터와 조직 조회 범위를 따릅니다. 자원 관리 읽기가 필요합니다. 관계도 불러오기를 눌러 조회하고 인원 노드 선택은 자원 관리로 이동합니다.

롤 / 레벨 분포 비교

보여주는 내용: 선택 프로젝트별 인원 구성(명)

계산 기준

프로젝트별로 롤(또는 레벨)별 인원수를 세어 누적막대로 표시(y축=명).

해석 방법

막대 높이는 총 투입 인원, 색 구간은 롤/레벨 구성. 프로젝트 간 인력 규모·구성을 비교.

필터·권한·주의사항: 선택 프로젝트 기준입니다. 역할·레벨 축을 전환합니다. 같은 인원이 여러 프로젝트에 참여하면 프로젝트별 인원수에 각각 포함될 수 있으므로 조직의 고유 인원수와 구분합니다.

인력 가동률

보여주는 내용: 종합(전사 분포·과부하 명단) / 프로젝트별(멤버 가동률)

계산 기준

가동률 = 실제 일한 양 ÷ 일할 수 있었던 양. 분자(실제) = 워크로그 시간을 일(MD)로 환산(1MD = 하루 근무시간). 분모(가용) = 그 기간의 근무일(주말·공휴일 제외)에서 연차/휴가를 뺀 실제 출근 가능 일수. 1.0 = 100%(풀가동). 종합은 한 사람이 참여한 모든 프로젝트 기간을 '겹치지 않게' 합쳐(중복 기간 1회만 — 이중계상 방지) 분모를 잡고, 프로젝트별은 해당 프로젝트 기간만으로 분모를 잡는다.

해석 방법

1.0(100%)을 넘으면 초과 투입(과부하), 못 미치면 여유. 연차를 분모에서 빼므로 휴가자가 과소평가되지 않는다. 종합 = '이 사람이 전사적으로 과부하인가'(여러 프로젝트 합산이라 필터 무관), 프로젝트별 = '이 프로젝트에서 누가 과부하인가'. 두 값은 분모가 달라 의미가 다르다.

필터·권한·주의사항: 종합은 상단 프로젝트 선택과 무관한 전체 집계 범위이고, 프로젝트별은 선택 프로젝트 기준입니다. 두 보기의 기간·분모를 맞추어 해석합니다.

작업 분포 — 투입 인력 대비 공수

보여주는 내용: 점=인원 1명 공수(MD) · 프로젝트별 분포+집계

계산 기준

점은 인원 1명의 투입 공수(MD), 막대는 프로젝트별 평균 공수.

해석 방법

점이 위아래로 흩어지면 인원 간 부하 편차가 큼. 막대로 프로젝트 평균을 비교.

필터·권한·주의사항: 상단에서 선택한 프로젝트와 본인의 조회 권한 범위를 따릅니다. 선택 변경 후 집계 기준 시각을 함께 확인합니다.

인력 집중도

보여주는 내용: 인원별 투입 공수를 많은 순으로 놓고, 몇 명에게 일이 몰려 있는지 봅니다

계산 기준

선택한 프로젝트의 인원별 투입 공수(MD)를 합산해 많은 순으로 정렬하고, 전체 인원 기준으로 누적 비중을 구합니다. 위 문장은 상위 20% 인원이 차지하는 비중입니다.

해석 방법

누적선이 일찍 80%에 닿을수록 소수 인원에게 일이 몰려 있다는 뜻입니다. 그 인원이 빠지면 일정에 바로 영향이 갑니다.

계산 기준

가로축은 선택한 프로젝트에서 인원별로 합산한 투입 공수(MD), 세로축은 전사 가동률입니다. 구간 색은 자원관리·마이페이지와 같은 기준을 씁니다.

해석 방법

오른쪽 위는 맡은 일도 많고 전사 가동률도 높은 사람이라 가장 먼저 부담을 덜어줘야 합니다. 오른쪽 아래는 일은 많지만 아직 여유가 있고, 왼쪽 위는 다른 프로젝트 쪽 부담이 큰 사람입니다.

필터·권한·주의사항: 가로축의 MD는 선택 프로젝트 합계이고 세로축은 전체 집계의 가동률입니다. 두 축의 범위가 다릅니다.

완료 시 예상 비용

보여주는 내용: 지금 속도가 유지되면 프로젝트가 끝날 때 인건비가 얼마가 되는지 봅니다

계산 기준

CPI=완료 진척÷일정 경과이며 CPI가 양수일 때 완료 시 예상 비용=계획 인건비÷CPI입니다. 일정 경과가 없거나 CPI가 0이면 현재 구현은 계획 인건비를 대신 표시합니다. 같은 높이의 막대라도 위험이 없다는 뜻은 아니므로 CPI와 진행 상태를 함께 확인합니다.

해석 방법

예상 막대가 예산 막대보다 높으면 지금대로 갈 때 예산을 넘깁니다. 맨 위 문장은 지금 손대지 않으면 얼마가 더 드는지를 알려줍니다.
