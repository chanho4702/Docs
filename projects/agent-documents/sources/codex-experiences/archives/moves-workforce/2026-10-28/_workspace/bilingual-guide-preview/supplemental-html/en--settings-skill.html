Define the skill dictionary

Skill management read opens the dictionary; write permits adding, editing, deleting, and preset additions. The dictionary defines choices, not who holds a skill or which skills a project requires.

Assigning people's skills uses Resource management write or the applicable self/team-lead path. Defining project requirements uses Project write.

Register skills

The table shows a unique skill name, job category, and description. Add skill creates one entry. Category presets add several typical skills at once and skip existing entries. Categories can be selected or entered.

Deletion and duplicate checks

A skill in use cannot be deleted. Remove it from people's skills and project requirements first. Names must be unique. The dictionary and duplicate checks cover the complete supported list, including more than 100 entries.

Make fit useful

  1. Register the skill dictionary.
  2. Select project required skills in the project form or assignment screen.
  3. Select people's skills in the people overview, My Page, or the leader's My Team view.
  4. Compare candidates by fit in Project assignment.

Fit compares requirements with registered skills. If either set is empty, the result cannot provide a meaningful match.

Buttons, fields, and result checks

Skill Management maintains the dictionary for personal/project skills, separate from editing a user's selected skills.

Control or field Function, conditions, and data affected Result check and recovery
Add Skill / name / category / description Name is required and must not duplicate an existing name. Select/type a category to organize entries. Check user/project choices after saving. Adding to the dictionary does not assign the skill to users.
Add Preset / Select All Select category presets for registration. Existing names are skipped. Check equivalent names/organizational needs and review added/skipped results.
Edit / Delete Edit name/category/description or remove an unused dictionary entry. In-use skills cannot be deleted. Review personal/project references and remove them first.
