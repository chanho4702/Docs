## 1. 목적·범위

Moves Workforce를 설치한 직후, **첫 화면을 의미 있게 볼 수 있는 상태까지** 최소 단계로 안내한다(약 15분). 각 단계의 상세 옵션은 관리자/사용자 매뉴얼을 참조한다.

## 2. 관리자 — 15분 셋업

> 아래 순서대로 하면 지표가 정상적으로 계산되는 최소 상태가 된다. 설치 시 시드·DB는 **자동 초기화**되므로 별도 초기화 작업은 없다.

### 단계 1. 설치 확인 (1분)
- Jira 상단/앱 메뉴에서 **"Moves Workforce"** 글로벌 페이지가 열리는지 확인한다.
- 라이선스 미활성 시 안내 페이지가 뜨면, 평가(Trial) 활성화 또는 라이선스 적용 후 진행한다.

### 단계 2. 공휴일 등록 (2분) — *가장 먼저 할 것*
- **백오피스 → 공휴일 관리(`/backoffice/public-holiday`)**
- 해당 연도의 공휴일을 등록한다. 반휴는 근무 비율(workRatio 0.5 등)로 설정.
- ⚠️ 근무일 기반 계산(1MM·가동률·일정률)의 분모가 여기서 정해지므로, **워크로그보다 먼저** 맞춰두는 것이 좋다.

### 단계 3. 일반 설정과 급여 정책 확인 (2분)
- **백오피스 → 환경설정(`/backoffice/setting`)**
- 통화, 1일 근무시간, 가동률 밴드·범위·진척 임계값을 조직 기준에 맞게 확인·조정한다.
- 인건비 원천을 **인원별(`INDIVIDUAL`)** 또는 **등급 기반(`LEVEL_BAND`)**으로 선택한다. 등급 기반이면 다음 단계에서 모든 사용 등급에 대표값을 입력하거나 하한·상한을 모두 입력해 중앙값을 사용할 수 있게 한다.

### 단계 4. 기준정보·팀 등록 (3분)
- **역할(`/backoffice/role`)·등급(`/backoffice/level`)·스킬(`/backoffice/skill`)·팀(`/backoffice/team`)·프로젝트 상태(`/backoffice/project-status`)**를 조직에 맞게 정리한다.
- 등급 기반 급여 정책에서는 등급별 **대표값** 또는 **하한·상한 모두**를 입력한다. 대표값이 비어 있고 하한·상한이 모두 있으면 중앙값을 사용한다. 팀은 상위/하위 관계와 팀장을 지정하고, 필요하면 드래그앤드롭으로 계층을 정리한다.

### 단계 5. 사용자 등록 (2분)
- **백오피스 → 구성원 관리(`/backoffice/users`)**
- 단건 추가 또는 **엑셀 대량 업로드**로 인력을 등록한다(대량은 백그라운드 처리 + 진행 표시).
- 사용자별 소속 팀·역할·등급·권한을 지정한다. `INDIVIDUAL` 정책일 때만 개인 연봉을 입력한다.

### 단계 6. 권한 확인 (1분)
- **백오피스 → 권한 관리(`/backoffice/permission`)**
- 시드 권한 세트(Admin/Member), 권한 묶음 프리셋(PM/PMO/Team Lead/Team Member), 각 세트의 projectScope(`ALL`/`MEMBER_ONLY`/`TEAM_ONLY`)를 확인한다. Jira 사이트 관리자는 자동 Admin.
- 인건비 등 민감 정보 노출 범위(`PROJECT_COST`)를 정책에 맞게 확인한다.
- 자원관리 담당자에게는 `RESOURCE_MANAGEMENT`, 조직 편성 담당자에게는 `TEAM_MANAGEMENT`, 스킬 관리자에게는 `SKILL_MANAGEMENT`를 명시적으로 부여한다.

### 단계 7. 첫 프로젝트 생성과 결과 확인 (4분)
- **프로젝트 목록(`/project`)**에서 **+ 프로젝트 추가**를 눌러 이름·상태·시작일·종료일·프로젝트 비용을 입력한다.
- 생성한 프로젝트의 상세 화면을 열어 담당 팀과 인력을 배정한다. 담당 팀 지정만으로 팀원이 자동 추가되지는 않으므로 필요한 인원 또는 **팀 전체 추가**를 실행한다.
- `INDIVIDUAL` 정책의 프로젝트 인력은 `PROJECT` 급여 모드가 기본이다. **급여 관리**에서 투입 급여를 입력하거나, 개인 연봉을 사용할 인원은 `ANNUAL`로 바꾼다. 이 단계를 건너뛰면 계획 인건비가 0으로 보일 수 있다.
- 실무자가 워크로그를 기록하기 시작하면 상세·분석·진척도 화면에 값이 채워진다.
- Jira 스페이스/보드의 이슈를 자동 편입하려면 프로젝트 상세 → 작업 관리 → **작업 추가 → 구독 설정**에서 소스를 구독한다. 기존 이슈까지 가져오려면 **기존 이슈도 가져오기**를 선택한다.
- **전사 대시보드(`/dashboard`)**는 하루 한 번 배치 후 채워진다. 즉시 보려면 화면의 **"재집계"** 버튼을 사용한다.

## 3. 사용자 — 3분 시작

1. **내 작업(`/myWork`)** — 앱을 열면 기본으로 보이는 화면. 나의 프로젝트·업무·요약 지표를 확인.
2. **워크로그 기록** — "내 작업"에서 업무일지(워크로그)를 추가한다. 이 기록이 모든 공수·가동률·진척 지표의 원천이다.
3. **마이페이지(`/my-page`)** — 내 프로젝트·작업·워크로그·권한·스킬을 확인한다. 팀장은 자신이 이끄는 팀과 하위 팀의 업무 분석도 볼 수 있다.
4. **프로젝트 보기** — 프로젝트 목록에서 상세로 들어가 대시보드·인력/급여/배정·작업(목록/트리/간트)·캘린더·분석 탭을 확인한다.
5. **자원관리(`/resource`)** — 권한이 있다면 인력 현황·조직 현황·팀 분석·프로젝트 배정을 확인한다.

팀 관련 화면은 목적이 다르다. **마이페이지의 내 팀**은 팀장이 자기 조직의 업무를 보는 화면, **프로젝트 상세의 팀 분석**은 해당 프로젝트의 담당 팀과 실제 기여 팀을 대조하는 화면, **자원관리의 팀 분석**은 권한 범위 안의 여러 팀·프로젝트를 비교하고 계층 롤업을 보는 화면이다.
