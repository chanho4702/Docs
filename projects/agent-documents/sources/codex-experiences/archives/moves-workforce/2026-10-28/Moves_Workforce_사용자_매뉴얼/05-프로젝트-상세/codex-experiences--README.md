# 5. 프로젝트 상세

## 접근 권한

프로젝트 상세는 **탭마다 권한이 다릅니다.** 권한이 없는 탭은 목록에 나타나지 않습니다.

| 탭 / 서브탭 | 조회 | 편집(쓰기) |
|---|---|---|
| **대시보드** | 「대시보드」 읽기 | 「대시보드」 쓰기 (위젯 추가·레이아웃·필터) |
| **인력 관리** > 인력 목록 | 「프로젝트 관리」 읽기 | 「프로젝트 관리」 쓰기 또는 「자원관리」 쓰기 |
| **인력 관리** > 급여 관리 | 「비용」 읽기 | 「비용」 쓰기 |
| **인력 관리** > 작업 배정 | 「프로젝트 관리」 읽기 또는 「자원관리」 읽기 | 「프로젝트 관리」 쓰기 또는 「자원관리」 쓰기 |
| **작업 관리** (목록·트리·간트·맵) | 「프로젝트 관리」 읽기 | 「프로젝트 관리」 쓰기 |
| **프로젝트 캘린더** | 「프로젝트 관리」 읽기 | — |
| **분석 및 리포트** > 작업·인력 분석 | 「리포트」 읽기 | — |
| **분석 및 리포트** > 팀 | 「리포트」 읽기 **+** 「프로젝트 관리」 읽기 | — |
| **분석 및 리포트** > 진척률 | 「리포트」 읽기 | — |
| **분석 및 리포트** > 비용 | 「비용」 읽기 | — |
| **분석 및 리포트** > 작업 이력 | 「프로젝트 관리」 **쓰기** (탭 노출 조건) | — |
| **문서 관리** | 「프로젝트 관리」 읽기 | 「프로젝트 관리」 쓰기 (+ 작업 연결은 Jira의 Edit Issues) |

- **프로젝트 상세에 진입하는 것 자체**는 「프로젝트 관리」 읽기와 조회 범위 통과가 전제입니다. 범위 밖 프로젝트는 주소로 접근해도 거부됩니다.
- 총 인건비·급여·비용은 「비용」 권한이 없으면 **0원이 아니라 항목 자체가 사라집니다.**
- 작업 관리의 편집은 앱 권한 외에 **Jira 자체 권한**(이슈 편집·일정 변경·담당자 지정·이슈 연결)도 필요합니다.

프로젝트 목록·칸반·My Work 카드에서 프로젝트를 클릭하면 상세 화면으로 이동합니다.

![그림 5-1 프로젝트 상세 상단](../images/05-detail-header-tabs.png)
*그림 5-1. 프로젝트 상세 — ① 브레드크럼(프로젝트 관리 / 프로젝트명 / 탭 / 하위 탭) ② 링크 복사 ③ 상위 탭 6개 ④ 하위 탭.*

## 상단 헤더

- **브레드크럼**: `프로젝트 관리 / 프로젝트명 / 탭 / 하위 탭`. 각 항목을 눌러 목록이나 상위 탭으로 돌아갑니다.
- **링크 복사**: 지금 보고 있는 탭·하위 탭·보기 방식까지 담긴 주소를 복사합니다. 받은 사람은 같은 화면(예: 이 프로젝트의 작업 관리 > 간트)으로 바로 들어옵니다.
- 탭을 바꾸면 주소도 함께 바뀌므로 **새로고침·뒤로 가기**가 탭 단위로 동작합니다.
