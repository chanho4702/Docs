# 7.1 일반 설정

## 접근 권한

| 구분 | 필요 권한 |
|---|---|
| 화면 조회 | 「일반 설정」 읽기 |
| 설정 변경·전체 초기화 | 「일반 설정」 쓰기 |
| 급여 정책 변경 | 「일반 설정」 쓰기 |

- 여기서 정한 값(근무시간·가동률 밴드 등)은 **모든 사용자의 화면 계산에 쓰이므로**, 조회 권한 없이도 값 자체는 각 화면에 반영됩니다. 권한은 **이 설정 화면의 접근과 변경**을 제어합니다.
- 급여 정책을 바꾸면 전사 인건비 표시가 달라집니다. 영향 범위는 아래 본문을 확인하세요.

---

**언제 쓰나** — 전사 공통 기준값을 정할 때. **여기 값이 바뀌면 거의 모든 화면의 숫자가 함께 바뀝니다.**

![그림 7-2 일반 설정](../images/07-general-settings.png)
*그림 7-2. 일반 설정 — ① 화폐 단위·1Day 근무 시간·1MM 기준 일수 ② 월별 기준(일괄/개별) ③ 진척도 임계값·가동률 기준 3단계 ④ 급여 정책 카드(밴드 미설정 등급 수 경고) ⑤ 전체 초기화.*

## 설정 항목

| 항목 | 설명 | 기본값 |
|---|---|---|
| 화폐 단위 | 시스템 전역 통화 | — |
| **1Day 근무 시간** | `1MD = N시간`. 0.5 단위, 0.5~24h. 모든 MD/MM/목표시간 계산의 기준 | 8h |
| **1MM 기준 일수** | `1MM`이 며칠에 해당하는지 | — |
| 월별 기준 설정 | 모든 월에 같은 기준을 쓰거나(**일괄 적용**), 월마다 다르게(**개별 설정**) 지정 | 일괄 |
| 진척도 임계값 | 완성률과 일정률 차이를 "정상"으로 볼 허용 범위(%p). 0~100 | 5%p |
| 가동률 기준 — 과소 | 이 값 **미만**은 '과소' | 0.7 |
| 가동률 기준 — 과부하 | 이 값 **이상**은 '과부하' | 1.1 |
| 가동률 기준 — 심한 과부하 | 이 값 **이상**이면 신호등 적색(위험) | 1.3 |
| **급여 정책** | **인원별** 또는 **등급 기반** | 인원별 |
| 문서 — 분류 | 문서를 연결할 때 고르는 분류 목록. 분류마다 **필수** 지정 가능 | 기획·설계·회의록·산출물·기타 (필수 없음) |
| 문서 — 오래된 문서 기준 | 이 일수 넘게 수정되지 않은 문서를 「오래됨」으로 표시. 1~3650일 | 90일 |

하단의 **전체 초기화(기본값으로)** 로 되돌릴 수 있습니다. 값은 서버에서도 범위를 검증하므로 허용 범위 밖 값은 저장되지 않습니다.

## 각 값이 영향을 주는 곳

| 설정 | 영향 |
|---|---|
| 1Day 근무 시간 | [My Work 목표 시간](../codex-experiences--02-my-work.md#목표-시간-계산), 계획 작업량(MD) 환산, 인력 분석의 MD/MM, 진척률, [워크로그 추출](../codex-experiences--09-%EC%9B%8C%ED%81%AC%EB%A1%9C%EA%B7%B8-%EC%B6%94%EC%B6%9C.md)의 총 MD, [Jira 이슈 패널](../codex-experiences--10-jira-%EC%9D%B4%EC%8A%88-%ED%8C%A8%EB%84%90.md) KPI |
| 1MM 기준 일수 / 월별 기준 | 인력 분석의 `MM = MD ÷ 1MM 근무일`, 월별 1MM 기준선, 이슈 패널의 MM 환산 |
| 진척도 임계값 | [진척률](../05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/codex-experiences--05-%EB%B6%84%EC%84%9D-%EB%B0%8F-%EB%A6%AC%ED%8F%AC%ED%8A%B8.md#554-진척률)의 정상/주의/지연 배지 판정 |
| 가동률 기준(band) | [인력 현황](../06-%EC%9E%90%EC%9B%90-%EA%B4%80%EB%A6%AC/codex-experiences--01-%EC%9D%B8%EB%A0%A5-%ED%98%84%ED%99%A9.md) 밴드 색상, 전사 대시보드의 가동률 분포 차트와 종합 개요 신호등(자원 축) |
| 문서 분류 / 오래된 문서 기준 | [문서 관리](../05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/codex-experiences--06-%EB%AC%B8%EC%84%9C-%EA%B4%80%EB%A6%AC.md) 탭의 분류 선택지, 「누락된 필수 분류」·「오래된 문서」 카드와 상태 표시 |
| 급여 정책 | [프로젝트 급여 관리](../05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/codex-experiences--02-%EC%9D%B8%EB%A0%A5-%EA%B4%80%EB%A6%AC.md#523-급여-관리), 비용 탭, 대시보드 총 인건비·비용 소진 위젯 |

> 가동률 1.0 = 100%(기준 가동)입니다.

## 문서 설정

화면 아래 **문서** 카드에서 [문서 관리](../05-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EC%83%81%EC%84%B8/codex-experiences--06-%EB%AC%B8%EC%84%9C-%EA%B4%80%EB%A6%AC.md) 탭의 분류와 오래된 문서 기준을 정합니다. 「일반 설정」 쓰기 권한이 없으면 읽기 전용으로 표시됩니다.

- **분류 추가·삭제·필수 지정**: 필수로 지정한 분류의 문서가 프로젝트에 하나도 없으면 문서 관리 탭의 「누락된 필수 분류」 카드에 그 분류 이름이 표시됩니다.
- 분류를 삭제해도 이미 그 분류로 연결된 문서의 분류 값은 남습니다.
- **오래된 문서 기준**: Confluence 최종 수정일로부터 이 일수가 지나면 「오래됨」입니다.

## 급여 정책을 바꿀 때 일어나는 일

변경 전 확인 창에서 영향 범위를 안내합니다.

| 방향 | 즉시 일어나는 일 |
|---|---|
| → **등급 기반** | 개인 연봉이 화면·응답에서 **즉시 숨겨지고**, 인건비가 등급 대표값 기준으로 재계산됩니다. **저장된 값은 삭제되지 않으며** 언제든 되돌릴 수 있습니다 |
| → **인원별** | 개인 연봉이 다시 표시되고 인건비가 개인 연봉·투입 급여 기준으로 돌아갑니다. 등급 기반으로 운영하는 동안 등록된 인원은 연봉이 비어 있을 수 있습니다 |

**반영 시점**

- 프로젝트 비용 분석: 최대 **10분**
- 전사 대시보드: **다음 집계** 후. 그 전까지 비용 서브탭은 "급여 정책이 변경되어 이전 집계 결과의 인건비는 표시하지 않습니다"로 가려집니다

**주의**

- **급여 밴드가 없는 등급**의 인원은 인건비가 0으로 계산됩니다. 전환 전 "등급 N개에 급여 밴드가 없습니다" 경고가 표시되며, [7.5 등급 관리](codex-experiences--05-%EB%93%B1%EA%B8%89-%EA%B4%80%EB%A6%AC.md)에서 채울 수 있습니다.
- 프로젝트에 직접 입력한 **프로젝트 비용(예산)** 값은 이 전환으로 바뀌지 않습니다.
