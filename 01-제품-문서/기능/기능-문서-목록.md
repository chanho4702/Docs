# 기능 문서 목록

최근 기능의 전체 흐름은 [최근 작업 설명](../%EA%B0%9C%EC%9A%94/%EC%B5%9C%EA%B7%BC-%EC%9E%91%EC%97%85%EC%9D%84-%EC%89%BD%EA%B2%8C-%EC%9D%B4%ED%95%B4%ED%95%98%EA%B8%B0.md), 설계와 코드 연결은 [설계·구현 지도](../%EA%B0%9C%EC%9A%94/%EC%84%A4%EA%B3%84%EC%99%80-%EA%B5%AC%ED%98%84%EC%9D%98-%EC%97%B0%EA%B2%B0-%EC%A7%80%EB%8F%84.md), APM의 미완료 과제는 [부족점 리포트](../%EA%B0%9C%EC%9A%94/%ED%98%84%EC%9E%AC-APM-%EA%B5%AC%ED%98%84%EC%9D%98-%EB%B6%80%EC%A1%B1%EC%A0%90-%EB%B6%84%EC%84%9D-%EB%A6%AC%ED%8F%AC%ED%8A%B8.md)를 먼저 읽습니다(2026-10-05 소스 기준).

영역 단위로 현재 동작과 문제점을 보려면 [기능별 상세 가이드](../%EA%B0%80%EC%9D%B4%EB%93%9C/%EA%B8%B0%EB%8A%A5/MovesEye-%EA%B8%B0%EB%8A%A5%EB%B3%84-%EC%83%81%EC%84%B8-%EA%B0%80%EC%9D%B4%EB%93%9C.md)(2026-10-06 소스 기준, 13개 영역)를 읽습니다. 이 디렉터리는 이슈 단위 기능 문서를, 그쪽은 영역 전체의 동작 원리와 보완점을 다룹니다.

완료된 기능의 “왜·경계·운영·검증”을 한곳에서 찾기 위한 디렉터리다. Controller와 component를 나열하는 문서가 아니라, 다음 질문에 답하는 문서만 둔다.

- 사용자가 달성하는 목표는 무엇인가?
- 원천 데이터와 편집 소유자는 누구인가?
- BE↔FE 요청·응답과 상태 전이는 무엇인가?
- 권한·실패·빈 데이터·동시성은 어떻게 처리하는가?
- 어떤 runtime evidence로 동작을 확인했는가?

새 문서는 [기능 문서 템플릿](../%ED%85%9C%ED%94%8C%EB%A6%BF/%EA%B8%B0%EB%8A%A5-%EB%AC%B8%EC%84%9C-%ED%85%9C%ED%94%8C%EB%A6%BF.md)을 복사한다.

현재 stable 영역으로 승격 완료된 기능 문서는 **0건**이다. 아래 `_workspace` 원천은 설계·계약·QA 증거이며 current 기능 문서를 대신하지 않는다.
