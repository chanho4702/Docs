# 아이템 관리

> **사이드바** Zabbix 관리 > 아이템 관리
> **경로** `/zabbix-management/item-lens`

> ⚠️ **여기서 한 변경은 실제 Zabbix에 반영된다.**

## 무엇을 하는 화면인가

수집 항목(아이템)을 **전체 범위에서 탐색하고 관리**하는 화면이다. 렌즈(Lens)라고 부르는 이유는 "이 정의가 어디서 와서 어디까지 퍼졌는지"를 보는 도구이기 때문이다.

호스트 관리의 아이템 탭이 "이 호스트의 아이템"을 본다면, 이 화면은 **호스트·템플릿을 가로질러** 아이템을 찾는다.

## 화면 구성

### 필터

| 필터 | 값 |
|---|---|
| 호스트 그룹 / 호스트 / 템플릿 | 범위 지정 |
| 유형 | 아이템 타입 |
| 상태 | 활성 / 비활성 |
| **원천** | 일반 / **디스커버리 생성** |
| 검색 | 아이템 이름 또는 키 |

### 보기 전환

| 보기 | 내용 |
|---|---|
| **정의** (기본) | 정의 단위로 본다. 디스커버리가 자동 생성한 것은 숨긴다 |
| **전체** | 자동 생성분까지 모두 본다 |

기본이 '정의'인 이유는 디스커버리 자동 생성 아이템이 수천 건씩 쌓여 **노이즈가 심하기 때문**이다.

### 동작

- 아이템 생성 (대상 선택 후)
- 수정 / 삭제
- **상태 전환** (활성 ↔ 비활성) — 스위치로 즉시

## 사용 흐름

1. 호스트 그룹·호스트·템플릿으로 범위를 좁힌다.
2. 이름이나 키로 검색한다.
3. **정의처를 확인한다** — 템플릿에서 왔는지, 호스트에 직접 만든 것인지.
4. 필요한 작업(상태 전환·수정·삭제)을 한다.

## 주의할 점

### 상속된 아이템

🔴 템플릿에서 상속된 아이템은 이렇게 안내된다.

> "템플릿에서 상속된 아이템입니다. 이름/키 수정과 삭제는 원본 템플릿에서 하세요. 상태(활성/비활성) 변경은 가능합니다."

**상태만 개별 호스트에서 끌 수 있고, 정의 자체는 템플릿에서 고쳐야 한다.** 템플릿에서 고치면 연결된 호스트 전부가 바뀐다는 점을 잊지 않는다.

### 탐색 상한

전체 조회는 무겁다. 상한을 넘으면 이렇게 안내된다.

> "전체 N건 중 상위 M건만 탐색할 수 있습니다 — 필터를 좁혀 주세요."

상한을 벗어난 페이지로 가면 "첫 페이지로" 안내가 뜬다. **필터를 좁히는 것이 정답**이며, 상한 자체는 서버 설정(`LENS_CAP`)으로 조정할 수 있다.

전체 탐색은 **몇 초가 걸릴 수 있다**는 안내도 나온다. 정상이다.

### 아이템 생성

새 아이템을 만들려면 **대상(호스트 또는 템플릿)을 먼저 선택**해야 한다. 아이템은 소속 없이 존재할 수 없다.

### 비활성화의 의미

아이템을 비활성화하면 수집이 멈춘다. 그 아이템을 쓰는 트리거와 차트도 값을 잃는다. 화면에서 "데이터가 안 나온다"는 문의의 원인이 여기인 경우가 있다.
