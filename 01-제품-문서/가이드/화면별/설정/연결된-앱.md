# 연결된 앱

> **메뉴** 헤더 ⚙ 설정 > 연결된 앱
> **경로** `/setting/connected-apps`

## 무엇을 하는 화면인가

Claude·Cursor·VS Code 같은 외부 AI 앱을 MCP로 내 계정에 연결할 때 쓰는 화면이다. 커넥터 주소를 복사하고, 내 계정에 연결된 앱을 확인하고, 연결을 끊는다. 관리자 전용이 아니며 사용자마다 자기 연결만 보인다.

연결 절차 전체는 [MCP 연결 가이드](../../MCP-%EC%97%B0%EA%B2%B0-%EA%B0%80%EC%9D%B4%EB%93%9C.md)를 본다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| 커넥터 주소 | 외부 AI 앱에 넣을 주소(`…/mcp`)와 복사 버튼 |
| 연결 목록 | 앱 이름, 권한(조회만·조회+변경), 연결일, 마지막 사용, 만료 |
| 연결 끊기 | 행마다 있는 버튼. 확인 후 그 앱의 연결을 끊는다 |

## 사용 흐름

1. 커넥터 주소를 복사한다.
2. 외부 AI 앱에 주소를 넣고 연결을 시작한다([MCP 연결 가이드 §3](../../MCP-%EC%97%B0%EA%B2%B0-%EA%B0%80%EC%9D%B4%EB%93%9C.md)).
3. 브라우저에서 MovesEye 동의 화면이 열리면 요청 내용을 확인하고 허용한다.
4. 이 화면으로 돌아와 목록에 앱이 나타났는지 확인한다.

## 주의할 점

- **커넥터 주소 영역이 보이지 않으면** 설치본에서 MCP 연동이 꺼져 있는 것이다. 관리자에게 문의한다.
- **내 MCP 권한이 "사용 안 함"이면** 동의 단계에서 연결이 막힌다. 권한은 관리자가 사용자 관리에서 정한다.
- **연결을 끊어도** 앱이 이미 받은 접속 권한은 최대 1시간(기본값) 더 동작할 수 있다.
- **연결은 연결일부터 30일(기본값)** 이 지나면 만료되어 목록에서 사라진다. 앱에서 다시 연결한다.
- **비밀번호를 바꿔도 연결은 끊기지 않는다.** 비밀번호 유출이 의심되면 이 화면에서 연결도 끊는다.
- 연결된 앱이 가져가는 데이터는 그 앱의 AI 서비스로 전달된다.
